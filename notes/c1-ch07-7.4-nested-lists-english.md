## 6. Nested lists and tables

A nested list stores lists inside a list. Each inner list can represent a row.

```python
sales_table = [
    [12000, 9500, 8800],
    [13200, 7500, 11000],
]
print(sales_table)
print(sales_table[0])
```

**Output**

```text
[[12000, 9500, 8800], [13200, 7500, 11000]]
[12000, 9500, 8800]
```

- The outer list holds the table.
- `sales_table[0]` reads the first row.
- Each row stores daily sales.

## 7. Row and cell access

Two indexes read one cell. The first index is the row. The second is the column.

```python
sales_table = [
    [12000, 9500, 8800],
    [13200, 7500, 11000],
]
print(sales_table[1][2])
print(sales_table[0][1])
```

**Output**

```text
11000
9500
```

- `[1]` selects the second row.
- `[2]` selects its third column.
- Therefore `[1][2]` is the second row’s third cell.

## 8. Row totals

Calculate each row total separately.

```python
sales_table = [
    [12000, 9500, 8800],
    [13200, 7500, 11000],
]
for row in sales_table:
    print(sum(row))
```

**Output**

```text
30300
31700
```

- The outer loop takes one row.
- `sum(row)` adds that row’s cells.
- Each customer or branch can have its own total.

## 9. Nested loops and grand totals

Use nested loops to process every row and every cell.

```python
sales_table = [
    [12000, 9500, 8800],
    [13200, 7500, 11000],
]
grand_total = 0

for row in sales_table:
    for sale in row:
        grand_total += sale

print(grand_total)
```

**Output**

```text
62000
```

- `grand_total` starts outside the table loop.
- The outer loop changes the row.
- The inner loop adds each sale in that row.

## 10. A customer table

A row can hold an opening balance and a payment. Consistent positions make calculations easier.

```python
customer_balances = [
    [50000, 12000],
    [32000, 8000],
    [71000, 15000],
]

for balance_row in customer_balances:
    print(f"Opening: {balance_row[0]}, Payment: {balance_row[1]}")
```

**Output**

```text
Opening: 50000, Payment: 12000
Opening: 32000, Payment: 8000
Opening: 71000, Payment: 15000
```

- Each row stores an opening balance and payment.
- `[0]` means opening. `[1]` means payment.
- The same positions have the same meaning in each row.

## 11. Column totals

Add the same column across rows to find a column total.

```python
weekly_sales = [
    [12000, 9500, 8800],
    [13200, 7500, 11000],
]

day_one_total = weekly_sales[0][0] + weekly_sales[1][0]
day_two_total = weekly_sales[0][1] + weekly_sales[1][1]
print(day_one_total)
print(day_two_total)
```

**Output**

```text
25200
17000
```

- The first index selects a row.
- The second index selects the same column.
- Adding matching columns creates a column report.

## 12. Troubleshooting

### Problem 1
- What happens: a number appears instead of a row.
- Likely cause: `table[0][1]` requested a cell.
- Fix: use `table[0]` for the whole row.
- Prevention: separate row and cell indexes.

### Problem 2
- What happens: `IndexError: list index out of range` appears.
- Likely cause: a row or column index is outside its valid range.
- Fix: check the row and cell lengths.
- Prevention: write the table shape first.

### Problem 3
- What happens: the grand total equals only the last row.
- Likely cause: `grand_total = 0` was reset inside the outer loop.
- Fix: start it before the outer loop.
- Prevention: separate row-total and grand-total scope.

### Problem 4
- What happens: the column total is wrong.
- Likely cause: row and column positions were mixed.
- Fix: use `[row][column]` consistently.
- Prevention: label table rows and columns.

## 13. Common Misconceptions

1. **Wrong:** the first nested index is the column → **Truth:** it is the row.
2. **Wrong:** `table[0]` is the first cell → **Truth:** it is the first row.
3. **Wrong:** a table total always needs two loops → **Truth:** row totals can use `sum`.
4. **Wrong:** every row can safely use every column → **Truth:** a missing cell can cause an error.
5. **Wrong:** row and grand totals use one variable → **Truth:** their scope and jobs differ.

## 15. Quiz

1. What is a nested list?  
   a) a list inside a list  b) only a string  c) an empty variable  
   **Answer: a**, because an inner list can represent a row.
2. In `table[1][2]`, what is the first index?  
   a) row  b) column  c) total  
   **Answer: a**, because the row is selected first.
3. How do you read the whole first row?  
   a) `table[0]`  b) `table[0][0]`  c) `table[1]`  
   **Answer: a**, because there is no second index.
4. What is a simple row-total tool?  
   a) `sum(row)`  b) `len(row)`  c) `max(table)`  
   **Answer: a**, because it adds the row values.
5. Where should a grand total start?  
   a) before the outer loop  b) after the inner loop  c) at every cell  
   **Answer: a**, because it must keep every row.
6. What does the outer loop take?  
   a) one row  b) one cell only  c) one column only  
   **Answer: a**, because the inner loop processes that row.
7. How is a column total made?  
   a) add values from one column  b) print one row  c) delete the list  
   **Answer: a**, because the column position stays the same.

## 16. Key Idea

A nested list stores table data. The first index is the row. The second is the cell or column. Nested loops process both levels.

**Rhyme:**  
Rows hold their cells, and tables stay clear,  
Two loops count totals, row by row here.
