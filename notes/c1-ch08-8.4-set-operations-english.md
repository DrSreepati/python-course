## 6. Union: all unique items

Union combines two sets. It keeps every value once. A Dhaka wholesaler can combine invoices from two days this way.

```python
monday = {"INV-001", "INV-002", "INV-003"}
tuesday = {"INV-003", "INV-004"}

all_invoices = monday | tuesday
print(sorted(all_invoices))
```

**Output**

```text
['INV-001', 'INV-002', 'INV-003', 'INV-004']
```

`|` takes all values. `INV-003` appears once, although both sets contain it.

## 7. Intersection: common items

Intersection keeps values found in both sets. It helps compare a sales report with a payment report.

```python
sales_report = {"INV-001", "INV-002", "INV-003"}
payment_report = {"INV-002", "INV-003", "INV-004"}

matched = sales_report & payment_report
print(sorted(matched))
```

**Output**

```text
['INV-002', 'INV-003']
```

`&` means common. `INV-001` is not in the payment report.

## 8. Difference: values missing from the other set

Direction matters. `sales - payment` means values in sales but not in payment.

```python
sales_report = {"INV-001", "INV-002", "INV-003"}
payment_report = {"INV-002", "INV-003", "INV-004"}

unpaid_candidates = sales_report - payment_report
print(sorted(unpaid_candidates))
```

**Output**

```text
['INV-001']
```

This is an unpaid candidate. The reverse, `payment_report - sales_report`, finds extra payment records.

## 9. Symmetric difference: one-sided values

Symmetric difference removes common values. It keeps values found on only one side.

```python
sales_report = {"INV-001", "INV-002", "INV-003"}
payment_report = {"INV-002", "INV-003", "INV-004"}

report_difference = sales_report ^ payment_report
print(sorted(report_difference))
```

**Output**

```text
['INV-001', 'INV-004']
```

`INV-001` is only in sales. `INV-004` is only in payments. Both are exceptions.

## 10. Methods

Operators are short. Methods can be clearer.

```python
branch_a = {"C-101", "C-102"}
branch_b = {"C-102", "C-103"}

print(sorted(branch_a.union(branch_b)))
print(sorted(branch_a.intersection(branch_b)))
print(sorted(branch_a.difference(branch_b)))
print(sorted(branch_a.symmetric_difference(branch_b)))
```

**Output**

```text
['C-101', 'C-102', 'C-103']
['C-102']
['C-101']
['C-101', 'C-103']
```

The method names explain the operation. These methods return a new set.

## 11. Business comparison report

The boss wants matches, missing payments, extra payments, and all exceptions.

```python
sales = {"INV-2024-007", "INV-2024-008", "INV-2024-009"}
payments = {"INV-2024-008", "INV-2024-009", "INV-2024-010"}

print("Matched:", sorted(sales & payments))
print("Needs payment check:", sorted(sales - payments))
print("Payment register extra:", sorted(payments - sales))
print("All exceptions:", sorted(sales ^ payments))
```

**Output**

```text
Matched: ['INV-2024-008', 'INV-2024-009']
Needs payment check: ['INV-2024-007']
Payment register extra: ['INV-2024-010']
All exceptions: ['INV-2024-007', 'INV-2024-010']
```

The first line shows matches. The second shows sales without payment. The third shows extra payments. The last combines both exceptions.

## 12. Synthesis table

| Tool | Meaning | Business job |
|---|---|---|
| `a \| b` | all unique values | all invoices from two days |
| `a & b` | common values | sales-payment match |
| `a - b` | only in a | unpaid candidates |
| `a ^ b` | only on one side | reconciliation exceptions |
| `sorted(set)` | readable order | report output |

## 13. Troubleshooting

### Problem 1: The output order changes
- **Plain meaning:** sets do not promise positions or order.
- **Likely cause:** the set was printed directly.
- **Step-by-step fix:** create the set, call `sorted(result)`, then print it.
- **Prevention:** sort set results before showing reports.

### Problem 2: All invoices appeared instead of matched invoices
- **Plain meaning:** union returns all unique values.
- **Likely cause:** `|` was used instead of `&`.
- **Step-by-step fix:** use `sales & payments` for common values.
- **Prevention:** remember matched means intersection.

### Problem 3: Difference is backwards
- **Plain meaning:** the first set is the starting side.
- **Likely cause:** `payments - sales` was used to find missing sales payments.
- **Step-by-step fix:** use `sales - payments`.
- **Prevention:** read it as “a minus b”.

### Problem 4: The source set seems to have changed
- **Plain meaning:** operations normally return a new set.
- **Likely cause:** the result was not stored separately.
- **Step-by-step fix:** write `exceptions = sales ^ payments`.
- **Prevention:** keep audit data and calculated reports in separate variables.

## 14. Common Misconceptions

1. **Wrong:** union gives only common values → **Truth:** union gives all unique values.
2. **Wrong:** intersection gives every value from one set → **Truth:** it gives common values.
3. **Wrong:** `a - b` equals `b - a` → **Truth:** difference is directional.
4. **Wrong:** symmetric difference keeps common values → **Truth:** it removes common values.
5. **Wrong:** set items can be taken by index → **Truth:** sets are unordered.

## 16. Quiz

1. Which operator combines all unique invoices?  
   a) `|`  b) `&`  c) `^`  
   **Answer: a**, union keeps all unique values.
2. Which operation finds common customer IDs?  
   a) `-`  b) `&`  c) `|`  
   **Answer: b**, intersection finds common values.
3. What does `a - b` return?  
   a) values only in a  b) all values  c) common values  
   **Answer: a**, values in b are removed.
4. What does symmetric difference remove?  
   a) unique values  b) common values  c) the first set  
   **Answer: b**, the common part is removed.
5. What gives readable output?  
   a) `index()`  b) `sorted()`  c) `append()`  
   **Answer: b**, it displays sorted values.
6. What can `payments - sales` show?  
   a) extra payment records  b) matched records  c) all records  
   **Answer: a**, it finds payment-only values.
7. Can a set item be selected by index?  
   a) always  b) only when empty  c) no  
   **Answer: c**, sets are unordered.

## 17. Key Idea

Set operations make business comparison simple. `|` means all unique values, `&` common values, `-` one-sided values, and `^` exceptions on either side.

**Rhymes:**

Match with `&`, all with `|`,  
Subtract with `-`, exceptions `^` fulfil.

When two registers meet for review,  
Sets show what matches and what is new.
