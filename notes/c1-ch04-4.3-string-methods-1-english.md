## 1. What a string method is

A string method is a built-in operation for working with a string. Write a dot after the string variable. Use parentheses to call the method.

```python
customer = "Rahim Traders"

print(customer.upper())
print(customer.lower())
```

**Output**

```text
RAHIM TRADERS
rahim traders
```

`customer.upper()` creates uppercase text. `customer.lower()` creates lowercase text. The original `customer` remains unchanged.

Important lines:

- `customer = "Rahim Traders"` stores the original business text.
- `customer.upper()` creates an uppercase result.
- `customer.lower()` creates a lowercase result.

## 2. Lowercase with `lower()`

`lower()` changes English letters to lowercase. It is useful before a case-insensitive comparison or search.

```python
entered_name = "RAHIM TRADERS"
standard_name = entered_name.lower()

print(standard_name)
print(standard_name == "rahim traders")
```

**Output**

```text
rahim traders
True
```

The method creates a standard form, even when the user types uppercase text. The lowercase result is then compared with the reference.

`lower()` does not remove numbers, hyphens or spaces. It mainly changes letter case.

## 3. Uppercase with `upper()`

`upper()` changes English letters to uppercase. It helps with report headings, code labels and standard displays.

```python
customer = "Karim Store"
report_name = customer.upper()

print(report_name)
print(customer)
```

**Output**

```text
KARIM STORE
Karim Store
```

The uppercase result is stored in `report_name`. The original `customer` is unchanged. Store the result when you need it later.

## 4. Outer spaces with `strip()`

`strip()` removes whitespace at the beginning and end of a string. Whitespace includes spaces, tabs and line breaks.

```python
raw_name = "  Rahim Traders  "
clean_name = raw_name.strip()

print(clean_name)
print(len(raw_name))
print(len(clean_name))
```

**Output**

```text
Rahim Traders
17
13
```

The original text has two spaces on each side. `strip()` removes them. It does not remove the space between `Rahim` and `Traders`.

Related forms:

- `lstrip()` removes whitespace on the left.
- `rstrip()` removes whitespace on the right.
- Today's main method is `strip()`.

## 5. Changing text with `replace()`

`replace(old, new)` finds the old part and puts the new part in its place. It returns a new string.

```python
invoice_no = "INV/2024/007"
standard_invoice = invoice_no.replace("/", "-")

print(standard_invoice)
```

**Output**

```text
INV-2024-007
```

`replace("/", "-")` changes every slash to a hyphen. The invoice reference now has a standard format.

You can limit the number of replacements with a third argument:

```python
note = "paid paid pending"

print(note.replace("paid", "checked", 1))
print(note.replace("paid", "checked"))
```

**Output**

```text
checked paid pending
checked checked pending
```

The third argument, `1`, changes only the first matching part. Without it, every matching part changes.

## 6. Counting occurrences with `count()`

`count()` counts how often a character or piece of text appears. It returns an integer. It is case-sensitive.

```python
invoice_no = "INV-2024-007"

print(invoice_no.count("-"))
print(invoice_no.count("0"))
print(invoice_no.count("INV"))
```

**Output**

```text
2
3
1
```

The invoice has two hyphens, three zeroes and one `INV`. When choosing a text pattern, remember that `count()` does not count overlapping patterns separately.

Case-sensitive example:

```python
customer = "Rahim rahim"

print(customer.count("rahim"))
print(customer.lower().count("rahim"))
```

**Output**

```text
1
2
```

The first count finds only lowercase `rahim`. Lowercasing first makes both forms match.

## 7. Using methods together

Several methods can clean one raw business field. The inner method runs first, followed by the outer method.

```python
raw_customer = "  RAHIM traders  "

clean_customer = raw_customer.strip().lower()
display_customer = clean_customer.upper()

print(clean_customer)
print(display_customer)
```

**Output**

```text
rahim traders
RAHIM TRADERS
```

First, the outer spaces are removed. Then the letters become lowercase. The cleaned result is then made uppercase for display.

Many methods can fit on one line. As a beginner, separate stages make errors easier to find.

## 8. Cleaning a business customer name

Customer data may contain mixed case and extra spaces. `strip()` and `lower()` help create a comparison form.

```python
customer_from_form = "  rahim TRADERS "
customer_key = customer_from_form.strip().lower()
known_key = "rahim traders"

print(customer_key)
print(customer_key == known_key)
```

**Output**

```text
rahim traders
True
```

`customer_key` is a standard comparison key, not necessarily a display name. Keep the original value if the report needs its original spelling.

## 9. Cleaning an invoice reference

A sales assistant may enter an invoice with slashes, spaces or lowercase letters. A fixed format can be standardised with `strip()`, `upper()` and `replace()`.

```python
raw_invoice = " inv/2024/007 "

clean_invoice = raw_invoice.strip().upper().replace("/", "-")

print(clean_invoice)
print(clean_invoice.count("-"))
```

**Output**

```text
INV-2024-007
2
```

The order matters. Outer spaces are removed first, then letters become uppercase, and finally slashes become hyphens. The result has two separators.

## 10. Common method mistakes

The method name and parentheses are both needed. Writing only the method name does not call it. Also, the original variable does not change unless you store or assign the result.

```python
name = "  Karim Store  "

print(name.strip)
print(name.strip())

clean_name = name.strip()
print(clean_name)
```

**Output**

```text
<built-in method strip of str object at ...>
Karim Store
Karim Store
```

The first output can contain a memory address that varies by Python version and run. Do not memorise it as an exact output. `name.strip()` calls the method. `clean_name = name.strip()` stores the result.

## Troubleshooting

### Problem 1: The middle space remains after `strip()`

- What is happening: the space between `Rahim` and `Traders` remains.
- Most likely cause: `strip()` removes only outer whitespace.
- Step-by-step fix: use `strip()` for the two edges. If removing every space, first understand the business effect of `replace(" ", "")`.
- Prevention: separate outer whitespace from internal separators.

### Problem 2: `upper` or `lower` does not work

- What is happening: a method reference appears instead of changed text.
- Most likely cause: the parentheses `()` are missing.
- Step-by-step fix: write `text.upper()` or `text.lower()`, then print the result.
- Prevention: remember the parentheses when calling a method.

### Problem 3: The original variable did not change after `replace()`

- What is happening: the new output appears once, but the old variable still has old text.
- Most likely cause: the result was not stored, or the original variable was not reassigned.
- Step-by-step fix: write `clean_text = text.replace(...)`, or use `text = text.replace(...)` when appropriate.
- Prevention: decide whether the original or a new value should be kept.

### Problem 4: `count()` returns a smaller number

- What is happening: the count does not match the learner's expectation.
- Most likely cause: `count()` is case-sensitive.
- Step-by-step fix: standardise the case with `lower()` or `upper()`, then count.
- Prevention: set the text case before searching or counting.

## Common Misconceptions

1. **Wrong:** `strip()` removes every space in a string -> **Truth:** it removes outer whitespace only.
2. **Wrong:** writing `upper` runs the method -> **Truth:** write `upper()` to call it.
3. **Wrong:** `replace()` permanently changes the original string -> **Truth:** it returns a new string.
4. **Wrong:** `count("a")` also counts uppercase `A` -> **Truth:** `count()` is case-sensitive.
5. **Wrong:** `lower()` removes hyphens and numbers -> **Truth:** it mainly changes alphabetic case.

## Key Idea

`lower()` and `upper()` standardise case. `strip()` removes outer whitespace. `replace()` changes text. `count()` counts occurrences. Method order and result storage both matter when cleaning business data.

**Rhyme 1:** Strip the edges, lower and upper set the tone,  
**Rhyme 2:** Replace changes text, count makes numbers known.
