## 1. What type means

Type is a class of value. Money, a customer name, and a credit decision are not the same kind of data.

```python
daily_sales = 12000
customer = "Rahim Traders"
credit_approved = True

print(daily_sales)
print(customer)
print(credit_approved)
```

**Output**

```text
12000
Rahim Traders
True
```

`12000` is a whole number. `"Rahim Traders"` is text. `True` is Boolean. The variable name is separate from the value’s type.

## 2. `int`, whole numbers

`int` means integer, a whole number without a decimal part. Use it for quantities, invoice counts, or whole amounts.

```python
quantity = 4
invoice_count = 12
print(quantity)
print(invoice_count)
```

**Output**

```text
4
12
```

Neither value has a decimal part. Both are examples of `int`.

## 3. `float`, decimal numbers

`float` is a decimal number. A unit price with smaller currency units or a VAT rate may need a decimal.

```python
unit_price = 250.50
vat_rate = 7.5
print(unit_price)
print(vat_rate)
```

**Output**

```text
250.5
7.5
```

Python may remove an unnecessary final zero when it prints `250.50`. The value is still a `float`.

## 4. `str`, text

`str` means string, a sequence of text characters. Customer names, invoice codes, and product labels are usually strings.

```python
customer = "Rahim Traders"
invoice_number = "INV-2024-007"
print(customer)
print(invoice_number)
```

**Output**

```text
Rahim Traders
INV-2024-007
```

Quotation marks show the text boundary. An invoice number contains digits, but it is a code, so a string is suitable.

## 5. `bool`, true or false

`bool` means Boolean. It has only two values: `True` and `False`. Write them without quotation marks.

```python
stock_available = True
payment_received = False
print(stock_available)
print(payment_received)
```

**Output**

```text
True
False
```

`True` means a condition is true. `False` means it is not true. The capital letters matter.

## 6. Quotation marks change the type

The same digits become text when quotation marks surround them. Use numbers for calculations and text for codes.

```python
balance = 50000
balance_label = "50000"

print(balance)
print(balance_label)
```

**Output**

```text
50000
50000
```

The first value is an `int`. The second is a `str`. The output looks the same, so output alone does not always reveal the type.

## 7. Several types in one business record

One invoice record can contain a customer name, quantity, unit price, and payment status.

```python
customer = "Karim Store"
quantity = 6
unit_price = 120.0
paid = False

print(customer, quantity, unit_price, paid)
```

**Output**

```text
Karim Store 6 120.0 False
```

`customer` is `str`, `quantity` is `int`, `unit_price` is `float`, and `paid` is `bool`. Mixed types are normal in a business report.

## 8. A rule for choosing a type

Ask: can I count it, measure it, read it as text, or answer yes or no? A count can be `int`, a decimal measure can be `float`, a name or code can be `str`, and a decision can be `bool`.

```python
customer_code = "C-1023"
items_in_box = 24
discount_rate = 5.0
is_overdue = True

print(customer_code)
print(items_in_box)
print(discount_rate)
print(is_overdue)
```

**Output**

```text
C-1023
24
5.0
True
```

Although a customer code contains digits, it is an identifier, so it is a string. This matters for later validation and reporting.

## 9. What happens when the type is wrong

A value can look like a number without being a number. If `"120"` is stored as text, it will need conversion before arithmetic. We will study this fully in 2.5.

```python
quantity = 4
quantity_text = "4"

print(quantity + 2)
print(quantity_text)
```

**Output**

```text
6
4
```

The first line adds two integers. The second line only prints text. Do not assume that text containing digits is numeric data.

## 10. Reading types in code

When reading code, look at the value: quotation marks usually show `str`, a decimal shows `float`, `True` or `False` shows `bool`, and an ordinary whole number shows `int`.

```python
sales = 51000
margin_rate = 12.5
customer_name = "Jahid Enterprise"
report_ready = True

print(sales)
print(margin_rate)
print(customer_name)
print(report_ready)
```

**Output**

```text
51000
12.5
Jahid Enterprise
True
```

Each value has a different role and type. Keep this difference clear in business calculations.

## Troubleshooting

# Problem 1: `"50000"` looks like a number

- What is happening: the output looks numeric, but the value is text.
- Most likely cause: quotation marks were used.
- Step-by-step fix: remove the quotation marks, write `balance = 50000`, and run again.
- Prevent it next time: use quotes for code or names, not for numbers used in calculations.

# Problem 2: `True` or `False` does not work

- What is happening: Python does not recognise the Boolean value.
- Most likely cause: `true`, `false`, or `"True"` was written.
- Step-by-step fix: write `True` or `False` with capitals and remove quotation marks.
- Prevent it next time: remember the two exact Boolean spellings.

# Problem 3: The final decimal zero is missing

- What is happening: `250.50` prints as `250.5`.
- Most likely cause: Python does not print an unnecessary final zero.
- Step-by-step fix: keep the value as a float; treat display formatting as a separate task.
- Prevent it next time: do not infer type from the printed appearance alone.

# Problem 4: A code is treated as a calculation number

- What is happening: `C-1023` or an invoice code is used as arithmetic data.
- Most likely cause: its digits were mistaken for a numeric value.
- Step-by-step fix: put the code in quotation marks and use it as a `str`.
- Prevent it next time: an identifier is labelled data, not a count.

## Common Misconceptions

1. Wrong claim: digits inside quotation marks are always `int`. -> Truth: they are `str`.
2. Wrong claim: `250.50` and `250` have the same type. -> Truth: the first is `float`, the second is `int`.
3. Wrong claim: `True` is only an ordinary English word. -> Truth: it is a Boolean value.
4. Wrong claim: an invoice code containing digits is an `int`. -> Truth: a code is usually a `str`.
5. Wrong claim: every value in a report must have one type. -> Truth: business records commonly mix types.

## Quiz

1. What type is `12000`?  
   a) `str`  
   b) `int`  
   c) `bool`  
   **Answer: b.** It is a whole number without decimals.

2. Which is a `float`?  
   a) `7.5`  
   b) `"7.5"`  
   c) `True`  
   **Answer: a.** A decimal without quotes is a float.

3. Why is `"INV-2024-007"` a `str`?  
   a) It can be counted  
   b) It is Boolean  
   c) It is text or a code  
   **Answer: c.** An invoice code is stored as text.

4. Which is a valid Boolean value?  
   a) `"False"`  
   b) `False`  
   c) `false`  
   **Answer: b.** Python uses `False` with a capital F.

5. What does `paid = True` mean?  
   a) The payment condition is true  
   b) The payment is text  
   c) It is the payment amount  
   **Answer: a.** True is a Boolean decision.

6. Which is suitable for a customer code?  
   a) `customer_code = C-1023`  
   b) `customer_code = 1023`  
   c) `customer_code = "C-1023"`  
   **Answer: c.** A code with a prefix is a string.

7. Why might `250.50` print as `250.5`?  
   a) The value was deleted  
   b) Python omits an unnecessary final zero  
   c) It became a string  
   **Answer: b.** The numeric value remains the same.

## Key Idea

Core types tell us how a value should be used. `int` is a whole number, `float` is a decimal, `str` is text or a code, and `bool` is a true or false decision.

**Rhyme 1:** Whole numbers use int, decimals use float,  
Names and codes use strings, Boolean finds truth out.

**Rhyme 2:** True or False opens a decision door,  
Choose the right type for a cleaner store.
