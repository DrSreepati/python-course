## 1. Why formulas matter

A formula is a short mathematical description of a business rule. Code makes the rule repeatable across invoices and reports.

```python
quantity = 10
unit_price = 300
sales = quantity * unit_price

print(sales)
```

**Output**

```text
3000
```

Quantity and unit price are inputs. Multiplication creates the sales value.

## 2. The sales formula

Sales, or revenue, is the total value of goods sold. The formula is `Sales = Quantity × Unit Price`.

```python
quantity = 12
unit_price = 250
sales = quantity * unit_price

print(f"Sales: {sales:.2f} taka")
```

**Output**

```text
Sales: 3000.00 taka
```

The code directly follows the formula. `:.2f` only formats the display.

## 3. The cost formula

Cost is the total amount spent to buy or make the goods. Multiply quantity by unit cost.

```python
quantity = 12
unit_cost = 180
cost = quantity * unit_cost

print(f"Cost: {cost:.2f} taka")
```

**Output**

```text
Cost: 2160.00 taka
```

Twelve items at 180 taka each cost 2160 taka.

## 4. The profit formula

Profit is sales minus cost. The formula is `Profit = Sales - Cost`.

```python
sales = 3000
cost = 2160
profit = sales - cost

print(f"Profit: {profit:.2f} taka")
```

**Output**

```text
Profit: 840.00 taka
```

When sales exceed cost, profit is positive. Otherwise, it can be negative.

## 5. Margin percentage

Margin percentage shows what share of sales is profit. The formula is `Margin % = Profit / Sales × 100`.

```python
sales = 3000
profit = 840
margin_percentage = profit / sales * 100

print(f"Margin: {margin_percentage:.2f}%")
```

**Output**

```text
Margin: 28.00%
```

Divide profit by sales, then multiply by 100. Margin is a percentage, not a money amount.

## 6. Splitting a formula into steps

Separate steps make a report easier to check. Each intermediate value gets a clear name.

```python
quantity = 5
unit_price = 450
unit_cost = 320

sales = quantity * unit_price
cost = quantity * unit_cost
profit = sales - cost
margin = profit / sales * 100

print(sales)
print(cost)
print(profit)
print(margin)
```

**Output**

```text
2250
1600
650
28.88888888888889
```

The code calculates sales and cost first. It then calculates profit and margin.

## 7. A revenue and cost report

A summary should show both raw inputs and calculated values. This helps the boss trace each result.

```python
quantity = 5
unit_price = 450
unit_cost = 320
sales = quantity * unit_price
cost = quantity * unit_cost
profit = sales - cost

print(f"Quantity: {quantity}")
print(f"Sales: {sales:.2f}")
print(f"Cost: {cost:.2f}")
print(f"Profit: {profit:.2f}")
```

**Output**

```text
Quantity: 5
Sales: 2250.00
Cost: 1600.00
Profit: 650.00
```

Each line reports one business fact. Formatting makes the report easier to read.

## 8. A zero-sales guard

Sales is the denominator in the margin formula. Zero sales cannot be used for division. Check it first.

```python
sales = 0
profit = 0

if sales == 0:
    print("Margin is not available")
else:
    margin = profit / sales * 100
    print(margin)
```

**Output**

```text
Margin is not available
```

The condition is true, so the code avoids division by zero.

## 9. Checking a formula

Use familiar numbers for a manual check. Ten items at 100 taka must produce sales of 1000.

```python
quantity = 10
unit_price = 100
unit_cost = 70

sales = quantity * unit_price
cost = quantity * unit_cost
profit = sales - cost
margin = profit / sales * 100

print(sales == 1000)
print(cost == 700)
print(profit == 300)
print(margin == 30)
```

**Output**

```text
True
True
True
True
```

The comparisons check expected values. This is a useful small sanity check.

## 10. A business summary

Now combine quantity, price, cost and margin. The same pattern will support VAT and discount formulas.

```python
quantity = 8
unit_price = 500
unit_cost = 350

sales = quantity * unit_price
cost = quantity * unit_cost
profit = sales - cost
margin = profit / sales * 100

print(f"Sales: {sales:.2f}")
print(f"Profit: {profit:.2f}")
print(f"Margin: {margin:.2f}%")
```

**Output**

```text
Sales: 4000.00
Profit: 1200.00
Margin: 30.00%
```

Sales comes first. Cost, profit and margin depend on earlier values.

## Synthesis table

| Business measure | Formula | Code shape |
|---|---|---|
| Sales | quantity × unit price | `quantity * unit_price` |
| Cost | quantity × unit cost | `quantity * unit_cost` |
| Profit | sales - cost | `sales - cost` |
| Margin % | profit / sales × 100 | `profit / sales * 100` |
| Safe margin | do not calculate when sales is zero | `if sales == 0` |

## Troubleshooting

### Problem 1: Profit is negative

- What is happening: the result has a minus sign.
- Most likely cause: cost exceeds sales, or the formula is reversed.
- Fix: print sales and cost. Check `profit = sales - cost`.
- Prevention: estimate the expected profit first.

### Problem 2: Margin is 0.28, not 28

- What is happening: the ratio was calculated, not the percentage.
- Most likely cause: `* 100` was omitted.
- Fix: use `profit / sales * 100` and display `%`.
- Prevention: use separate names for ratio and percentage.

### Problem 3: `ZeroDivisionError` appears

- What is happening: sales is zero.
- Most likely cause: the denominator was not checked.
- Fix: test `sales == 0` before division.
- Prevention: identify every possible zero denominator.

### Problem 4: Sales amount is wrong

- What is happening: quantity and price exist, but the total is wrong.
- Most likely cause: unit cost was used, or values were added.
- Fix: inspect input names and use `quantity * unit_price`.
- Prevention: keep separate names for sales and cost inputs.

## Common Misconceptions

1. **Wrong:** profit and margin are the same → **Truth:** profit is money, margin is a percentage.
2. **Wrong:** margin is `profit / cost * 100` → **Truth:** this course defines margin over sales.
3. **Wrong:** margin can be calculated when sales is zero → **Truth:** division by zero is invalid.
4. **Wrong:** `:.2f` makes a formula financially safe → **Truth:** it only formats display.
5. **Wrong:** one-line formulas are always better → **Truth:** named steps make auditing easier.

**Answer: b.** Profit is sales minus cost.

a. Multiply by 100  
b. Divide by 100  
c. Add sales  

**Answer: a.** Multiplication by 100 gives percent.

a. `8%`

**Answer: b.** `800 / 5000 * 100 = 16`.

a. Divide anyway

**Answer: c.** A zero denominator is invalid.

a. A money amount  
b. A customer code

## Key Idea

Business formulas make sales, cost, profit and margin repeatable. Margin uses sales as its denominator. Guard against zero sales before division.

**Rhyme 1:** Multiply quantity by price, and sales take their form.  
**Rhyme 2:** Divide profit by sales, and margin keeps you informed.
