## 6. প্রথম for loop

`for` একটি sequence-এর প্রতিটি value নিয়ে block চালায়।

```python
for day in range(1, 4):
    print(f"Preparing report for day {day}")
```

**Output**

```text
Preparing report for day 1
Preparing report for day 2
Preparing report for day 3
```

`range(1, 4)` start 1 নেয়, stop 4-এর আগে থামে। তাই day হয় 1, 2, 3।

## 7. range() এবং stop value

`range(start, stop)`-এ stop value অন্তর্ভুক্ত হয় না।

```python
for invoice_number in range(1, 4):
    print(f"Checking invoice {invoice_number}")
```

**Output**

```text
Checking invoice 1
Checking invoice 2
Checking invoice 3
```

তিনটি invoice এসেছে, কারণ 4 হলো boundary, data নয়।

## 8. Step ব্যবহার

তৃতীয় argument step বলে কত করে value বদলাবে।

```python
for month in range(2, 8, 2):
    print(f"Reviewing month {month}")
```

**Output**

```text
Reviewing month 2
Reviewing month 4
Reviewing month 6
```

2 থেকে শুরু করে প্রতি বার 2 যোগ হয়েছে। Stop 8 বাদ গেছে।

## 9. Reverse range

Negative step দিয়ে উল্টো দিকে যাওয়া যায়।

```python
for priority in range(3, 0, -1):
    print(f"Priority level {priority}")
```

**Output**

```text
Priority level 3
Priority level 2
Priority level 1
```

Start 3, stop 0-এর আগে থামা, step -1। তাই 3, 2, 1 এসেছে।

## 10. Running total

`for` loop-এর ভিতরে accumulator রেখে business total করা যায়।

```python
total = 0

for day in range(1, 4):
    sale = day * 1000
    total += sale

print(total)
```

**Output**

```text
6000
```

Sale হয় 1000, 2000, 3000। `total` একে একে যোগ করে 6000 হয়েছে।

## 11. for এবং while বাছাই

Known count থাকলে `for` সহজ। Unknown stopping condition হলে `while` বেশি স্বাভাবিক।

```python
for invoice in range(1, 4):
    print(f"Fixed check {invoice}")

balance = 25000
while balance > 0:
    balance -= 10000
    print(f"Remaining balance: {balance}")
```

**Output**

```text
Fixed check 1
Fixed check 2
Fixed check 3
Remaining balance: 15000
Remaining balance: 5000
Remaining balance: -5000
```

প্রথম loop-এর count জানা ছিল। দ্বিতীয় loop balance শূন্যের দিকে যাচ্ছে, তাই condition state-based।

## 13. Troubleshooting

### সমস্যা 1
- কী হচ্ছে: শেষ day print হচ্ছে না।
- সম্ভাব্য কারণ: stop value বাদ যায়।
- Fix: শেষ day-এর পরের সংখ্যা stop হিসেবে দিন।
- Prevention: `range(1, 4)` হাতে 1, 2, 3 লিখে দেখুন।

### সমস্যা 2
- কী হচ্ছে: loop একবারও চলে না।
- সম্ভাব্য কারণ: start এবং stop-এর direction step-এর সঙ্গে মেলে না।
- Fix: reverse range-এ negative step দিন।
- Prevention: start থেকে stop-এর দিকে arrow আঁকুন।

### সমস্যা 3
- কী হচ্ছে: total বেশি বা কম হচ্ছে।
- সম্ভাব্য কারণ: accumulator loop-এর আগে 0 করা হয়নি।
- Fix: loop-এর আগে `total = 0` লিখুন।
- Prevention: প্রতি iteration-এর যোগফল আলাদা করে লিখুন।

### সমস্যা 4
- কী হচ্ছে: `for`-এ manual counter update করা হয়েছে।
- সম্ভাব্য কারণ: `while`-এর অভ্যাস।
- Fix: `range()`-কে count দিতে দিন।
- Prevention: `for` variable নিজে নিজে পরের value নেয় মনে রাখুন।

## 14. Common Misconceptions

1. **ভুল:** `range(1, 4)`-এ 4 আছে → **সত্য:** stop value বাদ যায়।
2. **ভুল:** `for` variable নিজে লিখে update করতে হয় → **সত্য:** `range()` পরের value দেয়।
3. **ভুল:** step শুধু positive হয় → **সত্য:** negative step-এ reverse range হয়।
4. **ভুল:** `for` সবসময় `while`-এর চেয়ে ভালো → **সত্য:** known count হলে `for` সহজ।
5. **ভুল:** `range()` list-এর মতো সব data আগে তৈরি করে → **সত্য:** এটি iteration-এর জন্য সংখ্যা দেয়।

### Exercise 5, Rafiq bhai bug

```python

    print(f"Day {day}")
day += 1
```

```python
for day in range(1, 4):
    print(f"Day {day}")
```

```text
Day 1
Day 2
Day 3
```

Lesson: `for` loop-এ repetition control করে `range()`, manual counter নয়।

## 17. Key Idea

`for` loop জানা সংখ্যক repetition সহজ করে। `range()`-এ start অন্তর্ভুক্ত, stop বাদ, আর step অগ্রগতির পরিমাণ ঠিক করে।

**ছড়া:**  
Start থেকে যাত্রা, stop-এ গিয়ে থামে,  
Step বলে কত দূর, `for` কাজটি নামে।
