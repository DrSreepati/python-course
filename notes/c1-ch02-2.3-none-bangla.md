## Objective

## 1. `None` কী

`None` হলো Python-এর বিশেষ মান। এটি বোঝায়, এই variable-এ এখন কোনো নির্দিষ্ট মান রাখা নেই।

```python
pending_balance = None
print(pending_balance)
```

**Output**

```text
None
```

`pending_balance` নামটি আছে, কিন্তু তার balance এখনও দেওয়া হয়নি। `print()` সেই বিশেষ মানটি দেখায়।

## 2. `None` কেন শূন্য নয়

`0` একটি জানা সংখ্যা। `None` জানায় যে সংখ্যাটি এখনও নেই বা জানা যায়নি।

```python
known_balance = 0
unknown_balance = None

print(known_balance)
print(unknown_balance)
```

**Output**

```text
0
None
```

`known_balance` সত্যিই শূন্য। `unknown_balance`-এর প্রকৃত অঙ্ক এখনও জানা নেই।

## 3. অজানা customer balance

Karim Store-এর balance যদি হিসাবের খাতায় এখনও যাচাই না করা হয়, তাহলে `0` লেখা ভুল হতে পারে। `None` সেই অসম্পূর্ণ তথ্যকে সৎভাবে প্রকাশ করে।

```python
customer = "Karim Store"
balance = None

print(customer)
print(balance)
```

**Output**

```text
Karim Store
None
```

`customer` হলো পরিচিত নাম। `balance`-এর `None` হলো এখনও যাচাই না হওয়ার চিহ্ন।

## 4. `None`-এর type

`None` নিজে কোনো `int`, `float`, `str`, বা `bool` নয়। Python এটিকে `NoneType` বলে।

```python
balance = None
print(type(balance))
```

**Output**

```text
<class 'NoneType'>
```

`type(balance)` দেখায় যে মানটির type `NoneType`। এটি `0`-এর মতো `int` নয়।

## 5. `is None` দিয়ে পরীক্ষা

কোনো variable-এ `None` আছে কি না জানতে `is None` ব্যবহার করুন।

```python
balance = None

if balance is None:
    print("Balance is not checked yet")
```

**Output**

```text
Balance is not checked yet
```

`is None` সরাসরি পরীক্ষা করে variable-টি Python-এর বিশেষ `None` মানটিই ধরে রেখেছে কি না। সত্য হলে message-টি ছাপা হয়।

## 6. `is not None` দিয়ে পরীক্ষা

যখন balance পাওয়া গেছে, তখন `is not None` দিয়ে হিসাব করা নিরাপদ কি না বোঝা যায়।

```python
balance = 50000

if balance is not None:
    print(balance)
```

**Output**

```text
50000
```

এখানে balance একটি জানা সংখ্যা। তাই `is not None` সত্য এবং value-টি print হয়।

## 7. `None` এবং খালি লেখা

`None` এবং `""` এক নয়। `""` হলো জানা একটি খালি string, আর `None` হলো কোনো মান না থাকার চিহ্ন।

```python
missing_note = None
empty_note = ""

print(missing_note)
print(empty_note)
```

**Output**

```text
None

```

দ্বিতীয় output-এর line ফাঁকা, কারণ `empty_note` একটি খালি লেখা। প্রথম output স্পষ্টভাবে `None` দেখায়।

## 8. হিসাবের আগে `None` সামলানো

`None`-কে সরাসরি সংখ্যার সঙ্গে যোগ করা যায় না। আগে পরীক্ষা করুন, তারপর হিসাব করুন।

```python
balance = None
payment = 5000

if balance is None:
    print("Cannot calculate: balance is unknown")
else:
    print(balance - payment)
```

**Output**

```text
Cannot calculate: balance is unknown
```

`balance` অজানা বলে প্রথম branch চলে। Python অজানা balance থেকে payment বাদ দেওয়ার চেষ্টা করে না।

## 9. ব্যবসায়িক record-এ `None`

একটি record-এ customer-এর নাম জানা থাকতে পারে, কিন্তু payment date এখনও না-ও জানা থাকতে পারে।

```python
invoice_number = "INV-2024-007"
payment_date = None

print(invoice_number, payment_date)
```

**Output**

```text
INV-2024-007 None
```

Invoice code আছে। Payment date নেই। `None` সেই অসম্পূর্ণ ক্ষেত্রটি আলাদা করে বোঝায়।

## 10. অনুপস্থিত ও সত্যিকারের শূন্য আলাদা করা

শূন্য sales এবং অজানা sales ব্যবসায়িক সিদ্ধান্তে এক নয়।

```python
closed_shop_sales = 0
unreported_sales = None

print(closed_shop_sales is None)
print(unreported_sales is None)
```

**Output**

```text
False
True
```

দোকান বন্ধ থাকলে sales সত্যিই `0` হতে পারে। Report না এলে sales `None`, অর্থাৎ অজানা।

## Troubleshooting

### Problem 1: `None`-কে `0` ধরে নেওয়া হচ্ছে

- **কী হচ্ছে:** অজানা balance-কে শূন্য হিসেবে report করা হচ্ছে।
- **সম্ভাব্য কারণ:** তথ্য না পাওয়াকে সত্যিকারের zero ধরা হয়েছে।
- **ধাপে ধাপে সমাধান:** 1. field-টির অর্থ লিখুন। 2. সত্যিই zero হলে `0` রাখুন। 3. জানা না থাকলে `None` রাখুন। 4. report-এ আলাদা message দেখান।
- **পরের বার ঠেকানোর উপায়:** প্রতিটি missing field-এর জন্য আগে ঠিক করুন, এটি unknown নাকি zero।

### Problem 2: `None`-এর সঙ্গে হিসাব করতে গিয়ে error

- **কী হচ্ছে:** `None` থেকে payment বাদ দিতে গেলে Python arithmetic error দেখায়।
- **সম্ভাব্য কারণ:** হিসাবের আগে `None` পরীক্ষা করা হয়নি।
- **ধাপে ধাপে সমাধান:** 1. `value is None` পরীক্ষা করুন। 2. হলে হিসাব বন্ধ রাখুন। 3. না হলে arithmetic চালান। 4. ফলটি print করুন।
- **পরের বার ঠেকানোর উপায়:** প্রত্যেক optional number-এর আগে guard লিখুন।

### Problem 3: `None` এবং খালি string গুলিয়ে যাচ্ছে

- **কী হচ্ছে:** খালি note-কে missing data বলা হচ্ছে, অথবা উল্টোটি।
- **সম্ভাব্য কারণ:** `""` এবং `None`-এর আলাদা অর্থ লেখা হয়নি।
- **ধাপে ধাপে সমাধান:** 1. `None` মানে value নেই। 2. `""` মানে string আছে, কিন্তু text শূন্য। 3. field-এর business meaning ঠিক করুন। 4. তারপর value বাছুন।
- **পরের বার ঠেকানোর উপায়:** data dictionary-তে missing এবং empty-এর নিয়ম লিখে রাখুন।

### Problem 4: `None` পরীক্ষা করতে `==` ব্যবহার

- **কী হচ্ছে:** code-এ `None` চেনার নিয়ম অস্পষ্ট হচ্ছে।
- **সম্ভাব্য কারণ:** Python-এর identity test `is` শেখা হয়নি।
- **ধাপে ধাপে সমাধান:** 1. `value is None` লিখুন। 2. জানা মানের জন্য `value is not None` লিখুন। 3. branch চালিয়ে দেখুন। 4. output মিলিয়ে নিন।
- **পরের বার ঠেকানোর উপায়:** `None`-এর জন্য সব সময় `is None` বা `is not None` ব্যবহার করুন।

## Common Misconceptions

1. **ভুল দাবি:** `None` এবং `0` একই। **সত্য:** `0` জানা integer, `None` অনুপস্থিত বা অজানা মান।
2. **ভুল দাবি:** `None` একটি খালি string। **সত্য:** `None` হলো `NoneType`, আর `""` হলো খালি `str`।
3. **ভুল দাবি:** `None` দিয়ে যোগ-বিয়োগ করা যায়। **সত্য:** আগে জানা মান আছে কি না পরীক্ষা করতে হয়।
4. **ভুল দাবি:** `None` print করলে কিছুই দেখা যায় না। **সত্য:** Python সাধারণত `None` শব্দটি print করে।
5. **ভুল দাবি:** অজানা sales-কে zero লিখলে report পরিষ্কার হয়। **সত্য:** এতে অজানা তথ্যকে ভুলভাবে zero বলা হয়।

### Exercise 5: Rafiq bhai-এর debugging bug

Rafiq bhai অজানা balance-কে zero ধরে ফেলেছেন:

```python
balance = None
payment = 5000
remaining = balance or 0
print(remaining - payment)
```

**Wrong output**

```text
-5000
```

Boss বললেন, “Karim Store-এর balance জানা নেই, তাহলে -5000 পাওনা কীভাবে এলো?”

**Solution**

এখানে `balance or 0` অজানা balance-কে সত্যিকারের zero বানিয়ে দিয়েছে। Unknown balance-এ payment বাদ দেওয়া যাবে না।

```python
balance = None
payment = 5000

if balance is None:
    print("Cannot calculate: balance is unknown")
else:
    print(balance - payment)
```

**Correct output**

```text
Cannot calculate: balance is unknown
```

এক লাইনের lesson: অজানা সংখ্যাকে zero বানিয়ে business result তৈরি করবেন না।

## Quiz

### 1. `None` কী বোঝায়?

a) অজানা বা অনুপস্থিত মান  
b) সব সময় zero  
c) খালি string  

**Answer:** a. `None` জানায় যে নির্দিষ্ট মান নেই বা এখনও জানা যায়নি।

### 2. কোনটি সত্যিকারের জানা integer zero?

a) `None`  
b) `0`  
c) `""`  

**Answer:** b. `0` একটি integer value।

### 3. `None` পরীক্ষা করার সঠিক রীতি কোনটি?

a) `value = None`  
b) `value == 0`  
c) `value is None`  

**Answer:** c. `is None` বিশেষ `None` মান পরীক্ষা করে।

### 4. `type(None)` কী ফল দেয়?

a) `int`  
b) `NoneType`  
c) `str`  

**Answer:** b. Python `None`-এর type হিসেবে `NoneType` দেখায়।

### 5. `""` কী?

a) খালি string  
b) অজানা number  
c) Boolean false  

**Answer:** a. উদ্ধৃতির ভিতরের কোনো character না থাকলে এটি empty string।

### 6. অজানা balance দিয়ে কী করা উচিত?

a) আগে `None` পরীক্ষা করা  
b) সব সময় `0` করা  
c) text-এর সঙ্গে যোগ করা  

**Answer:** a. জানা value না থাকলে arithmetic নিরাপদ নয়।

### 7. `sales = 0` সাধারণত কী বোঝাতে পারে?

a) sales report আসেনি  
b) sales সত্যিই শূন্য  
c) sales-এর নাম নেই  

**Answer:** b. `0` জানা একটি সংখ্যা, যদিও business context অবশ্যই যাচাই করতে হবে।

## Key Idea

`None` হলো অনুপস্থিত বা অজানা মানের সৎ চিহ্ন। `0` হলো জানা শূন্য, তাই দুটিকে এক করবেন না।

অজানা ঘর `None` রাখি,
