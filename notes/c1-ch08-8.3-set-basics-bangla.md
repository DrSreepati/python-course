## 6. Set কী

Set হলো unique values-এর collection। একই invoice reference বারবার থাকলেও set-এ একবার থাকবে।

```python
references = {"INV-2024-007", "INV-2024-008", "INV-2024-007"}
print(sorted(references))
```

**Output**

```text
['INV-2024-007', 'INV-2024-008']
```

- curly braces set-এর সাধারণ চিহ্ন।
- duplicate reference একবার হয়েছে।
- `sorted()` শুধু readable, predictable output-এর জন্য।

## 7. List থেকে set

```python
references = ["INV-2024-007", "INV-2024-008", "INV-2024-007"]
unique_references = set(references)

print(sorted(unique_references))
```

**Output**

```text
['INV-2024-007', 'INV-2024-008']
```

Set list-এর original order রাখার tool নয়। এর প্রধান কাজ uniqueness।

## 8. Empty set

```python
empty_set = set()
empty_dictionary = {}

print(type(empty_set).__name__)
print(type(empty_dictionary).__name__)
```

**Output**

```text
set
dict
```

`{}` empty set নয়, empty dictionary। Empty set-এর জন্য `set()` লিখুন।

## 9. `add()`

```python
customer_ids = {"C-1023", "C-2048"}
customer_ids.add("C-3099")
customer_ids.add("C-1023")

print(sorted(customer_ids))
```

**Output**

```text
['C-1023', 'C-2048', 'C-3099']
```

নতুন ID যোগ হয়েছে। আগের ID আবার add করলেও duplicate তৈরি হয়নি।

## 10. `remove()` এবং `discard()`

```python
products = {"Rice", "Oil", "Lentil"}
products.remove("Oil")
products.discard("Sugar")

print(sorted(products))
```

**Output**

```text
['Lentil', 'Rice']
```

`remove()` না থাকা value-তে error দেয়। `discard()` না থাকা value নীরবে উপেক্ষা করে।

## 11. Membership test

```python
invoice_ids = {"INV-2024-007", "INV-2024-008"}

print("INV-2024-007" in invoice_ids)
print("INV-2024-009" in invoice_ids)
```

**Output**

```text
True
False
```

Set দিয়ে দ্রুত জিজ্ঞেস করা যায়, কোনো ID আগে এসেছে কি না।

## 12. Set-এর সীমা

Set indexed নয় এবং duplicate রাখে না। তাই position দরকার হলে list, fixed ordered record হলে tuple, uniqueness দরকার হলে set ব্যবহার করুন।

## 14. Troubleshooting

### সমস্যা 1: set-এর output order বদলে যাচ্ছে
- **কী হচ্ছে:** print-এ item-এর ক্রম স্থির নয়।
- **সম্ভাব্য কারণ:** set unordered।
- **Fix:** দেখানোর আগে `sorted(my_set)` ব্যবহার করুন।
- **আগে প্রতিরোধ:** set-কে order-এর জন্য ব্যবহার করবেন না।

### সমস্যা 2: `KeyError` from `remove()`
- **কী হচ্ছে:** না থাকা value remove করতে error।
- **সম্ভাব্য কারণ:** `remove()` value উপস্থিত ধরে নেয়।
- **Fix:** membership test করুন বা `discard()` ব্যবহার করুন।
- **আগে প্রতিরোধ:** uncertain data-তে `discard()` বেছে নিন।

### সমস্যা 3: `{}` set হচ্ছে না
- **কী হচ্ছে:** type `dict` দেখা যাচ্ছে।
- **সম্ভাব্য কারণ:** empty braces dictionary বোঝায়।
- **Fix:** `set()` লিখুন।
- **আগে প্রতিরোধ:** empty set-এর syntax আলাদা মনে রাখুন।

### সমস্যা 4: `TypeError` set index করলে
- **কী হচ্ছে:** `my_set[0]` কাজ করছে না।
- **সম্ভাব্য কারণ:** set-এর index নেই।
- **Fix:** membership test বা `sorted()` list ব্যবহার করুন।
- **আগে প্রতিরোধ:** position দরকার হলে list ব্যবহার করুন।

## 15. Common Misconceptions

1. **ভুল:** set duplicate values রাখে। → **সত্য:** duplicate একবার থাকে।
2. **ভুল:** set-এর index আছে। → **সত্য:** set unordered এবং not indexed।
3. **ভুল:** `{}` empty set। → **সত্য:** এটি empty dictionary।
4. **ভুল:** `remove()` এবং `discard()` একই। → **সত্য:** missing value-তে `remove()` error দেয়।
5. **ভুল:** set report-এর original order রাখে। → **সত্য:** uniqueness রাখে, order নয়।

### Exercise 5: Sreepati debugging bug

Sreepati set-এর প্রথম invoice নিতে index ব্যবহার করেছিলেন।

```python
invoice_ids = {"INV-2024-007", "INV-2024-008"}
first_invoice = invoice_ids[0]
print(first_invoice)
```

**Wrong output**

```text
TypeError: 'set' object is not subscriptable
```

Boss বললেন, “Set-এর প্রথম item কীভাবে নেবে?”

**Diagnosis:** Set-এর index নেই, তাই `[0]` ব্যবহার করা যায় না।

**Minimal fix**

```python
invoice_ids = {"INV-2024-007", "INV-2024-008"}
ordered_ids = sorted(invoice_ids)
first_invoice = ordered_ids[0]
print(first_invoice)
```

**Correct output**

```text
INV-2024-007
```

**Lesson:** set-এ position নয়, uniqueness বা membership ব্যবহার করুন।

## 17. Quiz

1. Set-এর প্রধান কাজ কী?  
   a) duplicate রাখা  
   b) unique value রাখা  
   c) field unpack করা  
   **উত্তর: b।** duplicate একবার থাকে।

2. Empty set কীভাবে বানাব?  
   a) `{}`  
   b) `set()`  
   c) `[]`  
   **উত্তর: b।** `{}` dictionary।

3. নতুন value যোগ করার method কোনটি?  
   a) `add()`  
   b) `push()`  
   c) `append_only()`  
   **উত্তর: a।** set-এ `add()` ব্যবহার হয়।

4. Missing value-তে error না চাইলে কোনটি ভালো?  
   a) `remove()`  
   b) `discard()`  
   c) `del_index()`  
   **উত্তর: b।** `discard()` missing value উপেক্ষা করে।

5. Set-এ `my_set[0]` কী করবে?  
   a) প্রথম item দেবে  
   b) `TypeError` হবে  
   c) set sort করবে  
   **উত্তর: b।** set indexed নয়।

6. Set-এর order দেখাতে কোনটি ব্যবহার করা যায়?  
   a) `sorted(my_set)`  
   b) `my_set[0]`  
   c) `set.order()`  
   **উত্তর: a।** sorted একটি list result দেয়।

7. Duplicate invoice detection-এর জন্য কোন structure ভালো?  
   a) set  
   b) tuple only  
   c) float  
   **উত্তর: a।** unique references রাখে।

## 18. Key Idea

Set unique values রাখে। এটি indexed বা ordered নয়। Duplicate IDs, membership check, এবং safe add/remove-এর জন্য set কার্যকর।
