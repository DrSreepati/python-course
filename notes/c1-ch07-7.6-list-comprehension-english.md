## 6. Building a new list with a loop

First, add 10% to every sale.

```python
sales = [12000, 9500, 8800]
updated_sales = []

for sale in sales:
    updated_sales.append(sale * 1.10)

print(updated_sales)
```

**Output**

```text
[13200.000000000002, 10450.0, 9680.000000000002]
```

- The empty list receives new results.
- The loop reads one sale at a time.
- `append()` adds each result.
- Floating point can show a long decimal.

## 7. The comprehension structure

The same work can be shorter.

```python
sales = [12000, 9500, 8800]
updated_sales = [sale * 1.10 for sale in sales]

print(updated_sales)
```

**Output**

```text
[13200.000000000002, 10450.0, 9680.000000000002]
```

The pattern is:

```python
[expression for item in source]
```

The expression changes each item. The `for` part reads the source list.

## 8. Selecting items with a condition

Keep only sales above 10,000.

```python
sales = [12000, 9500, 8800, 13200, 7500]
large_sales = [sale for sale in sales if sale > 10000]

print(large_sales)
```

**Output**

```text
[12000, 13200]
```

- The loop checks every sale.
- The final `if` filters the items.
- Only true items enter the new list.

## 9. Labelling each item with `if-else`

Use an `if-else` expression when every item needs a label.

```python
sales = [12000, 9500, 13200]
labels = ["High" if sale >= 10000 else "Regular" for sale in sales]

print(labels)
```

**Output**

```text
['High', 'Regular', 'High']
```

The `if-else` expression comes first. A filtering `if` comes at the end. Do not mix these patterns.

## 10. Business report: balance filter

```python
customers = ["Rahim Traders", "Karim Store", "Jahid Enterprise"]
balances = [50000, 32000, 71000]
large_balances = [balance for balance in balances if balance >= 50000]

print(large_balances)
```

**Output**

```text
[50000, 71000]
```

This keeps balances only. A parallel index can keep names too.

## 11. Comprehension with `enumerate`

```python
sales = [12000, 9500, 8800]
day_labels = [f"Day {day}: {sale}" for day, sale in enumerate(sales, start=1)]

print(day_labels)
```

**Output**

```text
['Day 1: 12000', 'Day 2: 9500', 'Day 3: 8800']
```

`enumerate()` supplies the position and value. The comprehension builds text labels.

## 12. When an ordinary loop is better

Use a normal loop for long expressions, several steps, logging, or nested decisions. Comprehensions suit short transformations and filters. Shorter code is not always clearer.

## 13. Synthesis table

| Job | Suitable tool |
|---|---|
| Read items only | `for` loop |
| Read position and item | `enumerate()` |
| Transform every item | list comprehension |
| Select some items | comprehension with final `if` |
| Choose a label | `if-else` inside the expression |
| Perform many steps | ordinary `for` loop |

## 14. Troubleshooting

### Problem 1: `SyntaxError`
- **What happens:** The comprehension cannot be parsed.
- **Likely cause:** The expression or source list is missing.
- **Fix:** Use `[expression for item in source]`.
- **Prevent it:** Write the ordinary loop first.

### Problem 2: Empty list
- **What happens:** No item enters the result.
- **Likely cause:** The condition is false for every item.
- **Fix:** Check the threshold and comparison operator.
- **Prevent it:** Print each condition while testing.

### Problem 3: `NameError`
- **What happens:** Python cannot find a variable.
- **Likely cause:** The expression uses a different name from the loop variable.
- **Fix:** Use the exact name after `for`.
- **Prevent it:** Keep the variable name consistent.

### Problem 4: Unexpected nested list
- **What happens:** Each result is itself a list.
- **Likely cause:** The wrong data level was selected.
- **Fix:** Decide whether you need an item, a row, or the whole table.
- **Prevent it:** Inspect one result item and its type.

## 15. Common Misconceptions

1. **Wrong:** A comprehension changes the source list. → **Truth:** It normally creates a new list.
2. **Wrong:** It is always better than a loop. → **Truth:** Complex work is clearer in a loop.
3. **Wrong:** A final `if` transforms every item. → **Truth:** It filters items.
4. **Wrong:** `if-else` always comes last. → **Truth:** A transformation `if-else` sits in the expression.
5. **Wrong:** Removing the condition guarantees success. → **Truth:** The expression can still fail.

### Exercise 5: Rafiq bhai debugging bug

Rafiq bhai wanted every invoice amount. His code keeps only true conditions.

```python
amounts = [12000, 9500, 8800]
report = [amount for amount in amounts if amount > 10000]
print(report)
```

**Wrong output**

```text
[12000]
```

The boss asked, “Where is the full invoice report?”

**Diagnosis:** The final `if` filters items. It removes the smaller amounts.

**Minimal fix**

```python
amounts = [12000, 9500, 8800]
report = [amount for amount in amounts]
print(report)
```

**Correct output**

```text
[12000, 9500, 8800]
```

**Lesson:** Do not write a filtering condition when every item is required.

## 17. Quiz

1. What does `[x * 2 for x in [2, 3]]` produce?  
   a) `[2, 3]`  
   b) `[4, 6]`  
   c) `[2, 6]`  
   **Answer: b.** Each item is doubled.

2. Where does a filtering condition go?  
   a) Before the source  
   b) Before `for`  
   c) After the `for` part  
   **Answer: c.** The usual pattern ends with `if condition`.

3. What does `["High" if x >= 10 else "Low" for x in sales]` do?  
   a) Labels every item  
   b) Keeps High items only  
   c) Changes the source  
   **Answer: a.** Each item receives a label.

4. Which normally leaves the source list unchanged?  
   a) `append()`  
   b) list comprehension  
   c) `remove()`  
   **Answer: b.** It creates a new list.

5. What can `enumerate()` provide inside a comprehension?  
   a) Position and value  
   b) Only a total  
   c) Only a condition  
   **Answer: a.** It provides both values.

6. Which is clearer for many steps?  
   a) Always a comprehension  
   b) An ordinary `for` loop  
   c) Only `sum()`  
   **Answer: b.** A loop makes several steps visible.

7. What does `[x for x in sales if x > 10000]` do?  
   a) Raises every sale to 10,000  
   b) Selects large sales  
   c) Sorts sales  
   **Answer: b.** The final condition filters the list.

## 18. Key Idea

A list comprehension combines a loop, an expression, and sometimes a condition to build a new list.

**Rhyme 1:**  
Need a new list from a loop?  
Use comprehension as your group.

**Rhyme 2:**  
The final `if` selects the few,  
The middle expression changes each view.
