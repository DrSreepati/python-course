## 1. What a string is

A string is a sequence of text. Business codes, customer names and invoice numbers are often strings.

```python
customer = "Rahim Traders"
invoice_no = "INV-2024-007"

print(customer)
print(invoice_no)
```

**Output**

```text
Rahim Traders
INV-2024-007
```

Text inside quotes is a string. The variables hold two business identifiers.

## 2. Creating strings

Single quotes and double quotes both create strings. Use matching quotes around one string.

```python
product = "Rice"
warehouse = 'Dhaka'

print(product)
print(warehouse)
```

**Output**

```text
Rice
Dhaka
```

Both variables have type `str`. The quote marks define the text boundary.

## 3. Characters and indexes

Each letter or symbol is a character. Python gives each character an index, starting at 0.

```python
code = "C-1023"

print(code[0])
print(code[1])
print(code[2])
```

**Output**

```text
C
-
1
```

`code[0]` is the first character. `code[1]` is the second. `code[2]` is the third.

## 4. Positive indexing

Positive indexes grow from the left: 0, 1, 2 and so on. They help read an invoice prefix or separator.

```python
invoice_no = "INV-2024-007"

print(invoice_no[0])
print(invoice_no[1])
print(invoice_no[2])
print(invoice_no[3])
```

**Output**

```text
I
N
V
-
```

The first three characters are `INV`. The fourth character is a hyphen.

## 5. First and last characters

Use index 0 for the first character. Use a negative index for the last character.

```python
customer_code = "C-1023"

print(customer_code[0])
print(customer_code[-1])
```

**Output**

```text
C
3
```

`[0]` reads the first character. `[-1]` reads the last.

## 6. Negative indexing

Negative indexes start at `-1` from the right. The character before the last is `-2`.

```python
invoice_no = "INV-2024-007"

print(invoice_no[-1])
print(invoice_no[-2])
print(invoice_no[-3])
```

**Output**

```text
7
0
0
```

The last three characters are `007`. Negative indexing reads from the right.

## 7. Reading an invoice code

Indexes can read individual characters. Taking larger sections will use slicing in the next subtopic.

```python
invoice_no = "INV-2024-007"

print(f"Prefix: {invoice_no[0]}{invoice_no[1]}{invoice_no[2]}")
print(f"Last digit: {invoice_no[-1]}")
```

**Output**

```text
Prefix: INV
Last digit: 7
```

The first three indexes form the prefix. The negative index reads the final digit.

## 8. Reading a customer code

The first character and last digit of a customer code can support a simple report.

```python
customer_code = "C-1023"

print(f"Type marker: {customer_code[0]}")
print(f"Last digit: {customer_code[-1]}")
```

**Output**

```text
Type marker: C
Last digit: 3
```

Index 0 gives the marker. Index -1 gives the last digit.

## 9. String length

`len()` returns the number of characters. The last positive index is `len(text) - 1`.

```python
invoice_no = "INV-2024-007"

print(len(invoice_no))
print(invoice_no[len(invoice_no) - 1])
```

**Output**

```text
12
7
```

The invoice code has 12 characters. Its last positive index is 11.

## 10. Index errors

An index outside the string causes `IndexError`. Check the length and use a valid index.

```python
code = "C-1023"

print(code[5])
```

**Output**

```text
3
```

The valid positive indexes are 0 to 5. Index 5 reads the final character. Index 6 would cause an error.

## Synthesis table

| Job | Syntax | Example |
|---|---|---|
| First character | `text[0]` | `"C-1023"[0]` -> `C` |
| Second character | `text[1]` | `"C-1023"[1]` -> `-` |
| Last character | `text[-1]` | `"C-1023"[-1]` -> `3` |
| Character before last | `text[-2]` | `"C-1023"[-2]` -> `2` |
| Character count | `len(text)` | `len("C-1023")` -> `6` |
| Last positive index | `len(text) - 1` | `5` |

## Troubleshooting

### Problem 1: The first character is missing

- What is happening: the second character appears.
- Most likely cause: `[1]` was used, but the first index is 0.
- Fix: use `[0]` for the first character.
- Prevention: remember that indexes start at zero.

### Problem 2: `IndexError` appears

- What is happening: a character outside the string was requested.
- Most likely cause: the index is greater than `len(text) - 1`.
- Fix: print `len(text)` and choose a valid index.
- Prevention: check the length in dynamic code.

### Problem 3: The last digit is difficult to read

- What is happening: a large index must be counted from the left.
- Most likely cause: negative indexing was not used.
- Fix: use `[-1]` for the last character and `[-2]` for the previous one.
- Prevention: remember negative indexes for right-side data.

### Problem 4: Quote marks appear confusing

- What is happening: the learner thinks quote marks are string characters.
- Most likely cause: quotes are delimiters, not part of the text.
- Fix: print the string and its first character separately.
- Prevention: distinguish delimiters from characters.

## Common Misconceptions

1. **Wrong:** the first index is 1 → **Truth:** Python starts at index 0.
2. **Wrong:** `[-1]` is the first character → **Truth:** `[-1]` is the last.
3. **Wrong:** quote marks are inside the string → **Truth:** they mark the text boundary.
4. **Wrong:** a string's index can be changed → **Truth:** indexing reads characters; changing strings comes later.
5. **Wrong:** `len(text)` is the last index → **Truth:** the last index is `len(text) - 1`.

## Quiz

### 1. What is the first string index?

a. `1`  
b. `-1`  
c. `0`  

**Answer: c.** Python uses zero-based indexing.

### 2. What is `"C-1023"[-1]`?

a. `3`  
b. `C`  
c. `2`  

**Answer: a.** `-1` means the last character.

### 3. What is `len("C-1023")`?

a. `5`  
b. `6`  
c. `7`  

**Answer: b.** The code has six characters.

### 4. What is `"INV-2024-007"[3]`?

a. `V`  
b. `2`  
c. `-`  

**Answer: c.** Index 3 is the hyphen.

### 5. How do you find the last positive index?

a. `len(text)`  
b. `len(text) + 1`  
c. `len(text) - 1`  

**Answer: c.** The last index is one less than the count.

### 6. What does `[-2]` return?

a. The character before the last  
b. The first character  
c. The string length  

**Answer: a.** Negative indexes count from the right.

### 7. What happens for an invalid index?

a. `IndexError`  
b. `None`  
c. `float`  

**Answer: a.** The requested seat does not exist.

## Key Idea

A string is a sequence of text. Indexes start at 0. Negative indexes make it easy to read characters from the right.

**Rhyme 1:** Start at zero, then move right, and indexes grow in line.  
**Rhyme 2:** Minus one finds the final mark, so code reading is fine.
