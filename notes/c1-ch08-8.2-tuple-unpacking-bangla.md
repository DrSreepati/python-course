## 6. Basic tuple unpacking

একটি tuple-এর তিনটি value তিনটি variable-এ একসঙ্গে বসানো যায়।

```python
invoice = ("INV-2024-007", "Rahim Traders", 50000)
invoice_no, customer, amount = invoice

print(invoice_no)
print(customer)
print(amount)
```

**Output**

```text
INV-2024-007
Rahim Traders
50000
```

- ডান পাশের tuple-এর প্রথম value `invoice_no` পায়।
- দ্বিতীয় value `customer` পায়।
- তৃতীয় value `amount` পায়।

## 7. Unpacking এবং position

Unpacking index হাতে না লিখে record-এর fields আলাদা করে দেয়।

```python
customer_record = ("Karim Store", 32000, "Active")
name, balance, status = customer_record

print(f"{name}: {balance}, {status}")
```

**Output**

```text
Karim Store: 32000, Active
```

Variable-এর order tuple-এর order-এর সঙ্গে মিলতে হবে।

## 8. Count mismatch

Value এবং variable-এর সংখ্যা না মিললে error হয়।

```python
record = ("Rahim Traders", 50000, "Review")
name, balance = record
```

**Output**

```text
ValueError: too many values to unpack (expected 2)
```

তিনটি value ধরতে তিনটি variable, অথবা star unpacking ব্যবহার করুন।

## 9. Star unpacking

একটি variable একাধিক মাঝের value নিতে পারে।

```python
sales = ("Rahim Traders", 12000, 9500, 8800, 13200)
customer, *daily_sales = sales

print(customer)
print(daily_sales)
```

**Output**

```text
Rahim Traders
[12000, 9500, 8800, 13200]
```

`*daily_sales` বাকি values-কে list হিসেবে নেয়। Star variable একটি list পায়।

## 10. Tuple versus list

```python
approved_period = ("January", "Approved")
daily_report = ["Monday", "Tuesday"]

print(type(approved_period).__name__)
print(type(daily_report).__name__)
```

**Output**

```text
tuple
list
```

Approved period-এর fixed pair tuple-এ ভালো। Daily report-এ নতুন day যোগ হলে list ভালো।

## 11. Business choice

```python
invoice_fields = ("INV-2024-007", "Rahim Traders", 50000)
invoice_no, customer, amount = invoice_fields

daily_sales = [12000, 9500, 8800]
daily_sales.append(13200)

print(invoice_no, customer, amount)
print(daily_sales)
```

**Output**

```text
INV-2024-007 Rahim Traders 50000
[12000, 9500, 8800, 13200]
```

Invoice-এর fixed identity tuple, changing daily figures list।

## 12. Decision rule

যে data-এর item count এবং values স্থির, সেখানে tuple ভাবুন। যে data নিয়মিত যোগ, বাদ বা পরিবর্তন হবে, সেখানে list ভাবুন। Structure বেছে নেওয়া business meaning-এর অংশ।

## 14. Troubleshooting

### সমস্যা 1: `ValueError: too many values to unpack`
- **কী হচ্ছে:** tuple-এ variable-এর চেয়ে বেশি value আছে।
- **সম্ভাব্য কারণ:** record-এর নতুন field যোগ হয়েছে, code update হয়নি।
- **Fix:** variable যোগ করুন বা star unpacking ব্যবহার করুন।
- **আগে প্রতিরোধ:** record field count লিখে রাখুন।

### সমস্যা 2: `ValueError: not enough values to unpack`
- **কী হচ্ছে:** variable বেশি, tuple value কম।
- **সম্ভাব্য কারণ:** ভুল record structure ধরা হয়েছে।
- **Fix:** variable কমান বা source record যাচাই করুন।
- **আগে প্রতিরোধ:** unpack করার আগে sample tuple print করুন।

### সমস্যা 3: fields ভুল variable-এ গেছে
- **কী হচ্ছে:** output চলে, কিন্তু report ভুল।
- **সম্ভাব্য কারণ:** variable order tuple order-এর সঙ্গে মেলেনি।
- **Fix:** tuple-এর position অনুযায়ী variable সাজান।
- **আগে প্রতিরোধ:** field names লিখে তারপর unpack করুন।

### সমস্যা 4: tuple-এ append করা যাচ্ছে না
- **কী হচ্ছে:** `AttributeError` দেখা যাচ্ছে।
- **সম্ভাব্য কারণ:** tuple fixed, list method ব্যবহার করা হয়েছে।
- **Fix:** data পরিবর্তনযোগ্য হলে list বানান।
- **আগে প্রতিরোধ:** fixed record এবং changing collection আলাদা করুন।

## 15. Common Misconceptions

1. **ভুল:** unpacking tuple ভেঙে ফেলে। → **সত্য:** source tuple থাকে, values variable-এ reference হয়।
2. **ভুল:** variable order গুরুত্বপূর্ণ নয়। → **সত্য:** order ভুল হলে data ভুল field-এ যায়।
3. **ভুল:** star unpacking সব value tuple হিসেবে রাখে। → **সত্য:** star variable list পায়।
4. **ভুল:** tuple সবসময় list-এর চেয়ে ভালো। → **সত্য:** changing data-এর জন্য list ভালো।
5. **ভুল:** unpacking শুধু tuple-এ হয়। → **সত্য:** compatible iterable data-তেও হতে পারে, তবে আজ tuple-এ focus।

### Exercise 5: Sreepati debugging bug

Sreepati তিন-field customer record দুইটি variable-এ unpack করেছিলেন।

```python
record = ("Rahim Traders", 50000, "Review")
customer, balance = record
print(customer, balance)
```

**Wrong output**

```text
ValueError: too many values to unpack (expected 2)
```

Boss বললেন, “Review status-টি কোথায় রাখবে?”

**Diagnosis:** তিনটি value আছে, কিন্তু দুইটি variable দেওয়া হয়েছে।

**Minimal fix**

```python
record = ("Rahim Traders", 50000, "Review")
customer, balance, status = record
print(customer, balance, status)
```

**Correct output**

```text
Rahim Traders 50000 Review
```

**Lesson:** unpacking-এ variable count এবং value count মিলান।

## 17. Quiz

   a) values variable-এ বসায়  
   b) tuple sort করে  
   c) tuple delete করে  
   **উত্তর: a।** প্রতিটি value আলাদা name পায়।

   b) 20  
   c) 2  
   **উত্তর: b।** দ্বিতীয় value দ্বিতীয় variable-এ যায়।

3. Count mismatch হলে কী হতে পারে?  
   a) `ValueError`  
   b) tuple list হয়

   **উত্তর: a।** value এবং variable count মিলতে হয়।

7. Unpacking-এ variable order কেমন হওয়া উচিত?  
   a) tuple order-এর মতো

## 18. Key Idea

Tuple unpacking fixed record-এর values পরিষ্কার variable-এ দেয়। Tuple fixed data-এর জন্য, list changing data-এর জন্য ভালো।
