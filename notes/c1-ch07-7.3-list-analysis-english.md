## 6. `sort` and `reverse`

`sort()` orders a list from low to high. `reverse()` reverses its current order.

```python
sales = [12000, 9500, 8800, 13200, 7500]
sales.sort()
print(sales)
sales.reverse()
print(sales)
```

**Output**

```text
[7500, 8800, 9500, 12000, 13200]
[13200, 12000, 9500, 8800, 7500]
```

- `sort()` creates ascending order.
- `reverse()` reverses the sorted order.
- Both methods change the original list.

## 7. `sorted` and descending order

Use `sorted()` when the original list must stay unchanged.

```python
sales = [12000, 9500, 8800, 13200, 7500]
ascending = sorted(sales)
descending = sorted(sales, reverse=True)
print(ascending)
print(descending)
print(sales)
```

**Output**

```text
[7500, 8800, 9500, 12000, 13200]
[13200, 12000, 9500, 8800, 7500]
[12000, 9500, 8800, 13200, 7500]
```

- `sorted()` returns a new list.
- `reverse=True` orders from high to low.
- The original sales list remains unchanged.

## 8. `min`, `max`, `sum`, and `len`

These built-ins provide basic report measures.

```python
sales = [12000, 9500, 8800, 13200, 7500]
print(min(sales))
print(max(sales))
print(sum(sales))
print(len(sales))
```

**Output**

```text
7500
13200
51000
5
```

- `min()` returns the smallest value.
- `max()` returns the largest value.
- `sum()` adds every value.
- `len()` returns the item count.

## 9. Average and report

Divide the total by the count to calculate an average.

```python
sales = [12000, 9500, 8800, 13200, 7500]
total = sum(sales)
days = len(sales)
average = total / days
print(f"Total: {total}")
print(f"Average: {average}")
print(f"Best: {max(sales)}")
print(f"Slowest: {min(sales)}")
```

**Output**

```text
Total: 51000
Average: 10200.0
Best: 13200
Slowest: 7500
```

- `sum` supplies the total.
- `len` supplies the denominator.
- `/` keeps the decimal average.

## 10. Customer balance ranking

Sort a balance copy to see collection priority.

```python
balances = [50000, 32000, 71000]
print(sorted(balances, reverse=True))
print(max(balances))
```

**Output**

```text
[71000, 50000, 32000]
71000
```

- The descending copy puts the largest balance first.
- `max` gives the highest outstanding balance.

## 11. Troubleshooting

### Problem 1
- What happens: the original order is needed, but it is gone.
- Likely cause: `sort()` changed the original list.
- Fix: keep a copy or use `sorted()`.
- Prevention: decide whether mutation is wanted first.

### Problem 2
- What happens: `sorted_sales = sales.sort()` becomes `None`.
- Likely cause: `sort()` does not return the list.
- Fix: call `sales.sort()` as a separate statement.
- Prevention: use `sorted(sales)` for a new list.

### Problem 3
- What happens: the report prints a total, not an average.
- Likely cause: the sum was not divided by the length.
- Fix: use `sum(values) / len(values)`.
- Prevention: keep total and count in separate variables.

### Problem 4
- What happens: the highest balance is wrong.
- Likely cause: the wrong list or `min()` was used.
- Fix: check the balance list and use `max()`.
- Prevention: print the input list before summarising.

## 12. Common Misconceptions

1. **Wrong:** `sort()` returns a new list → **Truth:** it changes the original.
2. **Wrong:** `sorted()` changes the original → **Truth:** it returns a new sorted list.
3. **Wrong:** `reverse=True` is the reverse method → **Truth:** it is a descending option for sorting.
4. **Wrong:** `len` gives the total → **Truth:** it gives the item count.
5. **Wrong:** an average is the maximum → **Truth:** average means total divided by count.
