## 6. `sort` এবং `reverse`

`sort()` list-কে ছোট থেকে বড় সাজায়। `reverse()` বর্তমান order উল্টো করে।

```python
sales = [12000, 9500, 8800, 13200, 7500]
sales.sort()
print(sales)
sales.reverse()
print(sales)
```

**Output**

```text
[7500, 8800, 9500, 12000, 13200]
[13200, 12000, 9500, 8800, 7500]
```

- `sort()` ascending order করে।
- `reverse()` sorted list-এর order উল্টো করে।
- দুটো method original list বদলায়।

## 7. `sorted` এবং descending sort

Original list না বদলে sorted copy চাইলে `sorted()` ব্যবহার করুন।

```python
sales = [12000, 9500, 8800, 13200, 7500]
ascending = sorted(sales)
descending = sorted(sales, reverse=True)
print(ascending)
print(descending)
print(sales)
```

**Output**

```text
[7500, 8800, 9500, 12000, 13200]
[13200, 12000, 9500, 8800, 7500]
[12000, 9500, 8800, 13200, 7500]
```

- `sorted()` নতুন list দেয়।
- `reverse=True` বড় থেকে ছোট সাজায়।
- original sales অপরিবর্তিত থাকে।

## 8. `min`, `max`, `sum`, `len`

এই built-in functions report-এর basic measures দেয়।

```python
sales = [12000, 9500, 8800, 13200, 7500]
print(min(sales))
print(max(sales))
print(sum(sales))
print(len(sales))
```

**Output**

```text
7500
13200
51000
5
```

- `min()` সবচেয়ে ছোট value দেয়।
- `max()` সবচেয়ে বড় value দেয়।
- `sum()` সব value যোগ করে।
- `len()` item count দেয়।

## 9. Average এবং report

Total-কে count দিয়ে ভাগ করলে average পাওয়া যায়।

```python
sales = [12000, 9500, 8800, 13200, 7500]
total = sum(sales)
days = len(sales)
average = total / days
print(f"Total: {total}")
print(f"Average: {average}")
print(f"Best: {max(sales)}")
print(f"Slowest: {min(sales)}")
```

**Output**

```text
Total: 51000
Average: 10200.0
Best: 13200
Slowest: 7500
```

- `sum` total দেয়।
- `len` denominator দেয়।
- `/` decimal average রাখে।

## 10. Customer balance ranking

Balance list sorted copy করে collection priority দেখা যায়।

```python
balances = [50000, 32000, 71000]
print(sorted(balances, reverse=True))
print(max(balances))
```

**Output**

```text
[71000, 50000, 32000]
71000
```

- descending copy বড় balance আগে আনে।
- `max` highest outstanding balance দেয়।

## 11. Troubleshooting

### সমস্যা 1
- কী হচ্ছে: sort করার পরে original order দরকার, কিন্তু তা নেই।
- সম্ভাব্য কারণ: `sort()` original list বদলেছে।
- Fix: আগে copy রাখুন বা `sorted()` ব্যবহার করুন।
- Prevention: mutation দরকার কি না আগে ঠিক করুন।

### সমস্যা 2
- কী হচ্ছে: `sorted_sales = sales.sort()`-এ `None` দেখা যাচ্ছে।
- সম্ভাব্য কারণ: `sort()` list return করে না।
- Fix: `sales.sort()` আলাদা statement হিসেবে চালান।
- Prevention: নতুন list চাইলে `sorted(sales)` লিখুন।

### সমস্যা 3
- কী হচ্ছে: average-এর বদলে total print হচ্ছে।
- সম্ভাব্য কারণ: `sum`-কে `len` দিয়ে ভাগ করা হয়নি।
- Fix: `sum(values) / len(values)` করুন।
- Prevention: total এবং count variable আলাদা রাখুন।

### সমস্যা 4
- কী হচ্ছে: highest balance ভুল report হচ্ছে।
- সম্ভাব্য কারণ: wrong list বা `min()` ব্যবহার হয়েছে।
- Fix: customer balance list এবং `max()` যাচাই করুন।
- Prevention: input list print করে তারপর summary করুন।

## 12. Common Misconceptions

1. **ভুল:** `sort()` নতুন list ফেরত দেয় → **সত্য:** original list বদলায়।
2. **ভুল:** `sorted()` original list বদলায় → **সত্য:** নতুন sorted list দেয়।
3. **ভুল:** `reverse=True` reverse method → **সত্য:** sorted-এর descending option।
4. **ভুল:** `len` total দেয় → **সত্য:** item count দেয়।
5. **ভুল:** average মানেই `max` → **সত্য:** average হলো total ভাগ count।
