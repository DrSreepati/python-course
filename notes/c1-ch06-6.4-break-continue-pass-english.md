## 6. Stop a loop with break

`break` ends the loop immediately.

```python
for invoice in ["INV-001", "INV-002", "INV-URGENT", "INV-004"]:
    print(f"Checking {invoice}")
    if invoice == "INV-URGENT":
        print("Urgent invoice found")
        break
```

**Output**

```text
Checking INV-001
Checking INV-002
Checking INV-URGENT
Urgent invoice found
```

The urgent invoice stops the loop. `INV-004` is not processed.

## 7. Skip an item with continue

`continue` skips the rest of the current iteration.

```python
payments = [10000, 0, 12000]

for payment in payments:
    if payment == 0:
        continue
    print(f"Record payment: {payment}")
```

**Output**

```text
Record payment: 10000
Record payment: 12000
```

The zero payment is skipped. The loop continues to the next payment.

## 8. Use pass as a placeholder

`pass` is an empty statement. It keeps a block valid for later code.

```python
review_required = True

if review_required:
    pass

print("Report continues")
```

**Output**

```text
Report continues
```

`pass` produces no output. It does not stop or skip the loop.

## 9. Use break and continue together

Skip invalid records. Stop at an urgent record.

```python
references = ["INV-001", "", "INV-URGENT", "INV-004"]

for reference in references:
    if reference == "":
        continue
    print(f"Checking {reference}")
    if reference == "INV-URGENT":
        print("Stop for manager")
        break
```

**Output**

```text
Checking INV-001
Checking INV-URGENT
Stop for manager
```

The empty reference is skipped. The urgent reference stops processing.

## 10. Understand decision flow

Statement position changes the output.

```python
for day in range(1, 5):
    if day == 2:
        continue
    print(f"Report day {day}")
    if day == 3:
        break
```

**Output**

```text
Report day 1
Report day 3
```

Day 2 is skipped before printing. Day 3 prints, then stops the loop.

## 11. Synthesis table

| Job | Statement |
|---|---|
| Stop the whole loop | `break` |
| Skip one round | `continue` |
| Keep an empty block valid | `pass` |
| Avoid an invalid item | `continue` |
| Finish at an urgent item | `break` |

## 12. Troubleshooting

### Problem 1
- What happens: records print after the urgent item.
- Likely cause: `continue` was used, or `break` is outside the condition.
- Fix: put `break` inside the urgent condition.
- Prevention: test the item after the expected stop.

### Problem 2
- What happens: one bad item stops everything.
- Likely cause: `break` was used instead of `continue`.
- Fix: use `continue` for a skip.
- Prevention: define stop and skip meanings first.

### Problem 3
- What happens: `pass` does not print or skip.
- Likely cause: its purpose was misunderstood.
- Fix: use `print` for output and `continue` for skipping.
- Prevention: remember that `pass` does nothing.

### Problem 4
- What happens: valid records are skipped.
- Likely cause: the skip condition is too broad.
- Fix: test the exact invalid case.
- Prevention: include valid, invalid, and urgent samples.

## 13. Common Misconceptions

1. **Wrong:** `break` skips one item → **Truth:** it ends the whole loop.
2. **Wrong:** `continue` ends the programme → **Truth:** it moves to the next iteration.
3. **Wrong:** `pass` skips a loop item → **Truth:** it does nothing.
4. **Wrong:** code after `break` still processes the loop → **Truth:** the loop body ends.
5. **Wrong:** an empty block needs no statement → **Truth:** `pass` supplies a valid statement.

## 15. Quiz

1. What does `break` do?  
   a) stops the whole loop  b) adds an item  c) creates a placeholder  
   **Answer: a**, because the loop ends.
2. What does `continue` do?  
   a) skips the current iteration  b) ends the programme  c) resets a total  
   **Answer: a**, because execution moves to the next iteration.
3. What does `pass` do?  
   a) nothing  b) stops the loop  c) deletes an item  
   **Answer: a**, because it is an empty statement.
4. Which statement suits an urgent invoice?  
   a) `break`  b) `continue`  c) `pass`  
   **Answer: a**, because checking must stop.
5. Which statement skips zero payment and continues?  
   a) `pass`  b) `continue`  c) `break`  
   **Answer: b**, because only the current item is skipped.
6. What happens to the next item after `break`?  
   a) it runs  b) it does not run  c) it doubles  
   **Answer: b**, because the loop has ended.
7. What keeps an empty `if` block valid?  
   a) `pass`  b) `break`  c) `range`  
   **Answer: a**, because `pass` is a valid statement.

## 16. Key Idea

`break` ends a loop, `continue` skips one round, and `pass` is only a placeholder. Separate stop, skip, and future-block decisions.

**Rhyme:**  
Urgent means `break`, the journey must now cease,  
Skip a bad item with `continue`, `pass` leaves peace.
