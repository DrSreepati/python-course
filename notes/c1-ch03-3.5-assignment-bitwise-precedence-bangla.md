## 1. Assignment-এর কাজ

Assignment operator `=` variable-এর মধ্যে value রাখে। পরে একই variable-এ নতুন value বসানো যায়।

```python
sales = 12000
sales = sales + 9500
print(sales)
```

**Output**

```text
21500
```

প্রথম line-এ sales-এর শুরু value রাখা হয়েছে। দ্বিতীয় line-এ আগের sales-এর সঙ্গে নতুন sales যোগ হয়েছে।

## 2. `+=`

`+=` হলো `value = value + new_value`-এর সংক্ষিপ্ত রূপ। Running total update করতে এটি খুব কাজে লাগে।

```python
total_sales = 12000
total_sales += 9500
print(total_sales)
```

**Output**

```text
21500
```

`+=` আগের value রেখে তার সঙ্গে নতুন value যোগ করে। এটি assignment এবং addition একসঙ্গে করে।

## 3. `-=`

`-=` আগের value থেকে amount বাদ দেয়। Customer balance বা remaining stock update করতে এটি ব্যবহার করা যায়।

```python
balance = 50000
payment = 12000
balance -= payment
print(balance)
```

**Output**

```text
38000
```

Payment balance থেকে বাদ গেছে। Remaining balance 38000।

## 4. `*=`

`*=` variable-কে কোনো number দিয়ে গুণ করে update করে। Quantity বা rate factor update করার সময় এটি দেখা যায়।

```python
quantity = 10
quantity *= 3
print(quantity)
```

**Output**

```text
30
```

Quantity 10 থেকে 30 হয়েছে, কারণ 10 × 3 করা হয়েছে।

## 5. `/=`

`/=` variable-কে ভাগ করে update করে। Average বা proportional allocation-এর practice-এ এটি কাজে লাগতে পারে।

```python
total_sales = 35000
days = 7
total_sales /= days
print(total_sales)
```

**Output**

```text
5000.0
```

35000 কে 7 দিয়ে ভাগ করে variable-এ average রাখা হয়েছে। `/=` সাধারণত float result দেয়।

## 6. Bitwise ধারণা

Bitwise operator সংখ্যার binary bit নিয়ে কাজ করে। Business code-এ এগুলো কম লাগে, কিন্তু syntax চেনা দরকার। আজ আমরা শুধু ছোট integer example দেখব।

```python
a = 6
b = 3

print(bin(a))
print(bin(b))
```

**Output**

```text
0b110
0b11
```

`bin()` integer-এর binary representation দেখায়। `0b` binary notation বোঝায়।

## 7. `&`, `|`, `^`

`&` দুই bit-ই 1 হলে 1 রাখে। `|` অন্তত একটি 1 হলে 1 রাখে। `^` দুই bit আলাদা হলে 1 রাখে। এগুলোকে আজ accounting formula-এর বদলে concept হিসেবে দেখুন।

```python
a = 6
b = 3

print(a & b)
print(a | b)
print(a ^ b)
```

**Output**

```text
2
7
5
```

6-এর binary `110`, 3-এর binary `011`। Bit-by-bit operation থেকে তিনটি result এসেছে।

## 8. Precedence

এক expression-এ অনেক operator থাকলে Python নির্দিষ্ট precedence মেনে চলে। সাধারণভাবে parentheses আগে, তারপর power, multiplication বা division, শেষে addition বা subtraction।

```python
result = 100 + 20 * 3
print(result)
```

**Output**

```text
160
```

আগে `20 * 3 = 60`, তারপর `100 + 60 = 160`। তাই multiplication addition-এর আগে হয়েছে।

## 9. Parentheses

Parentheses calculation order স্পষ্ট করে এবং reader-এর ভুল কমায়।

```python
result = (100 + 20) * 3
print(result)
```

**Output**

```text
360
```

আগে parentheses-এর ভিতরের যোগ, 120, হয়েছে। তারপর 120 × 3 হয়েছে।

## 10. Invoice formula যাচাই

Discount এবং VAT formula-তে parentheses ব্যবহার করলে business rule পরিষ্কার হয়।

```python
gross = 10000
discount_rate = 0.10
vat_rate = 0.15

total = (gross - gross * discount_rate) * (1 + vat_rate)
print(total)
```

**Output**

```text
10350.0
```

প্রথম parentheses discount বাদ দেয়। দ্বিতীয় parentheses subtotal-কে VAT factor `1.15` দিয়ে গুণ করে।

## Troubleshooting

### Problem 1: Running total reset হয়ে যাচ্ছে

- কী হচ্ছে: নতুন sales যোগ না হয়ে variable-এ অপ্রত্যাশিত value বসছে।
- সম্ভাব্য কারণ: `=+` লেখা হয়েছে, `+=` নয়।
- ধাপ: update line-এ `total += new_value` লিখুন এবং আগের total print করুন।
- প্রতিরোধ: `+=`-কে “আগের value plus” হিসেবে পড়ুন।

### Problem 2: Formula result expected নয়

- কী হচ্ছে: `+` এবং `*` একসঙ্গে থাকায় result বদলে গেছে।
- সম্ভাব্য কারণ: precedence সম্পর্কে ধারণা নেই।
- ধাপ: expression-এ parentheses বসান এবং intermediate value আলাদা করুন।
- প্রতিরোধ: business formula-তে parentheses ব্যবহার করুন।

### Problem 3: `/=`-এর পর integer নয়

- কী হচ্ছে: variable-এর value `5000.0` হয়েছে।
- সম্ভাব্য কারণ: true division সাধারণত float result দেয়।
- ধাপ: প্রয়োজন হলে display format ব্যবহার করুন, অথবা integer দরকার হলে business rule ঠিক করুন।
- প্রতিরোধ: money বা average-এর type আগে নির্ধারণ করুন।

### Problem 4: Bitwise result অচেনা

- কী হচ্ছে: `6 & 3`-এর মতো result arithmetic মনে হচ্ছে না।
- সম্ভাব্য কারণ: bitwise operator binary bit-এ কাজ করে।
- ধাপ: `bin()` দিয়ে দুই input দেখুন, তারপর bit-by-bit compare করুন।
- প্রতিরোধ: bitwise-কে ordinary multiplication বা addition ভাববেন না।

## Common Misconceptions

1. **ভুল:** `=+` এবং `+=` একই → **সত্য:** `=+` নতুন positive value assign করতে পারে, `+=` আগের value-তে যোগ করে।
2. **ভুল:** parentheses কেবল style → **সত্য:** এটি calculation order বদলায় বা স্পষ্ট করে।
3. **ভুল:** `&` money যোগ করে → **সত্য:** `&` bitwise AND করে।
4. **ভুল:** `*` এবং `+` একই order-এ চলে → **সত্য:** multiplication আগে হয়।
5. **ভুল:** assignment operator কেবল প্রথম line-এ লাগে → **সত্য:** running calculation-এ বারবার update লাগে।

**Solution:** `total += 9500`।  
**Output:** `21500`

### Exercise 2

Balance 50000 থেকে payment 12000 বাদ দিন `-=` দিয়ে।

Gross 10000, discount 10%, VAT 15% দিয়ে parentheses ব্যবহার করে total বের করুন।

**Output:** `10350.0`

### Exercise 5: Rafiq bhai-এর debugging bug

Rafiq bhai লিখেছেন:

```python
total_sales = 12000
total_sales =+ 9500
print(total_sales)
```

Boss 21500 আশা করেন, কিন্তু output `9500`।  
**Cause:** `=+` আগের value-তে যোগ করে না, নতুন positive value assign করে।  
**Minimal fix:** `total_sales += 9500`।

```python
total_sales += 9500
print(total_sales)  # Expected: 21500
```

**Lesson:** running total update-এ `+=` ব্যবহার করুন।
