## 1. Assignment

The assignment operator `=` stores a value in a variable. The same variable can receive a new value later.

```python
sales = 12000
sales = sales + 9500
print(sales)
```

**Output**

```text
21500
```

The first line stores the opening value. The second line adds new sales.

## 2. `+=`

`+=` is short for `value = value + new_value`. It is useful for running totals.

```python
total_sales = 12000
total_sales += 9500
print(total_sales)
```

**Output**

```text
21500
```

The old value is kept. The new value is added.

## 3. `-=`

`-=` subtracts from the existing value. It suits customer balances and remaining stock.

```python
balance = 50000
payment = 12000
balance -= payment
print(balance)
```

**Output**

```text
38000
```

The payment is removed from the balance. The remainder is 38000.

## 4. `*=`

`*=` multiplies the existing value and stores the result.

```python
quantity = 10
quantity *= 3
print(quantity)
```

**Output**

```text
30
```

Quantity changes from 10 to 30.

## 5. `/=`

`/=` divides the existing value and stores the result. It can suit an average calculation.

```python
total_sales = 35000
days = 7
total_sales /= days
print(total_sales)
```

**Output**

```text
5000.0
```

The total is divided by seven. True division normally produces a float.

## 6. Bitwise idea

Bitwise operators work on the binary bits of integers. Business code uses them less often, but the syntax is useful to recognise.

```python
a = 6
b = 3

print(bin(a))
print(bin(b))
```

**Output**

```text
0b110
0b11
```

`bin()` shows an integer's binary representation. The `0b` prefix marks binary notation.

## 7. `&`, `|`, `^`

`&` keeps a bit when both bits are 1. `|` keeps it when at least one is 1. `^` keeps it when the bits differ. Treat these as concepts today.

```python
a = 6
b = 3

print(a & b)
print(a | b)
print(a ^ b)
```

**Output**

```text
2
7
5
```

The operations compare the binary bits of 6 and 3.

## 8. Precedence

When an expression has several operators, Python follows precedence. In simple arithmetic, parentheses come first, then powers, multiplication or division, then addition or subtraction.

```python
result = 100 + 20 * 3
print(result)
```

**Output**

```text
160
```

Python calculates `20 * 3` first. It then adds 100.

## 9. Parentheses

Parentheses make calculation order clear. They can also change the result.

```python
result = (100 + 20) * 3
print(result)
```

**Output**

```text
360
```

The addition runs first. The result 120 is then multiplied by 3.

## 10. Checking an invoice formula

Parentheses make discount and VAT rules readable.

```python
gross = 10000
discount_rate = 0.10
vat_rate = 0.15

total = (gross - gross * discount_rate) * (1 + vat_rate)
print(total)
```

**Output**

```text
10350.0
```

The first parentheses removes discount. The second applies the VAT factor, 1.15.

## Troubleshooting

### Problem 1: The running total resets

- What is happening: new sales do not add to the old total.
- Most likely cause: `=+` was written instead of `+=`.
- Fix: use `total += new_value` and print the old total while checking.
- Prevention: read `+=` as “old value plus”.

### Problem 2: The formula result is unexpected

- What is happening: `+` and `*` produce an unexpected order.
- Most likely cause: precedence was not considered.
- Fix: add parentheses and name intermediate values.
- Prevention: use parentheses in business formulas.

### Problem 3: `/=` produces a float

- What is happening: a value such as `5000.0` appears.
- Most likely cause: true division normally returns a float.
- Fix: format the display, or choose an integer rule deliberately.
- Prevention: decide the required type for each business value.

### Problem 4: A bitwise result looks unfamiliar

- What is happening: `6 & 3` does not look like normal arithmetic.
- Most likely cause: bitwise operators work on binary bits.
- Fix: use `bin()` and compare the bits.
- Prevention: do not treat bitwise operators as addition or multiplication.

## Common Misconceptions

1. **Wrong:** `=+` and `+=` are the same → **Truth:** `=+` can assign a new positive value, while `+=` adds to the old value.
2. **Wrong:** parentheses are only style → **Truth:** they make or change calculation order.
3. **Wrong:** `&` adds money → **Truth:** `&` performs bitwise AND.
4. **Wrong:** `*` and `+` have the same order → **Truth:** multiplication comes first.
5. **Wrong:** assignment is only for the first line → **Truth:** running calculations need repeated updates.

## Key Idea

Assignment operators update business values. Precedence calculates multiplication first. Parentheses make business formulas clear and safer.
