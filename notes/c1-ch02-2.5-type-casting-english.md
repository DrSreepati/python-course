## 1. What type casting means

Type casting means changing a value into another type. `"6"` is text, while `int("6")` is the integer 6.

```python
quantity_text = "6"
quantity = int(quantity_text)

print(quantity)
print(type(quantity_text))
print(type(quantity))
```

**Output**

```text
6
<class 'str'>
<class 'int'>
```

`quantity_text` stays as text. `int()` creates a new integer value. That value is stored in `quantity`.

## 2. Whole numbers with `int()`

`int()` makes an integer from suitable text or another number.

```python
items_text = "24"
items = int(items_text)
total_items = items + 6

print(items)
print(total_items)
```

**Output**

```text
24
30
```

`"24"` started as text. `int()` made 24. We can add 6 because both values are integers.

## 3. Decimal numbers with `float()`

`float()` makes a decimal number. It suits a unit price with smaller currency units.

```python
price_text = "250.50"
unit_price = float(price_text)
quantity = 4
amount = unit_price * quantity

print(unit_price)
print(amount)
```

**Output**

```text
250.5
1002.0
```

`float()` changed the price into a decimal number. Python may omit the final zero when printing it.

## 4. Text with `str()`

`str()` makes text from a value. It helps build a report line or invoice label.

```python
invoice_number = "INV-2024-007"
amount = 1002
report_line = str(invoice_number) + ": " + str(amount)

print(report_line)
print(type(report_line))
```

**Output**

```text
INV-2024-007: 1002
<class 'str'>
```

`str()` changed the number into text. The text pieces can then be joined. The invoice was already a string, but the explicit conversion is clear.

## 5. Making a quantity from input

`input()` returns text. Use `int()` before calculating a quantity.

```python
quantity_text = input("Quantity [6]: ") or "6"
quantity = int(quantity_text)

print(quantity)
print(type(quantity))
```

**Output, when the user presses Enter**

```text
Quantity [6]: 6
<class 'int'>
```

Blank input selects the default text `"6"`. `int()` makes it an integer. Arithmetic is now possible.

## 6. Making a price from input

A price may contain decimals, so use `float()` for price text.

```python
price_text = input("Unit price [250.50]: ") or "250.50"
unit_price = float(price_text)
quantity = 4
amount = unit_price * quantity

print(amount)
```

**Output, when the user presses Enter**

```text
Unit price [250.50]: 1002.0
```

The default price text becomes a float. Multiplying it by 4 gives 1002.0.

## 7. Checking the type after conversion

Use `type()` to confirm that conversion succeeded.

```python
quantity = int("6")
unit_price = float("250.50")
label = str(1002)

print(type(quantity))
print(type(unit_price))
print(type(label))
```

**Output**

```text
<class 'int'>
<class 'float'>
<class 'str'>
```

Each function returns a different type. Checking the type confirms what the code really produced.

## 8. Invalid text and errors

`int()` needs text that represents a whole number. `"six"` is not integer text.

```python
quantity_text = "six"
quantity = int(quantity_text)
print(quantity)
```

**Output, Python 3**

```text
ValueError: invalid literal for int() with base 10: 'six'
```

`int()` cannot interpret `"six"`. This is a `ValueError` because the value is not valid for the requested type.

## 9. Keeping business codes as text

A customer code or invoice number may contain digits, but it is still a code. Converting it to an integer can destroy hyphens or leading zeroes.

```python
customer_code = "C-1023"
invoice_number = "INV-2024-007"

print(customer_code)
print(invoice_number)
```

**Output**

```text
C-1023
INV-2024-007
```

Keep codes as strings. Use `int()` for real calculation numbers.

## 10. Safe conversion habits

Handle blank input first. Then convert non-blank input. This avoids turning missing data into a false number.

```python
balance_text = input("Balance [50000]: ")

if balance_text == "":
    balance = None
else:
    balance = int(balance_text)

print(balance)
```

**Output, when the user presses Enter**

```text
Balance [50000]:
None
```

The blank response is handled first. Therefore the program does not call `int("")`. A number goes through the conversion branch.

## Troubleshooting

### Problem 1: `int()` raises a conversion error

- **What is happening:** Python reports a `ValueError`.
- **Most likely cause:** The text contains `"six"` or a decimal instead of a whole number.
- **Step-by-step fix:** 1. Print the input text. 2. Check for blank input. 3. Check the whole-number format. 4. Then call `int()`.
- **How to prevent it:** Validate the input format before conversion.

### Problem 2: `int()` is used for a price

- **What is happening:** `250.50` does not convert as expected.
- **Most likely cause:** `int()` was chosen for decimal text.
- **Step-by-step fix:** 1. Decide whether the price needs decimals. 2. Use `float()` when it does. 3. Print the type. 4. Calculate the amount.
- **How to prevent it:** Choose `int()` for counts and `float()` when a decimal price is needed.

### Problem 3: Text cannot be joined with a number

- **What is happening:** Building a report line raises `TypeError`.
- **Most likely cause:** A string and a number were joined directly.
- **Step-by-step fix:** 1. Inspect both types. 2. Convert the number with `str()`. 3. Join the text. 4. Print the report line.
- **How to prevent it:** Convert every report part to string before joining.

### Problem 4: Blank input raises a conversion error

- **What is happening:** Pressing Enter causes `int("")` or `float("")` to fail.
- **Most likely cause:** Blank input was not handled first.
- **Step-by-step fix:** 1. Test `value == ""`. 2. Use `None` or a default for blank input. 3. Convert non-blank input. 4. Check the result type.
- **How to prevent it:** Decide the blank policy before writing the conversion order.

## Common Misconceptions

1. **Wrong claim:** `int("6")` changes the original text. **Truth:** It returns a new integer value.
2. **Wrong claim:** Every business number should use `int()`. **Truth:** A decimal price may need `float()`.
3. **Wrong claim:** An invoice code should be an integer. **Truth:** A code is text because it may contain letters, hyphens, or leading zeroes.
4. **Wrong claim:** `str()` is only for input. **Truth:** It turns any value into text for a report.
5. **Wrong claim:** `int()` turns blank input into `None`. **Truth:** Blank input must be handled first, or conversion fails.
