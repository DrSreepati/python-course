## 6. `append`: one item at the end

Use `append()` to add a new customer at the end.

```python
customers = ["Rahim Traders", "Karim Store"]
customers.append("Jahid Enterprise")
print(customers)
```

**Output**

```text
['Rahim Traders', 'Karim Store', 'Jahid Enterprise']
```

- `append()` adds one item.
- The item goes at the end.
- The method changes the list.

## 7. `insert`: an item at a seat

Use `insert(index, value)` to place a priority customer first.

```python
customers = ["Karim Store", "Jahid Enterprise"]
customers.insert(0, "Rahim Traders")
print(customers)
```

**Output**

```text
['Rahim Traders', 'Karim Store', 'Jahid Enterprise']
```

- The item takes position `0`.
- Existing items move right.
- A wrong index can change the order.

## 8. `extend`: several items

Use `extend()` to add a branch’s customers together.

```python
customers = ["Rahim Traders"]
new_customers = ["Karim Store", "Jahid Enterprise"]
customers.extend(new_customers)
print(customers)
```

**Output**

```text
['Rahim Traders', 'Karim Store', 'Jahid Enterprise']
```

- `extend()` adds items from another sequence.
- It does not create a nested list.
- `append(new_customers)` would add the whole list as one item.

## 9. `remove`: remove by value

Use `remove(value)` when the closed account’s name is known.

```python
customers = ["Rahim Traders", "Karim Store", "Jahid Enterprise"]
customers.remove("Karim Store")
print(customers)
```

**Output**

```text
['Rahim Traders', 'Jahid Enterprise']
```

- The first matching value is removed.
- A missing value raises `ValueError`.
- A membership check makes removal safer.

## 10. `pop` and `del`

`pop()` removes and returns an item. `del` removes without returning it.

```python
customers = ["Rahim Traders", "Karim Store", "Jahid Enterprise"]
removed_customer = customers.pop(1)
print(removed_customer)
print(customers)

del customers[0]
print(customers)
```

**Output**

```text
Karim Store
['Rahim Traders', 'Jahid Enterprise']
['Jahid Enterprise']
```

- `pop(1)` removes the second item and stores it.
- `del customers[0]` removes the first item.
- `pop()` without an index removes the final item.

## 11. A safe business update

Check that a customer exists before removing it.

```python
customers = ["Rahim Traders", "Karim Store"]
name_to_close = "Jahid Enterprise"

if name_to_close in customers:
    customers.remove(name_to_close)
    print("Customer removed")
else:
    print("Customer not found")

print(customers)
```

**Output**

```text
Customer not found
['Rahim Traders', 'Karim Store']
```

- `in` checks membership.
- `remove` does not run when the name is absent.
- The report shows the unsuccessful lookup clearly.

## 12. Method return values

The method result and the changed list are separate things.

```python
sales = [12000, 9500]
result = sales.append(8800)
print(result)
print(sales)
```

**Output**

```text
None
[12000, 9500, 8800]
```

- `append()` changes the list.
- `append()` normally returns `None`.
- Do not expect `new_sales = sales.append(...)` to hold a list.

## 13. Synthesis table

| Tool | Job |
|---|---|
| `append(x)` | add one item at the end |
| `insert(i, x)` | add one item at a position |
| `extend(items)` | add several items |
| `remove(x)` | remove the first matching value |
| `pop(i)` | remove and return an indexed item |
| `del list[i]` | remove an indexed item |

## 14. Troubleshooting

### Problem 1
- What happens: several customers appear as a nested list.
- Likely cause: `append(new_customers)` was used.
- Fix: use `extend(new_customers)` for separate items.
- Prevention: decide whether the input is one item or many.

### Problem 2
- What happens: `ValueError: list.remove(x): x not in list` appears.
- Likely cause: the value is absent.
- Fix: check `if value in list` first.
- Prevention: never remove external data blindly.

### Problem 3
- What happens: `pop()` removes the wrong customer.
- Likely cause: the index was chosen for the old list.
- Fix: inspect the list immediately before popping.
- Prevention: count indexes as seats.

### Problem 4
- What happens: `None` appears as the append result.
- Likely cause: a mutating method was treated as a list-producing method.
- Fix: use the original list after appending.
- Prevention: remember that mutation does not always return the list.

## 15. Common Misconceptions

1. **Wrong:** `append` adds several items separately → **Truth:** it adds one object.
2. **Wrong:** `extend` stores the whole list as one item → **Truth:** it adds that list’s items.
3. **Wrong:** `remove(0)` removes the first position → **Truth:** it searches for value `0`.
4. **Wrong:** `pop` only deletes → **Truth:** it also returns the removed item.
5. **Wrong:** every list method returns the updated list → **Truth:** some return `None`.

## 17. Quiz

1. Which tool adds one item at the end?  
   a) `append`  b) `remove`  c) `pop`  
   **Answer: a**, because append adds at the end.
2. Where does `insert(0, value)` place an item?  
   a) end  b) beginning  c) nowhere  
   **Answer: b**, because index 0 is first.
3. Which tool adds several items?  
   a) `extend`  b) `del`  c) `remove`  
   **Answer: a**, because extend reads another sequence.
4. What does `remove("Karim Store")` use?  
   a) index  b) value  c) length  
   **Answer: b**, because remove searches by value.
5. What does `pop(1)` do?  
   a) removes and returns the second item  b) adds the first item  c) sorts  
   **Answer: a**, because index 1 is returned after removal.
6. What does `del customers[0]` return?  
   a) removed item  b) `None`  c) nothing  
   **Answer: c**, because `del` is a statement.
7. What does `append` normally return?  
   a) updated list  b) `None`  c) index  
   **Answer: b**, because append changes the list without returning it.

## 18. Key Idea

A list is a working customer register. `append`, `insert`, and `extend` add items. `remove`, `pop`, and `del` remove them.

**Rhyme:**  
Append adds one, extend adds a set,  
Remove old records, keep the list well met.
