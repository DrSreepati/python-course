## 1. String কী

String হলো text-এর sequence। Business code, customer name এবং invoice number সাধারণত string।

```python
customer = "Rahim Traders"
invoice_no = "INV-2024-007"

print(customer)
print(invoice_no)
```

**Output**

```text
Rahim Traders
INV-2024-007
```

Quotes-এর ভিতরের text string। দুইটি variable-এ দুই ধরনের business identifier রাখা হয়েছে।

## 2. String তৈরি

Single quote বা double quote, দুইভাবেই string তৈরি করা যায়। একটি string-এর শুরু এবং শেষে একই ধরনের quote ব্যবহার করুন।

```python
product = "Rice"
warehouse = 'Dhaka'

print(product)
print(warehouse)
```

**Output**

```text
Rice
Dhaka
```

দুই variable-ই `str`। Quote screen-এ print হয় না, শুধু text-এর সীমা বোঝায়।

## 3. Character এবং index

String-এর প্রতিটি অক্ষর বা symbol হলো character। Python প্রতিটি character-কে একটি index বা seat দেয়। Index 0 থেকে শুরু হয়।

```python
code = "C-1023"

print(code[0])
print(code[1])
print(code[2])
```

**Output**

```text
C
-
1
```

`code[0]` প্রথম character, `code[1]` দ্বিতীয় এবং `code[2]` তৃতীয় character।

## 4. Positive indexing

বাম দিক থেকে index 0, 1, 2 এভাবে বাড়ে। Invoice code-এর prefix বা separator পড়তে positive indexing কাজে লাগে।

```python
invoice_no = "INV-2024-007"

print(invoice_no[0])
print(invoice_no[1])
print(invoice_no[2])
print(invoice_no[3])
```

**Output**

```text
I
N
V
-
```

প্রথম তিনটি character `INV`, চতুর্থ character hyphen।

## 5. First এবং last character

First character পেতে index 0 ব্যবহার করি। Last character পেতে negative index বা length ব্যবহার করা যায়।

```python
customer_code = "C-1023"

print(customer_code[0])
print(customer_code[-1])
```

**Output**

```text
C
3
```

`[0]` প্রথম character। `[-1]` শেষ character।

## 6. Negative indexing

ডান দিক থেকে negative index শুরু হয় `-1` দিয়ে। শেষের character `-1`, তার আগেরটি `-2`।

```python
invoice_no = "INV-2024-007"

print(invoice_no[-1])
print(invoice_no[-2])
print(invoice_no[-3])
```

**Output**

```text
7
0
0
```

শেষের তিনটি character হলো `007`। Negative indexing ডান দিক থেকে পড়তে সাহায্য করে।

## 7. Invoice code পড়া

Index দিয়ে code-এর নির্দিষ্ট character দেখা যায়। তবে পুরো অংশ আলাদা করা, slicing, পরের subtopic-এ হবে।

```python
invoice_no = "INV-2024-007"

print(f"Prefix: {invoice_no[0]}{invoice_no[1]}{invoice_no[2]}")
print(f"Last digit: {invoice_no[-1]}")
```

**Output**

```text
Prefix: INV
Last digit: 7
```

প্রথম তিনটি index একসঙ্গে prefix তৈরি করেছে। Negative index দিয়ে শেষ digit নেওয়া হয়েছে।

## 8. Customer code পড়া

Customer code-এর প্রথম character এবং শেষ digit report-এ useful হতে পারে।

```python
customer_code = "C-1023"

print(f"Type marker: {customer_code[0]}")
print(f"Last digit: {customer_code[-1]}")
```

**Output**

```text
Type marker: C
Last digit: 3
```

Index 0 code-এর marker দেয়। Index -1 শেষ digit দেয়।

## 9. String length

`len()` string-এ কতটি character আছে তা দেয়। Valid index-এর শেষ positive position হলো `len(text) - 1`।

```python
invoice_no = "INV-2024-007"

print(len(invoice_no))
print(invoice_no[len(invoice_no) - 1])
```

**Output**

```text
12
7
```

এই invoice code-এ 12টি character। শেষ positive index 11, যা শেষের `7` character।

## 10. Index error

String-এর বাইরে index চাইলে `IndexError` হয়। তাই আগে `len()` জানুন এবং valid range-এর মধ্যে index ব্যবহার করুন।

```python
code = "C-1023"

print(code[5])
```

**Output**

```text
3
```

`C-1023`-এর valid positive index 0 থেকে 5। Index 5 শেষ character দেয়। Index 6 দিলে error হবে।

## Synthesis table

| কাজ | Syntax | Example |
|---|---|---|
| প্রথম character | `text[0]` | `"C-1023"[0]` → `C` |
| দ্বিতীয় character | `text[1]` | `"C-1023"[1]` → `-` |
| শেষ character | `text[-1]` | `"C-1023"[-1]` → `3` |
| শেষের আগেরটি | `text[-2]` | `"C-1023"[-2]` → `2` |
| character count | `len(text)` | `len("C-1023")` → `6` |
| শেষ positive index | `len(text) - 1` | `5` |

## Troubleshooting

### Problem 1: প্রথম character পাওয়া যাচ্ছে না

- কী হচ্ছে: code-এর দ্বিতীয় character দেখা যাচ্ছে।
- সম্ভাব্য কারণ: `[1]` ব্যবহার করা হয়েছে, কিন্তু প্রথম index 0।
- ধাপ: প্রথম character-এর জন্য `[0]` লিখুন।
- প্রতিরোধ: index সবসময় 0 থেকে শুরু মনে রাখুন।

### Problem 2: `IndexError` দেখা যাচ্ছে

- কী হচ্ছে: string-এর বাইরে character চাওয়া হয়েছে।
- সম্ভাব্য কারণ: index `len(text) - 1`-এর চেয়ে বড়।
- ধাপ: `len(text)` print করুন, valid index বেছে নিন।
- প্রতিরোধ: dynamic code-এ আগে length যাচাই করুন।

### Problem 3: শেষ digit পড়তে কষ্ট হচ্ছে

- কী হচ্ছে: string-এর length গুনে বড় index লিখতে হচ্ছে।
- সম্ভাব্য কারণ: negative indexing ব্যবহার করা হয়নি।
- ধাপ: শেষের জন্য `[-1]`, আগের জন্য `[-2]` ব্যবহার করুন।
- প্রতিরোধ: ডান দিকের data-এর জন্য negative index মনে রাখুন।

### Problem 4: Quote output-এ দেখা যাচ্ছে

- কী হচ্ছে: learner ভাবছে quote-ও string-এর character।
- সম্ভাব্য কারণ: code-এর quote delimiter, text-এর অংশ নয়।
- ধাপ: `print(text)` এবং `print(text[0])` আলাদা করে দেখুন।
- প্রতিরোধ: delimiter এবং character আলাদা ধারণা হিসেবে শিখুন।

## Common Misconceptions

1. **ভুল:** প্রথম index 1 → **সত্য:** Python-এ প্রথম index 0।
2. **ভুল:** `[-1]` প্রথম character → **সত্য:** `[-1]` শেষ character।
3. **ভুল:** quote string-এর ভিতরের character → **সত্য:** quote text-এর boundary।
4. **ভুল:** string-এর index পরিবর্তন করা যায় → **সত্য:** index দিয়ে পড়া যায়, পরিবর্তন শেখা হবে পরে।
5. **ভুল:** `len(text)` শেষ index দেয় → **সত্য:** শেষ positive index হলো `len(text) - 1`।

## Quiz

### 1. String-এর প্রথম index কত?

a. `1`  
b. `-1`  
c. `0`  

**উত্তর: c।** Python zero-based indexing ব্যবহার করে।

### 2. `"C-1023"[-1]` কী?

a. `3`  
b. `C`  
c. `2`  

**উত্তর: a।** `-1` শেষ character।

### 3. `len("C-1023")` কত?

a. `5`  
b. `6`  
c. `7`  

**উত্তর: b।** Code-এ ছয়টি character আছে।

### 4. `"INV-2024-007"[3]` কী?

a. `V`  
b. `2`  
c. `-`  

**উত্তর: c।** Index 3-এর character hyphen।

### 5. শেষ positive index কীভাবে পাওয়া যায়?

a. `len(text)`  
b. `len(text) + 1`  
c. `len(text) - 1`  

**উত্তর: c।** Count থেকে এক কম হলো শেষ index।

### 6. `[-2]` কী দেয়?

a. শেষের আগের character  
b. প্রথম character  
c. string length  

**উত্তর: a।** Negative indexing ডান দিক থেকে চলে।

### 7. Valid range-এর বাইরে index দিলে কী হয়?

a. `IndexError`  
b. `None`  
c. `float`  

**উত্তর: a।** String-এ না থাকা seat চাইলে error হয়।

## Key Idea

String text data-এর sequence। Index 0 থেকে শুরু হয়, আর negative index ডান দিক থেকে character পড়তে সাহায্য করে।

**ছড়া ১:** শূন্য seat-এ শুরু, ডানে index বাড়ে,  
**ছড়া ২:** minus একে শেষটি মেলে, code reading সারে।
