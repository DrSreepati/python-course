## 6. Creating a list

A list is like a garland. Each bead is an item. The wholesale shop can store daily sales in one list.

```python
daily_sales = [12000, 9500, 8800, 13200, 7500]
print(daily_sales)
print(len(daily_sales))
```

**Output**

```text
[12000, 9500, 8800, 13200, 7500]
5
```

- Square brackets create a list.
- Commas separate items.
- `len()` counts the items.

## 7. Positive indexes

An index is a seat number in the list. Python calls the first seat `0`.

```python
daily_sales = [12000, 9500, 8800, 13200, 7500]
print(daily_sales[0])
print(daily_sales[3])
```

**Output**

```text
12000
13200
```

- `[0]` reads day one’s sale.
- `[3]` reads day four’s sale.
- Index `3` means the fourth item.

## 8. Negative indexes

Negative indexes read from the end.

```python
daily_sales = [12000, 9500, 8800, 13200, 7500]
print(daily_sales[-1])
print(daily_sales[-2])
```

**Output**

```text
7500
13200
```

- `-1` means the final item.
- `-2` means the item before the final item.
- This helps when the list length is not known.

## 9. Slicing

Slicing takes a section of a list. The form is `list[start:stop]`. The stop position is excluded.

```python
daily_sales = [12000, 9500, 8800, 13200, 7500]
first_three_days = daily_sales[0:3]
last_two_days = daily_sales[-2:]
print(first_three_days)
print(last_two_days)
```

**Output**

```text
[12000, 9500, 8800]
[13200, 7500]
```

- `[0:3]` takes indexes 0, 1, and 2.
- Index 3 is excluded.
- `[-2:]` takes the final two items.

## 10. Slice steps

The third part, `step`, controls the gap between selected items.

```python
daily_sales = [12000, 9500, 8800, 13200, 7500]
alternate_days = daily_sales[::2]
reversed_sales = daily_sales[::-1]
print(alternate_days)
print(reversed_sales)
```

**Output**

```text
[12000, 8800, 7500]
[7500, 13200, 8800, 9500, 12000]
```

- `::2` takes every second item.
- `[::-1]` gives the list in reverse order.
- The original list does not change here.

## 11. A business record list

Lists can contain strings as well as numbers.

```python
customers = ["Rahim Traders", "Karim Store", "Jahid Enterprise"]
print(customers[1])
print(customers[:2])
```

**Output**

```text
Karim Store
['Rahim Traders', 'Karim Store']
```

- `customers[1]` reads the second customer.
- `[:2]` takes the first two items.
- A list can hold text records.

## 12. Troubleshooting

### Problem 1
- What happens: the second sale appears when you ask for the first.
- Likely cause: `[1]` was treated as the first index.
- Fix: use `[0]` for the first item.
- Prevention: remember that the first seat is zero.

### Problem 2
- What happens: `IndexError: list index out of range` appears.
- Likely cause: the index is larger than the final valid index.
- Fix: use indexes up to `len(list) - 1`.
- Prevention: count the items before choosing an index.

### Problem 3
- What happens: a slice contains fewer items than expected.
- Likely cause: the stop position is excluded.
- Fix: put the stop one position after the final wanted index.
- Prevention: remember that `0:3` means 0, 1, and 2.

### Problem 4
- What happens: a reverse slice seems to change the original data.
- Likely cause: the result and original list were not printed separately.
- Fix: print both variables.
- Prevention: slicing normally creates a new list.

## 13. Common Misconceptions

1. **Wrong:** the first index is `1` → **Truth:** Python indexes start at `0`.
2. **Wrong:** a slice includes its stop item → **Truth:** the stop position is excluded.
3. **Wrong:** negative indexes are invalid → **Truth:** they read from the end.
4. **Wrong:** slicing changes the original list → **Truth:** slicing normally creates a new list.
5. **Wrong:** lists can store only numbers → **Truth:** lists can store strings and other types.

## 15. Quiz

1. Which brackets create a list?  
   a) `[]`  b) `{}`  c) `()`  
   **Answer: a**, because square brackets create lists.
2. What is the first item’s index?  
   a) 1  b) 0  c) -1  
   **Answer: b**, because Python is zero-based.
3. What does `sales[-1]` read?  
   a) first item  b) final item  c) middle item  
   **Answer: b**, because `-1` is the final seat.
4. Which indexes does `sales[0:2]` take?  
   a) 0 and 1  b) 0, 1 and 2  c) only 2  
   **Answer: a**, because stop 2 is excluded.
5. What does `sales[::-1]` do?  
   a) returns a reverse copy  b) totals the list  c) removes the first item  
   **Answer: a**, because the step is negative one.
6. What does `len(sales)` return?  
   a) final value  b) item count  c) index list  
   **Answer: b**, because `len()` counts.
7. What does `customers[:2]` take?  
   a) first two items  b) final two items  c) only index 2  
   **Answer: a**, because the start defaults to the beginning.
