## 1. Operator কী

Operator হলো এমন একটি চিহ্ন, যা value-এর উপর কাজ করে। `+` যোগ করে, `-` বিয়োগ করে, `*` গুণ করে, আর `/` ভাগ করে।

```python
sales = 12000
cost = 8500

profit = sales - cost
print(profit)
```

**Output**

```text
3500
```

`sales` এবং `cost` input value। `-` ব্যবহার করে sales থেকে cost বাদ দেওয়া হয়েছে। Result হলো profit।

## 2. যোগ ও বিয়োগ

`+` দিয়ে total বা combined value পাওয়া যায়। `-` দিয়ে difference বা remaining value পাওয়া যায়।

```python
day_one = 12000
day_two = 9500
two_day_sales = day_one + day_two
sales_gap = day_one - day_two

print(two_day_sales)
print(sales_gap)
```

**Output**

```text
21500
2500
```

প্রথম expression দুই দিনের sales যোগ করে। দ্বিতীয় expression দুই দিনের sales-এর পার্থক্য বের করে।

## 3. গুণ ও ভাগ

`*` সাধারণত quantity এবং unit price-এর জন্য ব্যবহার হয়। `/` ভাগ করে এবং সাধারণত decimal result দেয়।

```python
quantity = 8
unit_price = 175
amount = quantity * unit_price
average_daily_sales = amount / 4

print(amount)
print(average_daily_sales)
```

**Output**

```text
1400
350.0
```

`8 * 175` হলো 1400। তারপর 1400 কে 4 দিয়ে ভাগ করে 350.0 পাওয়া যায়।

## 4. Floor division

`//` হলো floor division। এটি ভাগের পূর্ণ অংশ রাখে এবং ভগ্নাংশ বাদ দেয়। Employee বা box-এর পূর্ণ সংখ্যা হিসাবের সময় এটি কাজে লাগে।

```python
items = 23
items_per_box = 5
full_boxes = items // items_per_box

print(full_boxes)
```

**Output**

```text
4
```

23টি item দিয়ে 5টি করে 4টি পূর্ণ box হয়। বাকি item আলাদা করে জানতে `%` ব্যবহার করব।

## 5. Remainder বা modulus

`%` ভাগশেষ দেয়। Stock কতটি পড়ে থাকল, বা টাকা সমান ভাগের পর কত বাকি, তা জানতে এটি ব্যবহার করা যায়।

```python
items = 23
items_per_box = 5
leftover_items = items % items_per_box

print(leftover_items)
```

**Output**

```text
3
```

23 কে 5 দিয়ে ভাগ করলে 4টি পূর্ণ group এবং 3টি item বাকি থাকে। `%` সেই 3 দেখায়।

## 6. Power operator

`**` হলো power operator। এটি একটি সংখ্যাকে নির্দিষ্ট ঘাতে তোলে। Business programming-এ growth বা compound-style practice-এ এটি দেখা যায়।

```python
opening_balance = 1000
growth_factor = 1.10
two_period_value = opening_balance * growth_factor ** 2

print(two_period_value)
```

**Output**

```text
1210.0000000000002
```

`growth_factor ** 2` মানে 1.10-কে দুইবার গুণ করা। Float representation-এর কারণে output-এ সামান্য অতিরিক্ত digit দেখা যেতে পারে।

## 7. একটি sales formula

Sales-এর সহজ formula হলো `quantity * unit_price`। Operator দিয়ে formula লিখলে business language এবং code একসঙ্গে থাকে।

```python
quantity = 12
unit_price = 250
sales = quantity * unit_price

print(f"Sales: {sales:.2f} taka")
```

**Output**

```text
Sales: 3000.00 taka
```

Quantity এবং price গুণ করে sales পাওয়া হয়েছে। `:.2f` display-এ দুই decimal ঘর দেখিয়েছে।

## 8. Stock ভাগ করা

একটি carton-এ নির্দিষ্ট সংখ্যক item থাকে। `//` পূর্ণ carton এবং `%` loose item একসঙ্গে বের করতে পারে।

```python
stock = 47
carton_size = 12
cartons = stock // carton_size
loose_items = stock % carton_size

print(f"Full cartons: {cartons}")
print(f"Loose items: {loose_items}")
```

**Output**

```text
Full cartons: 3
Loose items: 11
```

47টি item থেকে 12টি করে 3টি পূর্ণ carton হয়। 11টি item carton-এর বাইরে থাকে।

## 9. Operator বেছে নেওয়া

প্রশ্নটি আগে business ভাষায় বলুন। Total চাইলে `+`, difference চাইলে `-`, total price চাইলে `*`, average চাইলে `/`, পূর্ণ group চাইলে `//`, remainder চাইলে `%`, এবং repeated multiplication চাইলে `**` ব্যবহার করুন।

```python
weekly_sales = [5000, 4200, 6100, 3800, 5500, 4700, 5700]
total_sales = sum(weekly_sales)
average_sales = total_sales / len(weekly_sales)

print(total_sales)
print(average_sales)
```

**Output**

```text
35000
5000.0
```

`sum()` list-এর value যোগ করে। `len()` কয়টি value আছে তা দেয়। `/` দিয়ে average হিসাব করা হয়েছে।

## 10. Formula যাচাই

Python error না দিলেও formula ভুল হতে পারে। তাই expected business result আগে অনুমান করুন, তারপর output মিলিয়ে দেখুন।

```python
sales = 5000
cost = 4200
profit = sales - cost
margin_base = sales
profit_rate = profit / margin_base * 100

print(profit)
print(profit_rate)
```

**Output**

```text
800
16.0
```

Profit হলো 800। Sales-এর উপর profit ভাগ করে 100 দিয়ে গুণ করলে 16.0 percent পাওয়া যায়।

## Synthesis table

| Operator | নাম | Business কাজ | Example |
|---|---|---|---|
| `+` | addition | total বা combined value | `12000 + 9500` |
| `-` | subtraction | difference বা profit | `sales - cost` |
| `*` | multiplication | amount বা repeated value | `quantity * price` |
| `/` | true division | average বা rate | `total / days` |
| `//` | floor division | পূর্ণ box বা group | `items // box_size` |
| `%` | modulus | ভাগশেষ বা leftover | `items % box_size` |
| `**` | exponentiation | power বা repeated growth | `factor ** 2` |

## Troubleshooting

### Problem 1: Average-এর result পূর্ণ সংখ্যা হয়ে গেছে

- কী হচ্ছে: average-এ decimal অংশ নেই।
- সম্ভাব্য কারণ: `/`-এর বদলে `//` ব্যবহার করা হয়েছে।
- ধাপ: formula-তে true average চাই কি না ঠিক করুন, চাইলে `/` ব্যবহার করুন।
- প্রতিরোধ: পূর্ণ group এবং average-এর জন্য আলাদা operator মনে রাখুন।

### Problem 2: Box-এর সংখ্যা ঠিক, কিন্তু loose item ভুল

- কী হচ্ছে: পূর্ণ box পাওয়া যাচ্ছে, বাকি item পাওয়া যাচ্ছে না।
- সম্ভাব্য কারণ: `%` calculation করা হয়নি বা ভুল divisor ব্যবহার হয়েছে।
- ধাপ: `full = items // size` এবং `leftover = items % size` লিখুন।
- প্রতিরোধ: group count এবং remainder দুটোই report করুন।

### Problem 3: Float result-এ অতিরিক্ত digit দেখা যাচ্ছে

- কী হচ্ছে: result `1210.0000000000002`-এর মতো দেখা যাচ্ছে।
- সম্ভাব্য কারণ: binary float representation।
- ধাপ: display-এর জন্য `:.2f` বা `round()` ব্যবহার করুন, financial storage rule মনে রাখুন।
- প্রতিরোধ: money comparison-এ raw float equality এড়িয়ে চলুন।

### Problem 4: Profit-এর sign উল্টো

- কী হচ্ছে: লাভের জায়গায় negative value দেখা যাচ্ছে।
- সম্ভাব্য কারণ: `cost - sales` লেখা হয়েছে।
- ধাপ: formula লিখুন `profit = sales - cost`, তারপর expected result মিলান।
- প্রতিরোধ: code-এর আগে formula কথায় লিখুন।

## Common Misconceptions

1. **ভুল:** `/` এবং `//` একই → **সত্য:** `/` ভাগের decimal result দেয়, `//` floor division করে।
2. **ভুল:** `%` percentage হিসাব করে → **সত্য:** `%` operator ভাগশেষ দেয়, percentage formula আলাদা।
3. **ভুল:** `*` শুধু money-এর জন্য → **সত্য:** এটি যেকোনো সংখ্যার multiplication করে।
4. **ভুল:** Python error না দিলে formula ঠিক → **সত্য:** silent business error-ও হতে পারে।
5. **ভুল:** `**` string concatenate করে → **সত্য:** `**` power calculation করে।

### Exercise 5: Rafiq bhai-এর debugging bug

Rafiq bhai লিখেছেন:

```python
total_sales = 35000
days = 7
average_sales = total_sales // days
print(average_sales)
```

Boss average sales-এ decimal-সহ সঠিক result চান। Rafiq bhai output পেয়েছেন `5000`, যা এই data-তে একই হলেও অন্য data-তে decimal হারাতে পারে।  
**Cause:** true average-এর জন্য floor division ব্যবহার করা হয়েছে।  
**Minimal fix:** `average_sales = total_sales / days`।

```python
total_sales = 35001
days = 7
average_sales = total_sales / days
print(average_sales)  # Expected: 5000.142857142857
```

**Lesson:** পূর্ণ group চাইলে `//`, সঠিক average চাইলে `/` ব্যবহার করুন।

## Key Idea

Arithmetic operator business formula-কে code-এ রূপ দেয়। `/` average-এর জন্য, `//` পূর্ণ group-এর জন্য, `%` remainder-এর জন্য, আর `**` power-এর জন্য ব্যবহার হয়।

**ছড়া ১:** যোগে total, বিয়োগে লাভ, গুণে amount ঠিক,  
**ছড়া ২:** ভাগে average, ভাগশেষে stock, power-এ growth লিখ।
