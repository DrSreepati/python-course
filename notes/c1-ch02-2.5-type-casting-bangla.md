## 1. Type casting কী

Type casting মানে একটি value-এর type বদলে নতুন value তৈরি করা। যেমন `"6"` হলো text, আর `int("6")` হলো integer 6।

```python
quantity_text = "6"
quantity = int(quantity_text)

print(quantity)
print(type(quantity_text))
print(type(quantity))
```

**Output**

```text
6
<class 'str'>
<class 'int'>
```

`quantity_text` আগের text-ই থাকে। `int()` একটি নতুন integer value তৈরি করে, যা `quantity`-তে রাখা হয়।

## 2. `int()` দিয়ে whole number

`int()` এমন text বা number-কে integer বানায়, যার মানে পূর্ণ সংখ্যা।

```python
items_text = "24"
items = int(items_text)
total_items = items + 6

print(items)
print(total_items)
```

**Output**

```text
24
30
```

প্রথমে `"24"` text ছিল। `int()` সেটিকে 24 বানিয়েছে। তারপর 6 যোগ করা গেছে, কারণ দুই value-ই integer।

## 3. `float()` দিয়ে decimal number

`float()` text বা integer-কে decimal number বানায়। Unit price-এ ছোট currency unit থাকলে এটি কাজে লাগে।

```python
price_text = "250.50"
unit_price = float(price_text)
quantity = 4
amount = unit_price * quantity

print(unit_price)
print(amount)
```

**Output**

```text
250.5
1002.0
```

`float()` price-কে decimal number করেছে। Python `250.50` print করার সময় শেষের zero বাদ দিতে পারে, কিন্তু হিসাবটি decimal type-এ হয়েছে।

## 4. `str()` দিয়ে text

`str()` একটি value-কে text বানায়। Report-এর একটি line বা invoice label তৈরি করতে এটি উপকারী।

```python
invoice_number = "INV-2024-007"
amount = 1002
report_line = str(invoice_number) + ": " + str(amount)

print(report_line)
print(type(report_line))
```

**Output**

```text
INV-2024-007: 1002
<class 'str'>
```

`str()` number-কে text করেছে। তাই text-এর সঙ্গে text জোড়া হয়েছে। এখানে `invoice_number` আগে থেকেই string হলেও `str()` ব্যবহার নিরাপদ ও স্পষ্ট।

## 5. `input()` থেকে quantity বানানো

`input()` text দেয়, তাই quantity-এর হিসাবের আগে `int()` ব্যবহার করুন।

```python
quantity_text = input("Quantity [6]: ") or "6"
quantity = int(quantity_text)

print(quantity)
print(type(quantity))
```

**Output, user Enter চাপলে**

```text
Quantity [6]: 6
<class 'int'>
```

Blank response হলে default text `"6"` নেওয়া হয়। `int()` সেই text-কে integer বানায়। এখন quantity দিয়ে arithmetic করা যায়।

## 6. `input()` থেকে price বানানো

Price-এ decimal থাকতে পারে, তাই price text-এর জন্য `float()` বেছে নিন।

```python
price_text = input("Unit price [250.50]: ") or "250.50"
unit_price = float(price_text)
quantity = 4
amount = unit_price * quantity

print(amount)
```

**Output, user Enter চাপলে**

```text
Unit price [250.50]: 1002.0
```

Default price text float-এ বদলেছে। Quantity 4 দিয়ে গুণ করে amount 1002.0 হয়েছে।

## 7. Conversion-এর পরে `type()`

Conversion সফল হয়েছে কি না, `type()` দিয়ে পরীক্ষা করা যায়।

```python
quantity = int("6")
unit_price = float("250.50")
label = str(1002)

print(type(quantity))
print(type(unit_price))
print(type(label))
```

**Output**

```text
<class 'int'>
<class 'float'>
<class 'str'>
```

প্রতিটি function-এর ফল আলাদা type-এর। Type পরীক্ষা করলে code-এর ধারণা এবং বাস্তব value মিলছে কি না বোঝা যায়।

## 8. Invalid text এবং error

`int()`-এর কাছে পূর্ণ সংখ্যার মতো text দিতে হয়। `"six"` integer text নয়।

```python
quantity_text = "six"
quantity = int(quantity_text)
print(quantity)
```

**Output, Python 3**

```text
ValueError: invalid literal for int() with base 10: 'six'
```

`int()` `"six"` বুঝতে পারেনি। এটি `ValueError`, কারণ text-এর value চাওয়া type-এর জন্য বৈধ নয়। আগে input-এর format যাচাই করা দরকার।

## 9. Business code text রাখা

Customer code বা invoice number দেখতে সংখ্যার মতো হলেও এগুলো code। এগুলোকে integer বানালে শুরুর zero বা hyphen-এর অর্থ নষ্ট হতে পারে।

```python
customer_code = "C-1023"
invoice_number = "INV-2024-007"

print(customer_code)
print(invoice_number)
```

**Output**

```text
C-1023
INV-2024-007
```

Code-এর জন্য `str()` বা string literal ব্যবহার করুন। `int()` শুধু সত্যিকারের হিসাবের সংখ্যার জন্য ব্যবহার করুন।

## 10. Safe conversion-এর অভ্যাস

Conversion-এর আগে blank input সামলান, তারপর conversion করুন। এই ক্রমে missing data-কে ভুল number বানানো হয় না।

```python
balance_text = input("Balance [50000]: ")

if balance_text == "":
    balance = None
else:
    balance = int(balance_text)

print(balance)
```

**Output, user Enter চাপলে**

```text
Balance [50000]:
None
```

Blank input আগে ধরা হয়েছে, তাই `int("")` চালানো হয়নি। User number দিলে `else` branch-এ integer conversion হবে।

## Troubleshooting

### Problem 1: `int()` conversion error

- **কী হচ্ছে:** Python `ValueError` দেখাচ্ছে।
- **সম্ভাব্য কারণ:** text-এ পূর্ণ সংখ্যার বদলে `"six"` বা decimal লেখা আছে।
- **ধাপে ধাপে সমাধান:** 1. input text print করুন। 2. blank কি না দেখুন। 3. পূর্ণ সংখ্যার format যাচাই করুন। 4. তারপর `int()` চালান।
- **পরের বার ঠেকানোর উপায়:** conversion-এর আগে input format যাচাই করুন।

### Problem 2: Price-এ `int()` ব্যবহার করা হয়েছে

- **কী হচ্ছে:** `250.50` convert হচ্ছে না।
- **সম্ভাব্য কারণ:** decimal text-এর জন্য `int()` বেছে নেওয়া হয়েছে।
- **ধাপে ধাপে সমাধান:** 1. price-এ decimal দরকার কি না দেখুন। 2. দরকার হলে `float()` ব্যবহার করুন। 3. type print করুন। 4. amount হিসাব করুন।
- **পরের বার ঠেকানোর উপায়:** quantity-এর জন্য `int()`, price-এর জন্য প্রয়োজন অনুযায়ী `float()` বেছে নিন।

### Problem 3: Text-এর সঙ্গে number জোড়া যাচ্ছে না

- **কী হচ্ছে:** report line বানাতে TypeError হচ্ছে।
- **সম্ভাব্য কারণ:** string এবং number সরাসরি `+` করা হয়েছে।
- **ধাপে ধাপে সমাধান:** 1. দুই value-এর type দেখুন। 2. number-কে `str()` করুন। 3. text জোড়া দিন। 4. report line print করুন।
- **পরের বার ঠেকানোর উপায়:** text concatenation-এর আগে সব অংশ string করুন।

### Problem 4: Blank input conversion error

- **কী হচ্ছে:** user Enter চাপলে `int("")` বা `float("")` error দেয়।
- **সম্ভাব্য কারণ:** blank response conversion-এর আগে ধরা হয়নি।
- **ধাপে ধাপে সমাধান:** 1. `value == ""` পরীক্ষা করুন। 2. blank হলে `None` বা default নিন। 3. non-blank হলে conversion করুন। 4. ফলের type পরীক্ষা করুন।
- **পরের বার ঠেকানোর উপায়:** blank policy এবং conversion order আগে লিখে নিন।

## Common Misconceptions

1. **ভুল দাবি:** `int("6")` আগের text value বদলে দেয়। **সত্য:** এটি নতুন integer value ফেরত দেয়।
2. **ভুল দাবি:** সব business number-এ `int()` ব্যবহার করা যায়। **সত্য:** decimal price-এর জন্য `float()` দরকার হতে পারে।
3. **ভুল দাবি:** invoice code-কে integer করা উচিত। **সত্য:** code হলো text, কারণ এতে letters, hyphens, বা leading zero থাকতে পারে।
4. **ভুল দাবি:** `str()` শুধু input-এর জন্য। **সত্য:** যেকোনো value-কে text report অংশে বদলাতে `str()` ব্যবহার করা যায়।
5. **ভুল দাবি:** blank input-এ `int()` নিজে `None` বানায়। **সত্য:** blank আগে সামলাতে হয়, নইলে conversion error হয়।

```python
quantity_text = "6"
quantity = int(quantity_text)
print(quantity)
```

```text
6
```

## Quiz

### 1. `int("6")` কী ফেরত দেয়?

a) `"6"`  
b) `6`  
c) `6.0`  

**Answer:** b. `int()` text number-কে integer করে।

### 2. Decimal price text-এর জন্য কোন function উপযুক্ত?

a) `str()`  
b) `int()`  
c) `float()`  

**Answer:** c. `float()` decimal value তৈরি করে।

### 3. `str(1002)` কী দেয়?

a) `"1002"`  
b) `1002`  
c) `None`  

**Answer:** a. `str()` value-কে text বানায়।

### 4. `int("six")` সাধারণত কোন error দেয়?

a) `NameError`  
b) `ValueError`  
c) `SyntaxError`  

**Answer:** b. Text-এর value integer conversion-এর জন্য বৈধ নয়।

### 5. Invoice code `"INV-2024-007"` কী হিসেবে রাখা উচিত?

a) `float`  
b) `int`  
c) `str`  

**Answer:** c. Code-এ letters এবং hyphens আছে, তাই এটি text।

### 6. Blank balance conversion-এর আগে কী করা উচিত?

a) blank পরীক্ষা করা  
b) সব সময় 0 করা  
c) `int("")` চালানো  

**Answer:** a. Blank হলে `None` বা default নেওয়া যায়।

### 7. `float("250.50")`-এর type কী?

a) `str`  
b) `float`  
c) `NoneType`  

**Answer:** b. `float()` decimal number তৈরি করে।
