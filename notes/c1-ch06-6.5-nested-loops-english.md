## 6. The first nested loop

A loop inside another loop is a nested loop.

```python
customers = ["Rahim Traders", "Karim Store"]
invoice_numbers = [1, 2]

for customer in customers:
    for invoice_number in invoice_numbers:
        print(f"{customer}: invoice {invoice_number}")
```

**Output**

```text
Rahim Traders: invoice 1
Rahim Traders: invoice 2
Karim Store: invoice 1
Karim Store: invoice 2
```

The outer loop takes one customer. The inner loop processes two invoices. Then the outer loop takes the next customer.

## 7. Customer invoice totals

Add each customer’s invoice amounts separately.

```python
customer_names = ["Rahim Traders", "Karim Store"]
invoice_amounts = [[12000, 8000], [7000, 5000]]

for name, amounts in zip(customer_names, invoice_amounts):
    total = 0
    for amount in amounts:
        total += amount
    print(f"{name}: {total}")
```

**Output**

```text
Rahim Traders: 20000
Karim Store: 12000
```

`total = 0` runs for each customer. The inner loop adds that customer’s amounts.

## 8. Nested range()

Nested ranges can create report rows and columns.

```python
for customer_number in range(1, 3):
    for invoice_number in range(1, 4):
        print(f"Customer {customer_number}, invoice {invoice_number}")
```

**Output**

```text
Customer 1, invoice 1
Customer 1, invoice 2
Customer 1, invoice 3
Customer 2, invoice 1
Customer 2, invoice 2
Customer 2, invoice 3
```

The inner loop runs three times for each customer. Total work is 2 × 3, or 6 prints.

## 9. Break in the inner loop

`break` normally stops the closest loop containing it.

```python
customers = ["Rahim Traders", "Karim Store"]
invoices = ["INV-001", "INV-URGENT", "INV-003"]

for customer in customers:
    for invoice in invoices:
        print(f"{customer}: {invoice}")
        if invoice == "INV-URGENT":
            break
```

**Output**

```text
Rahim Traders: INV-001
Rahim Traders: INV-URGENT
Karim Store: INV-001
Karim Store: INV-URGENT
```

Each inner loop stops at the urgent invoice. The outer loop still takes the next customer.

## 10. An overall business total

Keep group totals and the overall total separately.

```python
invoice_groups = [[12000, 8000], [7000, 5000]]
overall_total = 0

for amounts in invoice_groups:
    group_total = 0
    for amount in amounts:
        group_total += amount
        overall_total += amount
    print(f"Group total: {group_total}")

print(f"Overall total: {overall_total}")
```

**Output**

```text
Group total: 20000
Group total: 12000
Overall total: 32000
```

`group_total` resets for each group. `overall_total` starts once and keeps every amount.

## 11. Synthesis table

| Job | Loop design |
|---|---|
| Visit customers | outer loop |
| Visit their invoices | inner loop |
| Customer total | zero before inner loop |
| Overall total | zero before all loops |
| Stop urgent detail | `break` in inner loop |

## 12. Troubleshooting

### Problem 1
- What happens: only the last customer’s total appears.
- Likely cause: the total was not reset inside the outer loop.
- Fix: set the customer total to zero for each outer pass.
- Prevention: name group and overall totals separately.

### Problem 2
- What happens: an invoice is processed once only.
- Likely cause: the inner loop is not indented inside the outer loop.
- Fix: place the inner loop inside the outer body.
- Prevention: check four-space indentation.

### Problem 3
- What happens: an urgent invoice stops later customers too.
- Likely cause: break scope was misunderstood.
- Fix: remember that inner break stops only the inner loop.
- Prevention: test with two customers.

### Problem 4
- What happens: the total is too large.
- Likely cause: the overall accumulator is reset inside a loop.
- Fix: initialise overall total before all loops.
- Prevention: keep group and overall totals separate.

## 13. Common Misconceptions

1. **Wrong:** nested loops receive two items together → **Truth:** the inner loop runs for each outer item.
2. **Wrong:** the inner loop runs once → **Truth:** it runs on every outer pass.
3. **Wrong:** inner `break` stops every loop → **Truth:** it stops the closest loop.
4. **Wrong:** all totals should share one variable → **Truth:** group and overall totals differ.
5. **Wrong:** nested work equals outer work → **Truth:** inner repetition increases work.

## 15. Quiz

1. What is a nested loop?  
   a) a loop inside a loop  b) a loop outside a condition  c) a string  
   **Answer: a**, because the inner loop is in the outer body.
2. What does the outer loop usually change?  
   a) the group or customer  b) every total  c) syntax  
   **Answer: a**, because it controls the larger unit.
3. What does the inner loop process?  
   a) detail for the outer item  b) a file name  c) programme exit  
   **Answer: a**, because details are in the inner sequence.
4. When should a group total be zeroed?  
   a) at each outer pass  b) after all loops  c) never  
   **Answer: a**, because groups are separate.
5. What does inner `break` normally stop?  
   a) the closest loop  b) the whole programme  c) the outer loop always  
   **Answer: a**, because it applies to the nearest loop.
6. How many passes are two outer and three inner passes?  
   a) 5  b) 6  c) 3  
   **Answer: b**, because 2 × 3 equals 6.
7. Where should an overall total start?  
   a) before all loops  b) inside the inner loop  c) after printing  
   **Answer: a**, because it must keep every group.

## 16. Key Idea

The outer loop handles the larger unit. The inner loop handles its details. Reset group totals inside. Start the overall total before all loops.

**Rhyme:**  
Outside the customer, inside each invoice line,  
Two loops build the report, one clear step at a time.
