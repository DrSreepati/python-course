## 1. Immutability কী

Immutability মানে তৈরি হওয়ার পরে কোনো value-এর ভেতরের অংশ সরাসরি বদলানো যায় না। Python-এর string immutable, অর্থাৎ string-এর character-কে তার index দিয়ে update করা যায় না।

```python
customer_code = "C-1023"

print(customer_code)
print(customer_code[0])
```

**Output**

```text
C-1023
C
```

Index দিয়ে character পড়া যায়। কিন্তু index দিয়ে character বসিয়ে original string বদলানো যায় না।

গুরুত্বপূর্ণ পার্থক্য:

- string immutable, তাই ভেতরের character direct update করা যায় না।
- variable mutable নয়, এমন নয়। Variable-এ নতুন string assign করা যায়।

## 2. String-এর character সরাসরি বদলানো

List-এর item index দিয়ে update করা যায়, কিন্তু string-এর character যায় না। তাই নিচের code error দেবে।

```python
invoice_no = "INV-2024-007"
invoice_no[0] = "X"
```

**Output**

```text
TypeError: 'str' object does not support item assignment
```

`invoice_no[0]` একটি character পড়ার expression। এটি assignment-এর target হতে পারে না, কারণ `str` object-এর item assignment support নেই।

Error-এর plain meaning:

- Python বলছে, string-এর ভেতরের item-এ নতুন value বসানো যায় না।
- নতুন string বানিয়ে variable-এ assign করতে হবে।

## 3. Error বোঝা

Immutability error দেখলে original string-এর কোনো অংশ direct update না করে update plan বদলাতে হবে।

```python
customer_code = "C-1023"

try:
    customer_code[0] = "S"
except TypeError as error:
    print(type(error).__name__)
    print(error)
```

**Output**

```text
TypeError
'str' object does not support item assignment
```

এখানে `try` এবং `except` শুধু error message দেখানোর জন্য ব্যবহার করা হয়েছে। Exception handling-এর পূর্ণ আলোচনা Chapter 12-এ হবে। মূল ধারণা হলো, string item assignment অনুমোদিত নয়।

## 4. নতুন string বানানো

Original string না বদলে নতুন string বানিয়ে একই variable-এ assign করা যায়। এতে পুরোনো string object বদলায় না, variable নতুন result-এর দিকে যায়।

```python
customer_name = "Rahim Traders"

updated_name = "Mr. " + customer_name

print(customer_name)
print(updated_name)
```

**Output**

```text
Rahim Traders
Mr. Rahim Traders
```

`customer_name` original value রেখেছে। `updated_name` নতুন string। Concatenation `+` দিয়ে দুইটি string জোড়া লেগেছে।

## 5. Concatenation ব্যবহার

Concatenation মানে string জোড়া লাগানো। `+` দিয়ে নতুন string তৈরি হয়।

```python
prefix = "INV"
year = "2024"
serial = "007"

invoice_no = prefix + "-" + year + "-" + serial
print(invoice_no)
```

**Output**

```text
INV-2024-007
```

প্রতিটি অংশ আলাদা variable-এ ছিল। Hyphen-সহ concatenation নতুন invoice code তৈরি করেছে।

একটি string-এর সঙ্গে number সরাসরি যোগ করা যায় না। এখানে সব অংশ string হওয়ায় code ঠিকভাবে চলছে।

## 6. Slicing দিয়ে middle অংশ বদলানো

কোনো character বা অংশ বদলাতে original string-এর আগে এবং পরের অংশ slice করে, মাঝখানে নতুন text বসানো যায়।

```python
invoice_no = "INV-2024-007"

updated_invoice = invoice_no[:4] + "2025" + invoice_no[8:]

print(invoice_no)
print(updated_invoice)
```

**Output**

```text
INV-2024-007
INV-2025-007
```

`invoice_no[:4]` prefix এবং প্রথম hyphen রেখেছে। `invoice_no[8:]` দ্বিতীয় hyphen থেকে serial রেখেছে। মাঝখানে `"2025"` বসিয়ে নতুন invoice তৈরি হয়েছে।

এটি direct character assignment নয়। এটি তিনটি অংশ জোড়া দিয়ে নতুন string বানানো।

## 7. `replace()` দিয়ে safe update

নির্দিষ্ট text বদলাতে `replace()` ব্যবহার করা যায়। এটি original string বদলায় না, নতুন string ফেরত দেয়।

```python
invoice_no = "INV-2024-007"
updated_invoice = invoice_no.replace("2024", "2025")

print(invoice_no)
print(updated_invoice)
```

**Output**

```text
INV-2024-007
INV-2025-007
```

Original invoice একই আছে। `updated_invoice`-এ নতুন year এসেছে। এটি slicing boundary গোনার চেয়ে readable, যখন বদলানোর text জানা থাকে।

`replace()` সব matching অংশ বদলাতে পারে। তাই business data-তে exact target নির্বাচন করুন।

## 8. `split()` এবং `join()` দিয়ে update

Invoice-এর অংশ list-এ ভেঙে একটি item বদলে আবার join করা যায়। এতে parts স্পষ্ট দেখা যায়।

```python
invoice_no = "INV-2024-007"
parts = invoice_no.split("-")
parts[1] = "2025"
updated_invoice = "-".join(parts)

print(parts)
print(updated_invoice)
```

**Output**

```text
['INV', '2025', '007']
INV-2025-007
```

এখানে string immutable হলেও `parts` একটি list, তাই list-এর item update করা গেছে। শেষে `join()` নতুন string বানিয়েছে।

সতর্কতা: list-এর item বদলেছে, original `invoice_no` বদলায়নি।

## 9. Original ও updated value রাখা

Business report-এ audit বা comparison-এর জন্য original এবং updated দুইটি value রাখা useful।

```python
raw_invoice = " inv/2024/007 "

clean_invoice = raw_invoice.strip().upper().replace("/", "-")

print(f"Original: {raw_invoice}")
print(f"Cleaned: {clean_invoice}")
```

**Output**

```text
Original:  inv/2024/007 
Cleaned: INV-2024-007
```

Original input audit trail-এর জন্য রাখা হয়েছে। Cleaned value report-এর জন্য তৈরি হয়েছে। নতুন value বানানো immutability-এর সঙ্গে সামঞ্জস্যপূর্ণ।

## 10. Business code correction workflow

একটি customer code-এর prefix বদলাতে direct assignment করা যাবে না। Slicing করে নতুন code বানানো যায়।

```python
customer_code = "C-1023"

supplier_code = "S" + customer_code[1:]

print(customer_code)
print(supplier_code)
```

**Output**

```text
C-1023
S-1023
```

`customer_code[1:]` hyphen এবং number রেখেছে। `"S"` যোগ করে নতুন supplier code বানানো হয়েছে। Original customer code অক্ষত আছে।

## Synthesis table

| কাজ | Wrong idea | Safe pattern | Result |
|---|---|---|---|
| প্রথম character বদলানো | `text[0] = "X"` | `"X" + text[1:]` | নতুন string |
| মাঝের অংশ বদলানো | direct assignment | `text[:start] + new + text[stop:]` | নতুন string |
| জানা text বদলানো | character assignment | `text.replace(old, new)` | নতুন string |
| separator-যুক্ত অংশ বদলানো | string item update | `parts = text.split(...)`, update, `join()` | নতুন string |
| original রাখা | overwrite only | `old_text`, `new_text` দুই variable | audit-friendly |
| string পড়া | `text[index]` | একই syntax | character result |

## Troubleshooting

### Problem 1: `TypeError` দেখা যাচ্ছে

- কী হচ্ছে: learner `text[0] = "X"` দিয়ে character বদলাতে চেয়েছে।
- সম্ভাব্য কারণ: string immutable।
- ধাপ: পুরোনো অংশ slice করুন, নতুন অংশ যোগ করুন, অথবা `replace()` ব্যবহার করুন।
- প্রতিরোধ: string-এ direct item assignment না লেখুন।

### Problem 2: নতুন result তৈরি হলেও original বদলায়নি

- কী হচ্ছে: updated value print করলে নতুন text দেখা যায়, কিন্তু original variable পুরোনো।
- সম্ভাব্য কারণ: Python নতুন string ফেরত দিয়েছে, original object বদলায়নি।
- ধাপ: result নতুন variable-এ রাখুন, অথবা প্রয়োজন হলে `text = text.replace(...)` লিখুন।
- প্রতিরোধ: original এবং updated value-এর উদ্দেশ্য আলাদা রাখুন।

### Problem 3: slicing update-এ একটি character হারিয়েছে

- কী হচ্ছে: নতুন string-এ prefix বা suffix-এর একটি অংশ নেই।
- সম্ভাব্য কারণ: slice boundary ভুল, বিশেষ করে stop index excluded নিয়ম ভুলে যাওয়া।
- ধাপ: আগে prefix এবং suffix আলাদাভাবে print করুন, তারপর নতুন অংশ জোড়া দিন।
- প্রতিরোধ: boundary-এর আগে ও পরে কোন character থাকবে তা লিখে নিন।

### Problem 4: `split()` এবং `join()` update-এ format ভুল

- কী হচ্ছে: invoice-এ hyphen কম বা বেশি হয়েছে।
- সম্ভাব্য কারণ: split separator ও join separator এক নয়, অথবা empty item তৈরি হয়েছে।
- ধাপ: parts list print করুন, item count দেখুন, তারপর সঠিক separator দিয়ে join করুন।
- প্রতিরোধ: update-এর আগে এবং পরে code format যাচাই করুন।

## Common Misconceptions

1. **ভুল:** variable immutable হলে নতুন value assign করা যায় না → **সত্য:** variable-এ নতুন string assign করা যায়।
2. **ভুল:** `text[0]` দিয়ে character বদলানো যায় → **সত্য:** এটি শুধু character পড়ার জন্য।
3. **ভুল:** `replace()` original string-এর ভেতর বদলে দেয় → **সত্য:** নতুন string ফেরত দেয়।
4. **ভুল:** `split()` করলে original string list হয়ে যায় → **সত্য:** original string থাকে, আলাদা list result তৈরি হয়।
5. **ভুল:** একই variable-এ নতুন string assign করলে পুরোনো text object বদলায় → **সত্য:** variable নতুন object-এর reference ধরে।

### Exercise 5: Rafiq bhai-এর debugging bug

Rafiq bhai invoice year বদলাতে লিখেছেন:

invoice_no = "INV-2024-007"

```text
INV-2025-007
```

**Lesson:** string বদলাতে direct assignment নয়, নতুন string তৈরি করতে হয়।

**উত্তর: b।** `replace()` নতুন string ফেরত দেয়।

### 6. `replace()` সাধারণত কী ফেরত দেয়?

a. নতুন string  
b. list

**উত্তর: a।** Original না বদলে নতুন string result আসে।

### 7. `invoice_no[:4] + "2025" + invoice_no[8:]` কী করে?

a. invoice মুছে দেয়  
b. নতুন year-সহ নতুন invoice বানায়  
c. শুধু year খুঁজে

**উত্তর: b।** Prefix, নতুন year এবং suffix জোড়া লাগে।

## Key Idea

String immutable, তাই character বা slice-এ direct assignment করা যায় না। Slicing, concatenation, `replace()`, অথবা `split()` ও `join()` ব্যবহার করে নতুন string বানাতে হয়। Original এবং updated value আলাদা রাখা business audit-এর জন্য ভালো।

**ছড়া ১:** string ভাঙে না, নতুন রূপে সাজে,  
**ছড়া ২:** slice জোড়া লাগাও, clean code কাজে বাজে।
