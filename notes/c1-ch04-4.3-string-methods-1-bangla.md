## 1. String method কী

String method হলো string-এর সঙ্গে কাজ করার জন্য Python-এর তৈরি একটি কাজের নিয়ম। Dot `.` দিয়ে string variable-এর পরে method লিখি, আর parentheses `()` দিয়ে method চালাই।

```python
customer = "Rahim Traders"

print(customer.upper())
print(customer.lower())
```

**Output**

```text
RAHIM TRADERS
rahim traders
```

`customer.upper()` বড় হাতের text তৈরি করেছে। `customer.lower()` ছোট হাতের text তৈরি করেছে। Original variable `customer` একই আছে।

গুরুত্বপূর্ণ line:

- `customer = "Rahim Traders"` original business text রাখে।
- `customer.upper()` একটি নতুন uppercase result তৈরি করে।
- `customer.lower()` একটি নতুন lowercase result তৈরি করে।

## 2. `lower()` দিয়ে ছোট হাতের অক্ষর

`lower()` string-এর ইংরেজি অক্ষরগুলো lowercase করে। Case-insensitive comparison বা search-এর আগে এটি useful।

```python
entered_name = "RAHIM TRADERS"
standard_name = entered_name.lower()

print(standard_name)
print(standard_name == "rahim traders")
```

**Output**

```text
rahim traders
True
```

User বড় হাতের অক্ষরে লিখলেও `lower()` standard form বানিয়েছে। পরে lowercase reference-এর সঙ্গে comparison করা হয়েছে।

`lower()` সংখ্যা, hyphen বা space সরায় না। এটি মূলত ইংরেজি অক্ষরের case বদলায়।

## 3. `upper()` দিয়ে বড় হাতের অক্ষর

`upper()` string-এর ইংরেজি অক্ষরগুলো uppercase করে। Report heading, code label বা standard display-এর জন্য এটি কাজে লাগে।

```python
customer = "Karim Store"
report_name = customer.upper()

print(report_name)
print(customer)
```

**Output**

```text
KARIM STORE
Karim Store
```

`report_name`-এ uppercase result রাখা হয়েছে। Original `customer` বদলায়নি। তাই method-এর result প্রয়োজন হলে নতুন variable-এ রাখা ভালো।

## 4. `strip()` দিয়ে দুই পাশের space

`strip()` string-এর শুরু এবং শেষের whitespace সরায়। Whitespace বলতে space, tab বা line break-এর মতো ফাঁকা জায়গা বোঝায়।

```python
raw_name = "  Rahim Traders  "
clean_name = raw_name.strip()

print(clean_name)
print(len(raw_name))
print(len(clean_name))
```

**Output**

```text
Rahim Traders
17
13
```

Original text-এ দুই পাশে দুইটি করে space ছিল। `strip()` সেগুলো সরিয়ে customer name পরিষ্কার করেছে। মাঝের space, অর্থাৎ `Rahim` এবং `Traders`-এর মাঝের space, সরায়নি।

`strip()`-এর related forms:

- `lstrip()` শুধু বাম পাশের whitespace সরায়।
- `rstrip()` শুধু ডান পাশের whitespace সরায়।
- আজকের মূল method হলো `strip()`।

## 5. `replace()` দিয়ে text বদলানো

`replace(old, new)` string-এর old অংশ খুঁজে new অংশ বসায়। এটি নতুন string result তৈরি করে।

```python
invoice_no = "INV/2024/007"
standard_invoice = invoice_no.replace("/", "-")

print(standard_invoice)
```

**Output**

```text
INV-2024-007
```

`replace("/", "-")` প্রতিটি slash-এর জায়গায় hyphen বসিয়েছে। Invoice reference-এর format standard হয়েছে।

নির্দিষ্ট সংখ্যক replacement চাইলে তৃতীয় argument দেওয়া যায়:

```python
note = "paid paid pending"

print(note.replace("paid", "checked", 1))
print(note.replace("paid", "checked"))
```

**Output**

```text
checked paid pending
checked checked pending
```

তৃতীয় argument `1` শুধু প্রথম matching অংশ বদলেছে। Argument না দিলে সব matching অংশ বদলায়।

## 6. `count()` দিয়ে occurrence গোনা

`count()` কোনো character বা text কতবার আছে তা গুনে integer result দেয়। এটি case-sensitive।

```python
invoice_no = "INV-2024-007"

print(invoice_no.count("-"))
print(invoice_no.count("0"))
print(invoice_no.count("INV"))
```

**Output**

```text
2
3
1
```

Invoice-এ দুইটি hyphen, তিনটি zero এবং একটি `INV` আছে। `count()` overlapping pattern আলাদা করে গণনা করে না, তাই text pattern নির্বাচন করার সময় সতর্ক থাকতে হয়।

Case-sensitive উদাহরণ:

```python
customer = "Rahim rahim"

print(customer.count("rahim"))
print(customer.lower().count("rahim"))
```

**Output**

```text
1
2
```

প্রথম count শুধু ছোট হাতের `rahim` খুঁজেছে। আগে `lower()` চালালে দুই ধরনের case একই হয়ে যায়।

## 7. Methods একসঙ্গে ব্যবহার

একটি raw business field পরিষ্কার করতে একাধিক method ধারাবাহিকভাবে ব্যবহার করা যায়। ভেতরের method আগে চলে, তারপর বাইরের method।

```python
raw_customer = "  RAHIM traders  "

clean_customer = raw_customer.strip().lower()
display_customer = clean_customer.upper()

print(clean_customer)
print(display_customer)
```

**Output**

```text
rahim traders
RAHIM TRADERS
```

প্রথমে দুই পাশের space সরেছে, তারপর সব অক্ষর lowercase হয়েছে। পরে একই cleaned result থেকে report display-এর জন্য uppercase text তৈরি হয়েছে।

এক লাইনে অনেক method লেখা যায়, কিন্তু beginner হিসেবে প্রতিটি stage আলাদা variable-এ রাখলে ভুল খুঁজে পাওয়া সহজ।

## 8. Business customer name পরিষ্কার

Customer master data-তে একই নাম mixed case এবং extra space-সহ আসতে পারে। `strip()` এবং `lower()` একটি comparison form তৈরি করতে সাহায্য করে।

```python
customer_from_form = "  rahim TRADERS "
customer_key = customer_from_form.strip().lower()
known_key = "rahim traders"

print(customer_key)
print(customer_key == known_key)
```

**Output**

```text
rahim traders
True
```

এখানে `customer_key` display name নয়, comparison-এর জন্য standard key। Original spelling report-এ রাখতে হলে original value আলাদা করে রাখতে হবে।

## 9. Invoice reference পরিষ্কার

একজন sales assistant slash, space বা lowercase দিয়ে invoice reference লিখতে পারে। নির্দিষ্ট format থাকলে `strip()`, `upper()` এবং `replace()` দিয়ে standard form বানানো যায়।

```python
raw_invoice = " inv/2024/007 "

clean_invoice = raw_invoice.strip().upper().replace("/", "-")

print(clean_invoice)
print(clean_invoice.count("-"))
```

**Output**

```text
INV-2024-007
2
```

Method-এর ক্রম গুরুত্বপূর্ণ। আগে outer spaces সরানো হয়েছে, তারপর uppercase, শেষে slash hyphen হয়েছে। Result-এ দুইটি separator আছে।

## 10. Method ব্যবহারের common ভুল

Method-এর নাম এবং parentheses দুটোই দরকার। শুধু method name লিখলে method চালানো হয় না। আবার method result variable-এ না রাখলে original variable automatically বদলায় না।

```python
name = "  Karim Store  "

print(name.strip)
print(name.strip())

clean_name = name.strip()
print(clean_name)
```

**Output**

```text
<built-in method strip of str object at ...>
Karim Store
Karim Store
```

প্রথম output-এর memory address Python version ও run-এর উপর নির্ভর করতে পারে, তাই এটি নির্দিষ্ট output হিসেবে মুখস্থ করা উচিত নয়। `name.strip()` method চালায়। `clean_name = name.strip()` result-টি সংরক্ষণ করে।

## Troubleshooting

### Problem 1: `strip()`-এর পরও মাঝের space আছে

- কী হচ্ছে: `"Rahim Traders"`-এর মাঝখানের space সরেনি।
- সম্ভাব্য কারণ: `strip()` শুধু শুরু এবং শেষের whitespace সরায়।
- ধাপ: দুই পাশ পরিষ্কার করতে `strip()` ব্যবহার করুন; সব space বদলাতে হলে `replace(" ", "")`-এর business effect আগে বুঝুন।
- প্রতিরোধ: outer space এবং internal separator আলাদা সমস্যা হিসেবে চিনুন।

### Problem 2: `upper` বা `lower` কাজ করছে না

- কী হচ্ছে: text বদলানোর বদলে method-এর reference দেখা যাচ্ছে।
- সম্ভাব্য কারণ: parentheses `()` বাদ গেছে।
- ধাপ: `text.upper()` বা `text.lower()` লিখুন, তারপর result print করুন।
- প্রতিরোধ: method চালানোর সময় সবসময় parentheses মনে রাখুন।

### Problem 3: `replace()` করার পর original variable বদলায়নি

- কী হচ্ছে: নতুন output একবার দেখা গেলেও পুরোনো variable print করলে পুরোনো text আসে।
- সম্ভাব্য কারণ: result নতুন variable-এ রাখা হয়নি, অথবা original variable update করা হয়নি।
- ধাপ: `clean_text = text.replace(...)` লিখুন, অথবা প্রয়োজন হলে `text = text.replace(...)` লিখুন।
- প্রতিরোধ: নতুন result সংরক্ষণ করার সিদ্ধান্ত আগে নিন।

### Problem 4: `count()` কম সংখ্যা দিচ্ছে

- কী হচ্ছে: learner যে spelling বা case আশা করেছে, count তা খুঁজে পায়নি।
- সম্ভাব্য কারণ: `count()` case-sensitive।
- ধাপ: case standard করতে `lower()` বা `upper()` ব্যবহার করুন, তারপর count করুন।
- প্রতিরোধ: search এবং count-এর আগে text-এর case ঠিক করুন।

## Common Misconceptions

1. **ভুল:** `strip()` string-এর সব space সরায় → **সত্য:** এটি শুধু শুরু এবং শেষের whitespace সরায়।
2. **ভুল:** `upper` লিখলেই method চলে → **সত্য:** method চালাতে `upper()` লিখতে হয়।
3. **ভুল:** `replace()` original string স্থায়ীভাবে বদলে দেয় → **সত্য:** result নতুন string হিসেবে ফেরত আসে।
4. **ভুল:** `count("a")` বড় হাতের `A`-ও গুনবে → **সত্য:** `count()` case-sensitive।
5. **ভুল:** `lower()` invoice-এর hyphen বা number সরিয়ে দেয় → **সত্য:** এটি মূলত alphabet-এর case বদলায়।

### 1. `lower()` কী করে?

**উত্তর: a।** `strip()` দুই পাশের whitespace সরায়।

### 3. `"A/B".replace("/", "-")` কী দেয়?

a. `A/B`  
b. `A-B`  
c. `A B`

**উত্তর: b।** Slash-এর জায়গায় hyphen বসে।

### 4. `"INV-2024-007".count("-")` কত?

a. `1`  
b. `3`  
c. `2`

**উত্তর: c।** Invoice code-এ দুইটি hyphen আছে।

### 5. `upper()` চালাতে কোনটি দরকার?

a. `[]`  
b. `()`  
c. `{}`

**উত্তর: b।** Parentheses method call করে।

### 6. `replace()`-এর result কীভাবে ধরে রাখা যায়?

a. `clean = text.replace(old, new)`  
b. `clean = text.count(old)`  
c. `clean = text[old, new]`

**উত্তর: a।** `replace()` নতুন string ফেরত দেয়।

### 7. `count()` সাধারণত কী ফেরত দেয়?

a. `str`  
b. `bool`  
c. `int`

**উত্তর: c।** Occurrence-এর সংখ্যা integer হয়।

## Key Idea

`lower()` ও `upper()` case standard করে, `strip()` দুই পাশের whitespace সরায়, `replace()` text বদলায় এবং `count()` occurrence গুনে। Business data পরিষ্কার করতে method-এর ক্রম এবং result সংরক্ষণ দুটোই গুরুত্বপূর্ণ।

**ছড়া ১:** strip করে দুই ধার, lower-upper সাজে,  
**ছড়া ২:** replace বদলায়, count গুনে, clean data কাজে লাগে।
