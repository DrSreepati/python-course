## 5. Compound condition কী?

একটি condition-এর ভিতরে একাধিক comparison থাকলে তাকে compound condition বলা যায়। Dhaka-র wholesale দোকানে discount পেতে order বড় এবং balance নিরাপদ, দুটোই লাগতে পারে।

```python
order_amount = 12000
customer_balance = 32000

if order_amount >= 10000 and customer_balance >= 30000:
    print("Discount review approved")
else:
    print("Discount review held")
```

**Output**

```text
Discount review approved
```

`and`-এর দুই পাশের comparison সত্য। তাই approval block চলে। যেকোনো একটি false হলে `else` চলত।

## 6. `and`: সব শর্ত সত্য

`and` মানে সব প্রয়োজনীয় শর্ত পূরণ করতে হবে। এটি nested if-এর একটি সংক্ষিপ্ত রূপ হতে পারে।

```python
order_amount = 10000
customer_balance = 30000
profit = 2500

if order_amount >= 10000 and customer_balance >= 30000 and profit > 0:
    print("Approve profitable credit order")
else:
    print("Review order")
```

**Output**

```text
Approve profitable credit order
```

তিনটি comparison-ই true। `and` তাদের একসঙ্গে জোড়া দিয়েছে। Exact boundary 10000 এবং 30000-ও accepted হয়েছে।

## 7. `or`: অন্তত একটি শর্ত

কখনও customer-কে দুইটি কারণে priority দেওয়া যায়। একটি কারণ সত্য হলেই rule সত্য হয়।

```python
customer_name = "Karim Store"
outstanding = 32000
order_amount = 8000

if outstanding >= 30000 or order_amount >= 15000:
    priority = "Manager review"
else:
    priority = "Normal review"

print(f"{customer_name}: {priority}")
```

**Output**

```text
Karim Store: Manager review
```

Outstanding 32000 হওয়ায় প্রথম শর্ত true। Order 15000 না হলেও `or`-এর কারণে পুরো condition true।

## 8. `not`: শর্তের বিপরীত

`not` true-কে false এবং false-কে true করে। Business code-এ পরিষ্কার নামের Boolean variable-এর সঙ্গে এটি পড়তে সহজ হয়।

```python
payment_received = False

if not payment_received:
    print("Payment follow-up required")
else:
    print("Payment received")
```

**Output**

```text
Payment follow-up required
```

`payment_received` false। `not` সেটিকে true করে, তাই follow-up message আসে।

## 9. Parentheses এবং mixed rules

`and` এবং `or` একসঙ্গে থাকলে parentheses business intention স্পষ্ট করে। আগে rule-টি বাংলায় বলুন, পরে code লিখুন।

```python
order_amount = 12000
customer_balance = 32000
urgent_request = False

if (order_amount >= 10000 and customer_balance >= 30000) or urgent_request:
    print("Send to manager")
else:
    print("Keep in normal queue")
```

**Output**

```text
Send to manager
```

Parentheses-এর ভিতরের দুই শর্ত true, তাই পুরো left side true। `urgent_request` false হলেও `or`-এর কারণে ফল true থাকে।

## 10. Compound business classifications

Compound rules দিয়ে overdue status এবং payment status আলাদা করা যায়।

```python
customer_name = "Rahim Traders"
outstanding = 50000
days_overdue = 12
payment_received = False

if outstanding > 0 and days_overdue > 0 and not payment_received:
    status = "Overdue follow-up"
elif outstanding == 0 or payment_received:
    status = "Clear"
else:
    status = "Review account"

print(f"{customer_name}: {status}")
```

**Output**

```text
Rahim Traders: Overdue follow-up
```

প্রথম rule-এ outstanding এবং overdue দুটোই positive, payment-ও পাওয়া যায়নি। তাই follow-up status নির্বাচিত হয়েছে।

## 11. Boundary testing

Compound rule-এ প্রতিটি threshold-এর নিচে, ঠিক সমান, এবং উপরে test করুন।

```python
order_amount = 9999
balance = 30000

if order_amount >= 10000 and balance >= 30000:
    print("Eligible")
else:
    print("Not eligible")
```

**Output**

```text
Not eligible
```

Balance threshold পেরোলেও order 9999 হওয়ায় `and` rule false। তাই একটিমাত্র failure-ও approval আটকায়।

## 12. Readability এবং rule naming

দীর্ঘ condition-এর অর্থ variable-এ নাম দিলে audit সহজ হয়। নামটি rule-এর business meaning বলবে।

```python
order_amount = 13200
customer_balance = 71000
payment_received = True

large_order = order_amount >= 10000
safe_balance = customer_balance >= 30000
paid = payment_received

if large_order and safe_balance and paid:
    print("Release order")
else:
    print("Hold order")
```

**Output**

```text
Release order
```

তিনটি named Boolean rule input-কে readable করেছে। শেষ condition-এ business decision দেখা যাচ্ছে, raw numbers নয়।

## 13. Synthesis table

| Business meaning | Python tool |
|---|---|
| সব শর্ত সত্য চাই | `and` |
| যেকোনো একটি শর্ত যথেষ্ট | `or` |
| একটি শর্ত সত্য নয় চাই | `not` |
| mixed rule পরিষ্কার করা | parentheses |
| long rule readable করা | named Boolean variables |

## 14. Troubleshooting

### সমস্যা 1
- কী হচ্ছে: একটি valid order-ও rejected হচ্ছে।
- সম্ভাব্য কারণ: `and`-এর একটি comparison false।
- Fix: প্রতিটি comparison আলাদা variable বা print দিয়ে পরীক্ষা করুন।
- Prevention: নিচে, সমান, উপরের boundary তিনটিই test করুন।

### সমস্যা 2
- কী হচ্ছে: balance অথবা order, যেকোনো একটি থাকলেই approval হচ্ছে না।
- সম্ভাব্য কারণ: `and` ব্যবহার করা হয়েছে, অথচ rule-এ alternative দরকার।
- Fix: অন্তত একটি কারণ যথেষ্ট হলে `or` ব্যবহার করুন।
- Prevention: code-এর আগে rule-টি “সব” না “যেকোনো” বলে লিখুন।

### সমস্যা 3
- কী হচ্ছে: urgent request থাকা সত্ত্বেও normal queue হচ্ছে।
- সম্ভাব্য কারণ: parentheses ছাড়া mixed rule-এর grouping ভুল বোঝা হয়েছে।
- Fix: intended group parentheses-এর ভিতরে লিখুন।
- Prevention: mixed `and` এবং `or` rule-এ parentheses সবসময় দিন।

### সমস্যা 4
- কী হচ্ছে: payment পাওয়া গেলেও follow-up message আসছে।
- সম্ভাব্য কারণ: `not payment_received` ভুলভাবে অন্য condition-এর সঙ্গে জোড়া হয়েছে।
- Fix: Boolean value print করুন এবং `not` কোন expression-এ লাগছে দেখুন।
- Prevention: positive নাম, যেমন `payment_received`, ব্যবহার করুন।

## 15. Common Misconceptions

1. **ভুল:** `and` মানে যেকোনো একটি সত্য → **সত্য:** `and`-এ সব শর্ত সত্য লাগে।
2. **ভুল:** `or`-এ দুই শর্তই সত্য লাগবে → **সত্য:** অন্তত একটি সত্য হলেই চলে।
3. **ভুল:** `not` variable বদলে দেয় → **সত্য:** expression-এর ফল উল্টে দেয়, variable বদলায় না।
4. **ভুল:** parentheses শুধু সাজানোর জন্য → **সত্য:** mixed rule-এর grouping পরিষ্কার করে।
5. **ভুল:** named Boolean অপ্রয়োজনীয় → **সত্য:** business rule audit এবং debugging সহজ হয়।

## 18. Key Idea

`and` সব শর্ত চায়, `or` বিকল্প শর্তে চলে, আর `not` ফল উল্টে দেয়। Parentheses এবং named Boolean ব্যবহার করলে compound business rule পড়া ও audit করা সহজ হয়।

**ছড়া:**  
সব দরজা খুললে `and` বলে, কাজটি তবে হবে,  
একটি পথ পেলেই `or`, `not` উল্টো রবে।
