## 6. Union: দুই দলের সব unique item

Union দুই set মিলিয়ে সব unique value দেয়। Dhaka wholesale business-এর দুই দিনের invoice list একত্র করতে এটি কাজে লাগে।

```python
monday = {"INV-001", "INV-002", "INV-003"}
tuesday = {"INV-003", "INV-004"}

all_invoices = monday | tuesday
print(sorted(all_invoices))
```

**Output**

```text
['INV-001', 'INV-002', 'INV-003', 'INV-004']
```

`|` দুই set-এর সব value নেয়। `INV-003` দুই দিনে থাকলেও একবার এসেছে।

## 7. Intersection: দুই দলের common item

Intersection শুধু দুই set-এ থাকা value রাখে। এটি দুইটি report-এ একই invoice আছে কি না দেখতে সাহায্য করে।

```python
sales_report = {"INV-001", "INV-002", "INV-003"}
payment_report = {"INV-002", "INV-003", "INV-004"}

matched = sales_report & payment_report
print(sorted(matched))
```

**Output**

```text
['INV-002', 'INV-003']
```

`&` হলো common অংশ। `INV-001` payment report-এ নেই, তাই বাদ গেছে।

## 8. Difference: এক set-এ আছে, অন্যটিতে নেই

Difference-এর দিক গুরুত্বপূর্ণ। `sales - payment` মানে sales-এ আছে কিন্তু payment-এ নেই।

```python
sales_report = {"INV-001", "INV-002", "INV-003"}
payment_report = {"INV-002", "INV-003", "INV-004"}

unpaid_candidates = sales_report - payment_report
print(sorted(unpaid_candidates))
```

**Output**

```text
['INV-001']
```

এটি unpaid candidate। বিপরীতটি, `payment_report - sales_report`, payment report-এর extra invoice দেখাবে।

## 9. Symmetric difference: শুধু এক পাশে থাকা value

Symmetric difference common value বাদ দিয়ে দুই পাশে থাকা আলাদা value দেয়।

```python
sales_report = {"INV-001", "INV-002", "INV-003"}
payment_report = {"INV-002", "INV-003", "INV-004"}

report_difference = sales_report ^ payment_report
print(sorted(report_difference))
```

**Output**

```text
['INV-001', 'INV-004']
```

`INV-001` শুধু sales-এ, `INV-004` শুধু payment-এ। তাই দুটিই exception।

## 10. Operation method হিসেবেও লেখা যায়

Operator ছোট এবং readable। একই কাজ method দিয়েও লেখা যায়।

```python
branch_a = {"C-101", "C-102"}
branch_b = {"C-102", "C-103"}

print(sorted(branch_a.union(branch_b)))
print(sorted(branch_a.intersection(branch_b)))
print(sorted(branch_a.difference(branch_b)))
print(sorted(branch_a.symmetric_difference(branch_b)))
```

**Output**

```text
['C-101', 'C-102', 'C-103']
['C-102']
['C-101']
['C-101', 'C-103']
```

Method-এর নাম বেশি স্পষ্ট। `union()` নতুন set ফেরত দেয়, মূল set বদলায় না।

## 11. Business comparison report

Boss জানতে চান, sales এবং payment register-এর মধ্যে কোন invoice মিলে, কোনটি অসম্পূর্ণ, এবং কোনটি extra।

```python
sales = {"INV-2024-007", "INV-2024-008", "INV-2024-009"}
payments = {"INV-2024-008", "INV-2024-009", "INV-2024-010"}

print("Matched:", sorted(sales & payments))
print("Needs payment check:", sorted(sales - payments))
print("Payment register extra:", sorted(payments - sales))
print("All exceptions:", sorted(sales ^ payments))
```

**Output**

```text
Matched: ['INV-2024-008', 'INV-2024-009']
Needs payment check: ['INV-2024-007']
Payment register extra: ['INV-2024-010']
All exceptions: ['INV-2024-007', 'INV-2024-010']
```

প্রথম line matched records, দ্বিতীয় line sales-এর missing payment, তৃতীয় line payment-এর extra record, শেষ line দুই ধরনের exception একসঙ্গে দেখায়।

## 12. Synthesis table

| Tool | অর্থ | Business কাজ |
|---|---|---|
| `a \| b` | সব unique value | দুই দিনের সব invoice |
| `a & b` | common value | sales-payment match |
| `a - b` | শুধু a-তে | unpaid candidate |
| `a ^ b` | শুধু এক পাশে | reconciliation exception |
| `sorted(set)` | readable order | report output |

## 13. Troubleshooting

### সমস্যা 1: output-এর order বদলে যাচ্ছে
- **সহজ ভাষায়:** set position বা fixed order রাখে না।
- **সম্ভাব্য কারণ:** set সরাসরি print করা হয়েছে।
- **ধাপে ধাপে fix:** set তৈরি করুন, `sorted(result)` করুন, তারপর print করুন।
- **পরেরবার প্রতিরোধ:** report-এর output-এর আগে `sorted()` ব্যবহার করুন।

### সমস্যা 2: common invoice-এর বদলে সব invoice এসেছে
- **সহজ ভাষায়:** union ব্যবহার করলে common নয়, সব unique value আসে।
- **সম্ভাব্য কারণ:** `&`-এর বদলে `|` লেখা হয়েছে।
- **ধাপে ধাপে fix:** common চাইলে `sales & payments` লিখুন।
- **পরেরবার প্রতিরোধ:** matched মানে intersection, এই জোড়াটি মনে রাখুন।

### সমস্যা 3: difference-এর ফল উল্টো হয়েছে
- **সহজ ভাষায়:** প্রথম set-টি হলো report-এর starting side।
- **সম্ভাব্য কারণ:** `payments - sales` লিখে sales-এর missing invoice খোঁজা।
- **ধাপে ধাপে fix:** sales-এ আছে, payment-এ নেই চাইলে `sales - payments` লিখুন।
- **পরেরবার প্রতিরোধ:** operation পড়ুন, “a থেকে b বাদ”।

### সমস্যা 4: মূল set বদলে গেছে মনে হচ্ছে
- **সহজ ভাষায়:** operation সাধারণত নতুন set দেয়, মূল set নয়।
- **সম্ভাব্য কারণ:** result variable না রেখে output পরীক্ষা করা হয়েছে।
- **ধাপে ধাপে fix:** `exceptions = sales ^ payments` লিখে আলাদা variable রাখুন।
- **পরেরবার প্রতিরোধ:** audit data এবং calculated report আলাদা নামে রাখুন।

## 14. Common Misconceptions

1. **ভুল:** union শুধু common value দেয় → **সত্য:** union সব unique value দেয়।
2. **ভুল:** intersection-এ এক set-এর সব value থাকে → **সত্য:** দুই set-এর common value থাকে।
3. **ভুল:** `a - b` এবং `b - a` একই → **সত্য:** difference দিকনির্ভর।
4. **ভুল:** symmetric difference common value রাখে → **সত্য:** common value বাদ দেয়।
5. **ভুল:** set-এ index দিয়ে item নেওয়া যায় → **সত্য:** set unordered, membership বা operation ব্যবহার করুন।

## 15. Exercises with solutions

### Exercise 1
`north = {"C-101", "C-102"}` এবং `south = {"C-102", "C-103"}`-এর সব customer ID বের করুন।

**Solution**

```python
north = {"C-101", "C-102"}
south = {"C-102", "C-103"}
print(sorted(north | south))
```

**Output:** `['C-101', 'C-102', 'C-103']`

### Exercise 2
দুই report-এর matched invoice বের করুন।

**Solution**

```python
first = {"INV-01", "INV-02", "INV-03"}
second = {"INV-02", "INV-04"}
print(sorted(first & second))
```

**Output:** `['INV-02']`

### Exercise 3
sales-এ আছে কিন্তু collection-এ নেই এমন invoice বের করুন।

**Solution**

```python
sales = {"INV-01", "INV-02", "INV-03"}
collection = {"INV-02"}
print(sorted(sales - collection))
```

**Output:** `['INV-01', 'INV-03']`

### Exercise 4
দুই branch-এর exclusive customer ID বের করুন।

**Solution**

```python
dhaka = {"C-101", "C-102"}
chattogram = {"C-102", "C-104"}
print(sorted(dhaka ^ chattogram))
```

**Output:** `['C-101', 'C-104']`

### Exercise 5: Sreepati debugging bug
Sreepati matched invoice খুঁজতে union লিখেছেন:

```python
sales = {"INV-01", "INV-02"}
payments = {"INV-02", "INV-03"}
matched = sales | payments
print(sorted(matched))
```

Wrong output: `['INV-01', 'INV-02', 'INV-03']`. Boss বললেন, “সব invoice নয়, শুধু দুই register-এ থাকা invoice চাই।”

**Diagnosis:** union সব unique value নেয়। Matched value-এর জন্য intersection দরকার।

**Minimal fix**

```python
matched = sales & payments
print(sorted(matched))
```

**Output:** `['INV-02']`

**Lesson:** matched মানে intersection, তাই `&` ব্যবহার করুন।

## 17. Key Idea

Set operation business comparison সহজ করে। `|` সব unique, `&` common, `-` exclusive, `^` exception দুপাশে খোঁজে।

**ছড়া ১:**  
মিললে `&`, সব হলে `|`,  
বাদে `-`, exception `^` ঠিকই মিল।

**ছড়া ২:**  
Register দুই পাশে যখন হয় দেখা,  
Set বলে কোনটি মেলেনি, কোনটি একা।
