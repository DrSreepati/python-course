## 5. Nested if কী?

একটি `if` block-এর ভিতরে থাকা আরেকটি `if`-কে nested if বলে। Dhaka-র wholesale দোকানে আগে দেখা যেতে পারে order বড় কি না, তারপর customer-এর balance দেখে approval দেওয়া যায়।

```python
order_amount = 12000
customer_balance = 32000

if order_amount >= 10000:
    if customer_balance >= 30000:
        print("Discount review approved")
    else:
        print("Hold for balance review")
else:
    print("Order too small")
```

**Output**

```text
Discount review approved
```

প্রথম `if` order-এর দরজা। দ্বিতীয় `if` শুধু বড় order হলে পরীক্ষা হয়। দুই comparison সত্য হওয়ায় approval ছাপা হয়।

## 6. Outer এবং inner condition

বাইরের শর্ত broad eligibility ঠিক করে। ভিতরের শর্ত সেই eligible case-এর আরও নির্দিষ্ট সিদ্ধান্ত নেয়।

```python
customer_name = "Rahim Traders"
order_amount = 9500
customer_balance = 50000

if order_amount >= 10000:
    if customer_balance >= 30000:
        decision = "Review approved"
    else:
        decision = "Review held"
else:
    decision = "Not eligible"

print(f"{customer_name}: {decision}")
```

**Output**

```text
Rahim Traders: Not eligible
```

`customer_name`, `order_amount` এবং `customer_balance` data ধরে। বাইরের শর্ত মিথ্যা, তাই ভিতরের শর্তে যাওয়া হয়নি। শেষে common `decision` ছাপা হয়েছে।

## 7. Nested if-else দিয়ে তিনটি ফল

প্রথমে order size, পরে payment status দেখা যায়।

```python
order_amount = 15000
outstanding = 0

if order_amount >= 10000:
    if outstanding == 0:
        label = "Large order, paid"
    else:
        label = "Large order, payment pending"
else:
    label = "Small order"

print(label)
```

**Output**

```text
Large order, paid
```

প্রথম comparison বড় order নিশ্চিত করে। দ্বিতীয় comparison zero outstanding আলাদা business meaning দেয়। তিনটি possible label-এর একটি বেছে নেওয়া হয়।

## 8. তিন স্তরের nested decision

একাধিক প্রশ্ন ধারাবাহিকভাবে করতে হলে nesting তিন স্তরেও যেতে পারে। তবে প্রতিটি indentation block পরিষ্কার রাখতে হবে।

```python
customer_balance = 71000
order_amount = 13200
profit = 2500

if customer_balance >= 30000:
    if order_amount >= 10000:
        if profit > 0:
            print("Approve profitable credit order")
        else:
            print("Review profit before approval")
    else:
        print("Review order size")
else:
    print("Hold customer account")
```

**Output**

```text
Approve profitable credit order
```

প্রথমে account eligibility, তারপর order size, শেষে profit দেখা হয়েছে। প্রতিটি ভিতরের block তার আগের শর্তের সত্য branch-এর অংশ।

## 9. Branch audit এবং boundary

Nested code-এ boundary value আলাদা করে পরীক্ষা করা জরুরি। `>= 10000` হলে 10000 eligible, আর 9999 eligible নয়।

```python
order_amount = 10000
customer_balance = 29999

if order_amount >= 10000:
    if customer_balance >= 30000:
        print("Approve")
    else:
        print("Hold: balance below threshold")
else:
    print("Reject: order below threshold")
```

**Output**

```text
Hold: balance below threshold
```

Order boundary পেরিয়েছে, কিন্তু balance boundary পেরোয়নি। তাই outer true এবং inner false branch চলছে।

## 10. অপ্রয়োজনীয় nesting কমানো

কখনও nested if-এর বদলে `and` একই business rule সংক্ষেপে প্রকাশ করে। আজ nested form আগে বুঝে, পরে equivalent form দেখা হচ্ছে।

```python
order_amount = 12000
customer_balance = 32000

if order_amount >= 10000 and customer_balance >= 30000:
    print("Approve")
else:
    print("Hold")
```

**Output**

```text
Approve
```

`and`-এ দুই শর্ত সত্য হতে হয়। ছোট rule-এ এটি সহজ, কিন্তু আলাদা failure message দরকার হলে nested if বেশি পরিষ্কার।

## 12. Troubleshooting

### সমস্যা 1
- কী হচ্ছে: inner message কখনও দেখা যাচ্ছে না।
- সম্ভাব্য কারণ: outer condition false।
- Fix: outer value এবং comparison print করে দেখুন, তারপর boundary 9999 ও 10000 পরীক্ষা করুন।
- Prevention: decision table-এ outer false case লিখুন।

### সমস্যা 2
- কী হচ্ছে: inner `else` ভুল customer-কে message দিচ্ছে।
- সম্ভাব্য কারণ: indentation ভুল।
- Fix: inner `else`-কে inner `if`-এর সমান indentation দিন।
- Prevention: প্রতি block-এ চারটি space ব্যবহার করুন।

### সমস্যা 3
- কী হচ্ছে: 10000-এর order বাদ যাচ্ছে।
- সম্ভাব্য কারণ: `>` ব্যবহার করা হয়েছে।
- Fix: inclusive threshold হলে `>=` লিখুন।
- Prevention: exact boundary দিয়ে একটি test চালান।

### সমস্যা 4
- কী হচ্ছে: approval হলেও balance-এর কারণ বোঝা যাচ্ছে না।
- সম্ভাব্য কারণ: সব failure-কে একটি generic `else`-এ মেশানো হয়েছে।
- Fix: outer এবং inner false branch-এর আলাদা message রাখুন।
- Prevention: প্রতিটি business rule-এর আলাদা output ঠিক করুন।

## 13. Common Misconceptions

1. **ভুল:** inner `if` সবসময় পরীক্ষা হয় → **সত্য:** outer condition সত্য হলেই inner block চলে।
2. **ভুল:** nesting মানেই loop → **সত্য:** nesting শুধু একটি block-এর ভিতরে আরেকটি block।
3. **ভুল:** `>=` এবং `>` একই → **সত্য:** `>=` boundary value-ও গ্রহণ করে।
4. **ভুল:** সব nested if এক লাইনে লেখা ভালো → **সত্য:** readable indentation business audit সহজ করে।
5. **ভুল:** nested if-এ একাধিক ফল রাখা যায় না → **সত্য:** প্রতিটি branch-এ আলাদা ফল রাখা যায়।

```python
order_amount = 8000
```

```python
    if balance >= 30000:
        print("Approve")
    else:
        print("Hold")
else:
    print("Small order")
```

```text
Small order
```

Lesson: nested workflow-এ eligibility-এর প্রতিটি gate স্পষ্টভাবে লিখতে হয়।

## 16. Key Idea

Nested if মানে, প্রথম দরজা পেরিয়ে দ্বিতীয় দরজা পরীক্ষা করা। Outer rule eligibility, inner rule detail। ছোট rule-এ `and`, আলাদা কারণ দরকার হলে nested block ব্যবহার করুন।

ধাপে ধাপে business rule, ভুল পথ নিজেই বলে।
