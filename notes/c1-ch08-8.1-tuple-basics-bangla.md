## 6. Tuple কী

Tuple হলো কয়েকটি value-এর ordered group। List-এর মতো position থাকে, কিন্তু tuple তৈরি হওয়ার পরে item বদলানো যায় না।

```python
invoice_summary = ("INV-2024-007", "Rahim Traders", 50000)
print(invoice_summary)
```

**Output**

```text
('INV-2024-007', 'Rahim Traders', 50000)
```

- parentheses tuple-এর সাধারণ চিহ্ন।
- order বজায় থাকে।
- একই tuple-এ text এবং number থাকতে পারে।

## 7. Tuple তৈরি

Parentheses ছাড়াও comma tuple তৈরি করে।

```python
customer = "Rahim Traders", 50000
print(customer)

single_value = ("INV-2024-007",)
print(single_value)
```

**Output**

```text
('Rahim Traders', 50000)
('INV-2024-007',)
```

একটি item-এর tuple-এ trailing comma অবশ্যই দরকার। `("code")` শুধু string।

## 8. Indexing

Tuple-এর index list-এর মতো zero-based।

```python
invoice_summary = ("INV-2024-007", "Rahim Traders", 50000)
print(invoice_summary[0])
print(invoice_summary[1])
print(invoice_summary[-1])
```

**Output**

```text
INV-2024-007
Rahim Traders
50000
```

প্রথম item index 0, শেষ item negative index -1।

## 9. Slicing

Tuple slice করলে নতুন tuple পাওয়া যায়।

```python
weekly_summary = ("Mon", 5000, "Tue", 4200, "Wed", 6100)
print(weekly_summary[0:3])
print(weekly_summary[2:])
```

**Output**

```text
('Mon', 5000, 'Tue')
('Tue', 4200, 'Wed', 6100)
```

Start included, stop excluded। Slice original tuple বদলায় না।

## 10. Immutability

Tuple-এর item assignment করা যায় না।

```python
invoice_summary = ("INV-2024-007", "Rahim Traders", 50000)
invoice_summary[2] = 55000
```

**Output**

```text
TypeError: 'tuple' object does not support item assignment
```

এই error expected। Fixed invoice identity বা approved category-এর মতো data accidental change থেকে রক্ষা করতে tuple উপকারী।

## 11. Tuple পড়া এবং হিসাব

Tuple immutable হলেও loop করা যায় এবং item পড়া যায়।

```python
daily_sales = (12000, 9500, 8800, 13200, 7500)
total = sum(daily_sales)
best = max(daily_sales)

print(total)
print(best)
```

**Output**

```text
51000
13200
```

Tuple read-only হওয়া মানে এটি ব্যবহার করা যায় না, এমন নয়। পড়া, slice, `sum()` এবং `max()` করা যায়।

## 12. List থেকে tuple

Mutable list-এর fixed snapshot বানানো যায়।

```python
report = [12000, 9500, 8800]
approved_report = tuple(report)
report[0] = 13000

print(report)
print(approved_report)
```

**Output**

```text
[13000, 9500, 8800]
(12000, 9500, 8800)
```

`tuple(report)` সময়ের একটি snapshot তৈরি করেছে। পরে list বদলালেও tuple বদলায় না।

Run the practice file to confirm every output.

## 14. Troubleshooting

### সমস্যা 1: `TypeError` item assignment
- **কী হচ্ছে:** tuple-এর item বদলাতে গেলে error।
- **সম্ভাব্য কারণ:** tuple immutable।
- **Fix:** নতুন tuple বানান, অথবা editable data হলে list ব্যবহার করুন।
- **আগে প্রতিরোধ:** data fixed না changing, আগে ঠিক করুন।

### সমস্যা 2: single value tuple নয়
- **কী হচ্ছে:** `("INV-001")` string হয়ে গেছে।
- **সম্ভাব্য কারণ:** trailing comma নেই।
- **Fix:** `("INV-001",)` লিখুন।
- **আগে প্রতিরোধ:** one-item tuple-এ comma মনে রাখুন।

### সমস্যা 3: `IndexError`
- **কী হচ্ছে:** tuple-এর বাইরে index চাওয়া হয়েছে।
- **সম্ভাব্য কারণ:** zero-based position ভুল হয়েছে।
- **Fix:** `len()` দেখে valid index ব্যবহার করুন।
- **আগে প্রতিরোধ:** শেষ item-এর জন্য `-1` ব্যবহার করুন।

### সমস্যা 4: slice-এ item কম
- **কী হচ্ছে:** stop position-এর item আসেনি।
- **সম্ভাব্য কারণ:** slice-এর stop boundary excluded।
- **Fix:** প্রয়োজন হলে stop এক বাড়ান।
- **আগে প্রতিরোধ:** start included, stop excluded নিয়ম লিখে নিন।

## 15. Common Misconceptions

1. **ভুল:** tuple-এ index নেই। → **সত্য:** tuple ordered এবং indexed।
2. **ভুল:** tuple একেবারেই ব্যবহার করা যায় না। → **সত্য:** read, loop, slice এবং হিসাব করা যায়।
3. **ভুল:** `("code")` single-item tuple। → **সত্য:** এটি string, comma দরকার।
4. **ভুল:** tuple slice original tuple বদলায়। → **সত্য:** নতুন tuple তৈরি হয়।
5. **ভুল:** সব business data tuple হওয়া উচিত। → **সত্য:** changing data-এর জন্য list ভালো।

### Exercise 5: Sreepati debugging bug

Sreepati approved invoice record-এর amount ঠিক করতে চেয়েছিলেন।

```python
approved = ("INV-2024-007", 50000)
approved[1] = 55000
print(approved)
```

**Wrong output**

```text
TypeError: 'tuple' object does not support item assignment
```

Boss বললেন, “Approved record বদলাতে চাইলে কী করব?”

**Diagnosis:** tuple immutable। Item assignment করা যায় না।

**Minimal fix**

```python
approved = ("INV-2024-007", 50000)
corrected = (approved[0], 55000)
print(corrected)
```

**Correct output**

```text
('INV-2024-007', 55000)
```

**Lesson:** immutable data বদলাতে হলে নতুন tuple বানান।

## 17. Quiz

1. Tuple-এর প্রধান বৈশিষ্ট্য কী?  
   a) ordered এবং immutable  
   b) unordered এবং editable  
   c) শুধু number রাখে  
   **উত্তর: a।** tuple position রাখে, কিন্তু item assignment নেয় না।

2. Single-item tuple-এর সঠিক syntax কোনটি?  
   a) `("INV")`  
   b) `["INV"]`  
   c) `("INV",)`  
   **উত্তর: c।** comma tuple তৈরি করে।

3. Tuple-এর প্রথম item কোন index-এ?  
   a) 0  
   b) 1  
   c) -1  
   **উত্তর: a।** Python zero-based indexing ব্যবহার করে।

4. `data[1:3]` কী করে?  
   a) index 1 এবং 2 নেয়  
   b) index 1, 2 এবং 3 নেয়  
   c) শুধু index 3 নেয়  
   **উত্তর: a।** stop boundary বাদ যায়।

5. Tuple-এর item assignment করলে কী হয়?  
   a) item বদলে যায়  
   b) `TypeError` হয়  
   c) tuple list হয়ে যায়  
   **উত্তর: b।** tuple immutable।

6. List-এর fixed snapshot কীভাবে বানাব?  
   a) `tuple(report)`  
   b) `report == tuple`  
   c) `report[0]`  
   **উত্তর: a।** list-এর values দিয়ে নতুন tuple হয়।

7. কোন data-এর জন্য list বেশি উপযুক্ত?  
   a) approved fixed record  
   b) changing daily report  
   c) immutable invoice code  
   **উত্তর: b।** changing data-তে list ব্যবহার করা যায়।

## 18. Key Idea

Tuple হলো ordered এবং immutable collection। Fixed business record বা approved snapshot-এর জন্য এটি useful, কিন্তু changing report-এর জন্য list বেশি উপযুক্ত।
