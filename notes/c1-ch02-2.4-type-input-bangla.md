## Objective

5. user-এর data হিসাবের আগে type যাচাই করতে।
6. blank input হলে `None` বা default value ব্যবহারের সিদ্ধান্ত নিতে।

## 1. `type()` কী দেখায়

`type()` হলো Python-এর একটি built-in function। এটি একটি value কোন শ্রেণির, তা জানায়।

```python
daily_sales = 12000
customer = "Rahim Traders"
paid = True

print(type(daily_sales))
print(type(customer))
print(type(paid))
```

**Output**

```text
<class 'int'>
<class 'str'>
<class 'bool'>
```

`daily_sales` একটি integer, `customer` একটি string, এবং `paid` একটি Boolean। `type()` value বদলায় না, শুধু তার ধরন জানায়।

## 2. `type()` দিয়ে business value দেখা

একটি business record-এ একই সঙ্গে number, text, এবং missing value থাকতে পারে।

```python
customer = "Karim Store"
balance = None
invoice_count = 12

print(type(customer))
print(type(balance))
print(type(invoice_count))
```

**Output**

```text
<class 'str'>
<class 'NoneType'>
<class 'int'>
```

নামটি text, অজানা balance-এর type `NoneType`, এবং invoice count একটি integer। এই পরীক্ষা ভুল data ধরতে সাহায্য করে।

## 3. `input()` কী করে

`input()` terminal-এ user-এর লেখা নেওয়ার জন্য অপেক্ষা করে। user Enter চাপলে লেখা value হিসেবে ফেরত আসে।

```python
customer_name = input("Customer name: ")
print("Customer:", customer_name)
```

**Output, user লিখেছে `Rahim Traders`**

```text
Customer name: Rahim Traders
Customer: Rahim Traders
```

Prompt user-কে কী লিখতে হবে তা জানায়। `input()`-এর ফল `customer_name`-এ রাখা হয়, তারপর print করা হয়।

## 4. Input-এর prompt

Prompt হলো input-এর ভিতরের ছোট নির্দেশনা। ভালো prompt-এ field-এর অর্থ এবং দরকার হলে default value থাকে।

```python
invoice_number = input("Invoice number [INV-2024-007]: ")
if invoice_number == "":
    invoice_number = "INV-2024-007"
print(invoice_number)
```

**Output, user Enter চাপলে**

```text
Invoice number [INV-2024-007]:
INV-2024-007
```

User blank দিলে `input()` একটি empty string, অর্থাৎ `""`, দেয়। `if` সেই blank value ধরে default invoice number বসায়।

## 5. Input সব সময় string

User number-এর মতো কিছু লিখলেও `input()` প্রথমে string দেয়।

```python
quantity = input("Quantity: ")
print(quantity)
print(type(quantity))
```

**Output, user লিখেছে `6`**

```text
Quantity: 6
6
<class 'str'>
```

স্ক্রিনে `6` দেখা গেলেও `quantity`-এর type `str`। পরের 2.5 subtopic-এ type casting দিয়ে এটিকে number বানানো হবে।

## 6. Blank input এবং `None`

Blank input সরাসরি `None` নয়। `input()` blank হলে `""` দেয়, তারপর program চাইলে সেটিকে `None` করতে পারে।

```python
note_text = input("Note [optional]: ")
if note_text == "":
    note_text = None
print(note_text)
```

**Output, user Enter চাপলে**

```text
Note [optional]:
None
```

প্রথমে user-এর blank response একটি empty string। business rule অনুযায়ী code সেটিকে missing note হিসেবে `None`-এ বদলায়।

## 7. Input-এর data যাচাই

User যা লিখেছে, তা business field-এর জন্য গ্রহণযোগ্য কি না, আগে যাচাই করা উচিত।

```python
customer_code = input("Customer code [C-1023]: ")
if customer_code == "":
    customer_code = None

if customer_code is None:
    print("Customer code is missing")
else:
    print("Customer code:", customer_code)
```

**Output, user Enter চাপলে**

```text
Customer code [C-1023]:
Customer code is missing
```

Blank response-কে `None` করা হয়েছে। `is None` দিয়ে missing code ধরা হয়েছে, তাই ভুল বা অসম্পূর্ণ record report হয়নি।

## 8. Input দিয়ে business record তৈরি

একাধিক input নিয়ে একটি ছোট sales record তৈরি করা যায়। প্রতিটি input-এর ফল শুরুতে string থাকে।

```python
customer = input("Customer [Rahim Traders]: ") or "Rahim Traders"
invoice_number = input("Invoice [INV-2024-007]: ") or "INV-2024-007"
print(customer, invoice_number)
```

**Output, user দুইবার Enter চাপলে**

```text
Customer [Rahim Traders]: Invoice [INV-2024-007]: Rahim Traders INV-2024-007
```

`or` blank string হলে default text বেছে নেয়। এখানে দুটো business field text, তাই তাদের string হিসেবেই রাখা ঠিক।

## 9. Input ও arithmetic-এর সতর্কতা

`input()` থেকে পাওয়া quantity-কে সরাসরি integer-এর সঙ্গে যোগ করা যাবে না। আগে type দেখুন।

```python
quantity = input("Quantity [6]: ") or "6"
print(type(quantity))
print("The quantity is text:", quantity)
```

**Output, user Enter চাপলে**

```text
Quantity [6]: <class 'str'>
The quantity is text: 6
```

`quantity` এখনও string। তাই `quantity + 100`-এর মতো arithmetic করলে error হবে। Type casting এই সমস্যার পরের ধাপ।

## 10. Type casting-এর জন্য প্রস্তুতি

আজ আমরা শুধু type চিনলাম। `int()` দিয়ে text number বানানো হবে পরের subtopic-এ।

```python
quantity_text = "6"
print(type(quantity_text))

quantity_number = int(quantity_text)
print(type(quantity_number))
```

**Output**

```text
<class 'str'>
<class 'int'>
```

প্রথম value text। `int()` সেটিকে integer-এ বদলেছে। আজকের lesson-এর সীমা মনে রাখুন: `input()` পড়ে, type casting বদলায়।

## Troubleshooting

### Problem 1: User `6` লিখেও quantity number হচ্ছে না

- **কী হচ্ছে:** `type(quantity)` output-এ `str` দেখা যাচ্ছে।
- **সম্ভাব্য কারণ:** `input()` সব response text হিসেবে ফেরত দেয়।
- **ধাপে ধাপে সমাধান:** 1. `type(quantity)` print করুন। 2. text number আলাদা করুন। 3. পরের lesson-এ `int()` ব্যবহার করুন। 4. আবার type পরীক্ষা করুন।
- **পরের বার ঠেকানোর উপায়:** input-এর পরে field-টির expected type লিখে রাখুন।

### Problem 2: Blank input-কে `None` মনে হচ্ছে

- **কী হচ্ছে:** user Enter চাপলে value `None` নয়, `""` হচ্ছে।
- **সম্ভাব্য কারণ:** blank string এবং missing value এক করে দেখা হয়েছে।
- **ধাপে ধাপে সমাধান:** 1. `value == ""` পরীক্ষা করুন। 2. business rule অনুযায়ী `None` বসান। 3. `value is None` দিয়ে পরে পরীক্ষা করুন।
- **পরের বার ঠেকানোর উপায়:** input-এর blank policy আগে ঠিক করুন।

### Problem 3: Prompt এবং user response গুলিয়ে যাচ্ছে

- **কী হচ্ছে:** output দেখে মনে হচ্ছে prompt-টিই variable-এ রাখা হয়েছে।
- **সম্ভাব্য কারণ:** `input("...")`-এর string prompt, user-এর response নয়।
- **ধাপে ধাপে সমাধান:** 1. prompt-কে নির্দেশনা হিসেবে দেখুন। 2. response variable-এ রাখুন। 3. variable print করুন। 4. type পরীক্ষা করুন।
- **পরের বার ঠেকানোর উপায়:** prompt-এ field name এবং default স্পষ্ট লিখুন।

### Problem 4: Input-এর পরে arithmetic error

- **কী হচ্ছে:** quantity-এর সঙ্গে number যোগ করতে error হচ্ছে।
- **সম্ভাব্য কারণ:** string এবং integer একসঙ্গে ব্যবহার করা হয়েছে।
- **ধাপে ধাপে সমাধান:** 1. `type(quantity)` দেখুন। 2. quantity text কি না নিশ্চিত করুন। 3. type casting শিখে `int()` ব্যবহার করুন। 4. তারপর arithmetic চালান।
- **পরের বার ঠেকানোর উপায়:** input data-কে হিসাবের আগে validate এবং convert করুন।

## Common Misconceptions

1. **ভুল দাবি:** `input()` user-এর number-কে integer দেয়। **সত্য:** `input()` সব সময় string দেয়।
2. **ভুল দাবি:** blank input নিজেই `None`। **সত্য:** blank input হলো `""`, code চাইলে সেটিকে `None` করতে পারে।
3. **ভুল দাবি:** `type()` value বদলে দেয়। **সত্য:** `type()` শুধু value-এর ধরন জানায়।
4. **ভুল দাবি:** prompt-টাই user-এর data। **সত্য:** prompt নির্দেশনা, user-এর লেখা আলাদা response।
5. **ভুল দাবি:** string number-এর সঙ্গে integer যোগ করা যায়। **সত্য:** আগে type casting দরকার।
