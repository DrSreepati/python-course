## 6. `append`: শেষে একটি item

নতুন customer list-এর শেষে যোগ করতে `append()` ব্যবহার করি।

```python
customers = ["Rahim Traders", "Karim Store"]
customers.append("Jahid Enterprise")
print(customers)
```

**Output**

```text
['Rahim Traders', 'Karim Store', 'Jahid Enterprise']
```

- `append()` list-এ একটি item যোগ করে।
- item শেষে বসে।
- method list-টি বদলায়।

## 7. `insert`: নির্দিষ্ট আসনে item

Boss-এর priority customer-কে শুরুতে রাখতে `insert(index, value)` ব্যবহার করা যায়।

```python
customers = ["Karim Store", "Jahid Enterprise"]
customers.insert(0, "Rahim Traders")
print(customers)
```

**Output**

```text
['Rahim Traders', 'Karim Store', 'Jahid Enterprise']
```

- `0` position-এ item বসেছে।
- পুরনো item-গুলো ডানদিকে সরে গেছে।
- index ভুল হলে order বদলে যেতে পারে।

## 8. `extend`: একসঙ্গে অনেক item

নতুন branch-এর customer list একসঙ্গে যোগ করতে `extend()` ব্যবহার করি।

```python
customers = ["Rahim Traders"]
new_customers = ["Karim Store", "Jahid Enterprise"]
customers.extend(new_customers)
print(customers)
```

**Output**

```text
['Rahim Traders', 'Karim Store', 'Jahid Enterprise']
```

- `extend()` অন্য sequence-এর item-গুলো একে একে যোগ করে।
- এটি nested list তৈরি করে না।
- `append(new_customers)` করলে পুরো list একটি item হতো।

## 9. `remove`: value দিয়ে মুছুন

Closed account customer-এর নাম জানা থাকলে `remove(value)` ব্যবহার করি।

```python
customers = ["Rahim Traders", "Karim Store", "Jahid Enterprise"]
customers.remove("Karim Store")
print(customers)
```

**Output**

```text
['Rahim Traders', 'Jahid Enterprise']
```

- value-এর প্রথম matching item মুছে যায়।
- value না থাকলে `ValueError` হয়।
- remove-এর আগে membership check করা নিরাপদ।

## 10. `pop` এবং `del`

`pop()` item মুছে সেই item ফেরত দেয়। `del` item মুছে, কিন্তু ফেরত দেয় না।

```python
customers = ["Rahim Traders", "Karim Store", "Jahid Enterprise"]
removed_customer = customers.pop(1)
print(removed_customer)
print(customers)

del customers[0]
print(customers)
```

**Output**

```text
Karim Store
['Rahim Traders', 'Jahid Enterprise']
['Jahid Enterprise']
```

- `pop(1)` দ্বিতীয় item সরিয়ে variable-এ রাখে।
- `del customers[0]` প্রথম item সরায়।
- `pop()` index না পেলে শেষ item সরায়।

## 11. Safe business update

কোনো customer আছে কি না দেখে remove করা ভালো।

```python
customers = ["Rahim Traders", "Karim Store"]
name_to_close = "Jahid Enterprise"

if name_to_close in customers:
    customers.remove(name_to_close)
    print("Customer removed")
else:
    print("Customer not found")

print(customers)
```

**Output**

```text
Customer not found
['Rahim Traders', 'Karim Store']
```

- `in` membership check করে।
- না থাকলে `remove` চালানো হয়নি।
- report-এ failure স্পষ্ট থাকে।

## 12. Method-এর return value

List method-এর result এবং list-এর পরিবর্তন আলাদা বিষয়।

```python
sales = [12000, 9500]
result = sales.append(8800)
print(result)
print(sales)
```

**Output**

```text
None
[12000, 9500, 8800]
```

- `append()` list বদলায়।
- `append()` সাধারণত `None` ফেরত দেয়।
- তাই `new_sales = sales.append(...)` করে list পাওয়া যায় না।

## 13. Synthesis table

| Tool | কাজ |
|---|---|
| `append(x)` | শেষে একটি item যোগ |
| `insert(i, x)` | position-এ একটি item যোগ |
| `extend(items)` | অনেক item যোগ |
| `remove(x)` | value-এর প্রথম match মুছে |
| `pop(i)` | index-এর item মুছে ফেরত দেয় |
| `del list[i]` | index-এর item মুছে |

## 14. Troubleshooting

### সমস্যা 1
- কী হচ্ছে: অনেক customer যোগ করলে nested list দেখা যাচ্ছে।
- সম্ভাব্য কারণ: `append(new_customers)` ব্যবহার হয়েছে।
- Fix: আলাদা item চাইলে `extend(new_customers)` দিন।
- Prevention: একটি item বনাম অনেক item ঠিক করুন।

### সমস্যা 2
- কী হচ্ছে: `ValueError: list.remove(x): x not in list` আসছে।
- সম্ভাব্য কারণ: value list-এ নেই।
- Fix: আগে `if value in list` check করুন।
- Prevention: external data সরাসরি remove করবেন না।

### সমস্যা 3
- কী হচ্ছে: `pop()`-এর পরে ভুল customer মুছে গেছে।
- সম্ভাব্য কারণ: index position পুরনো list অনুযায়ী ধরা হয়েছে।
- Fix: pop-এর ঠিক আগের list এবং index যাচাই করুন।
- Prevention: index-কে আসন হিসেবে গুনুন।

### সমস্যা 4
- কী হচ্ছে: append-এর result-এ `None` দেখা যাচ্ছে।
- সম্ভাব্য কারণ: method-এর return value-কে নতুন list ভাবা হয়েছে।
- Fix: original list print বা ব্যবহার করুন।
- Prevention: mutating method list বদলায়, সবসময় list ফেরত দেয় না।

## 15. Common Misconceptions

1. **ভুল:** `append` অনেক item আলাদা আলাদা যোগ করে → **সত্য:** একটি object যোগ করে।
2. **ভুল:** `extend` পুরো list-কে একটি item করে → **সত্য:** তার item-গুলো যোগ করে।
3. **ভুল:** `remove(0)` প্রথম position মুছে → **সত্য:** value `0` খোঁজে।
4. **ভুল:** `pop` শুধু delete করে → **সত্য:** মুছে item ফেরতও দেয়।
5. **ভুল:** list method-এর result সবসময় updated list → **সত্য:** কিছু method `None` ফেরত দেয়।

## 17. Quiz

1. শেষে একটি item যোগ করতে কী ব্যবহার করবেন?  
   a) `append`  b) `remove`  c) `pop`  
   **উত্তর: a**, কারণ append শেষে item দেয়।

   a) শেষে  b) শুরুতে  c) মুছে  
   **উত্তর: b**, কারণ index 0 প্রথম আসন।
3. অনেক item একসঙ্গে যোগ করতে কোনটি?  
   a) `extend`  b) `del`  c) `remove`  
   **উত্তর: a**, কারণ extend sequence-এর item যোগ করে।
4. `remove("Karim Store")` কী দিয়ে খোঁজে?  
   a) index  b) value  c) length  
   **উত্তর: b**, কারণ remove value নেয়।
5. `pop(1)` কী করে?  
   a) দ্বিতীয় item মুছে ফেরত দেয়  b) প্রথম item যোগ করে  c) list sort করে  
   **উত্তর: a**, কারণ index 1-এর item return হয়।
6. `del customers[0]` কী ফেরত দেয়?  
   a) removed item  b) `None`  c) কিছুই নয়

   a) updated list  b) `None`  c) index

## 18. Key Idea

List হলো দোকানের চলমান customer register। `append`, `insert`, `extend` যোগ করে; `remove`, `pop`, `del` সরায়।

**ছড়া:**  
শেষে যোগ append, অনেক হলে extend,  
ভুল record সরাই, list থাকে well-kept।
