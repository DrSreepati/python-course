## 6. break দিয়ে loop থামানো

`break` চললে loop সঙ্গে সঙ্গে শেষ হয়।

```python
for invoice in ["INV-001", "INV-002", "INV-URGENT", "INV-004"]:
    print(f"Checking {invoice}")
    if invoice == "INV-URGENT":
        print("Urgent invoice found")
        break
```

**Output**

```text
Checking INV-001
Checking INV-002
Checking INV-URGENT
Urgent invoice found
```

`break` urgent invoice পাওয়ার পর `INV-004` আর process হতে দেয়নি। Loop-এর পরের code থাকলে সেটি চলত।

## 7. continue দিয়ে item skip

`continue` বর্তমান iteration-এর বাকি অংশ বাদ দিয়ে পরের item-এ যায়।

```python
payments = [10000, 0, 12000]

for payment in payments:
    if payment == 0:
        continue
    print(f"Record payment: {payment}")
```

**Output**

```text
Record payment: 10000
Record payment: 12000
```

Zero payment-এর print বাদ গেছে। Loop কিন্তু থামেনি, পরের payment process হয়েছে।

## 8. pass দিয়ে placeholder

`pass` একটি empty statement। ভবিষ্যতে code লিখব, এখন block খালি রাখা যাবে।

```python
review_required = True

if review_required:
    pass

print("Report continues")
```

**Output**

```text
Report continues
```

`pass` কোনো output দেয় না এবং loop থামায় না। শুধু syntactically valid empty block রাখে।

## 9. break এবং continue একসঙ্গে

Business process-এ invalid record skip করে urgent record-এ থামা যায়।

```python
references = ["INV-001", "", "INV-URGENT", "INV-004"]

for reference in references:
    if reference == "":
        continue
    print(f"Checking {reference}")
    if reference == "INV-URGENT":
        print("Stop for manager")
        break
```

**Output**

```text
Checking INV-001
Checking INV-URGENT
Stop for manager
```

Empty reference skip হয়েছে। Urgent reference print হওয়ার পরে loop থেমেছে।

## 10. Decision flow বুঝি

Statement-এর অবস্থান output বদলায়।

```python
for day in range(1, 5):
    if day == 2:
        continue
    print(f"Report day {day}")
    if day == 3:
        break
```

**Output**

```text
Report day 1
Report day 3
```

Day 2-এর `continue` print-এর আগে এসেছে, তাই day 2 বাদ। Day 3 print হওয়ার পরে `break`, তাই day 4 নেই।

## 11. Synthesis table

| কাজ | Statement |
|---|---|
| পুরো loop থামানো | `break` |
| বর্তমান round বাদ | `continue` |
| খালি block valid রাখা | `pass` |
| invalid item এড়িয়ে যাওয়া | `continue` |
| urgent item-এ process শেষ | `break` |

## 12. Troubleshooting

### সমস্যা 1
- কী হচ্ছে: urgent item-এর পরও records print হচ্ছে।
- সম্ভাব্য কারণ: `break` condition-এর ভিতরে নেই, বা `continue` ব্যবহার হয়েছে।
- Fix: urgent condition সত্য হলে `break` দিন।
- Prevention: expected stop item-এর পরের item test করুন।

### সমস্যা 2
- কী হচ্ছে: শুধু একটি item বাদ দিতে গিয়ে পুরো loop থেমে যাচ্ছে।
- সম্ভাব্য কারণ: `continue`-এর বদলে `break` লেখা হয়েছে।
- Fix: skip দরকার হলে `continue` ব্যবহার করুন।
- Prevention: stop এবং skip-এর business meaning আলাদা লিখুন।

### সমস্যা 3
- কী হচ্ছে: `pass` দিয়ে output বা skip আশা করা হচ্ছে।
- সম্ভাব্য কারণ: `pass`-এর কাজ ভুল বোঝা হয়েছে।
- Fix: output চাইলে `print`, skip চাইলে `continue` লিখুন।
- Prevention: মনে রাখুন, `pass` কিছুই করে না।

### সমস্যা 4
- কী হচ্ছে: valid record-ও process হচ্ছে না।
- সম্ভাব্য কারণ: condition বেশি broad, তাই `continue` আগে চলে যাচ্ছে।
- Fix: exact invalid case পরীক্ষা করুন।
- Prevention: valid, invalid এবং urgent তিন ধরনের sample রাখুন।

## 13. Common Misconceptions

1. **ভুল:** `break` শুধু বর্তমান item বাদ দেয় → **সত্য:** পুরো loop শেষ করে।
2. **ভুল:** `continue` program বন্ধ করে → **সত্য:** পরের iteration-এ যায়।
3. **ভুল:** `pass` loop skip করে → **সত্য:** এটি কোনো কাজ করে না।
4. **ভুল:** `break`-এর পরের loop code চলে → **সত্য:** loop body আর চলে না।
5. **ভুল:** `pass` না লিখলেও empty block চলে → **সত্য:** block-এ অন্তত একটি statement দরকার।

### Exercise 5, Rafiq bhai bug

Rafiq bhai লিখেছেন:

```python
payments = [10000, 0, 12000]
for payment in payments:
    if payment == 0:
        break
    print(payment)
```

ভুল output: শুধু `10000`। Boss বললেন zero payment বাদ যাবে, কিন্তু পরে 12000-ও process করা দরকার। `break` পুরো loop থামিয়েছে। Fix:

```python
payments = [10000, 0, 12000]
for payment in payments:
    if payment == 0:
        continue
    print(payment)
```

Output:

```text
10000
12000
```

Lesson: one bad item skip করতে `continue`, পুরো process stop করতে `break`।

## 16. Key Idea

`break` পুরো loop থামায়, `continue` একটি round বাদ দেয়, আর `pass` শুধু placeholder। Business flow-এর stop, skip এবং future block আলাদা করে চিনুন।

**ছড়া:**  
জরুরি এলে `break`, পথটি তখন থামে,  
খারাপ item `continue`, `pass` চুপচাপ নামে।
