## 6. A mutable list

Mutable means that an object can change after creation.

```python
sales = [12000, 9500, 8800]
sales[1] = 10000

print(sales)
```

**Output**

```text
[12000, 10000, 8800]
```

- A list is mutable.
- Index 1 receives a new value.
- The list changes inside the same object.

## 7. Immutable values

Immutable means that the object cannot be changed directly. A new value is created.

```python
customer_code = "C-1023"
updated_code = customer_code.replace("1023", "2048")

print(customer_code)
print(updated_code)
```

**Output**

```text
C-1023
C-2048
```

The old string stays unchanged. `replace()` returns a new string. Tuple items also cannot be assigned directly.

## 8. The outer level of a shallow copy

```python
table = [[12000, 9500], [8800, 13200]]
table_copy = table[:]
table_copy.append([7500, 6100])

print(table)
print(table_copy)
```

**Output**

```text
[[12000, 9500], [8800, 13200]]
[[12000, 9500], [8800, 13200], [7500, 6100]]
```

The outer lists are separate. A new row does not change the original table.

## 9. Why an inner row is shared

```python
table = [[12000, 9500], [8800, 13200]]
table_copy = table[:]
table_copy[0][0] = 13000

print(table)
print(table_copy)
```

**Output**

```text
[[13000, 9500], [8800, 13200]]
[[13000, 9500], [8800, 13200]]
```

Only the outer list was copied. `table[0]` and `table_copy[0]` are the same inner row.

## 10. Copying every row

```python
table = [[12000, 9500], [8800, 13200]]
safe_table = [row[:] for row in table]
safe_table[0][0] = 13000

print(table)
print(safe_table)
```

**Output**

```text
[[12000, 9500], [8800, 13200]]
[[13000, 9500], [8800, 13200]]
```

The comprehension creates a new slice for every row. A cell edit stays in the working table.

## 11. Copying every row with `.copy()`

```python
table = [[12000, 9500], [8800, 13200]]
safe_table = [row.copy() for row in table]
safe_table[1].append(11000)

print(table)
print(safe_table)
```

**Output**

```text
[[12000, 9500], [8800, 13200]]
[[12000, 9500], [8800, 13200, 11000]]
```

Each inner row has its own copy. The row append does not affect the original.

Keep the original customer-day table as audit evidence. Edit a working table. For a flat list, use `.copy()`. For a nested table, copy every row.

## 13. Synthesis table

| Data or job | Safe method |
|---|---|
| Flat list reference | `b = a`, changes are shared |
| Flat list shallow copy | `a[:]` or `a.copy()` |
| Outer copy of nested table | `table[:]`, inner rows remain shared |
| Row copies in a nested table | `[row[:] for row in table]` |
| String or tuple edit | Build a new value |
| Protect audit data | Copy before editing |

## 14. Troubleshooting

### Problem 1: The original cell changes
- **What happens:** A cell edit in the copy appears in the original.
- **Likely cause:** Inner rows are shared.
- **Fix:** Use `[row[:] for row in table]`.
- **Prevent it:** Plan a copy for every required level.

### Problem 2: `TypeError` on an immutable value
- **What happens:** A string or tuple item assignment fails.
- **Likely cause:** The object is immutable.
- **Fix:** Build a new string or tuple.
- **Prevent it:** Identify mutability before editing.

### Problem 3: Adding a row changes the original
- **What happens:** `append()` appears in both tables.
- **Likely cause:** The outer list was not copied.
- **Fix:** Copy the outer list first.
- **Prevent it:** Test both outer and inner independence.

### Problem 4: The copy code is confusing
- **What happens:** Shared levels are unclear.
- **Likely cause:** Too many nested operations are on one line.
- **Fix:** Name the original, working table, and row copy separately.
- **Prevent it:** Keep audit code explicit.

## 15. Common Misconceptions

1. **Wrong:** A shallow copy copies every level. → **Truth:** It usually copies the outer level.
2. **Wrong:** `table[:]` is enough for a nested table. → **Truth:** Inner rows need copies too.
3. **Wrong:** A string character can be assigned. → **Truth:** Strings are immutable.
4. **Wrong:** Tuple items can be assigned. → **Truth:** Tuples are immutable.
5. **Wrong:** Mutable values are always bad. → **Truth:** Controlled working copies are useful.

## 16. Exercises with solutions

### Exercise 1

Copy a flat sales list. Change the first item in the working list.

**Solution**

```python
sales = [12000, 9500, 8800]
working = sales.copy()

```

**Output**


### Exercise 2

**Solution**

```python
table = [[12000, 9500], [8800, 13200]]
working = table[:]

print(table)
print(working)
```

**Output**

```text
[[12000, 9500], [8800, 13200]]
```

### Exercise 3

Copy every row. Change one cell in the second row.

**Solution**

```python

print(table)
print(working)
```

**Output**

```text
[[12000, 9500], [8800, 13200]]
[[12000, 9500], [9000, 13200]]
```

### Exercise 5: Sreepati debugging bug

Sreepati wanted a working customer-day table.

```python
original = [[12000, 9500], [8800, 13200]]
working = original[:]
working[0][0] = 13000
print(original)
```

**Wrong output**

```text
[[13000, 9500], [8800, 13200]]
```

The boss asked, “Why did the correction enter the audit table?”

**Diagnosis:** Only the outer list was copied. The inner row was shared.

**Minimal fix**

```python
original = [[12000, 9500], [8800, 13200]]
working = [row[:] for row in original]
working[0][0] = 13000
print(original)
print(working)
```

**Correct output**

```text
[[12000, 9500], [8800, 13200]]
[[13000, 9500], [8800, 13200]]
```

**Lesson:** Copy the outer table and every inner row.

## 17. Quiz

1. Which is mutable?  
   a) list  
   b) string  
   c) tuple  
   **Answer: a.** List items can change.

2. Can a string character be assigned directly?  
   a) Yes  
   b) Only in a loop  
   c) No, build a new string  
   **Answer: c.** Strings are immutable.

3. What does `table[:]` copy in a nested table?  
   a) The outer list  
   b) Every inner cell  
   c) Only the last row  
   **Answer: a.** Inner rows may remain shared.

4. Which copies every row?  
   a) `table = original`  
   b) `[row[:] for row in original]`  
   c) `original == table`  
   **Answer: b.** It creates a new slice for each row.

5. What is a tuple usually?  
   a) Mutable  
   b) Immutable  
   c) Always empty  
   **Answer: b.** Tuple items cannot be assigned.

6. What does `.copy()` do for a nested list?  
   a) Copies every nested level  
   b) Copies the outer list, while inner lists may remain shared  
   c) Makes a string  
   **Answer: b.** It is a shallow copy.

7. What is a safe nested working-table method?  
   a) Copy the outer list and every row  
   b) Use an alias  
   c) Use only `==`  
   **Answer: a.** Inner mutations stay separate.

## 18. Key Idea

A shallow copy may suit a flat list. A nested table also needs a copy for every inner row. Lists are mutable. Strings and tuples are immutable.

**Rhyme 2:**  
Strings and tuples hold steady and still,  
Lists can change with a careful will.
