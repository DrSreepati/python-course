## 1. Money data কেন গুরুত্বপূর্ণ

Money-র এক পয়সার ভুলও বড় report-এ জমা হতে পারে। তাই price, quantity, এবং amount আলাদা করে দেখে হিসাব করতে হয়।

```python
unit_price = 250.50
quantity = 4
amount = unit_price * quantity

print(amount)
```

**Output**

```text
1002.0
```

`unit_price` হলো প্রতি item-এর দাম। `quantity` হলো 4টি item। তাদের গুণফল হলো amount।

## 2. `float` দিয়ে price

`float` decimal number রাখে। সাধারণ শেখার উদাহরণে এটি price এবং rate-এর জন্য ব্যবহার করা যায়।

```python
unit_price = float("250.50")
vat_rate = float("7.5")

print(unit_price)
print(vat_rate)
print(type(unit_price))
```

**Output**

```text
250.5
7.5
<class 'float'>
```

`float()` text-কে decimal number করেছে। Python price-এর শেষের অপ্রয়োজনীয় zero print নাও করতে পারে।

## 3. `0.1 + 0.2` surprise

Computer অনেক decimal value binary fraction হিসেবে আনুমানিকভাবে রাখে। তাই যোগফল মানুষের প্রত্যাশার মতো text নাও হতে পারে।

```python
result = 0.1 + 0.2
print(result)
```

**Output**

```text
0.30000000000000004
```

এটি arithmetic-এর ভুল নয়। `0.1` এবং `0.2` binary-তে ঠিকভাবে প্রকাশ করা কঠিন, তাই ছোট representation error দেখা যায়।

## 4. `repr()` এবং `print()`-এর পার্থক্য

`repr()` value-এর আরও নির্ভুল representation দেখাতে সাহায্য করে। `print()` সাধারণ display-এর জন্য।

```python
result = 0.1 + 0.2
print(result)
print(repr(result))
```

**Output**

```text
0.30000000000000004
0.30000000000000004
```

দুটি output এখানে একই। এতে বোঝা যায় যে ভেতরের float result-এ অতিরিক্ত digits আছে, যদিও business report-এ আমরা সাধারণত cents পর্যন্ত দেখাতে চাই।

## 5. `round()` দিয়ে display

`round()` একটি value-কে নির্দিষ্ট decimal ঘর পর্যন্ত গোল করে। এটি display বা সাধারণ presentation-এর জন্য উপকারী।

```python
result = 0.1 + 0.2
display_value = round(result, 2)

print(result)
print(display_value)
```

**Output**

```text
0.30000000000000004
0.3
```

প্রথম line-এ raw float result আছে। দ্বিতীয় line-এ দুই decimal ঘর পর্যন্ত round করা result আছে।

## 6. Amount calculation-এ float

Quantity এবং unit price গুণ করলে amount পাওয়া যায়। Report-এ amount সাধারণত দুই decimal ঘর পর্যন্ত দেখানো হয়।

```python
unit_price = 19.99
quantity = 3
amount = unit_price * quantity

print(amount)
print(round(amount, 2))
```

**Output**

```text
59.97
59.97
```

এই উদাহরণে raw result-ই পরিষ্কার দেখা যাচ্ছে। তবু report display-এর জন্য `round(amount, 2)` ব্যবহার করা যায়।

## 7. Comparison-এর ঝুঁকি

দুটি float দেখতে একই মনে হলেও exact equality test false হতে পারে।

```python
calculated = 0.1 + 0.2
expected = 0.3

print(calculated == expected)
print(round(calculated, 2) == expected)
```

**Output**

```text
False
True
```

প্রথম test raw representation তুলনা করে। দ্বিতীয় test দুই decimal ঘর পর্যন্ত তুলনা করে, তাই এই ছোট example-এ true হয়।

## 8. Cents হিসেবে integer রাখা

যদি currency-এর smallest unit cents বা পয়সা হয়, amount-কে integer unit হিসেবে রাখা যায়। এতে float-এর এই সমস্যাটি এড়ানো যায়।

```python
price_paisa = 1999
quantity = 3
amount_paisa = price_paisa * quantity

print(amount_paisa)
print(amount_paisa / 100)
```

**Output**

```text
5997
59.97
```

প্রথম হিসাবটি পুরো paisa integer-এ হয়েছে। শেষ line display-এর জন্য division করেছে, তাই financial storage rule আলাদা করে ঠিক করতে হবে।

## 9. Decimal-based approach-এর পরিচয়

Python-এর `decimal.Decimal` decimal text-কে financial-style decimal value হিসেবে রাখতে সাহায্য করে। এটি আজ শুধু পরিচয় হিসেবে দেখছি।

```python
from decimal import Decimal

result = Decimal("0.1") + Decimal("0.2")
print(result)
```

**Output**

```text
0.3
```

`Decimal` তৈরি করার সময় string ব্যবহার করা হয়েছে। এতে decimal intent স্পষ্ট থাকে এবং এই যোগফল `0.3` হয়।

## 10. Business rule বেছে নেওয়া

সব project একই rule ব্যবহার করে না। ছোট শেখার example-এ `float` এবং `round()` দেখা যায়, আর financial system-এ cents integer বা `Decimal` বেছে নেওয়া হতে পারে।

```python
from decimal import Decimal

unit_price = Decimal("19.99")
quantity = 3
amount = unit_price * quantity

print(amount)
```

**Output**

```text
59.97
```

এখানে price `Decimal`। Quantity integer। তাদের গুণে exact decimal-style amount পাওয়া যায়।

## Troubleshooting

### Problem 1: `0.1 + 0.2`-এর output অদ্ভুত

- **কী হচ্ছে:** `0.30000000000000004` দেখা যাচ্ছে।
- **সম্ভাব্য কারণ:** float decimal value binary-তে আনুমানিকভাবে রাখে।
- **ধাপে ধাপে সমাধান:** 1. Raw result print করুন। 2. Display-এর জন্য `round(result, 2)` দিন। 3. Financial storage rule ঠিক করুন। 4. প্রয়োজন হলে integer unit বা `Decimal` ব্যবহার করুন।
- **পরের বার ঠেকানোর উপায়:** Raw float result-কে final money report হিসেবে সরাসরি দেখাবেন না।

### Problem 2: একই দামের দুই output

- **কী হচ্ছে:** raw amount এবং rounded amount আলাদা দেখাচ্ছে।
- **সম্ভাব্য কারণ:** calculation value এবং display value এক মনে করা হয়েছে।
- **ধাপে ধাপে সমাধান:** 1. Raw value আলাদা রাখুন। 2. Report-এর জন্য round করুন। 3. কোনটি storage আর কোনটি display লিখে দিন।
- **পরের বার ঠেকানোর উপায়:** variable name-এ `raw_amount` এবং `display_amount`-এর মতো অর্থপূর্ণ নাম দিন।

### Problem 3: Float equality false

- **কী হচ্ছে:** `0.1 + 0.2 == 0.3` false।
- **সম্ভাব্য কারণ:** binary representation-এর ক্ষুদ্র পার্থক্য।
- **ধাপে ধাপে সমাধান:** 1. Raw values print করুন। 2. প্রয়োজনীয় precision ঠিক করুন। 3. round করে তুলনা করুন, অথবা `Decimal` ব্যবহার করুন।
- **পরের বার ঠেকানোর উপায়:** money float-কে exact equality দিয়ে compare করবেন না।

### Problem 4: Financial storage rule অস্পষ্ট

- **কী হচ্ছে:** team কখন float, integer unit, বা Decimal ব্যবহার করবে জানে না।
- **সম্ভাব্য কারণ:** currency এবং precision-এর policy আগে লেখা হয়নি।
- **ধাপে ধাপে সমাধান:** 1. smallest currency unit ঠিক করুন। 2. storage type বাছুন। 3. display rule লিখুন। 4. sample calculations test করুন।
- **পরের বার ঠেকানোর উপায়:** project শুরুতেই money data policy লিখে রাখুন।

## Common Misconceptions

1. **ভুল দাবি:** `0.1 + 0.2` সব সময় ঠিক `0.3` হয়। **সত্য:** float representation-এর কারণে raw result-এ ক্ষুদ্র পার্থক্য হতে পারে।
2. **ভুল দাবি:** `round()` ভেতরের float storage-কে সব সময় exact money বানায়। **সত্য:** এটি result round করে, তাই storage policy আলাদা বিষয়।
3. **ভুল দাবি:** screen-এ `59.97` দেখালেই internal value exact। **সত্য:** display format এবং internal representation আলাদা হতে পারে।
4. **ভুল দাবি:** সব money field-এ `float` সেরা। **সত্য:** integer smallest units বা `Decimal` financial rule অনুযায়ী বেশি উপযুক্ত হতে পারে।
5. **ভুল দাবি:** float equality সব business comparison-এর জন্য নিরাপদ। **সত্য:** precision ঠিক করে তুলনা করতে হয়।

### Exercise 5: Rafiq bhai-এর debugging bug

Rafiq bhai float equality দিয়ে boss-এর expected amount পরীক্ষা করেছেন:

```python
calculated = 0.1 + 0.2
if calculated == 0.3:
    print("Amount matches")
else:
    print("Amount does not match")
```

**Wrong output**

```text
Amount does not match
```

Boss বললেন, “দুইটি ছোট amount যোগ করে report-এ mismatch কেন?”

**Solution**

Raw float equality representation-এর ক্ষুদ্র পার্থক্য দেখে false হয়েছে। এই simple display comparison-এ দুই decimal ঘর পর্যন্ত round করে test করা যায়।

```python
calculated = 0.1 + 0.2
if round(calculated, 2) == 0.3:
    print("Amount matches")
else:
    print("Amount does not match")
```

**Correct output**

```text
Amount matches
```

এক লাইনের lesson: money float compare করার আগে required precision ঠিক করুন।
