## 6. The first for loop

`for` runs a block for each value in a sequence.

```python
for day in range(1, 4):
    print(f"Preparing report for day {day}")
```

**Output**

```text
Preparing report for day 1
Preparing report for day 2
Preparing report for day 3
```

`range(1, 4)` starts at 1. It stops before 4. So day becomes 1, 2, and 3.

## 7. range() and the stop value

The stop value in `range(start, stop)` is excluded.

```python
for invoice_number in range(1, 4):
    print(f"Checking invoice {invoice_number}")
```

**Output**

```text
Checking invoice 1
Checking invoice 2
Checking invoice 3
```

Three invoices appear. The value 4 is the boundary, not data.

## 8. Using a step

The third argument says how far each value moves.

```python
for month in range(2, 8, 2):
    print(f"Reviewing month {month}")
```

**Output**

```text
Reviewing month 2
Reviewing month 4
Reviewing month 6
```

The loop starts at 2 and adds 2. The stop value 8 is excluded.

## 9. A reverse range

A negative step moves backwards.

```python
for priority in range(3, 0, -1):
    print(f"Priority level {priority}")
```

**Output**

```text
Priority level 3
Priority level 2
Priority level 1
```

It starts at 3, stops before 0, and subtracts 1 each time.

## 10. A running total

An accumulator inside a `for` loop can calculate a business total.

```python
total = 0

for day in range(1, 4):
    sale = day * 1000
    total += sale

print(total)
```

**Output**

```text
6000
```

Sales are 1000, 2000, and 3000. The total becomes 6000.

## 11. Choosing for or while

Use `for` when the count is known. Use `while` when the stop state is unknown.

```python
for invoice in range(1, 4):
    print(f"Fixed check {invoice}")

balance = 25000
while balance > 0:
    balance -= 10000
    print(f"Remaining balance: {balance}")
```

**Output**

```text
Fixed check 1
Fixed check 2
Fixed check 3
Remaining balance: 15000
Remaining balance: 5000
Remaining balance: -5000
```

The first count is known. The second loop depends on the balance state.

## 12. Synthesis table

| Job | Python tool |
|---|---|
| Known repetition count | `for` |
| Create numbers | `range()` |
| First value | start |
| Stop boundary | stop, excluded |
| Movement amount | step |
| Unknown stop state | `while` |

## 13. Troubleshooting

### Problem 1
- What happens: the final day is missing.
- Likely cause: the stop value is excluded.
- Fix: use the number after the final day as stop.
- Prevention: write the values from `range(1, 4)` by hand.

### Problem 2
- What happens: the loop runs zero times.
- Likely cause: direction and step do not match.
- Fix: use a negative step for a reverse range.
- Prevention: draw an arrow from start towards stop.

### Problem 3
- What happens: the total is wrong.
- Likely cause: the accumulator was not set to zero first.
- Fix: write `total = 0` before the loop.
- Prevention: record each running total.

### Problem 4
- What happens: a manual counter update appears inside `for`.
- Likely cause: a `while` habit.
- Fix: let `range()` provide the next value.
- Prevention: remember that `for` receives the next value automatically.

## 14. Common Misconceptions

1. **Wrong:** `range(1, 4)` includes 4 → **Truth:** the stop value is excluded.
2. **Wrong:** the `for` variable needs manual updates → **Truth:** `range()` supplies the next value.
3. **Wrong:** steps are always positive → **Truth:** negative steps reverse the range.
4. **Wrong:** `for` is always better than `while` → **Truth:** `for` is clearer for known counts.
5. **Wrong:** `range()` creates all data as a list first → **Truth:** it supplies values for iteration.

### Exercise 5, Rafiq bhai’s bug

Rafiq bhai wrote:

```python
for day in range(1, 4):
    print(f"Day {day}")
day += 1
```

The boss saw that the update after the loop did not change the loop count. The `for` loop gets its values from `range()`. The outside update does not control it. Minimal fix:

```python
for day in range(1, 4):
    print(f"Day {day}")
```

Output:

```text
Day 1
Day 2
Day 3
```

Lesson: `range()` controls a `for` loop. Do not add a manual counter.

## 16. Quiz

1. What does `range(1, 4)` give?  
   a) 1, 2, 3  b) 1, 2, 3, 4  c) 0, 1, 2  
   **Answer: a**, because 4 is excluded.
2. What is the third `range()` argument?  
   a) stop  b) step  c) name  
   **Answer: b**, because it controls the increment.
3. What does a reverse range need?  
   a) a negative step  b) zero  c) text  
   **Answer: a**, because values decrease.
4. Which loop suits a known count?  
   a) `for`  b) always `while`  c) `if`  
   **Answer: a**, because `range()` supplies the count.
5. Where does an accumulator usually start?  
   a) before the loop  b) after the loop  c) nowhere  
   **Answer: a**, because each iteration updates it.
6. What is the final value in `range(2, 8, 2)`?  
   a) 6  b) 8  c) 2  
   **Answer: a**, because 8 is the stop boundary.
7. Who supplies the next `for` value?  
   a) `range()`  b) `print()`  c) `if`  
   **Answer: a**, because the sequence supplies values.

## 17. Key Idea

`for` makes known repetition simple. In `range()`, start is included, stop is excluded, and step controls movement.

**Rhyme:**  
Start begins the journey, stop marks the door,  
Step tells the distance, then `for` does more.
