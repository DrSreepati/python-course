# উপবিষয় 2.2: Core types, int, float, str, bool

## Objective

এই পাঠের শেষে শিক্ষার্থী পারবে:

1. ডেটার type বা ধরন সহজ ভাষায় ব্যাখ্যা করতে।

3. `float` দিয়ে দশমিক সংখ্যা চিনতে ও ব্যবহার করতে।
4. `str` দিয়ে লেখা বা text চিনতে ও ব্যবহার করতে।
5. `bool`-এর `True` এবং `False` মান ব্যাখ্যা করতে।
6. ব্যবসায়িক ডেটায় উপযুক্ত core type বেছে নিতে।

## 1. Type কী

Type হলো একটি মানের শ্রেণি। দোকানের খাতায় টাকা, customer-এর নাম, এবং credit অনুমোদনের উত্তর এক ধরনের ডেটা নয়।

```python
daily_sales = 12000
customer = "Rahim Traders"
credit_approved = True

print(daily_sales)
print(customer)
print(credit_approved)
```

**Output**

```text
12000
Rahim Traders
True
```

`12000` একটি পূর্ণ সংখ্যা, `"Rahim Traders"` লেখা, এবং `True` একটি Boolean মান। Variable-এর নাম আলাদা, কিন্তু type মানের বৈশিষ্ট্য।

## 2. `int`, পূর্ণ সংখ্যা

`int` মানে integer, অর্থাৎ দশমিক অংশহীন পূর্ণ সংখ্যা। Quantity, invoice count, বা টাকার পূর্ণ অঙ্কে এটি ব্যবহার করা যায়।

```python
quantity = 4
invoice_count = 12
print(quantity)
print(invoice_count)
```

**Output**

```text
4
12
```

দুটি মানেরই দশমিক অংশ নেই। তাই এগুলো `int`-এর উদাহরণ।

## 3. `float`, দশমিক সংখ্যা

`float` হলো দশমিক সংখ্যা। Unit price-এ পয়সা বা VAT rate থাকলে দশমিক দরকার হতে পারে।

```python
unit_price = 250.50
vat_rate = 7.5
print(unit_price)
print(vat_rate)
```

**Output**

```text
250.5
7.5
```

Python `250.50`-কে দেখানোর সময় শেষের অপ্রয়োজনীয় শূন্য বাদ দিতে পারে। মানটি তবু `float`।

## 4. `str`, লেখা

`str` মানে string, অর্থাৎ অক্ষর বা text-এর ধারাবাহিকতা। Customer name, invoice code, এবং product label সাধারণত string।

```python
customer = "Rahim Traders"
invoice_number = "INV-2024-007"
print(customer)
print(invoice_number)
```

**Output**

```text
Rahim Traders
INV-2024-007
```

উদ্ধৃতি চিহ্ন text-এর সীমানা বোঝায়। Invoice number-এ সংখ্যা থাকলেও এটি code, তাই string হিসেবে রাখা উপযুক্ত।

## 5. `bool`, সত্য বা মিথ্যা

`bool` মানে Boolean। এতে মাত্র দুটি মান থাকে: `True` এবং `False`। এগুলো quotation marks ছাড়া লিখতে হয়।

```python
stock_available = True
payment_received = False
print(stock_available)
print(payment_received)
```

**Output**

```text
True
False
```

`True` মানে শর্তটি সত্য, আর `False` মানে শর্তটি সত্য নয়। Boolean spelling এবং capital letter ঠিক রাখতে হবে।

## 6. উদ্ধৃতি চিহ্ন type বদলায়

একই অঙ্ক quotation marks-এর ভিতরে দিলে তা text হয়ে যায়। হিসাবের জন্য সংখ্যা, code-এর জন্য text বেছে নিন।

```python
balance = 50000
balance_label = "50000"

print(balance)
print(balance_label)
```

**Output**

```text
50000
50000
```

দুই output দেখতে এক হলেও প্রথমটি `int`, দ্বিতীয়টি `str`। শুধু output দেখে type সব সময় বোঝা যায় না।

## 7. একটি business record-এ বহু type

একটি invoice record-এ customer-এর নাম, quantity, unit price, এবং payment status আলাদা type হতে পারে।

```python
customer = "Karim Store"
quantity = 6
unit_price = 120.0
paid = False

print(customer, quantity, unit_price, paid)
```

**Output**

```text
Karim Store 6 120.0 False
```

`customer` হলো `str`, `quantity` হলো `int`, `unit_price` হলো `float`, এবং `paid` হলো `bool`। একটি রিপোর্টে type মিশে থাকাই স্বাভাবিক।

## 8. Type বেছে নেওয়ার নিয়ম

প্রশ্ন করুন: এটি কি গোনা যায়, মাপা যায়, লেখা, না কি হ্যাঁ বা না? গোনা যায় এমন পূর্ণ সংখ্যা `int`, দশমিকসহ মাপ `float`, নাম বা code `str`, এবং সিদ্ধান্ত `bool` হতে পারে।

```python
customer_code = "C-1023"
items_in_box = 24
discount_rate = 5.0
is_overdue = True

print(customer_code)
print(items_in_box)
print(discount_rate)
print(is_overdue)
```

**Output**

```text
C-1023
24
5.0
True
```

Customer code-এ সংখ্যা থাকলেও এটি identifier, তাই string। এই পার্থক্য ভবিষ্যতের validation এবং reporting-এ গুরুত্বপূর্ণ।

## 9. Type ভুল বাছলে কী হয়

দেখতে সংখ্যা হলেই তা হিসাবের সংখ্যা নয়। `"120"` text হিসেবে রাখা হলে পরে হিসাব করতে casting দরকার হবে, যা আমরা 2.5-এ বিস্তারিত শিখব।

```python
quantity = 4
quantity_text = "4"

print(quantity + 2)
print(quantity_text)
```

**Output**

```text
6
4
```

প্রথম লাইনে `int`-এর সঙ্গে `int` যোগ হয়েছে। দ্বিতীয়টি শুধু text হিসেবে print হয়েছে। Text-কে জোর করে সংখ্যা ভাবা নিরাপদ নয়।

## 10. Type চিনে code পড়া

Code পড়ার সময় value-এর চিহ্ন দেখুন: quotation marks থাকলে সাধারণত `str`, দশমিক থাকলে `float`, `True` বা `False` হলে `bool`, আর সাধারণ পূর্ণ সংখ্যা হলে `int`।

```python
sales = 51000
margin_rate = 12.5
customer_name = "Jahid Enterprise"
report_ready = True

print(sales)
print(margin_rate)
print(customer_name)
print(report_ready)
```

**Output**

```text
51000
12.5
Jahid Enterprise
True
```

প্রতিটি value-এর role ও type আলাদা। ব্যবসায়িক হিসাব পরিষ্কার রাখতে এই পার্থক্য মনে রাখুন।

## Troubleshooting

# Problem 1: `"50000"`-কে সংখ্যা মনে হচ্ছে

- কী হচ্ছে: output সংখ্যা মতো দেখালেও value text।
- সম্ভাব্য কারণ: quotation marks ব্যবহার করা হয়েছে।
- ধাপে ধাপে সমাধান: quotation marks সরান, `balance = 50000` লিখুন, তারপর run করুন।
- পরের বার প্রতিরোধ: code বা name হলে quotes, হিসাবের সংখ্যা হলে quotes নয়।

# Problem 2: `True` বা `False` কাজ করছে না

- কী হচ্ছে: Python Boolean value চিনতে পারছে না।
- সম্ভাব্য কারণ: `true`, `false`, বা `"True"` লেখা হয়েছে।
- ধাপে ধাপে সমাধান: `True` বা `False` capital letter-সহ লিখুন এবং quotes সরান।
- পরের বার প্রতিরোধ: Boolean-এর দুইটি নির্দিষ্ট spelling মনে রাখুন।

# Problem 3: দশমিক মানের শেষে শূন্য নেই

- কী হচ্ছে: `250.50` print করলে `250.5` দেখা যাচ্ছে।
- সম্ভাব্য কারণ: Python অপ্রয়োজনীয় শেষের শূন্য দেখায় না।
- ধাপে ধাপে সমাধান: মানটি float হিসেবেই রাখুন; display format আলাদা বিষয়।
- পরের বার প্রতিরোধ: output-এর চেহারা দেখে type বিচার করবেন না।

# Problem 4: code-কে হিসাবের সংখ্যা করা হয়েছে

- কী হচ্ছে: `C-1023` বা invoice code-কে arithmetic value হিসেবে ব্যবহার করা হচ্ছে।
- সম্ভাব্য কারণ: code-এর ভিতরে সংখ্যা দেখে `int` ভাবা হয়েছে।
- ধাপে ধাপে সমাধান: code-টি quotation marks-এর ভিতরে রাখুন এবং `str` হিসেবে ব্যবহার করুন।
- পরের বার প্রতিরোধ: identifier গোনা নয়, তাই string।

## Common Misconceptions

1. ভুল দাবি: quotation marks-এর ভিতরের সংখ্যা সব সময় `int`। → সত্য: তা `str`।
2. ভুল দাবি: `250.50` এবং `250` একই type। → সত্য: প্রথমটি `float`, দ্বিতীয়টি `int`।
3. ভুল দাবি: `True` শুধু সাধারণ English word। → সত্য: এটি Boolean value।
4. ভুল দাবি: invoice code-এ সংখ্যা আছে, তাই তা `int`। → সত্য: code সাধারণত `str`।
5. ভুল দাবি: একটি report-এ সব value একই type হতে হবে। → সত্য: business record-এ বহু type একসঙ্গে থাকে।

## Key Idea

Core type বলে value কীভাবে ব্যবহার করা উচিত। `int` পূর্ণ সংখ্যা, `float` দশমিক সংখ্যা, `str` লেখা বা code, আর `bool` সত্য বা মিথ্যা সিদ্ধান্ত রাখে।

**ছড়া 1:** পূর্ণ সংখ্যা int, দশমিকে float,  
নাম আর code string, Boolean-এ truth ফল।

**ছড়া 2:** True বা False, সিদ্ধান্তের দরজা,  
সঠিক type রাখলে সহজ হয় খাতা।
