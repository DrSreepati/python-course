## 6. What is a tuple?

A tuple is an ordered group of values. It has positions like a list, but its items cannot change after creation.

```python
invoice_summary = ("INV-2024-007", "Rahim Traders", 50000)
print(invoice_summary)
```

**Output**

```text
('INV-2024-007', 'Rahim Traders', 50000)
```

- Parentheses are the usual tuple markers.
- The order stays fixed.
- A tuple can hold text and numbers together.

## 7. Creating tuples

A comma creates a tuple, even without parentheses.

```python
customer = "Rahim Traders", 50000
print(customer)

single_value = ("INV-2024-007",)
print(single_value)
```

**Output**

```text
('Rahim Traders', 50000)
('INV-2024-007',)
```

A one-item tuple needs a trailing comma. `("code")` is only a string.

## 8. Indexing

Tuple indexes are zero-based, like list indexes.

```python
invoice_summary = ("INV-2024-007", "Rahim Traders", 50000)
print(invoice_summary[0])
print(invoice_summary[1])
print(invoice_summary[-1])
```

**Output**

```text
INV-2024-007
Rahim Traders
50000
```

The first item is index 0. The last item is index -1.

## 9. Slicing

A tuple slice returns a new tuple.

```python
weekly_summary = ("Mon", 5000, "Tue", 4200, "Wed", 6100)
print(weekly_summary[0:3])
print(weekly_summary[2:])
```

**Output**

```text
('Mon', 5000, 'Tue')
('Tue', 4200, 'Wed', 6100)
```

The start is included. The stop is excluded. The original tuple stays unchanged.

## 10. Immutability

Tuple item assignment is not allowed.

```python
invoice_summary = ("INV-2024-007", "Rahim Traders", 50000)
invoice_summary[2] = 55000
```

**Output**

```text
TypeError: 'tuple' object does not support item assignment
```

This error is expected. Tuples protect fixed invoice identity or approved categories from accidental changes.

## 11. Reading and calculating

A tuple is immutable, but it can be read and processed.

```python
daily_sales = (12000, 9500, 8800, 13200, 7500)
total = sum(daily_sales)
best = max(daily_sales)

print(total)
print(best)
```

**Output**

```text
51000
13200
```

Read-only does not mean unusable. You can loop, slice, sum, and inspect a tuple.

## 12. List to tuple

Make a fixed snapshot from a mutable list.

```python
report = [12000, 9500, 8800]
approved_report = tuple(report)
report[0] = 13000

print(report)
print(approved_report)
```

**Output**

```text
[13000, 9500, 8800]
(12000, 9500, 8800)
```

`tuple(report)` captures a snapshot. Later list changes do not change it.

## 14. Troubleshooting

### Problem 1: `TypeError` on item assignment
- **What happens:** A tuple item change fails.
- **Likely cause:** Tuples are immutable.
- **Fix:** Build a new tuple, or use a list for changing data.
- **Prevent it:** Decide whether the data is fixed or changing.

### Problem 2: A single value is not a tuple
- **What happens:** `("INV-001")` is a string.
- **Likely cause:** The trailing comma is missing.
- **Fix:** Write `("INV-001",)`.
- **Prevent it:** Remember the comma for one-item tuples.

### Problem 3: `IndexError`
- **What happens:** An index is outside the tuple.
- **Likely cause:** The zero-based position was miscounted.
- **Fix:** Check `len()` and use a valid index.
- **Prevent it:** Use `-1` for the final item.

### Problem 4: A slice has fewer items
- **What happens:** The stop item is missing.
- **Likely cause:** The stop boundary is excluded.
- **Fix:** Increase the stop position when needed.
- **Prevent it:** Remember, start included and stop excluded.

## 15. Common Misconceptions

1. **Wrong:** Tuples have no indexes. → **Truth:** Tuples are ordered and indexed.
2. **Wrong:** Tuples cannot be used. → **Truth:** They can be read, looped, sliced, and calculated.
3. **Wrong:** `("code")` is a one-item tuple. → **Truth:** It is a string.
4. **Wrong:** A tuple slice changes the original. → **Truth:** It returns a new tuple.
5. **Wrong:** All business data should be tuples. → **Truth:** Lists suit changing data.

### Exercise 5: Sreepati debugging bug

Sreepati wanted to correct the amount in an approved invoice record.

```python
approved = ("INV-2024-007", 50000)
approved[1] = 55000
print(approved)
```

**Wrong output**

```text
TypeError: 'tuple' object does not support item assignment
```

The boss asked, “How can we change an approved record?”

**Diagnosis:** A tuple is immutable. Item assignment is not allowed.

**Minimal fix**

```python
approved = ("INV-2024-007", 50000)
corrected = (approved[0], 55000)
print(corrected)
```

**Correct output**

```text
('INV-2024-007', 55000)
```

**Lesson:** Build a new tuple when immutable data needs a new value.

## 17. Quiz

1. What is a main tuple feature?  
   a) Ordered and immutable  
   b) Unordered and editable  
   c) Numbers only  
   **Answer: a.** Tuples keep positions but reject item assignment.

2. Which is a one-item tuple?  
   a) `("INV")`  
   b) `["INV"]`  
   c) `("INV",)`  
   **Answer: c.** The comma creates the tuple.

3. What is the first tuple index?  
   a) 0  
   b) 1  
   c) -1  
   **Answer: a.** Python uses zero-based indexes.

4. What does `data[1:3]` include?  
   a) Indexes 1 and 2  
   b) Indexes 1, 2, and 3  
   c) Only index 3  
   **Answer: a.** The stop boundary is excluded.

5. What happens on tuple item assignment?  
   a) The item changes  
   b) `TypeError` occurs  
   c) The tuple becomes a list  
   **Answer: b.** Tuples are immutable.

6. How do you make a fixed snapshot from a list?  
   a) `tuple(report)`  
   b) `report == tuple`  
   c) `report[0]`  
   **Answer: a.** It creates a tuple from the list values.

7. Which data suits a list better?  
   a) An approved fixed record  
   b) A changing daily report  
   c) An immutable invoice code  
   **Answer: b.** Lists suit changing data.
