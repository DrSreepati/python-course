## 1. Formula কেন দরকার

Formula হলো business rule-এর সংক্ষিপ্ত mathematical ভাষা। Code-এ formula লিখলে একই নিয়ম বহু invoice বা report-এ ব্যবহার করা যায়।

```python
quantity = 10
unit_price = 300
sales = quantity * unit_price

print(sales)
```

**Output**

```text
3000
```

Quantity এবং unit price input। Multiplication sales amount তৈরি করেছে।

## 2. Sales formula

Sales বা revenue হলো বিক্রির মোট value। Formula: `Sales = Quantity × Unit Price`।

```python
quantity = 12
unit_price = 250
sales = quantity * unit_price

print(f"Sales: {sales:.2f} taka")
```

**Output**

```text
Sales: 3000.00 taka
```

`quantity * unit_price` formula-র সরাসরি code। `:.2f` শুধু display format।

## 3. Cost formula

কোনো পণ্য কিনতে বা তৈরি করতে যে total খরচ হয়, তা cost। Quantity এবং unit cost গুণ করে total cost পাওয়া যায়।

```python
quantity = 12
unit_cost = 180
cost = quantity * unit_cost

print(f"Cost: {cost:.2f} taka")
```

**Output**

```text
Cost: 2160.00 taka
```

12টি item, প্রতিটির cost 180 টাকা। Total cost 2160 টাকা।

## 4. Profit formula

Profit হলো sales থেকে cost বাদ দেওয়ার ফল। Formula: `Profit = Sales - Cost`।

```python
sales = 3000
cost = 2160
profit = sales - cost

print(f"Profit: {profit:.2f} taka")
```

**Output**

```text
Profit: 840.00 taka
```

Sales বেশি হলে positive profit দেখা যায়। Cost বেশি হলে result negative হতে পারে।

## 5. Margin percentage

Margin percentage বলে sales-এর কত অংশ profit। Formula: `Margin % = Profit / Sales × 100`।

```python
sales = 3000
profit = 840
margin_percentage = profit / sales * 100

print(f"Margin: {margin_percentage:.2f}%")
```

**Output**

```text
Margin: 28.00%
```

Profit 840 কে sales 3000 দিয়ে ভাগ করে 100 গুণ করা হয়েছে। Margin হলো percentage, profit amount নয়।

## 6. Formula-কে ধাপে ভাঙা

এক লাইনে সব না লিখে ধাপে ধাপে লিখলে report যাচাই সহজ হয়। প্রতিটি intermediate value আলাদা নাম পায়।

```python
quantity = 5
unit_price = 450
unit_cost = 320

sales = quantity * unit_price
cost = quantity * unit_cost
profit = sales - cost
margin = profit / sales * 100

print(sales)
print(cost)
print(profit)
print(margin)
```

**Output**

```text
2250
1600
650
28.88888888888889
```

প্রথমে sales এবং cost, তারপর profit, শেষে margin হিসাব হয়েছে। ধাপগুলো formula-র dependency অনুসরণ করে।

## 7. Revenue ও cost report

একটি summary-তে raw inputs এবং calculated values দুটোই রাখা উচিত। এতে boss result-এর উৎস বুঝতে পারেন।

```python
quantity = 5
unit_price = 450
unit_cost = 320
sales = quantity * unit_price
cost = quantity * unit_cost
profit = sales - cost

print(f"Quantity: {quantity}")
print(f"Sales: {sales:.2f}")
print(f"Cost: {cost:.2f}")
print(f"Profit: {profit:.2f}")
```

**Output**

```text
Quantity: 5
Sales: 2250.00
Cost: 1600.00
Profit: 650.00
```

প্রতিটি line report-এর একটি business fact দেখায়। Formatting report-কে readable করে।

## 8. Zero sales guard

Margin formula-তে sales denominator। Sales zero হলে division করা যাবে না। আগে comparison করে condition আলাদা রাখা নিরাপদ।

```python
sales = 0
profit = 0

if sales == 0:
    print("Margin is not available")
else:
    margin = profit / sales * 100
    print(margin)
```

**Output**

```text
Margin is not available
```

`sales == 0` সত্য, তাই division-এর আগে program থেমে safe message দেখায়।

## 9. Formula যাচাই

Formula ঠিক আছে কি না, পরিচিত numbers দিয়ে manual check করুন। Quantity 10, price 100 হলে sales অবশ্যই 1000 হবে।

```python
quantity = 10
unit_price = 100
unit_cost = 70

sales = quantity * unit_price
cost = quantity * unit_cost
profit = sales - cost
margin = profit / sales * 100

print(sales == 1000)
print(cost == 700)
print(profit == 300)
print(margin == 30)
```

**Output**

```text
True
True
True
True
```

Comparison result দিয়ে expected values যাচাই করা হয়েছে। এটি ছোট calculation-এর জন্য useful sanity check।

## 10. একটি business summary

এখন quantity, price, cost এবং margin একসঙ্গে ব্যবহার করি। এই pattern পরে VAT এবং discount formula-তেও কাজে লাগবে।

```python
quantity = 8
unit_price = 500
unit_cost = 350

sales = quantity * unit_price
cost = quantity * unit_cost
profit = sales - cost
margin = profit / sales * 100

print(f"Sales: {sales:.2f}")
print(f"Profit: {profit:.2f}")
print(f"Margin: {margin:.2f}%")
```

**Output**

```text
Sales: 4000.00
Profit: 1200.00
Margin: 30.00%
```

প্রথমে sales, তারপর cost, profit এবং margin তৈরি হয়েছে। প্রতিটি result আগের value-এর উপর নির্ভরশীল।

## Synthesis table

|---|---|---|

| Cost | quantity × unit cost | `quantity * unit_cost` |

## Troubleshooting

### Problem 1: Profit negative হচ্ছে

- কী হচ্ছে: result-এর আগে minus sign দেখা যাচ্ছে।
- সম্ভাব্য কারণ: cost sales-এর চেয়ে বেশি, অথবা formula উল্টো লেখা হয়েছে।
- ধাপ: sales এবং cost print করুন, formula `sales - cost` যাচাই করুন।
- প্রতিরোধ: expected profit আগে অনুমান করুন।

### Problem 2: Margin 28 না হয়ে 0.28 দেখাচ্ছে

- কী হচ্ছে: margin ratio পাওয়া গেছে, percentage নয়।
- সম্ভাব্য কারণ: `* 100` বাদ গেছে।
- ধাপ: `profit / sales * 100` লিখুন এবং `%` sign display করুন।
- প্রতিরোধ: ratio এবং percentage আলাদা নাম ব্যবহার করুন।

### Problem 3: ZeroDivisionError দেখা যাচ্ছে

- কী হচ্ছে: sales zero হওয়ায় margin হিসাব করা যাচ্ছে না।
- সম্ভাব্য কারণ: denominator check করা হয়নি।
- ধাপ: `if sales == 0` আগে পরীক্ষা করুন, তারপর division করুন।
- প্রতিরোধ: যেকোনো denominator-এর zero case লিখে রাখুন।

### Problem 4: Sales amount ভুল

- কী হচ্ছে: quantity এবং price থাকা সত্ত্বেও total ভুল।
- সম্ভাব্য কারণ: unit price-এর বদলে unit cost ব্যবহার হয়েছে, অথবা যোগ করা হয়েছে।
- ধাপ: input names print করুন, formula `quantity * unit_price` মিলান।
- প্রতিরোধ: sales এবং cost-এর জন্য আলাদা variable name রাখুন।

## Common Misconceptions

1. **ভুল:** profit এবং margin একই → **সত্য:** profit টাকার amount, margin percentage।
2. **ভুল:** margin হলো `profit / cost * 100` → **সত্য:** এই course formula-তে margin sales-এর উপর ভিত্তি করে।
3. **ভুল:** sales zero হলেও margin বের করা যায় → **সত্য:** zero denominator-এ division করা যায় না।
4. **ভুল:** `:.2f` formula rounding rule ঠিক করে → **সত্য:** এটি display formatting।
5. **ভুল:** formula এক লাইনে লিখলেই ভালো → **সত্য:** ধাপে লিখলে audit এবং debugging সহজ।

### Exercise 5: Rafiq bhai-এর debugging bug

Rafiq bhai লিখেছেন:

```python
sales = 5000
cost = 3500
profit = sales - cost
margin = profit / cost * 100
print(margin)
```

Boss sales-এর উপর margin চান, কিন্তু Rafiq bhai cost-কে denominator করেছেন। Output `42.857142857142854`।  
**Cause:** margin formula-তে sales-এর বদলে cost ব্যবহার হয়েছে।  
**Minimal fix:** `margin = profit / sales * 100`।

```python
margin = profit / sales * 100
print(margin)  # Expected: 30.0
```

**Lesson:** margin-এর denominator business definition অনুযায়ী বেছে নিন।
