## 6. সাধারণ loop থেকে নতুন list

প্রথমে প্রতিটি sale-এর সঙ্গে 10% যোগ করে নতুন list বানাই।

```python
sales = [12000, 9500, 8800]
updated_sales = []

for sale in sales:
    updated_sales.append(sale * 1.10)

print(updated_sales)
```

**Output**

```text
[13200.000000000002, 10450.0, 9680.000000000002]
```

- `updated_sales = []` খালি list।
- loop প্রতিটি sale নেয়।
- `append()` নতুন হিসাবটি যোগ করে।
- floating-point ফলের জন্য দীর্ঘ decimal দেখা যেতে পারে।

## 7. List comprehension-এর গঠন

একই কাজ সংক্ষিপ্তভাবে লেখা যায়।

```python
sales = [12000, 9500, 8800]
updated_sales = [sale * 1.10 for sale in sales]

print(updated_sales)
```

**Output**

```text
[13200.000000000002, 10450.0, 9680.000000000002]
```

গঠনটি হলো:

```python
[expression for item in source]
```

`sale * 1.10` হলো expression, `sale` হলো একবারে নেওয়া item, আর `sales` হলো source list।

## 8. Condition দিয়ে item বাছাই

শুধু ১০,০০০-এর বেশি sale চাইলে condition শেষে বসে।

```python
sales = [12000, 9500, 8800, 13200, 7500]
large_sales = [sale for sale in sales if sale > 10000]

print(large_sales)
```

**Output**

```text
[12000, 13200]
```

- `for sale in sales` সব item দেখে।
- `if sale > 10000` ছোট sale বাদ দেয়।
- condition সত্য হলে সেই `sale` নতুন list-এ যায়।

## 9. `if-else` দিয়ে প্রতিটি item-এর label

একটি expression-এর ফল condition অনুযায়ী বদলাতে চাইলে `if-else` expression-এর জায়গায় থাকে।

```python
sales = [12000, 9500, 13200]
labels = ["High" if sale >= 10000 else "Regular" for sale in sales]

print(labels)
```

**Output**

```text
['High', 'Regular', 'High']
```

এখানে `if-else` আগে এসেছে, কিন্তু filtering-এর `if` শেষে আসে। এই পার্থক্য মনে রাখুন।

## 10. Business report: customer balance filter

```python
customers = ["Rahim Traders", "Karim Store", "Jahid Enterprise"]
balances = [50000, 32000, 71000]
large_balances = [balance for balance in balances if balance >= 50000]

print(large_balances)
```

**Output**

```text
[50000, 71000]
```

এটি শুধু balance রাখে। customer name-ও রাখতে হলে parallel list-এর index ব্যবহার করা যায়।

## 11. Comprehension এবং enumerate

```python
sales = [12000, 9500, 8800]
day_labels = [f"Day {day}: {sale}" for day, sale in enumerate(sales, start=1)]

print(day_labels)
```

**Output**

```text
['Day 1: 12000', 'Day 2: 9500', 'Day 3: 8800']
```

`enumerate()` position ও value দেয়, আর comprehension তাদের দিয়ে নতুন text list বানায়।

## 14. Troubleshooting

### সমস্যা 1: `SyntaxError`
- **কী হচ্ছে:** comprehension-এর bracket বা order ভুল।
- **সম্ভাব্য কারণ:** `for`-এর আগে source list বা expression নেই।
- **Fix:** `[expression for item in source]` pattern লিখুন।
- **আগে প্রতিরোধ:** আগে সাধারণ loop লিখে অংশগুলো চিহ্নিত করুন।

### সমস্যা 2: খালি list
- **কী হচ্ছে:** নতুন list-এ কোনো item নেই।
- **সম্ভাব্য কারণ:** condition কোনো item-এর জন্য সত্য নয়।
- **Fix:** threshold এবং comparison operator পরীক্ষা করুন।
- **আগে প্রতিরোধ:** একই data-তে condition আলাদা করে print করুন।

### সমস্যা 3: `NameError`
- **কী হচ্ছে:** comprehension-এর variable চেনা যাচ্ছে না।
- **সম্ভাব্য কারণ:** expression-এ loop variable-এর বদলে অন্য নাম লেখা।
- **Fix:** `for`-এর পরের নাম expression-এ একইভাবে ব্যবহার করুন।
- **আগে প্রতিরোধ:** variable name ছোট ও consistent রাখুন।

### সমস্যা 4: unexpected nested list
- **কী হচ্ছে:** নতুন list-এর item নিজেই list হয়ে গেছে।
- **সম্ভাব্য কারণ:** `append()`-এর মতো করে পুরো list ঢুকেছে, বা nested data-এর level বোঝা হয়নি।
- **Fix:** আপনার দরকার item, row, না পুরো table, তা আগে ঠিক করুন।
- **আগে প্রতিরোধ:** output-এর একটি item-এর type দেখে নিন।

## 15. Common Misconceptions

1. **ভুল:** comprehension নতুন source list বদলায়। → **সত্য:** সাধারণত নতুন list বানায়।
2. **ভুল:** comprehension সবসময় সাধারণ loop-এর চেয়ে ভালো। → **সত্য:** জটিল কাজে loop বেশি পাঠযোগ্য।
3. **ভুল:** শেষে `if` দিলে প্রতিটি item বদলায়। → **সত্য:** শেষে `if` item বাছাই করে।
4. **ভুল:** `if-else` সবসময় শেষে থাকে। → **সত্য:** transformation-এর `if-else` expression-এর মধ্যে থাকে।
5. **ভুল:** comprehension-এ condition বাদ দিলে সব item অবশ্যই থাকবে। → **সত্য:** expression error করলে list তৈরি হবে না।

## 16. Exercises with solutions

### Exercise 1

`report = [12000, 9500, 8800, 13200, 7500]` থেকে ১০০০ কমিয়ে নতুন list বানান।

**Solution**

```python
report = [12000, 9500, 8800, 13200, 7500]
reduced = [sale - 1000 for sale in report]
print(reduced)
```

**Output**

```text
[11000, 8500, 7800, 12200, 6500]
```

### Exercise 4

### Exercise 5: Rafiq bhai debugging bug

Rafiq bhai সব invoice-এর amount চেয়েছিলেন, কিন্তু তাঁর code শুধু সত্য condition-সহ item রাখছে।

```python
amounts = [12000, 9500, 8800]
report = [amount for amount in amounts if amount > 10000]
print(report)
```

**Wrong output**

```text
[12000]
```

Boss বললেন, “পুরো invoice report কোথায়?”

**Diagnosis:** শেষে `if` filtering করে। এটি transformation নয়, তাই ছোট amount বাদ গেছে।

**Minimal fix**

```python
amounts = [12000, 9500, 8800]
report = [amount for amount in amounts]
print(report)
```

**Correct output**

```text
[12000, 9500, 8800]
```

**Lesson:** নতুন list-এ সব item চাইলে filtering condition লিখবেন না।

## 17. Quiz

   a) `[2, 3]`

   b) expression-এর আগে  
   c) `for` অংশের পরে  
   **উত্তর: c।** সাধারণ pattern হলো `[x for x in data if condition]`।

3. `["High" if x >= 10 else "Low" for x in sales]` কী করে?  
   a) প্রতিটি item label করে  
   b) শুধু High রাখে  
   c) source বদলায়

4. কোনটি source list সাধারণত বদলায় না?  
   a) `append()`  
   b) list comprehension  
   c) `remove()`

## 18. Key Idea

List comprehension হলো loop, expression এবং প্রয়োজনে condition মিলিয়ে নতুন list বানানোর সংক্ষিপ্ত পদ্ধতি।

**ছড়া ১:**  
লুপের কাজে নতুন list চাই,  
comprehension মনে রাখি তাই।

**ছড়া ২:**  
শেষে `if` বেছে নেয়,  
মাঝের expression মান বদলায়।
