## 6. Transaction processing

Transaction list-এর প্রতিটি amount দেখে receipt তৈরি করা যায়।

```python
transactions = [5000, 4200, 6100, 3800]
transaction_total = 0

for amount in transactions:
    if amount <= 0:
        continue
    transaction_total += amount
    print(f"Processed transaction: {amount}")

print(f"Transaction total: {transaction_total}")
```

**Output**

```text
Processed transaction: 5000
Processed transaction: 4200
Processed transaction: 6100
Processed transaction: 3800
Transaction total: 19100
```

Loop প্রতিটি transaction নেয়। valid amount total-এ যোগ হয়, আর `continue` invalid amount বাদ দিতে পারে।

## 7. Invoice total

একটি invoice-এর line item যোগ করে invoice total পাওয়া যায়।

```python
invoice_items = [12000, 8000, 5000]
invoice_total = 0

for item_amount in invoice_items:
    invoice_total += item_amount

print(f"Invoice total: {invoice_total}")
```

**Output**

```text
Invoice total: 25000
```

`invoice_total` আগে zero। প্রতিটি line item একবার যোগ হয়েছে।

## 8. Running balance

Opening balance থেকে payment বাদ দিয়ে প্রতিটি ধাপ print করা যায়।

```python
balance = 50000
payments = [10000, 15000, 5000]

for payment in payments:
    balance -= payment
    print(f"After payment {payment}: balance {balance}")
```

**Output**

```text
After payment 10000: balance 40000
After payment 15000: balance 25000
After payment 5000: balance 20000
```

প্রতিটি payment পুরনো balance কমায়। এটি দাঁড়িপাল্লার মতো running state ধরে।

## 9. Monthly expense summary

Nested list-এ প্রতিটি month-এর expense group আছে।

```python
monthly_expenses = [
    [12000, 8000],
    [9500, 7000],
    [11000, 6000],
]

overall_expense = 0
month_number = 1

for expenses in monthly_expenses:
    month_total = 0
    for expense in expenses:
        month_total += expense
        overall_expense += expense
    print(f"Month {month_number}: {month_total}")
    month_number += 1

print(f"Overall expense: {overall_expense}")
```

**Output**

```text
Month 1: 20000
Month 2: 16500
Month 3: 17000
Overall expense: 53500
```

`month_total` প্রতি month-এ reset হয়। `overall_expense` সব month-এর amount ধরে।

## 10. Stop at an urgent transaction

আগের flow tools ব্যবহার করে urgent reference-এ processing থামানো যায়।

```python
references = ["INV-001", "INV-002", "INV-URGENT", "INV-004"]

for reference in references:
    print(f"Reviewing {reference}")
    if reference == "INV-URGENT":
        print("Manager review required")
        break
```

**Output**

```text
Reviewing INV-001
Reviewing INV-002
Reviewing INV-URGENT
Manager review required
```

Urgent record-এর পরে loop বন্ধ হয়েছে। এটি transaction report-এ safety gate হিসেবে কাজ করে।

## 12. Troubleshooting

### সমস্যা 1
- কী হচ্ছে: total শুধু শেষ amount দেখাচ্ছে।
- সম্ভাব্য কারণ: `=` দিয়ে accumulator overwrite হয়েছে।
- Fix: `+=` ব্যবহার করুন।
- Prevention: total-এর পুরনো value রাখতে হবে।

### সমস্যা 2
- কী হচ্ছে: month total সব month-এর combined total হচ্ছে।
- সম্ভাব্য কারণ: `month_total = 0` outer loop-এর ভিতরে নেই।
- Fix: প্রতিটি month শুরুতে reset করুন।
- Prevention: group total এবং overall total আলাদা নাম দিন।

### সমস্যা 3
- কী হচ্ছে: urgent transaction-এর পরেও record process হচ্ছে।
- সম্ভাব্য কারণ: `break` নেই বা wrong condition।
- Fix: urgent reference-এর ভিতরে `break` দিন।
- Prevention: urgent record-এর পরের sample রাখুন।

### সমস্যা 4
- কী হচ্ছে: balance payment-এর পরে ভুল।
- সম্ভাব্য কারণ: payment যোগ করা হয়েছে, বাদ নয়, অথবা update ভুল জায়গায়।
- Fix: `balance -= payment` loop-এর ভিতরে রাখুন।
- Prevention: প্রতিটি payment-এর পর expected balance লিখুন।

## 13. Common Misconceptions

1. **ভুল:** সব report-এর জন্য একটি total যথেষ্ট → **সত্য:** প্রতিটি business measure-এর আলাদা accumulator দরকার।
2. **ভুল:** nested loop শুধু display-এর জন্য → **সত্য:** grouped summary-তেও লাগে।
3. **ভুল:** payment balance বাড়ায় → **সত্য:** outstanding balance থেকে payment বাদ যায়।
4. **ভুল:** `continue` invalid record delete করে → **সত্য:** শুধু current iteration skip করে।
5. **ভুল:** report output দেখলেই correct → **সত্য:** expected totals দিয়ে verify করতে হয়।

### Exercise 5, Rafiq bhai bug

Rafiq bhai লিখেছেন:

```python
balance = 50000
for payment in [10000, 5000]:
    balance = payment
print(balance)
```

ভুল output: `5000`। Boss বললেন, final balance 5000 নয়। কারণ payment-কে balance বানানো হয়েছে। Fix:

```python
balance = 50000
for payment in [10000, 5000]:
    balance -= payment
print(balance)
```

Output:

```text
35000
```

Lesson: running balance-এ state update করতে হয়, replace নয়।
