## 6. List loop এবং manual counter

শুধু value দরকার হলে সাধারণ `for` যথেষ্ট।

```python
sales = [12000, 9500, 8800]

for sale in sales:
    print(sale)
```

**Output**

```text
12000
9500
8800
```

- `sale` একবারে একটি item নেয়।
- position দরকার হলে আলাদা counter লাগতে পারে।

## 7. Manual counter

পুরনো পদ্ধতিতে counter নিজে update করতে হয়।

```python
sales = [12000, 9500, 8800]
day_number = 1

for sale in sales:
    print(f"Day {day_number}: {sale}")
    day_number += 1
```

**Output**

```text
Day 1: 12000
Day 2: 9500
Day 3: 8800
```

- `day_number` report-এর label।
- `+= 1` না দিলে একই day বারবার আসবে।
- counter এবং list position আলাদা state।

## 8. `enumerate`

`enumerate()` loop-এ position এবং value একসঙ্গে দেয়।

```python
sales = [12000, 9500, 8800]

for index, sale in enumerate(sales):
    print(f"Index {index}: {sale}")
```

**Output**

```text
Index 0: 12000
Index 1: 9500
Index 2: 8800
```

- `index` zero-based position।
- `sale` current value।
- counter manually update করতে হয়নি।

## 9. `start=1`

Business report-এ day one দেখাতে `start=1` ব্যবহার করা যায়।

```python
sales = [12000, 9500, 8800]

for day_number, sale in enumerate(sales, start=1):
    print(f"Day {day_number}: {sale}")
```

**Output**

```text
Day 1: 12000
Day 2: 9500
Day 3: 8800
```

- list-এর প্রথম item এখনও index zero।
- শুধু displayed counter one থেকে শুরু হয়েছে।
- customer-facing report-এর জন্য এটি পরিষ্কার।

## 10. Customer এবং nested row report

`enumerate()` nested list-এর row number-ও দিতে পারে।

```python
customers = ["Rahim Traders", "Karim Store", "Jahid Enterprise"]
balances = [50000, 32000, 71000]

for customer_number, customer in enumerate(customers, start=1):
    print(f"Customer {customer_number}: {customer}, balance {balances[customer_number - 1]}")
```

**Output**

```text
Customer 1: Rahim Traders, balance 50000
Customer 2: Karim Store, balance 32000
Customer 3: Jahid Enterprise, balance 71000
```

- display number one-based।
- balance list-এর index পেতে `customer_number - 1` হয়েছে।
- একই position-এর দুই list aligned রাখা হয়েছে।

## 11. Audit report

Position এবং value একসঙ্গে থাকলে audit message সহজ হয়।

```python
references = ["INV-2024-007", "INV-2024-008", "INV-2024-009"]

for reference_number, reference in enumerate(references, start=1):
    print(f"Review {reference_number}: {reference}")
```

**Output**

```text
Review 1: INV-2024-007
Review 2: INV-2024-008
Review 3: INV-2024-009
```

- `reference_number` report sequence।
- `reference` আসল invoice code।
- code নিজে বদলায়নি, শুধু label যোগ হয়েছে।

## 12. Troubleshooting

### সমস্যা 1
- কী হচ্ছে: report day zero থেকে শুরু হচ্ছে।
- সম্ভাব্য কারণ: `enumerate(sales)`-এর default start zero।
- Fix: `enumerate(sales, start=1)` লিখুন।
- Prevention: technical index আর business label আলাদা ভাবুন।

### সমস্যা 2
- কী হচ্ছে: একই day number বারবার আসছে।
- সম্ভাব্য কারণ: manual counter update করা হয়নি।
- Fix: loop-এর শেষে `counter += 1` দিন।
- Prevention: সম্ভব হলে `enumerate()` ব্যবহার করুন।

### সমস্যা 3
- কী হচ্ছে: customer এবং balance mismatch।
- সম্ভাব্য কারণ: one-based display number-কে list index হিসেবে ব্যবহার করা হয়েছে।
- Fix: index দরকার হলে `number - 1` করুন, অথবা `enumerate`-এর index ব্যবহার করুন।
- Prevention: parallel lists-এর position check করুন।

### সমস্যা 4
- কী হচ্ছে: `ValueError: too many values to unpack` আসে।
- সম্ভাব্য কারণ: `enumerate()`-এর pair-কে একটি variable দিয়ে ধরার চেষ্টা।
- Fix: `for index, value in enumerate(items)` লিখুন।
- Prevention: enumerate দুইটি value দেয় মনে রাখুন।

## 13. Common Misconceptions

1. **ভুল:** `enumerate()` value বদলে দেয় → **সত্য:** position এবং value-এর pair দেয়।
2. **ভুল:** `start=1` list index-কে one-based করে → **সত্য:** শুধু returned counter-এর শুরু বদলায়।
3. **ভুল:** manual counter সবসময় সহজ → **সত্য:** update ভুলে গেলে bug হয়।
4. **ভুল:** enumerate-এর output শুধু index → **সত্য:** index এবং item দুটোই আসে।
5. **ভুল:** display number সরাসরি list index → **সত্য:** one-based display হলে index পেতে এক কমাতে হয়।

## 16. Key Idea

`enumerate()` list loop-এ position এবং value একসঙ্গে দেয়। Technical index zero-based থাকে, কিন্তু `start=1` দিয়ে business label পরিষ্কার করা যায়।

**ছড়া:**

Start one দিলে business day, বোঝা যায় একদম ঠিক।
