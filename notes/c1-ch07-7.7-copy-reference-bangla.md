## 6. একটি list-এর দুই নাম

`b = a` নতুন list বানায় না। দুই নাম একই list-কে refer করে।

```python
sales = [12000, 9500, 8800]
review_sales = sales
review_sales[0] = 13000

print(sales)
print(review_sales)
```

**Output**

```text
[13000, 9500, 8800]
[13000, 9500, 8800]
```

- `sales` একটি list-এর নাম।
- `review_sales = sales` একই list-এর আরেকটি নাম।
- একটি নাম দিয়ে item বদলালে অন্য নামেও বদল দেখা যায়।

## 7. Aliasing কেন ঝুঁকিপূর্ণ

যদি boss-এর original report এবং আপনার working report আলাদা হওয়া দরকার হয়, aliasing সমস্যা তৈরি করবে।

```python
original_report = [12000, 9500, 8800]
working_report = original_report
working_report.append(13200)

print(original_report)
```

**Output**

```text
[12000, 9500, 8800, 13200]
```

`append()` working report-এ নয়, একই shared list-এ item যোগ করেছে।

## 8. Slice দিয়ে shallow copy

```python
original_report = [12000, 9500, 8800]
working_report = original_report[:]
working_report[0] = 13000

print(original_report)
print(working_report)
```

**Output**

```text
[12000, 9500, 8800]
[13000, 9500, 8800]
```

`[:]` list-এর outer items নিয়ে নতুন list বানায়। তাই দুই list independent।

## 9. `.copy()` দিয়ে copy

```python
balances = [50000, 32000, 71000]
audit_balances = balances.copy()
audit_balances.pop()

print(balances)
print(audit_balances)
```

**Output**

```text
[50000, 32000, 71000]
[50000, 32000]
```

`.copy()`-ও একটি shallow copy। সাধারণ flat list-এর জন্য এটি পরিষ্কার পদ্ধতি।

## 10. Copy নাকি reference

```python
sales = [12000, 9500]
alias = sales
copy_one = sales[:]
copy_two = sales.copy()

alias.append(8800)
copy_one.append(13200)
copy_two.append(7500)

print(sales)
print(copy_one)
print(copy_two)
```

**Output**

```text
[12000, 9500, 8800]
[12000, 9500, 13200]
[12000, 9500, 7500]
```

শুধু `alias` original list-কে বদলেছে। দুই copy আলাদা list।

## 11. Nested list-এর সতর্কতা

Shallow copy outer list আলাদা করে, কিন্তু ভিতরের row একই থাকতে পারে।

```python
table = [[12000, 9500], [8800, 13200]]
table_copy = table[:]
table_copy[0][0] = 13000

print(table)
print(table_copy)
```

**Output**

```text
[[13000, 9500], [8800, 13200]]
[[13000, 9500], [8800, 13200]]
```

আজকের নিয়ম: flat list-এর shallow copy নিরাপদ। nested list-এর ভেতরের row আলাদা করতে আরও গভীর copying ধারণা পরে লাগবে।

## 12. Business rule

Original report সংরক্ষণ করে working copy-তে পরিবর্তন করুন। Audit-এর জন্য এটি নিরাপদ অভ্যাস।

## 13. Synthesis table

| প্রয়োজন | পদ্ধতি |
|---|---|
| একই list-এর আরেক নাম | `b = a` |
| flat list-এর slice copy | `a[:]` |
| flat list-এর স্পষ্ট copy | `a.copy()` |
| original-ও বদলাতে চাই | reference ব্যবহার |
| original অপরিবর্তিত রাখতে চাই | copy ব্যবহার |
| nested rows-ও independent চাই | shallow copy যথেষ্ট নয় |

## 14. Troubleshooting

### সমস্যা 1: original report বদলে গেছে
- **কী হচ্ছে:** working list বদলালে original-ও বদলেছে।
- **সম্ভাব্য কারণ:** `working = original` reference assignment হয়েছে।
- **Fix:** `working = original[:]` বা `working = original.copy()` লিখুন।
- **আগে প্রতিরোধ:** edit করার আগে list copy করুন।

### সমস্যা 2: copy-ও বদলে যাচ্ছে
- **কী হচ্ছে:** outer copy থাকা সত্ত্বেও nested row বদলেছে।
- **সম্ভাব্য কারণ:** shallow copy ভিতরের row copy করেনি।
- **Fix:** nested structure-এর জন্য আলাদা row copy নকশা করুন।
- **আগে প্রতিরোধ:** flat এবং nested data আলাদা ভাবে চিনুন।

### সমস্যা 3: দুই report একই দেখাচ্ছে
- **কী হচ্ছে:** দুই নামের output এক।
- **সম্ভাব্য কারণ:** change করার আগে তারা একই data দেখছে, অথবা copy-তে change করা হয়নি।
- **Fix:** `id()` নয়, values এবং assignment line পরীক্ষা করুন।
- **আগে প্রতিরোধ:** copy করার পর সঙ্গে সঙ্গে একটি item বদলে পরীক্ষা করুন।

### সমস্যা 4: `AttributeError: 'list' object has no attribute 'clone'`
- **কী হচ্ছে:** Python list-এ `clone()` নেই।
- **সম্ভাব্য কারণ:** অন্য ভাষার copy method ব্যবহার করা হয়েছে।
- **Fix:** `[:]` বা `.copy()` ব্যবহার করুন।
- **আগে প্রতিরোধ:** Python list-এর পরিচিত copy patterns মনে রাখুন।

## 15. Common Misconceptions

1. **ভুল:** `b = a` copy বানায়। → **সত্য:** এটি একই list-এর দ্বিতীয় নাম।
2. **ভুল:** alias বদলালে শুধু alias বদলায়। → **সত্য:** shared list বদলায়।
3. **ভুল:** `a[:]` original list বদলায়। → **সত্য:** এটি নতুন outer list তৈরি করে।
4. **ভুল:** `.copy()` nested list পুরোপুরি আলাদা করে। → **সত্য:** এটি shallow copy।
5. **ভুল:** দুই list একই output দেখালে তারা অবশ্যই একই object। → **সত্য:** আলাদা copy-র values একই হতে পারে।

## 16. Exercises with solutions

### Exercise 1

`report`-এর alias বানিয়ে দ্বিতীয় নাম দিয়ে day one-এর sale বদলান। দুই output দেখুন।

**Solution**

```python
report = [12000, 9500, 8800]
alias = report
alias[0] = 13000
print(report)
print(alias)
```

**Output**

```text
[13000, 9500, 8800]
[13000, 9500, 8800]
```

### Exercise 2

slice ব্যবহার করে independent working report বানান।

**Solution**

```python
report = [12000, 9500, 8800]
working = report[:]
working[0] = 13000
print(report)
print(working)
```

**Output**

```text
[12000, 9500, 8800]
[13000, 9500, 8800]
```

### Exercise 3

`.copy()` ব্যবহার করে balance list থেকে audit list বানান, তারপর audit list-এ একটি balance বাদ দিন।

**Solution**

```python
balances = [50000, 32000, 71000]
audit = balances.copy()
audit.pop()
print(balances)
print(audit)
```

**Output**

```text
[50000, 32000, 71000]
[50000, 32000]
```

### Exercise 4

একটি alias, একটি slice copy, এবং একটি method copy বানিয়ে প্রতিটিতে আলাদা item যোগ করুন।

**Solution**

```python
sales = [12000, 9500]
alias = sales
slice_copy = sales[:]
method_copy = sales.copy()
alias.append(8800)
slice_copy.append(13200)
method_copy.append(7500)
print(sales)
print(slice_copy)
print(method_copy)
```

**Output**

```text
[12000, 9500, 8800]
[12000, 9500, 13200]
[12000, 9500, 7500]
```

### Exercise 5: Sreepati debugging bug

Sreepati original sales report রেখে working report বানাতে চেয়েছিলেন।

```python
original = [12000, 9500, 8800]
working = original
working.pop()
print(original)
```

**Wrong output**

```text
[12000, 9500]
```

Boss বললেন, “Audit-এর original report-ও ছোট হয়ে গেল কেন?”

**Diagnosis:** `working = original` copy নয়। দুই নাম একই list refer করছে।

**Minimal fix**

```python
original = [12000, 9500, 8800]
working = original.copy()
working.pop()
print(original)
print(working)
```

**Correct output**

```text
[12000, 9500, 8800]
[12000, 9500]
```

**Lesson:** original data রক্ষা করতে edit-এর আগে copy করুন।

## 17. Quiz

1. `b = a` সাধারণত কী করে?  
   a) একই list-এর আরেক নাম দেয়  
   b) নতুন list বানায়  
   c) list sort করে  
   **উত্তর: a।** দুই নাম একই object refer করে।

2. কোনটি flat list copy করে?  
   a) `a = b`  
   b) `a[:]`  
   c) `a == b`  
   **উত্তর: b।** slice নতুন outer list বানায়।

3. alias-এ `append()` করলে কী হতে পারে?  
   a) original অপরিবর্তিত থাকে  
   b) shared original list-ও বদলায়  
   c) syntax error হয়  
   **উত্তর: b।** alias একই list refer করে।

4. `.copy()` কী তৈরি করে?  
   a) shallow copy  
   b) string  
   c) tuple  
   **উত্তর: a।** outer list নতুন হয়।

5. nested list-এর shallow copy-তে কী shared থাকতে পারে?  
   a) inner rows  
   b) variable spelling  
   c) Python version  
   **উত্তর: a।** ভিতরের list একই থাকতে পারে।

6. audit-safe working report-এর জন্য কোনটি ব্যবহার করবেন?  
   a) `working = original`  
   b) `working = original.copy()`  
   c) `working == original`  
   **উত্তর: b।** এতে flat list independent হয়।

7. দুই copy-র values একই হওয়া মানে কী?  
   a) তারা অবশ্যই একই object  
   b) তারা একই values রাখতে পারে  
   c) তারা ব্যবহার করা যাবে না  
   **উত্তর: b।** আলাদা list-এর contents একই হতে পারে।

## 18. Key Idea

`b = a` reference তৈরি করে, copy নয়। Original business data রক্ষা করতে flat list-এর জন্য `[:]` বা `.copy()` ব্যবহার করুন।
