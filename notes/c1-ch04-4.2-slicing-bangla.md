## 1. Slicing কী

String slicing হলো একটি string-এর নির্দিষ্ট অংশ কেটে নতুন string নেওয়া। একটি character নিতে index ব্যবহার করি, আর অনেক character একসঙ্গে নিতে slice ব্যবহার করি।

```python
invoice_no = "INV-2024-007"

prefix = invoice_no[0:3]
print(prefix)
```

**Output**

```text
INV
```

`invoice_no[0:3]` index 0 থেকে শুরু করেছে এবং index 3-এর আগে থেমেছে। তাই `I`, `N`, `V` পাওয়া গেছে।

## 2. `start:stop` নিয়ম

সাধারণ slice-এর গঠন হলো `text[start:stop]`। `start` হলো কোথা থেকে শুরু হবে। `stop` হলো কোন index-এর আগে থামবে।

```python
code = "C-1023"

print(code[0:2])
print(code[2:5])
```

**Output**

```text
C-
102
```

প্রথম slice index 0 এবং 1 নিয়েছে। দ্বিতীয় slice index 2, 3 এবং 4 নিয়েছে।

প্রতিটি গুরুত্বপূর্ণ line-এর অর্থ:

- `code = "C-1023"` একটি customer code রাখে।
- `code[0:2]` শুরু থেকে index 2-এর আগে পর্যন্ত নেয়।
- `code[2:5]` index 2 থেকে index 5-এর আগে পর্যন্ত নেয়।

## 3. `stop` index বাদ পড়ে

Slicing-এর সবচেয়ে গুরুত্বপূর্ণ নিয়ম হলো, `stop` index-এর character নেওয়া হয় না। একে half-open range বলা হয়, কারণ শুরুটি অন্তর্ভুক্ত হয়, শেষটি অন্তর্ভুক্ত হয় না।

```python
invoice_no = "INV-2024-007"

print(invoice_no[0:3])
print(invoice_no[4:8])
```

**Output**

```text
INV
2024
```

প্রথম slice-এ index 3-এর hyphen বাদ পড়েছে। দ্বিতীয় slice-এ index 4 থেকে শুরু করে index 8-এর আগ পর্যন্ত year নেওয়া হয়েছে।

ভুল ধারণা এড়ানোর নিয়ম:

- তিনটি character চাইলে `0:3` লিখুন।
- চারটি character চাইলে `4:8` লিখুন।
- `stop`-কে শেষ character-এর index নয়, তার পরের boundary ভাবুন।

## 4. শুরু থেকে slice

`start` বাদ দিলে Python string-এর শুরু থেকে নেয়। তাই `text[:stop]` অর্থ index 0 থেকে `stop`-এর আগে পর্যন্ত।

```python
invoice_no = "INV-2024-007"
customer_code = "C-1023"

print(invoice_no[:3])
print(customer_code[:2])
```

**Output**

```text
INV
C-
```

`invoice_no[:3]` হলো `invoice_no[0:3]`-এর সংক্ষিপ্ত রূপ। একইভাবে `customer_code[:2]` শুরু থেকে দুইটি character নেয়।

## 5. শেষ পর্যন্ত slice

`stop` বাদ দিলে Python `start` থেকে string-এর শেষ পর্যন্ত নেয়। তাই `text[start:]` ব্যবহার করে কোনো অংশের শেষ পর্যন্ত যাওয়া যায়।

```python
invoice_no = "INV-2024-007"

print(invoice_no[4:])
print(invoice_no[9:])
```

**Output**

```text
2024-007
007
```

প্রথম slice index 4 থেকে শেষ পর্যন্ত নিয়েছে। দ্বিতীয়টি index 9 থেকে শেষ পর্যন্ত নিয়েছে। এই পদ্ধতিতে আগে থেকে string-এর length গুনতে হয় না।

## 6. `step` ব্যবহার

তিন অংশের slice-এর গঠন হলো `text[start:stop:step]`। `step` বলে কত ঘর করে এগোতে হবে। `step` না লিখলে তার মান 1।

```python
invoice_no = "INV-2024-007"

print(invoice_no[0:12:2])
print(invoice_no[0:12:3])
```

**Output**

```text
IV22-0
I-2-
```

প্রথম slice index 0, 2, 4, 6, 8 এবং 10 নিয়েছে। দ্বিতীয় slice index 0, 3, 6 এবং 9 নিয়েছে।

মনে রাখুন, `step` বড় হলে মাঝের কিছু character বাদ পড়ে। তাই এটি শুধু text কাটা নয়, নির্দিষ্ট দূরত্বে character নেওয়ার নিয়মও।

## 7. Negative index দিয়ে slice

Slicing-এ negative index ব্যবহার করলে ডান দিক থেকে boundary ধরা যায়। এটি শেষের অংশ নেওয়ার সময় useful।

```python
invoice_no = "INV-2024-007"

print(invoice_no[-3:])
print(invoice_no[-8:-4])
```

**Output**

```text
007
2024
```

`invoice_no[-3:]` শেষ তিনটি character নেয়। `invoice_no[-8:-4]` index -8 থেকে শুরু করে -4-এর আগে থামে, তাই year `2024` পাওয়া যায়।

প্রতিটি গুরুত্বপূর্ণ line-এর অর্থ:

- `[-3:]` শেষের তিনটি character-এর জন্য শুরু boundary দেয়।
- `[-7:-3]` ডান দিকের boundary ব্যবহার করে year আলাদা করে।
- negative slicing-এও `stop` বাদ পড়ার নিয়ম একই থাকে।

## 8. Reverse slicing

`step` ঋণাত্মক হলে slice ডান দিক থেকে বাম দিকে চলে। পুরো string উল্টো করতে `[::-1]` ব্যবহার করা যায়।

```python
customer_code = "C-1023"

print(customer_code[::-1])
print(customer_code[5:1:-1])
```

**Output**

```text
3201-C
3201
```

`[::-1]` পুরো string-এর শেষ character থেকে প্রথম character পর্যন্ত যায়। দ্বিতীয় slice index 5 থেকে শুরু করে index 1-এর আগে থেমেছে, তাই `3`, `2`, `0`, `1` পাওয়া গেছে।

Negative step ব্যবহার করার সময় শুরু boundary সাধারণত ডান দিকে এবং stop boundary বাম দিকে রাখতে হয়।

## 9. Business code থেকে অংশ নেওয়া

Invoice number-এর prefix, year এবং serial আলাদা করে report-এ দেখানো যায়। এখানে slicing ব্যবহার করছি, কোনো string method নয়।

```python
invoice_no = "INV-2024-007"

prefix = invoice_no[:3]
year = invoice_no[4:8]
serial = invoice_no[9:]

print(f"Prefix: {prefix}")
print(f"Year: {year}")
print(f"Serial: {serial}")
```

**Output**

```text
Prefix: INV
Year: 2024
Serial: 007
```

Hyphen-এর অবস্থান জেনে boundary বসানো হয়েছে। `serial`-এর জন্য `9:` ব্যবহার করায় শেষের অংশের length আলাদা করে গুনতে হয়নি।

## 10. নিরাপদ slicing এবং common boundary

Indexing-এ ভুল boundary দিলে `IndexError` হতে পারে। Slicing-এর সুবিধা হলো, বড় `stop` দিলেও সাধারণত error হয় না, Python যতটুকু আছে ততটুকুই নেয়। তবে business code-এর format ভুল হলে result ভুল হতে পারে, তাই boundary বুঝে নিতে হবে।

```python
customer_code = "C-1023"

print(customer_code[0:100])
print(customer_code[100:105])
```

**Output**

```text
C-1023

```

প্রথম slice available text-এর শেষ পর্যন্ত নিয়েছে। দ্বিতীয় slice-এর শুরু string-এর length-এর পরে, তাই empty string, অর্থাৎ কিছুই print হয়নি। এটি error নয়, কিন্তু business validation-এর বিকল্পও নয়।

## Troubleshooting

### Problem 1: শেষ character slice-এ আসছে না

- কী হচ্ছে: learner `text[0:5]` লিখে ছয়টি character আশা করছে।
- সম্ভাব্য কারণ: `stop` index slice-এ অন্তর্ভুক্ত হয় না।
- ধাপ: কতটি character দরকার গুনুন, তারপর boundary এক ঘর পরে দিন।
- প্রতিরোধ: `start` included, `stop` excluded নিয়মটি মনে রাখুন।

### Problem 2: year-এর সঙ্গে hyphen চলে আসছে

- কী হচ্ছে: output `-2024` বা `2024-` দেখা যাচ্ছে।
- সম্ভাব্য কারণ: hyphen-এর index boundary হিসেবে বাদ দেওয়া হয়নি।
- ধাপ: `invoice_no`-এর index লিখে দেখুন, year-এর শুরু ও শেষ boundary ঠিক করুন।
- প্রতিরোধ: slice লেখার আগে code-এর character positions মিলিয়ে নিন।

### Problem 3: reverse slice খালি output দিচ্ছে

- কী হচ্ছে: negative step ব্যবহার করেও কিছু print হচ্ছে না।
- সম্ভাব্য কারণ: শুরু, stop এবং step-এর দিক পরস্পরের সঙ্গে মেলেনি।
- ধাপ: ডান দিকের start এবং বাম দিকের stop দিন, তারপর negative step ব্যবহার করুন।
- প্রতিরোধ: reverse slice-এ movement-এর দিক আগে কাগজে লিখুন।

### Problem 4: slice result খালি string হচ্ছে

- কী হচ্ছে: error নেই, কিন্তু output-এ কোনো text নেই।
- সম্ভাব্য কারণ: start boundary string-এর শেষের পরে, অথবা start ও stop-এর দিক ভুল।
- ধাপ: `len(text)` print করুন, boundary দুটির অবস্থান যাচাই করুন।
- প্রতিরোধ: format নিশ্চিত না হলে sample code-এর length ও positions আগে পরীক্ষা করুন।

## Common Misconceptions

1. **ভুল:** `text[0:3]` index 3-ও নেয় → **সত্য:** stop index বাদ পড়ে।
2. **ভুল:** `text[:3]` মানে শেষ তিনটি character → **সত্য:** এটি শুরু থেকে index 3-এর আগ পর্যন্ত নেয়।
3. **ভুল:** `text[4:]`-এ শেষ index লিখতেই হবে → **সত্য:** stop বাদ দিলে শেষ পর্যন্ত slice হয়।
4. **ভুল:** `[::-1]` text-কে স্থায়ীভাবে বদলে দেয় → **সত্য:** এটি নতুন reversed string তৈরি করে।
5. **ভুল:** বড় stop দিলে slicing সবসময় `IndexError` দেয় → **সত্য:** slicing সাধারণত available অংশ নেয়, তবে result যাচাই করতে হয়।

### Exercise 5: Rafiq bhai-এর debugging bug

Rafiq bhai invoice number থেকে year report করতে লিখেছেন:

```python
invoice_no = "INV-2024-007"
year = invoice_no[4:9]
print(year)
```

Output:

```text
2024-
```

Boss শুধু `2024` চান। Rafiq bhai একটি extra hyphen নিয়ে ফেলেছেন।

**Cause:** year-এর শেষ boundary 8-এর বদলে 9 দেওয়া হয়েছে। Stop index slice-এ বাদ পড়ে, তাই index 8-এর hyphen ঢুকে গেছে।

**Minimal fix:**

```python
invoice_no = "INV-2024-007"
year = invoice_no[4:8]
print(year)
```

**Output:**

```text
2024
```

**Lesson:** slice-এর stop boundary হলো বাদ দেওয়ার boundary, নেওয়ার শেষ index নয়।

### 2. `text[:3]` কী বোঝায়?

a. শেষ তিনটি character  
b. শুরু থেকে index 3-এর আগ পর্যন্ত  
c. শুধু index 3

**উত্তর: b।** Start বাদ থাকলে Python শুরু থেকে নেয়।

### 3. `"INV-2024-007"[-3:]` কী?

a. `007`  
b. `-007`  
c. `2024`

**উত্তর: a।** Negative start শেষ তিনটি character নেয়।

### 4. `step`-এর কাজ কী?

a. string-এর type বদলানো  
b. কত ঘর করে এগোতে হবে তা বলা  
c. string মুছে ফেলা

**উত্তর: b।** Step character position-এর ব্যবধান নির্ধারণ করে।

### 5. `"C-1023"[::-1]` কী দেয়?

a. `C-1023`  
b. `3201-C`  
c. `C-`

**উত্তর: b।** Negative step পুরো string উল্টো করে।

### 6. `text[4:8]`-এ index 8-এর character কী হয়?

a. নেওয়া হয়  
b. দুইবার নেওয়া হয়  
c. বাদ পড়ে

**উত্তর: c।** Stop boundary সবসময় excluded।

### 7. বড় stop index দিয়ে slice করলে সাধারণত কী হয়?

a. available text-এর শেষ পর্যন্ত নেয়  
b. সবসময় `IndexError` হয়  
c. `None` ফেরত দেয়

**উত্তর: a।** Slicing সাধারণত যতটুকু text আছে ততটুকুই নেয়।

## Key Idea

Slicing দিয়ে একসঙ্গে string-এর অংশ নেওয়া যায়। `start` থেকে শুরু হয়, `stop` বাদ পড়ে, আর `step` চলার দূরত্ব ঠিক করে। Negative index ও negative step দিয়ে শেষের অংশ এবং reverse text পড়া যায়।

**ছড়া ১:** start থেকে হাঁটি, stop-এর আগে থামি,  
**ছড়া ২:** step বলে কত ঘর, code-এর টুকরো নামি।
