## 6. Transaction processing

Process each transaction and build a total.

```python
transactions = [5000, 4200, 6100, 3800]
transaction_total = 0

for amount in transactions:
    if amount <= 0:
        continue
    transaction_total += amount
    print(f"Processed transaction: {amount}")

print(f"Transaction total: {transaction_total}")
```

**Output**

```text
Processed transaction: 5000
Processed transaction: 4200
Processed transaction: 6100
Processed transaction: 3800
Transaction total: 19100
```

The loop reads each amount. Valid amounts enter the total. `continue` can skip invalid amounts.

## 7. Invoice total

Add invoice line items.

```python
invoice_items = [12000, 8000, 5000]
invoice_total = 0

for item_amount in invoice_items:
    invoice_total += item_amount

print(f"Invoice total: {invoice_total}")
```

**Output**

```text
Invoice total: 25000
```

The total starts at zero. Each line amount is added once.

## 8. Running balance

Subtract each payment from an opening balance.

```python
balance = 50000
payments = [10000, 15000, 5000]

for payment in payments:
    balance -= payment
    print(f"After payment {payment}: balance {balance}")
```

**Output**

```text
After payment 10000: balance 40000
After payment 15000: balance 25000
After payment 5000: balance 20000
```

Each payment changes the old balance. The balance is a running state.

## 9. Monthly expense summary

Each nested list stores one month’s expenses.

```python
monthly_expenses = [
    [12000, 8000],
    [9500, 7000],
    [11000, 6000],
]

overall_expense = 0
month_number = 1

for expenses in monthly_expenses:
    month_total = 0
    for expense in expenses:
        month_total += expense
        overall_expense += expense
    print(f"Month {month_number}: {month_total}")
    month_number += 1

print(f"Overall expense: {overall_expense}")
```

**Output**

```text
Month 1: 20000
Month 2: 16500
Month 3: 17000
Overall expense: 53500
```

`month_total` resets for each month. `overall_expense` keeps every month.

## 10. Stop at an urgent transaction

Use the earlier flow tools to stop at an urgent reference.

```python
references = ["INV-001", "INV-002", "INV-URGENT", "INV-004"]

for reference in references:
    print(f"Reviewing {reference}")
    if reference == "INV-URGENT":
        print("Manager review required")
        break
```

**Output**

```text
Reviewing INV-001
Reviewing INV-002
Reviewing INV-URGENT
Manager review required
```

The loop stops after the urgent record. This acts as a safety gate.

## 12. Troubleshooting

### Problem 1
- What happens: the total equals only the last amount.
- Likely cause: `=` overwrote the accumulator.
- Fix: use `+=`.
- Prevention: preserve the old total.

### Problem 2
- What happens: one total contains every month.
- Likely cause: `month_total = 0` is outside the outer loop.
- Fix: reset at the start of every month.
- Prevention: use separate group and overall names.

### Problem 3
- What happens: records continue after the urgent transaction.
- Likely cause: `break` is missing or tests the wrong reference.
- Fix: put `break` inside the urgent condition.
- Prevention: include a record after the urgent sample.

### Problem 4
- What happens: the balance is wrong after payment.
- Likely cause: payment was added, not subtracted, or updated outside the loop.
- Fix: use `balance -= payment` inside the loop.
- Prevention: write each expected balance.

## 13. Common Misconceptions

1. **Wrong:** one total is enough for every report → **Truth:** each measure needs its accumulator.
2. **Wrong:** nested loops are only for display → **Truth:** they build grouped summaries.
3. **Wrong:** payment increases outstanding balance → **Truth:** it reduces outstanding balance.
4. **Wrong:** `continue` deletes invalid data → **Truth:** it skips one iteration.
5. **Wrong:** visible output proves correctness → **Truth:** compare expected totals.

### Exercise 5, Rafiq bhai’s bug

Rafiq bhai wrote:

```python
balance = 50000
for payment in [10000, 5000]:
    balance = payment
print(balance)
```

Wrong output: `5000`. The boss expected the final balance to be 35000. The payment replaced the balance. Fix:

```python
balance = 50000
for payment in [10000, 5000]:
    balance -= payment
print(balance)
```

```text
35000
```

Lesson: update running state. Do not replace it.
