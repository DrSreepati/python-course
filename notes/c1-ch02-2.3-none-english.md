## 1. What `None` means

`None` is a special Python value. It says that a variable has no specific value yet.

```python
pending_balance = None
print(pending_balance)
```

**Output**

```text
None
```

The name exists, but the balance has not arrived. `print()` displays the special value.

## 2. Why `None` is not zero

`0` is a known number. `None` says that the number is missing or unknown.

```python
known_balance = 0
unknown_balance = None

print(known_balance)
print(unknown_balance)
```

**Output**

```text
0
None
```

`known_balance` really is zero. The real amount for `unknown_balance` is not known.

## 3. An unknown customer balance

If Karim Store’s balance has not been checked, writing `0` can mislead the business. `None` records the incomplete information honestly.

```python
customer = "Karim Store"
balance = None

print(customer)
print(balance)
```

**Output**

```text
Karim Store
None
```

The customer is known. The `None` balance has not been checked yet.

## 4. The type of `None`

`None` is not an `int`, `float`, `str`, or `bool`. Python calls its type `NoneType`.

```python
balance = None
print(type(balance))
```

**Output**

```text
<class 'NoneType'>
```

`type(balance)` reports `NoneType`. It is not the `int` value `0`.

## 5. Testing with `is None`

Use `is None` to check whether a variable holds Python’s special `None` value.

```python
balance = None

if balance is None:
    print("Balance is not checked yet")
```

**Output**

```text
Balance is not checked yet
```

`is None` checks the identity of the special value. The message prints because the test is true.

## 6. Testing with `is not None`

When a balance is available, `is not None` shows that arithmetic can proceed.

```python
balance = 50000

if balance is not None:
    print(balance)
```

**Output**

```text
50000
```

This balance is known. The test is true, so Python prints the value.

## 7. `None` and empty text

`None` and `""` are different. `""` is a known empty string. `None` marks an unavailable value.

```python
missing_note = None
empty_note = ""

print(missing_note)
print(empty_note)
```

**Output**

```text
None

```

The second output line is blank because `empty_note` is empty text. The first line shows `None`.

## 8. Handling `None` before arithmetic

Do not add or subtract `None` directly. Check it first.

```python
balance = None
payment = 5000

if balance is None:
    print("Cannot calculate: balance is unknown")
else:
    print(balance - payment)
```

**Output**

```text
Cannot calculate: balance is unknown
```

The first branch runs because the balance is unknown. Python does not subtract from an unknown amount.

## 9. `None` in a business record

An invoice number may be known while its payment date is not.

```python
invoice_number = "INV-2024-007"
payment_date = None

print(invoice_number, payment_date)
```

**Output**

```text
INV-2024-007 None
```

The invoice code exists. The payment date does not yet exist in the record.

## 10. Separating missing data from real zero

Zero sales and unknown sales lead to different business decisions.

```python
closed_shop_sales = 0
unreported_sales = None

print(closed_shop_sales is None)
print(unreported_sales is None)
```

**Output**

```text
False
True
```

The shop may truly have made zero sales. A missing report means sales are unknown.

## Troubleshooting

### Problem 1: `None` is being treated as `0`

- **What is happening:** An unknown balance is reported as zero.
- **Most likely cause:** Missing information was treated as a real zero.
- **Step-by-step fix:** 1. Define the field’s meaning. 2. Keep `0` when the amount is truly zero. 3. Keep `None` when it is unknown. 4. Show a separate message in the report.
- **How to prevent it:** Decide whether each missing field means unknown or zero.

### Problem 2: Arithmetic with `None` raises an error

- **What is happening:** Subtracting a payment from `None` fails.
- **Most likely cause:** The code did not check the value before arithmetic.
- **Step-by-step fix:** 1. Test `value is None`. 2. Stop the calculation when true. 3. Calculate only in the other branch. 4. Print the result.
- **How to prevent it:** Add a guard before every optional number is used.

### Problem 3: `None` and empty text are confused

- **What is happening:** An empty note is treated as missing data, or the reverse.
- **Most likely cause:** The meanings of `""` and `None` were not defined.
- **Step-by-step fix:** 1. Remember that `None` means no value. 2. Remember that `""` is an empty string. 3. Choose the business meaning. 4. Store the matching value.
- **How to prevent it:** Write the missing and empty rules in the data specification.

### Problem 4: `==` is used for a `None` check

- **What is happening:** The code uses a less clear test for `None`.
- **Most likely cause:** The identity test `is` has not been practised.
- **Step-by-step fix:** 1. Write `value is None`. 2. Write `value is not None` for an available value. 3. Run both branches. 4. Compare the output.
- **How to prevent it:** Always use `is None` or `is not None` for `None`.

## Common Misconceptions

1. **Wrong claim:** `None` and `0` are the same. **Truth:** `0` is a known integer. `None` is missing or unknown data.
2. **Wrong claim:** `None` is an empty string. **Truth:** `None` is `NoneType`, while `""` is an empty `str`.
3. **Wrong claim:** You can add or subtract `None`. **Truth:** Check for an available value before arithmetic.
4. **Wrong claim:** Printing `None` prints nothing. **Truth:** Python normally prints the word `None`.
5. **Wrong claim:** Unknown sales should be recorded as zero. **Truth:** That changes unknown data into a false business fact.

### Exercise 5: Rafiq bhai’s debugging bug

Rafiq bhai changed an unknown balance into zero:

```python

payment = 5000
remaining = balance or 0
print(remaining - payment)
```

**Wrong output**

```text
-5000
```

The boss said, “Karim Store’s balance is unknown. How did a debt of -5000 appear?”

**Solution**

`balance or 0` changed an unknown balance into a real zero. We must not subtract a payment from unknown data.

```python
balance = None
payment = 5000

if balance is None:
    print("Cannot calculate: balance is unknown")
else:
    print(balance - payment)
```

**Correct output**

```text
Cannot calculate: balance is unknown
```

One-line lesson: never turn unknown numbers into zero to create a business result.
