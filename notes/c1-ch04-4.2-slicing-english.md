## 1. What slicing is

String slicing means taking a selected part of a string as a new string. Use an index for one character. Use a slice for several characters together.

```python
invoice_no = "INV-2024-007"

prefix = invoice_no[0:3]
print(prefix)
```

**Output**

```text
INV
```

`invoice_no[0:3]` starts at index 0 and stops before index 3. Therefore, it takes `I`, `N` and `V`.

## 2. The `start:stop` rule

The usual slice form is `text[start:stop]`. `start` says where to begin. `stop` says where to stop before.

```python
code = "C-1023"

print(code[0:2])
print(code[2:5])
```

**Output**

```text
C-
102
```

The first slice takes indexes 0 and 1. The second takes indexes 2, 3 and 4.

Meaning of each important line:

- `code = "C-1023"` stores a customer code.
- `code[0:2]` takes text from the start to before index 2.
- `code[2:5]` takes text from index 2 to before index 5.

## 3. Excluding `stop`

The most important slicing rule is that the character at `stop` is not taken. This is called a half-open range. The start is included, but the end is excluded.

```python
invoice_no = "INV-2024-007"

print(invoice_no[0:3])
print(invoice_no[4:8])
```

**Output**

```text
INV
2024
```

The hyphen at index 3 is excluded from the first slice. The second slice takes the year from index 4 to before index 8.

Use these rules:

- To take three characters, write `0:3`.
- To take four characters, write `4:8`.
- Treat `stop` as the boundary after the final character, not its index.

## 4. Slicing from the beginning

If `start` is missing, Python starts at the beginning. Thus, `text[:stop]` means from index 0 to before `stop`.

```python
invoice_no = "INV-2024-007"
customer_code = "C-1023"

print(invoice_no[:3])
print(customer_code[:2])
```

**Output**

```text
INV
C-
```

`invoice_no[:3]` is the short form of `invoice_no[0:3]`. Similarly, `customer_code[:2]` takes two characters from the start.

## 5. Slicing to the end

If `stop` is missing, Python takes text from `start` to the end. Thus, `text[start:]` reaches the end without counting the final position.

```python
invoice_no = "INV-2024-007"

print(invoice_no[4:])
print(invoice_no[9:])
```

**Output**

```text
2024-007
007
```

The first slice starts at index 4 and reaches the end. The second starts at index 9 and reaches the end.

## 6. Using `step`

The three-part form is `text[start:stop:step]`. `step` says how many positions to move each time. If it is missing, its value is 1.

```python
invoice_no = "INV-2024-007"

print(invoice_no[0:12:2])
print(invoice_no[0:12:3])
```

**Output**

```text
IV22-0
I-2-
```

The first slice takes indexes 0, 2, 4, 6, 8 and 10. The second takes indexes 0, 3, 6 and 9.

A larger `step` skips more characters. Slicing can therefore take characters at a regular distance.

## 7. Slicing with negative indexes

Negative indexes let us set boundaries from the right. This is useful when taking the final part of text.

```python
invoice_no = "INV-2024-007"

print(invoice_no[-3:])
print(invoice_no[-8:-4])
```

**Output**

```text
007
2024
```

`invoice_no[-3:]` takes the final three characters. `invoice_no[-8:-4]` starts at index -8 and stops before -4, giving the year `2024`.

The same excluded-stop rule still applies to negative slices.

## 8. Reverse slicing

When `step` is negative, the slice moves from right to left. Use `[::-1]` to reverse a whole string.

```python
customer_code = "C-1023"

print(customer_code[::-1])
print(customer_code[5:1:-1])
```

**Output**

```text
3201-C
3201
```

`[::-1]` moves from the final character to the first. The second slice starts at index 5 and stops before index 1, so it takes `3`, `2`, `0` and `1`.

With a negative step, the start boundary usually sits on the right and the stop boundary sits on the left.

## 9. Taking parts from business codes

We can separate an invoice prefix, year and serial for a report. This uses slicing, not string methods.

```python
invoice_no = "INV-2024-007"

prefix = invoice_no[:3]
year = invoice_no[4:8]
serial = invoice_no[9:]

print(f"Prefix: {prefix}")
print(f"Year: {year}")
print(f"Serial: {serial}")
```

**Output**

```text
Prefix: INV
Year: 2024
Serial: 007
```

The hyphen positions define the boundaries. `9:` takes the serial to the end without counting its length.

## 10. Safe slicing and common boundaries

An incorrect boundary can cause trouble with indexing. A large `stop` in a slice usually does not cause `IndexError`. Python takes only the available text. Still, a business format must be understood, or the result may be wrong.

```python
customer_code = "C-1023"

print(customer_code[0:100])
print(customer_code[100:105])
```

**Output**

```text
C-1023

```

The first slice reaches the end of the available text. The second starts after the string ends, so it is an empty string. This is not an error, but it is not business validation either.

## Synthesis table

| Task | Syntax | Example | Result |
|---|---|---|---|
| First three characters | `text[:3]` | `"INV-2024-007"[:3]` | `INV` |
| From index 4 to end | `text[4:]` | `"INV-2024-007"[4:]` | `2024-007` |
| Final three characters | `text[-3:]` | `"INV-2024-007"[-3:]` | `007` |
| Middle part | `text[4:8]` | `"INV-2024-007"[4:8]` | `2024` |
| Every second position | `text[::2]` | `"C-1023"[::2]` | `C12` |
| Reversed string | `text[::-1]` | `"C-1023"[::-1]` | `3201-C` |

## Troubleshooting

### Problem 1: The final character is missing

- What is happening: the learner writes `text[0:5]` and expects six characters.
- Most likely cause: the `stop` index is excluded.
- Step-by-step fix: count the required characters, then set the boundary one position after the last one.
- Prevention: remember, start is included and stop is excluded.

### Problem 2: A hyphen appears with the year

- What is happening: the output is `-2024` or `2024-`.
- Most likely cause: the hyphen position was not used as an excluded boundary.
- Step-by-step fix: write the code's indexes, then set the year's start and end boundaries.
- Prevention: check the character positions before writing the slice.

### Problem 3: A reverse slice gives empty output

- What is happening: a negative step is used, but nothing is printed.
- Most likely cause: the start, stop and step directions do not agree.
- Step-by-step fix: put the start on the right, the stop on the left, and use a negative step.
- Prevention: write the movement direction down before making a reverse slice.

### Problem 4: The slice result is an empty string

- What is happening: there is no error, but no text appears.
- Most likely cause: the start boundary is after the string, or the boundaries point in the wrong direction.
- Step-by-step fix: print `len(text)` and check both boundaries.
- Prevention: check the string length and format first.

## Common Misconceptions

1. **Wrong:** `text[0:3]` includes index 3 -> **Truth:** the stop index is excluded.
2. **Wrong:** `text[:3]` means the final three characters -> **Truth:** it takes from the start to before index 3.
3. **Wrong:** `text[4:]` needs a final index -> **Truth:** a missing stop means to the end.
4. **Wrong:** `[::-1]` permanently changes the text -> **Truth:** it creates a new reversed string.
5. **Wrong:** a large stop always causes `IndexError` -> **Truth:** slicing usually takes the available part.

## Quiz

### 1. What does `"C-1023"[0:2]` return?

a. `C-`  
b. `C-1`  
c. `-1`

**Answer: a.** Stop index 2 is excluded, so indexes 0 and 1 are taken.

### 2. What does `text[:3]` mean?

a. The final three characters  
b. From the beginning to before index 3  
c. Only index 3

**Answer: b.** A missing start means Python starts at the beginning.

### 3. What is `"INV-2024-007"[-3:]`?

a. `007`  
b. `-007`  
c. `2024`

**Answer: a.** A negative start takes the final three characters.

### 4. What does `step` do?

a. Changes the string type  
b. Says how many positions to move  
c. Deletes the string

**Answer: b.** Step sets the distance between selected positions.

### 5. What is `"C-1023"[::-1]`?

a. `C-1023`  
b. `3201-C`  
c. `C-`

**Answer: b.** A negative step reverses the whole string.

### 6. What happens to index 8 in `text[4:8]`?

a. It is included  
b. It is included twice  
c. It is excluded

**Answer: c.** The stop boundary is always excluded.

### 7. What usually happens with a large stop index?

a. The slice takes the available text to the end  
b. It always raises `IndexError`  
c. It returns `None`

**Answer: a.** Slicing usually takes only the text that exists.

## Key Idea

Slicing takes a part of a string at once. It starts at `start`, excludes `stop`, and uses `step` to set the movement. Negative indexes and negative steps help us read final parts and reversed text.

**Rhyme 1:** Start begins the walk, stop ends before the line,  
**Rhyme 2:** Step sets the distance, code pieces align.
