## 6. The first while loop

`while` repeats a block while its condition remains true.

```python
day = 1

while day <= 3:
    print(f"Preparing report for day {day}")
    day = day + 1
```

**Output**

```text
Preparing report for day 1
Preparing report for day 2
Preparing report for day 3
```

`day` starts at 1. The print runs. The update adds one. At 4, the condition is false.

## 7. Loop variable and counter

A loop variable tracks progress. It works like an abacus for each step.

```python
invoice_number = 1

while invoice_number <= 3:
    print(f"Checking invoice {invoice_number}")
    invoice_number += 1
```

**Output**

```text
Checking invoice 1
Checking invoice 2
Checking invoice 3
```

`+= 1` adds one to the old value. Without it, the same invoice would repeat.

## 8. Running balance

Each iteration can change a balance.

```python
balance = 50000
payment = 10000
month = 1

while month <= 3:
    balance = balance - payment
    print(f"Month {month}: balance {balance}")
    month += 1
```

**Output**

```text
Month 1: balance 40000
Month 2: balance 30000
Month 3: balance 20000
```

Each payment reduces the balance. `month` controls the three iterations.

## 9. A false condition skips the loop

If the first condition is false, the body runs zero times.

```python
stock = 0

while stock > 0:
    print("Dispatch one unit")
    stock -= 1

print("No stock to dispatch")
```

**Output**

```text
No stock to dispatch
```

`stock > 0` is false at the start. The body is skipped.

## 10. A business stop condition

A process can stop at a clear threshold.

```python
remaining_invoices = 3

while remaining_invoices > 0:
    print(f"Invoices left: {remaining_invoices}")
    remaining_invoices -= 1

print("Invoice check complete")
```

**Output**

```text
Invoices left: 3
Invoices left: 2
Invoices left: 1
Invoice check complete
```

The count is printed first. Then it decreases. At zero, the loop stops.

## 11. Beware infinite loops

If the condition stays true and the variable never changes, the loop may not stop.

```python
attempt = 1

while attempt <= 2:
    print(f"Attempt {attempt}")
    attempt += 1
```

**Output**

```text
Attempt 1
Attempt 2
```

The update makes this safe. If it is removed, press Stop in VS Code to end an endless programme.

## 13. Troubleshooting

### Problem 1
- What happens: the same line prints endlessly.
- Likely cause: the loop variable is not updated.
- Fix: add a counter update inside the body.
- Prevention: write start, condition, and update first.

### Problem 2
- What happens: the loop never runs.
- Likely cause: the initial condition is false.
- Fix: check the starting value and comparison.
- Prevention: calculate the first test by hand.

### Problem 3
- What happens: the final value is skipped.
- Likely cause: `<` was used instead of an inclusive comparison.
- Fix: use `<=` when equality belongs.
- Prevention: test the boundary value.

### Problem 4
- What happens: the balance changes incorrectly.
- Likely cause: the update is outside the loop or uses the wrong variable.
- Fix: keep the calculation and counter update inside the body.
- Prevention: write the expected balance for every iteration.

## 14. Common Misconceptions

1. **Wrong:** a `while` body runs once → **Truth:** it runs while the condition is true.
2. **Wrong:** the loop variable increases automatically → **Truth:** you must write the update.
3. **Wrong:** a false condition causes an error → **Truth:** the body is skipped.
4. **Wrong:** `<=` and `<` are the same → **Truth:** `<=` includes equality.
5. **Wrong:** every infinite loop is useful → **Truth:** an unintended one is a bug.

## 16. Quiz

1. What does `while` do?  
   a) repeats while true  b) creates a list  c) slices text  
   **Answer: a**, because a true condition runs the body.
2. What is the loop variable for?  
   a) tracking progress  b) deleting files  c) changing type  
   **Answer: a**, because it stores the iteration state.
3. How many times does `day = 1`, `while day <= 3` run?  
   a) 2  b) 3  c) 4  
   **Answer: b**, because 1, 2, and 3 run.
4. What can a missing update cause?  
   a) an infinite loop  b) an automatic stop  c) a syntax change  
   **Answer: a**, because the condition may never change.
5. What happens when the initial condition is false?  
   a) the body is skipped  b) it runs ten times  c) an error is required  
   **Answer: a**, because the first test stops the loop.
6. What does `stock -= 1` do?  
   a) adds one  b) subtracts one  c) deletes the value  
   **Answer: b**, because it decrements the value.
7. What does `<=` include?  
   a) equality  b) only larger values  c) text only  
   **Answer: a**, because it includes the boundary.

## 17. Key Idea

`while` repeats a process while a condition is true. Clear start, condition, and update values make business loops safe.
