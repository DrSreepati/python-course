## 1. Business data-এর নাম বোঝা

Business report-এ `quantity` হলো কয়টি পণ্য, `unit_price` হলো একটির দাম, আর `amount` হলো মোট দাম। যেমন, 6টি পণ্য, প্রতিটির দাম 250 টাকা হলে মোট amount 1500 টাকা।

```python
quantity = 6
unit_price = 250
amount = quantity * unit_price

print(quantity)    # Expected: 6
print(unit_price)  # Expected: 250
print(amount)      # Expected: 1500
```

`quantity` এবং `unit_price` variable-এ input রাখা হয়েছে। `*` দিয়ে মোট amount পাওয়া যায়। Output তিনটি value দেখায়।

## 2. Quantity ও unit price

পূর্ণ সংখ্যার quantity সাধারণত `int` হতে পারে। টাকার unit price-এ দশমিক থাকতে পারে, তাই `float` দেখা যায়। তবে financial system-এ Decimal বা smallest unit integer-ও ব্যবহার করা যায়, যা 2.6-এ দেখেছি।

```python
quantity = 4
unit_price = 125.50

print(type(quantity))    # Expected: <class 'int'>
print(type(unit_price))  # Expected: <class 'float'>
```

`type()` value-এর type দেখায়। `4` হলো integer, আর `125.50` হলো float।

## 3. Amount calculation

Formula হলো `amount = quantity * unit_price`। Quantity এবং price-এর position ভুল করলে Python error দেবে না, কিন্তু business result ভুল হতে পারে।

```python
quantity = 8
unit_price = 175.00
amount = quantity * unit_price

print(f"Amount: {amount:.2f} taka")  # Expected: Amount: 1400.00 taka
```

`f` string-এর `:.2f` display-এ দুই decimal ঘর রাখে। এটি display format, storage-এর পূর্ণ financial rule নয়।

## 4. Percentage ও rate

Percentage মানে প্রতি 100-এ কত। `15%` calculation-এ rate হিসেবে `15 / 100`, অর্থাৎ `0.15` ব্যবহার করা যায়।

```python
discount_percentage = 15
discount_rate = discount_percentage / 100

print(discount_rate)  # Expected: 0.15
```

প্রথম variable-এ report-এর ভাষার percentage রাখা হয়েছে। দ্বিতীয় variable-এ calculation-এর উপযোগী rate রাখা হয়েছে।

## 5. Percentage calculation

Discount amount পেতে amount-কে rate দিয়ে গুণ করি। Net amount হলো original amount থেকে discount বাদ।

```python
amount = 2000
discount_percentage = 15
discount_amount = amount * discount_percentage / 100
net_amount = amount - discount_amount

print(discount_amount)  # Expected: 300.0
print(net_amount)       # Expected: 1700.0
```

এখানে `2000 × 15 ÷ 100 = 300`। তারপর `2000 - 300 = 1700`।

## 6. Date কেন আলাদা data

`"2026-11-01"` দেখতে date-এর মতো হলেও এটি quotes-এর ভিতরে থাকলে Python-এর কাছে string। String দিয়ে date-এর মতো যোগ-বিয়োগ নিরাপদভাবে করা যায় না। আজ আমরা শুধু পার্থক্যটি বুঝব, date arithmetic Chapter 11.3-এ হবে।

```python
report_date_text = "2026-11-01"
print(report_date_text)             # Expected: 2026-11-01
print(type(report_date_text))       # Expected: <class 'str'>
```

Text হিসেবে date রাখা যায় display বা input-এর জন্য। কিন্তু date-এর আগে-পরে হিসাব করতে হলে পরে `datetime.date` ব্যবহার করতে হবে।

## 7. Type নির্বাচন

একটি record-এ different types একসঙ্গে থাকে। Code, customer name এবং date text হতে পারে। Quantity integer, percentage number, amount monetary number হতে পারে।

```python
invoice_no = "INV-2024-007"
customer = "Rahim Traders"
quantity = 3
unit_price = 450.00
paid = False

print(type(invoice_no))  # Expected: <class 'str'>
print(type(quantity))    # Expected: <class 'int'>
print(type(unit_price))  # Expected: <class 'float'>
print(type(paid))        # Expected: <class 'bool'>
```

প্রতিটি value তার কাজ অনুযায়ী type পেয়েছে। `paid` সত্য বা মিথ্যা, তাই `bool`।

## 8. Validation-এর প্রথম ধারণা

Validation মানে input business rule মেনে চলছে কি না দেখা। Quantity শূন্য বা negative হলে wholesale sale-এর জন্য তা সন্দেহজনক হতে পারে।

```python
quantity = 0

if quantity > 0:
    print("Quantity is usable")  # Expected: এই branch চলবে না
else:
    print("Check the quantity")  # Expected: Check the quantity
```

`if` condition পরীক্ষা করে। শূন্য `> 0` নয়, তাই দ্বিতীয় message দেখা যায়।

## 9. একটি ছোট sales record

একটি sale record-এ invoice, customer, quantity, unit price এবং date একসঙ্গে থাকতে পারে। আজ আমরা dictionary শেখাচ্ছি না, তাই আলাদা variables ব্যবহার করছি।

```python
invoice_no = "INV-2024-007"
customer = "Rahim Traders"
quantity = 5
unit_price = 320.00
amount = quantity * unit_price

print(invoice_no)  # Expected: INV-2024-007
print(customer)    # Expected: Rahim Traders
print(amount)      # Expected: 1600.0
```

প্রথম দুইটি identifier। পরের দুইটি calculation input। শেষ variable calculated output।

## 10. Business rule ও সাবধানতা

Percentage report-এ 15 লেখা থাকলে সেটি 15%। Calculation-এ 0.15 দরকার। একইভাবে date text হিসেবে পড়া গেলেও date calculation-এর জন্য আলাদা type দরকার। আর amount-এর output format এবং internal number এক জিনিস নয়।

```python
quantity = 6
unit_price = 250
percentage = 10
amount = quantity * unit_price
discount = amount * percentage / 100

print(f"Gross: {amount:.2f}")     # Expected: Gross: 1500.00
print(f"Discount: {discount:.2f}")  # Expected: Discount: 150.00
```

প্রথমে gross amount, পরে percentage অনুযায়ী discount হিসাব করা হয়েছে। Formatting কেবল দেখানোর ধরন ঠিক করেছে।

## Troubleshooting

### Problem 1: Amount-এর বদলে text জোড়া লাগছে

- কী হচ্ছে: `quantity * unit_price` না হয়ে `"6" + "250"`-এর মতো text operation হচ্ছে।
- সম্ভাব্য কারণ: `input()` থেকে পাওয়া value cast করা হয়নি।
- ধাপ: `type()` দিয়ে দেখুন, `int()` বা `float()` ব্যবহার করুন, তারপর calculation করুন।
- প্রতিরোধ: input পড়ার সঙ্গে সঙ্গে উপযুক্ত type-এ রূপান্তর করুন।

### Problem 2: Discount 15 গুণ বেশি হচ্ছে

- কী হচ্ছে: 15% rate হিসেবে 15 ব্যবহার করা হয়েছে।
- সম্ভাব্য কারণ: percentage এবং rate গুলিয়ে গেছে।
- ধাপ: `discount = amount * percentage / 100` লিখুন, অথবা আগে `rate = percentage / 100` করুন।
- প্রতিরোধ: variable-এর নাম `discount_percentage` বা `discount_rate` রাখুন।

### Problem 3: Date-এর উপর যোগ করা যাচ্ছে না

- কী হচ্ছে: date text-এর সঙ্গে number যোগ করতে গেলে error আসে।
- সম্ভাব্য কারণ: date এখনও `str`।
- ধাপ: `type()` পরীক্ষা করুন, পরে `datetime.date` ব্যবহার শিখুন।
- প্রতিরোধ: display text এবং date calculation-এর data আলাদা রাখুন।

### Problem 4: Amount output-এ অতিরিক্ত decimal দেখা যাচ্ছে

- কী হচ্ছে: `1600.0` বা float-এর লম্বা representation দেখা যাচ্ছে।
- সম্ভাব্য কারণ: display formatting করা হয়নি, অথবা float-এর সীমাবদ্ধতা দেখা দিয়েছে।
- ধাপ: display-এর জন্য `:.2f` ব্যবহার করুন, financial storage rule ঠিক করুন।
- প্রতিরোধ: display, calculation এবং storage-এর কাজ আলাদা ভাবুন।

## Common Misconceptions

1. **ভুল:** সব business data string হওয়া উচিত → **সত্য:** code ও name string, কিন্তু quantity calculation-এর জন্য number।
2. **ভুল:** 15 মানেই 15% rate → **সত্য:** rate হলো `0.15`।
3. **ভুল:** `"2026-11-01"` নিজেই date → **সত্য:** quotes-এর মধ্যে এটি string।
4. **ভুল:** `:.2f` number-কে financial-safe করে → **সত্য:** এটি শুধু display format।
5. **ভুল:** variable-এর type না জানলেও calculation করা যায় → **সত্য:** আগে type বোঝা ভুল কমায়।

## Exercises

### Exercise 1

Quantity `12`, unit price `85` দিয়ে amount বের করুন।  
**Solution:** `amount = 12 * 85`।  
**Output:** `1020`

### Exercise 2

Amount `5000` এবং discount `8%` হলে discount ও net amount বের করুন।  
**Solution:** `discount = 5000 * 8 / 100`, `net = 5000 - discount`।

### Exercise 3

`quantity = "7"` এবং `unit_price = "120.50"`-কে calculation-এর আগে cast করুন।  
**Solution:** `amount = int(quantity) * float(unit_price)`।  
**Output:** `843.5`

### Exercise 4

Invoice code, customer, quantity, unit price এবং report date print করুন।

### Exercise 5: Rafiq bhai-এর debugging bug

Rafiq bhai লিখেছেন:

```python
quantity = 6
unit_price = 250
wrong_amount = unit_price / quantity
print(wrong_amount)
```

Boss বললেন, 6টি পণ্যের মোট দাম 1500 হওয়া উচিত, কিন্তু output `41.666666666666664`।  
**Cause:** quantity দিয়ে price ভাগ করা হয়েছে।  
**Minimal fix:** `amount = quantity * unit_price`।  
**Corrected code and output:**

```python
amount = quantity * unit_price
print(amount)  # Expected: 1500
```

**Lesson:** business formula লেখার আগে formula-টি কথায় বলুন: amount equals quantity times unit price।
