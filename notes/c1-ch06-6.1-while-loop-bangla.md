## 6. প্রথম while loop

`while` মানে, যতক্ষণ condition সত্য, ততক্ষণ block repeat হবে।

```python
day = 1

while day <= 3:
    print(f"Preparing report for day {day}")
    day = day + 1
```

**Output**

```text
Preparing report for day 1
Preparing report for day 2
Preparing report for day 3
```

`day` শুরুতে 1। condition সত্য হলে print চলে। শেষে `day` এক বাড়ে, তাই 4 হলে condition false হয়।

## 7. Loop variable এবং counter

যে variable loop-এর অগ্রগতি ধরে, তাকে loop variable বলা যায়। এটি গুনতারাজের মতো প্রতিটি ধাপ গুনে।

```python
invoice_number = 1

while invoice_number <= 3:
    print(f"Checking invoice {invoice_number}")
    invoice_number += 1
```

**Output**

```text
Checking invoice 1
Checking invoice 2
Checking invoice 3
```

`invoice_number += 1` পুরনো value-এর সঙ্গে 1 যোগ করে। এই update ছাড়া একই invoice বারবার print হত।

## 8. Running balance

প্রতিটি iteration-এ balance কমানো যায়। দাঁড়িপাল্লা এখানে running value ধরে।

```python
balance = 50000
payment = 10000
month = 1

while month <= 3:
    balance = balance - payment
    print(f"Month {month}: balance {balance}")
    month += 1
```

**Output**

```text
Month 1: balance 40000
Month 2: balance 30000
Month 3: balance 20000
```

প্রতি বার payment balance থেকে বাদ যায়। `month` তিনটি iteration নিয়ন্ত্রণ করে।

## 9. Condition false হলে loop চলে না

শুরুতেই condition false হলে block একবারও চলে না।

```python
stock = 0

while stock > 0:
    print("Dispatch one unit")
    stock -= 1

print("No stock to dispatch")
```

**Output**

```text
No stock to dispatch
```

`stock > 0` শুরুতেই false। তাই loop body skip হয়েছে এবং পরের print চলেছে।

## 10. Stop condition এবং business rule

একটি business process নির্দিষ্ট threshold-এ থামতে পারে।

```python
remaining_invoices = 3

while remaining_invoices > 0:
    print(f"Invoices left: {remaining_invoices}")
    remaining_invoices -= 1

print("Invoice check complete")
```

**Output**

```text
Invoices left: 3
Invoices left: 2
Invoices left: 1
Invoice check complete
```

প্রথমে বর্তমান count দেখানো হয়, পরে এক কমানো হয়। 0 হলে condition false এবং final message চলে।

## 11. Infinite loop থেকে সাবধান

যদি condition সত্য থাকে কিন্তু loop variable বদলানো না হয়, loop থামবে না।

```python
attempt = 1

while attempt <= 2:
    print(f"Attempt {attempt}")
    attempt += 1
```

**Output**

```text
Attempt 1
Attempt 2
```

এখানে update থাকা নিরাপদ। ভুল করে `attempt += 1` বাদ দিলে program endlessly চলতে পারে। এমন program থামাতে VS Code-এ Stop চাপুন।

## 13. Troubleshooting

### সমস্যা 1
- কী হচ্ছে: একই line endlessly print হচ্ছে।
- সম্ভাব্য কারণ: loop variable update হয়নি।
- Fix: body-তে counter update যোগ করুন।
- Prevention: loop লেখার আগে start, condition, update লিখুন।

### সমস্যা 2
- কী হচ্ছে: loop একবারও চলে না।
- সম্ভাব্য কারণ: শুরু condition false।
- Fix: initial value এবং comparison মিলিয়ে দেখুন।
- Prevention: প্রথম condition হাতে হিসাব করুন।

### সমস্যা 3
- কী হচ্ছে: শেষ expected value process হচ্ছে না।
- সম্ভাব্য কারণ: `<` ব্যবহার করা হয়েছে, কিন্তু equality দরকার।
- Fix: inclusive শেষ value হলে `<=` ব্যবহার করুন।
- Prevention: boundary value দিয়ে test করুন।

### সমস্যা 4
- কী হচ্ছে: balance ভুলভাবে বদলাচ্ছে।
- সম্ভাব্য কারণ: update loop-এর বাইরে বা ভুল variable-এ হয়েছে।
- Fix: calculation এবং counter update body-এর ভিতরে রাখুন।
- Prevention: প্রতি iteration-এর expected balance লিখুন।

## 14. Common Misconceptions

1. **ভুল:** `while` block একবারই চলে → **সত্য:** condition সত্য থাকলে বহুবার চলে।
2. **ভুল:** loop variable নিজে নিজে বাড়ে → **সত্য:** programmer-কে update লিখতে হয়।
3. **ভুল:** false condition হলে error হয় → **সত্য:** body skip হয়।
4. **ভুল:** `<=` এবং `<` একই → **সত্য:** `<=` শেষ equality গ্রহণ করে।
5. **ভুল:** infinite loop সবসময় useful → **সত্য:** intentional না হলে এটি bug।

## 17. Key Idea

`while` loop একটি condition সত্য থাকা পর্যন্ত কাজ repeat করে। Loop variable-এর start, condition এবং update পরিষ্কার থাকলে business process নিরাপদে থামে।

**ছড়া:**
