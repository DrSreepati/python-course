## 6. List তৈরি

একটি list হলো মালা। প্রতিটি bead একটি item। Wholesale shop-এর daily sales এক list-এ রাখা যায়।

```python
daily_sales = [12000, 9500, 8800, 13200, 7500]
print(daily_sales)
print(len(daily_sales))
```

**Output**

```text
[12000, 9500, 8800, 13200, 7500]
5
```

- Square brackets list তৈরি করে।
- Comma আলাদা item চিহ্নিত করে।
- `len()` item-এর সংখ্যা গোনে।

## 7. Positive index

Index হলো list-এর আসন নম্বর। Python প্রথম আসনকে `0` বলে।

```python
daily_sales = [12000, 9500, 8800, 13200, 7500]
print(daily_sales[0])
print(daily_sales[3])
```

**Output**

```text
12000
13200
```

- `[0]` প্রথম দিনের sale নেয়।
- `[3]` চতুর্থ দিনের sale নেয়।
- Index `3` মানে চতুর্থ item, কারণ শুরু শূন্য।

## 8. Negative index

শেষ দিক থেকে item পড়তে negative index ব্যবহার করা যায়।

```python
daily_sales = [12000, 9500, 8800, 13200, 7500]
print(daily_sales[-1])
print(daily_sales[-2])
```

**Output**

```text
7500
13200
```

- `-1` শেষ item।
- `-2` শেষের আগের item।
- এতে list-এর length না জেনেও শেষের data পড়া যায়।

## 9. Slicing

Slicing হলো list-এর একটি অংশ কাটা। Form হলো `list[start:stop]`; stop item বাদ থাকে।

```python
daily_sales = [12000, 9500, 8800, 13200, 7500]
first_three_days = daily_sales[0:3]
last_two_days = daily_sales[-2:]
print(first_three_days)
print(last_two_days)
```

**Output**

```text
[12000, 9500, 8800]
[13200, 7500]
```

- `[0:3]` index 0, 1, 2 নেয়।
- index 3 নেওয়া হয় না।
- `[-2:]` শেষ দুই item নেয়।

## 10. Slice step

তৃতীয় অংশ `step` দিলে কত ঘর পর পর item নিতে হবে তা বলা যায়।

```python
daily_sales = [12000, 9500, 8800, 13200, 7500]
alternate_days = daily_sales[::2]
reversed_sales = daily_sales[::-1]
print(alternate_days)
print(reversed_sales)
```

**Output**

```text
[12000, 8800, 7500]
[7500, 13200, 8800, 9500, 12000]
```

- `::2` এক item বাদ দিয়ে নেয়।
- `[::-1]` list উল্টো করে নতুন list দেয়।
- Original list এখানে বদলায় না।

## 11. Business record list

List শুধু সংখ্যা নয়, string-ও রাখতে পারে।

```python
customers = ["Rahim Traders", "Karim Store", "Jahid Enterprise"]
print(customers[1])
print(customers[:2])
```

**Output**

```text
Karim Store
['Rahim Traders', 'Karim Store']
```

- `customers[1]` দ্বিতীয় customer।
- `[:2]` শুরু থেকে index 1 পর্যন্ত নেয়।
- একই list-এ text records রাখা যায়।

## 12. Troubleshooting

### সমস্যা 1
- কী হচ্ছে: প্রথম sale চাইলে দ্বিতীয় sale আসছে।
- সম্ভাব্য কারণ: `[1]`-কে প্রথম index ভাবা হয়েছে।
- Fix: প্রথম item-এর জন্য `[0]` ব্যবহার করুন।
- Prevention: index-কে আসন ভাবুন, প্রথম আসন শূন্য।

### সমস্যা 2
- কী হচ্ছে: `IndexError: list index out of range` আসছে।
- সম্ভাব্য কারণ: list-এর শেষ index-এর চেয়ে বড় index ব্যবহার হয়েছে।
- Fix: `len(list) - 1` পর্যন্ত valid index রাখুন।
- Prevention: item count দেখে index লিখুন।

### সমস্যা 3
- কী হচ্ছে: slice-এ প্রত্যাশার চেয়ে কম item আছে।
- সম্ভাব্য কারণ: stop position বাদ যায়।
- Fix: শেষ দরকারি index-এর পরের position stop দিন।
- Prevention: `0:3` মানে 0, 1, 2 মনে রাখুন।

### সমস্যা 4
- কী হচ্ছে: reverse slice দেখে original data বদলে গেছে মনে হচ্ছে।
- সম্ভাব্য কারণ: slice-এর result এবং original list আলাদা করে দেখা হয়নি।
- Fix: দুটো variable print করুন।
- Prevention: slicing নতুন list তৈরি করে, original list নিজে বদলায় না।

## 13. Common Misconceptions

1. **ভুল:** প্রথম index `1` → **সত্য:** Python index `0` থেকে শুরু করে।
2. **ভুল:** slice-এর stop item-ও আসে → **সত্য:** stop position বাদ থাকে।
3. **ভুল:** negative index invalid → **সত্য:** negative index শেষ দিক থেকে item নেয়।
4. **ভুল:** slicing original list বদলায় → **সত্য:** slicing সাধারণত নতুন list দেয়।
5. **ভুল:** list-এ শুধু number রাখা যায় → **সত্য:** string-সহ বিভিন্ন type রাখা যায়।

## 16. Key Idea

**ছড়া:**
