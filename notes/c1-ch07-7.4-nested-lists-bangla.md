## 6. Nested list এবং table

Nested list হলো list-এর ভিতরে list। প্রতিটি inner list একটি row হতে পারে।

```python
sales_table = [
    [12000, 9500, 8800],
    [13200, 7500, 11000],
]
print(sales_table)
print(sales_table[0])
```

**Output**

```text
[[12000, 9500, 8800], [13200, 7500, 11000]]
[12000, 9500, 8800]
```

- Outer list পুরো table ধরে।
- `sales_table[0]` প্রথম row নেয়।
- প্রতিটি row-এর ভিতরে দিনের sales আছে।

## 7. Row এবং cell access

দুটি index দিয়ে নির্দিষ্ট cell পড়া যায়। প্রথম index row, দ্বিতীয় index column।

```python
sales_table = [
    [12000, 9500, 8800],
    [13200, 7500, 11000],
]
print(sales_table[1][2])
print(sales_table[0][1])
```

**Output**

```text
11000
9500
```

- `[1]` দ্বিতীয় row।
- `[2]` সেই row-এর তৃতীয় column।
- তাই `[1][2]` হলো দ্বিতীয় row-এর তৃতীয় cell।

## 8. Row total

প্রতিটি row-এর total আলাদা করে বের করা যায়।

```python
sales_table = [
    [12000, 9500, 8800],
    [13200, 7500, 11000],
]
for row in sales_table:
    print(sum(row))
```

**Output**

```text
30300
31700
```

- Outer loop একটি row নেয়।
- `sum(row)` সেই row-এর cells যোগ করে।
- প্রতিটি customer বা branch-এর total আলাদা দেখা যায়।

## 9. Nested loop এবং grand total

সব row এবং সব cell process করতে nested loop ব্যবহার করি।

```python
sales_table = [
    [12000, 9500, 8800],
    [13200, 7500, 11000],
]
grand_total = 0

for row in sales_table:
    for sale in row:
        grand_total += sale

print(grand_total)
```

**Output**

```text
62000
```

- `grand_total` table-এর বাইরে শুরু হয়েছে।
- Outer loop row বদলায়।
- Inner loop row-এর প্রতিটি sale যোগ করে।

## 10. Customer table

একটি row customer-এর নাম এবং balances-এর table-ও হতে পারে, তবে একই ধরনের data রাখলে calculation সহজ হয়।

```python
customer_balances = [
    [50000, 12000],
    [32000, 8000],
    [71000, 15000],
]

for balance_row in customer_balances:
    print(f"Opening: {balance_row[0]}, Payment: {balance_row[1]}")
```

**Output**

```text
Opening: 50000, Payment: 12000
Opening: 32000, Payment: 8000
Opening: 71000, Payment: 15000
```

- একটি row-তে opening balance এবং payment আছে।
- `[0]` opening, `[1]` payment।
- একই position-এর অর্থ প্রতিটি row-তে একই থাকে।

## 11. Table-এর column total

প্রতিটি row-তে একই column যোগ করলে column total পাওয়া যায়।

```python
weekly_sales = [
    [12000, 9500, 8800],
    [13200, 7500, 11000],
]

day_one_total = weekly_sales[0][0] + weekly_sales[1][0]
day_two_total = weekly_sales[0][1] + weekly_sales[1][1]
print(day_one_total)
print(day_two_total)
```

**Output**

```text
25200
17000
```

- প্রথম index row বেছে নেয়।
- দ্বিতীয় index একই column বেছে নেয়।
- একই column-এর values যোগ করলে column report হয়।

## 12. Troubleshooting

### সমস্যা 1
- কী হচ্ছে: row-এর বদলে একটি number পাওয়া যাচ্ছে।
- সম্ভাব্য কারণ: `table[0][1]` cell চাওয়া হয়েছে, পুরো row নয়।
- Fix: পুরো row-এর জন্য শুধু `table[0]` লিখুন।
- Prevention: row index এবং cell index আলাদা করে পড়ুন।

### সমস্যা 2
- কী হচ্ছে: `IndexError: list index out of range` আসছে।
- সম্ভাব্য কারণ: row বা column-এর valid index-এর বাইরে যাওয়া হয়েছে।
- Fix: row-এর length এবং cell-এর length যাচাই করুন।
- Prevention: table-এর shape আগে লিখে নিন।

### সমস্যা 3
- কী হচ্ছে: grand total শুধু শেষ row-এর total।
- সম্ভাব্য কারণ: `grand_total = 0` outer loop-এর ভিতরে reset হয়েছে।
- Fix: grand total outer loop-এর আগে রাখুন।
- Prevention: row total এবং grand total-এর scope আলাদা রাখুন।

### সমস্যা 4
- কী হচ্ছে: column total ভুল হচ্ছে।
- সম্ভাব্য কারণ: row index বদলেছে, column index বদলায়নি, বা উল্টো হয়েছে।
- Fix: প্রতিটি access-এ `[row][column]` order ব্যবহার করুন।
- Prevention: table-এর row এবং column label লিখুন।

## 13. Common Misconceptions

1. **ভুল:** nested list-এর প্রথম index column → **সত্য:** প্রথম index row।
2. **ভুল:** `table[0]` প্রথম cell → **সত্য:** এটি প্রথম row।
3. **ভুল:** inner loop ছাড়া table total সম্ভব নয় → **সত্য:** row total দিয়ে nested loop বা `sum` ব্যবহার করা যায়।
4. **ভুল:** সব row-এর length আলাদা হলেও একই column access নিরাপদ → **সত্য:** missing cell হলে error হতে পারে।
5. **ভুল:** grand total এবং row total একই variable → **সত্য:** তাদের কাজ এবং scope আলাদা।

        grand_total += value
print(grand_total)

## 16. Key Idea

Nested list table-এর মতো data রাখে। প্রথম index row, দ্বিতীয় index cell বা column। Nested loop row এবং cell দুটোই process করে।

**ছড়া:**  
Row-এর ঘরে cell, table থাকে সাজানো,  
দুই loop-এ total, report হয় গোনা।
