## 6. Duplicate invoice কেন সমস্যা

একটি invoice দুইবার upload হলে sales total ভুল হতে পারে। Set দিয়ে unique count পাওয়া যায়, কিন্তু কোন invoice repeat হয়েছে তা জানতে loop-এর সঙ্গে `seen` set ব্যবহার করব।

```python
invoices = ["INV-007", "INV-008", "INV-007", "INV-009", "INV-008"]
unique_invoices = set(invoices)

print("Total rows:", len(invoices))
print("Unique invoices:", len(unique_invoices))
print("Unique list:", sorted(unique_invoices))
```

**Output**

```text
Total rows: 5
Unique invoices: 3
Unique list: ['INV-007', 'INV-008', 'INV-009']
```

List-এর length সব row গোনে। Set-এর length unique invoice গোনে।

## 7. Duplicate report বানানো

শুধু set বানালে duplicate-এর নাম হারিয়ে যায়। `seen`-এ প্রথম দেখা invoice রাখব। আবার দেখা গেলে `duplicates`-এ রাখব।

```python
invoices = ["INV-007", "INV-008", "INV-007", "INV-009", "INV-008"]
seen = set()
duplicates = []

for invoice in invoices:
    if invoice in seen:
        if invoice not in duplicates:
            duplicates.append(invoice)
    else:
        seen.add(invoice)

print("Duplicates:", duplicates)
```

**Output**

```text
Duplicates: ['INV-007', 'INV-008']
```

`seen` দ্রুত membership check করে। `duplicates` list original discovery order রাখে।

## 8. Unique customer IDs

একই customer একাধিক invoice করতে পারে। Customer register-এ একবার করে ID দরকার হলে set ব্যবহার করা যায়।

```python
customer_ids = ["C-1023", "C-1040", "C-1023", "C-1088"]
unique_customers = set(customer_ids)

print("Unique customer count:", len(unique_customers))
print("Customer IDs:", sorted(unique_customers))
```

**Output**

```text
Unique customer count: 3
Customer IDs: ['C-1023', 'C-1040', 'C-1088']
```

Set repeated customer ID বাদ দেয়। Customer-এর প্রথম দেখা order দরকার হলে আগের `seen` pattern ব্যবহার করতে হবে।

## 9. Product category comparison

দুই branch কোন category বিক্রি করেছে তা তুলনা করা যায়। Common category হলো shared stock, difference হলো branch-specific stock।

```python
dhaka_categories = {"rice", "oil", "lentils", "sugar"}
chattogram_categories = {"oil", "sugar", "tea"}

print("Shared:", sorted(dhaka_categories & chattogram_categories))
print("Dhaka only:", sorted(dhaka_categories - chattogram_categories))
print("Chattogram only:", sorted(chattogram_categories - dhaka_categories))
```

**Output**

```text
Shared: ['oil', 'sugar']
Dhaka only: ['lentils', 'rice']
Chattogram only: ['tea']
```

Intersection shared category দেখায়। Difference branch-specific category দেখায়।

## 10. Order-preserving unique report

Set unique value চেনে, কিন্তু display order নয়। তাই `seen` set এবং `unique_in_order` list একসঙ্গে ব্যবহার করা ভালো।

```python
invoice_rows = ["INV-003", "INV-001", "INV-003", "INV-002", "INV-001"]
seen = set()
unique_in_order = []

for invoice in invoice_rows:
    if invoice not in seen:
        seen.add(invoice)
        unique_in_order.append(invoice)

print("Unique in source order:", unique_in_order)
```

**Output**

```text
Unique in source order: ['INV-003', 'INV-001', 'INV-002']
```

`seen` duplicate আটকায়। List report-এর প্রথম দেখা order ধরে রাখে।

## 11. Complete business audit

Boss চান invoice row count, unique count, duplicate count এবং duplicate references।

```python
invoice_rows = [
    "INV-2024-007",
    "INV-2024-008",
    "INV-2024-007",
    "INV-2024-009",
    "INV-2024-008",
]

seen = set()
duplicates = []

for invoice in invoice_rows:
    if invoice in seen:
        if invoice not in duplicates:
            duplicates.append(invoice)
    else:
        seen.add(invoice)

print("Rows:", len(invoice_rows))
print("Unique:", len(seen))
print("Duplicate references:", duplicates)
print("Duplicate count:", len(duplicates))
```

**Output**

```text
Rows: 5
Unique: 3
Duplicate references: ['INV-2024-007', 'INV-2024-008']
Duplicate count: 2
```

এই report row-level সমস্যা এবং unique business record দুটোই আলাদা করে দেখায়।

## 12. Synthesis table

| Tool | কাজ | কখন ব্যবহার করবেন |
|---|---|---|
| `set(items)` | unique values | count বা membership |
| `seen` set | আগে দেখা item মনে রাখা | duplicate scan |
| `duplicates` list | duplicate-এর report order | audit output |
| `a & b` | shared values | branch/category comparison |
| `a - b` | one-sided values | branch-specific category |
| `sorted(set)` | ordered display | readable summary |

## 13. Troubleshooting

### সমস্যা 1: duplicate-এর নাম পাওয়া যাচ্ছে না
- **সহজ ভাষায়:** শুধু set বানালে repeated row-এর history থাকে না।
- **সম্ভাব্য কারণ:** original list scan করা হয়নি।
- **ধাপে ধাপে fix:** `seen` set রাখুন, আবার দেখা গেলে duplicate list-এ যোগ করুন।
- **পরেরবার প্রতিরোধ:** duplicate detection-এ list এবং set দুটো রাখুন।

### সমস্যা 2: duplicate list-এ একই নাম বারবার এসেছে
- **সহজ ভাষায়:** প্রতিটি repeated row সরাসরি report-এ যোগ হয়েছে।
- **সম্ভাব্য কারণ:** `invoice not in duplicates` check নেই।
- **ধাপে ধাপে fix:** append-এর আগে membership check করুন।
- **পরেরবার প্রতিরোধ:** report-এ unique duplicate reference রাখার rule লিখুন।

### সমস্যা 3: unique report-এর order বদলে গেছে
- **সহজ ভাষায়:** set order রাখে না।
- **সম্ভাব্য কারণ:** set সরাসরি display করা হয়েছে।
- **ধাপে ধাপে fix:** stable order চাইলে `sorted()` ব্যবহার করুন, অথবা `seen` এবং list ব্যবহার করুন।
- **পরেরবার প্রতিরোধ:** count-এর set এবং display-এর list আলাদা রাখুন।

### সমস্যা 4: category comparison উল্টো হয়েছে
- **সহজ ভাষায়:** difference-এর প্রথম set-এর দিকেই report নির্ভর করে।
- **সম্ভাব্য কারণ:** `chattogram - dhaka` লিখে Dhaka-only খোঁজা হয়েছে।
- **ধাপে ধাপে fix:** Dhaka-only-এর জন্য `dhaka - chattogram` লিখুন।
- **পরেরবার প্রতিরোধ:** operation পড়ুন, “প্রথম branch থেকে দ্বিতীয় branch বাদ”।

## 14. Common Misconceptions

1. **ভুল:** set-এ duplicate রাখা যায় → **সত্য:** set প্রতিটি value একবার রাখে।
2. **ভুল:** set বলবে duplicate কোন row-এ ছিল → **সত্য:** অবস্থান দরকার হলে original list scan করতে হয়।
3. **ভুল:** `len(set(rows))` duplicate-এর সংখ্যা দেয় → **সত্য:** এটি unique count দেয়।
4. **ভুল:** set দিয়ে original order সবসময় পাওয়া যায় → **সত্য:** order-এর জন্য list বা `sorted()` দরকার।
5. **ভুল:** category comparison-এ union-ই যথেষ্ট → **সত্য:** shared-এর জন্য intersection, branch-specific-এর জন্য difference দরকার।

invoices = ["A", "B", "A", "C"]

### Exercise 2
প্রথম দেখা order রেখে unique customer list বানান।

```python
customers = ["C-1", "C-2", "C-1", "C-3"]
seen = set()
unique = []
for customer in customers:
    if customer not in seen:
        seen.add(customer)
        unique.append(customer)

```

### Exercise 3
দুই category group-এর shared এবং exclusive values বের করুন।

```python
a = {"rice", "oil", "tea"}
b = {"oil", "sugar"}
print(sorted(a & b))
print(sorted(a - b))
print(sorted(b - a))
```

**Output:** `['oil']`, `['rice', 'tea']`, `['sugar']`

### Exercise 4
একবার করে duplicate invoice reference report করুন।

```python
rows = ["INV-1", "INV-2", "INV-1", "INV-3", "INV-2", "INV-2"]
seen = set()
duplicates = []
for invoice in rows:
    if invoice in seen and invoice not in duplicates:
        duplicates.append(invoice)
    else:
        seen.add(invoice)
print(duplicates)
```

**Output:** `['INV-1', 'INV-2']`

### Exercise 5: Sreepati debugging bug
Sreepati unique invoice count লিখেছেন:

```python
rows = ["INV-1", "INV-2", "INV-1", "INV-3"]
unique_count = len(rows)
print(unique_count)
```

Wrong output: `4`. Boss বললেন, “চারটি row নয়, তিনটি unique invoice আছে।”

**Diagnosis:** `len(rows)` সব row গোনে। Duplicate বাদ দিয়ে unique count পেতে set দরকার।

**Minimal fix**

```python
unique_count = len(set(rows))
print(unique_count)
```

**Output:** `3`

**Lesson:** unique count-এর আগে collection-কে set-এ রূপান্তর করুন।

## 17. Key Idea

Set business audit-এ duplicate ধরা, unique ID গোনা এবং group তুলনা করা সহজ করে। Original order দরকার হলে `seen` set-এর সঙ্গে list ব্যবহার করুন।

**ছড়া ১:**  
আগে দেখা রাখে `seen`-এ, duplicate যায় ধরা,  
Unique count set-এ, report থাকে গড়া।

**ছড়া ২:**  
Category মিলে `&`, আলাদা হলে `-`,  
Audit report পরিষ্কার হয়, ভুল থাকে দূর।
