## 6. Discount eligibility

Order কমপক্ষে 10000 এবং balance কমপক্ষে 30000 হলে discount review হবে। দুই শর্তই দরকার।

```python
order_amount = 12000
customer_balance = 32000

if order_amount >= 10000 and customer_balance >= 30000:
    discount_status = "Eligible"
else:
    discount_status = "Not eligible"

print(discount_status)
```

**Output**

```text
Eligible
```

`>=` exact threshold গ্রহণ করে। `and` দুইটি business gate একসঙ্গে পরীক্ষা করে।

## 7. Overdue status

Balance আছে এবং due date পেরিয়েছে, কিন্তু payment আসেনি, তাহলে overdue follow-up দরকার।

```python
outstanding = 50000
days_overdue = 12
payment_received = False

if outstanding > 0 and days_overdue > 0 and not payment_received:
    status = "Overdue"
elif outstanding == 0 or payment_received:
    status = "Clear"
else:
    status = "Review"

print(status)
```

**Output**

```text
Overdue
```

Positive outstanding, positive overdue days এবং unpaid condition একসঙ্গে সত্য।

## 8. Budget variance

Actual খরচ budget-এর চেয়ে বেশি হলে over budget, কম হলে under budget, সমান হলে on budget।

```python
budget = 40000
actual_cost = 42500

if actual_cost > budget:
    variance_status = "Over budget"
elif actual_cost < budget:
    variance_status = "Under budget"
else:
    variance_status = "On budget"

print(variance_status)
```

**Output**

```text
Over budget
```

`>` এবং `<` দুই বিপরীত দিক ধরে। বাকি একমাত্র case হলো equality।

## 9. Profit, loss and break-even

Profit positive হলে profit, negative হলে loss, শূন্য হলে break-even।

```python
profit = 0

if profit > 0:
    result = "Profit"
elif profit < 0:
    result = "Loss"
else:
    result = "Break-even"

print(result)
```

**Output**

```text
Break-even
```

Zero-কে loss বলা যাবে না। এটি আলাদা business meaning বহন করে।

## 10. Payment status

Payment amount-এর সঙ্গে invoice amount তুলনা করে status করা যায়।

```python
invoice_amount = 20000
paid_amount = 12000

if paid_amount == 0:
    payment_status = "Unpaid"
elif paid_amount < invoice_amount:
    payment_status = "Partly paid"
elif paid_amount == invoice_amount:
    payment_status = "Paid"
else:
    payment_status = "Overpaid"

print(payment_status)
```

**Output**

```text
Partly paid
```

Zero আগে আলাদা করা হয়েছে। তারপর partial, exact এবং extra payment category এসেছে।

## 11. One small report

আলাদা named variables ব্যবহার করলে boss-এর report পড়া সহজ হয়।

```python
customer_name = "Jahid Enterprise"
order_amount = 13200
balance = 71000
budget = 40000
actual_cost = 38000
profit = 2500
paid_amount = 20000
invoice_amount = 20000

if order_amount >= 10000 and balance >= 30000:
    discount_status = "Eligible"
else:
    discount_status = "Not eligible"

if actual_cost > budget:
    budget_status = "Over budget"
elif actual_cost < budget:
    budget_status = "Under budget"
else:
    budget_status = "On budget"

if profit > 0:
    profit_status = "Profit"
elif profit < 0:
    profit_status = "Loss"
else:
    profit_status = "Break-even"

if paid_amount == invoice_amount:
    payment_status = "Paid"
else:
    payment_status = "Review payment"

print(customer_name)
print(discount_status)
print(budget_status)
print(profit_status)
print(payment_status)
```

**Output**

```text
Jahid Enterprise
Eligible
Under budget
Profit
Paid
```

প্রতিটি rule নিজের status variable তৈরি করেছে। শেষে report একে একে print হয়েছে।

## 13. Troubleshooting

### সমস্যা 1
- কী হচ্ছে: 10000 order eligible হচ্ছে না।
- সম্ভাব্য কারণ: `>` ব্যবহার হয়েছে।
- Fix: inclusive policy হলে `>=` লিখুন।
- Prevention: exact threshold দিয়ে test করুন।

### সমস্যা 2
- কী হচ্ছে: zero profit loss দেখাচ্ছে।
- সম্ভাব্য কারণ: `else`-এ loss রাখা হয়েছে।
- Fix: `profit < 0` আলাদা branch করুন।
- Prevention: positive, negative, zero তিন case লিখুন।

### সমস্যা 3
- কী হচ্ছে: partly paid invoice paid দেখাচ্ছে।
- সম্ভাব্য কারণ: শুধু `paid_amount > 0` পরীক্ষা করা হয়েছে।
- Fix: invoice amount-এর সঙ্গে exact comparison করুন।
- Prevention: zero, partial, exact, extra চার case test করুন।

### সমস্যা 4
- কী হচ্ছে: under budget-কে over budget বলা হচ্ছে।
- সম্ভাব্য কারণ: comparison direction উল্টো।
- Fix: actual এবং budget-এর order মুখে বলুন, তারপর operator দিন।
- Prevention: actual 38000 এবং 42500, দুটো test করুন।

## 14. Common Misconceptions

1. **ভুল:** threshold-এ equal value বাদ যায় → **সত্য:** `>=` equal value নেয়।
2. **ভুল:** zero profit loss → **সত্য:** zero হলো break-even।
3. **ভুল:** payment positive হলেই paid → **সত্য:** invoice-এর সঙ্গে তুলনা দরকার।
4. **ভুল:** সব status এক condition-এ হবে → **সত্য:** প্রতিটি report question-এর নিজস্ব rule আছে।
5. **ভুল:** branch order গুরুত্বপূর্ণ নয় → **সত্য:** প্রথম matching branch-ই চলে।

```python

    print("Profit")
else:
    print("Loss")
```

ভুল output: `Profit`। Boss বললেন zero profit-কে profit বলা যাবে না। `>= 0` zero-কে positive category-তে ঢুকিয়েছে। Minimal fix:

```python
profit = 0
if profit > 0:
    print("Profit")
elif profit < 0:
    print("Loss")
else:
    print("Break-even")
```

Output:

```text
Break-even
```

Lesson: zero business result হলে সেটির আলাদা branch রাখুন।
