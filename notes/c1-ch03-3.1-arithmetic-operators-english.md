## 1. What an operator is

An operator is a sign that works on values. `+` adds, `-` subtracts, `*` multiplies, and `/` divides.

```python
sales = 12000
cost = 8500

profit = sales - cost
print(profit)
```

**Output**

```text
3500
```

The variables hold the inputs. The subtraction produces profit.

## 2. Addition and subtraction

Use `+` for a total or combined value. Use `-` for a difference or remaining value.

```python
day_one = 12000
day_two = 9500
two_day_sales = day_one + day_two
sales_gap = day_one - day_two

print(two_day_sales)
print(sales_gap)
```

**Output**

```text
21500
2500
```

The first expression adds sales. The second finds the gap.

## 3. Multiplication and division

Use `*` for quantity times unit price. Use `/` for division. It normally keeps a decimal result.

```python
quantity = 8
unit_price = 175
amount = quantity * unit_price
average_daily_sales = amount / 4

print(amount)
print(average_daily_sales)
```

**Output**

```text
1400
350.0
```

Eight times 175 is 1400. Dividing 1400 by 4 gives 350.0.

## 4. Floor division

`//` is floor division. It keeps the whole part and removes the fraction. It suits full boxes or full groups.

```python
items = 23
items_per_box = 5
full_boxes = items // items_per_box

print(full_boxes)
```

**Output**

```text
4
```

Twenty-three items make four full boxes of five. We will use `%` for the remainder.

## 5. Remainder or modulus

`%` gives the remainder after division. It helps find loose stock or money left after equal groups.

```python
items = 23
items_per_box = 5
leftover_items = items % items_per_box

print(leftover_items)
```

**Output**

```text
3
```

Twenty-three divided by five leaves three items.

## 6. The power operator

`**` is the power operator. It raises a number to a power. It can appear in growth practice.

```python
opening_balance = 1000
growth_factor = 1.10
two_period_value = opening_balance * growth_factor ** 2

print(two_period_value)
```

**Output**

```text
1210.0000000000002
```

`growth_factor ** 2` multiplies 1.10 twice. The extra digits come from float representation.

## 7. A sales formula

The simple sales formula is `quantity * unit_price`. Operators turn business language into code.

```python
quantity = 12
unit_price = 250
sales = quantity * unit_price

print(f"Sales: {sales:.2f} taka")
```

**Output**

```text
Sales: 3000.00 taka
```

The quantity and price are multiplied. `:.2f` displays two decimal places.

## 8. Dividing stock

A carton holds a fixed number of items. Use `//` for full cartons and `%` for loose items.

```python
stock = 47
carton_size = 12
cartons = stock // carton_size
loose_items = stock % carton_size

print(f"Full cartons: {cartons}")
print(f"Loose items: {loose_items}")
```

**Output**

```text
Full cartons: 3
Loose items: 11
```

Forty-seven items make three full cartons. Eleven items remain outside.

## 9. Choosing an operator

Say the business question first. Use `+` for a total, `-` for a difference, `*` for a total price, `/` for an average, `//` for full groups, `%` for a remainder, and `**` for repeated multiplication.

```python
weekly_sales = [5000, 4200, 6100, 3800, 5500, 4700, 5700]
total_sales = sum(weekly_sales)
average_sales = total_sales / len(weekly_sales)

print(total_sales)
print(average_sales)
```

**Output**

```text
35000
5000.0
```

`sum()` adds the list values. `len()` counts them. Division gives the average.

## 10. Checking a formula

Python can run a wrong formula without an error. Estimate the business result first, then compare the output.

```python
sales = 5000
cost = 4200
profit = sales - cost
margin_base = sales
profit_rate = profit / margin_base * 100

print(profit)
print(profit_rate)
```

**Output**

```text
800
16.0
```

Profit is 800. Dividing it by sales and multiplying by 100 gives 16.0 percent.

## Synthesis table

| Operator | Name | Business job | Example |
|---|---|---|---|
| `+` | addition | total or combined value | `12000 + 9500` |
| `-` | subtraction | difference or profit | `sales - cost` |
| `*` | multiplication | amount or repeated value | `quantity * price` |
| `/` | true division | average or rate | `total / days` |
| `//` | floor division | full boxes or groups | `items // box_size` |
| `%` | modulus | remainder or leftover | `items % box_size` |
| `**` | exponentiation | power or repeated growth | `factor ** 2` |

## Troubleshooting

### Problem 1: The average became a whole number

- What is happening: the decimal part disappeared.
- Most likely cause: `//` was used instead of `/`.
- Fix: use `/` when the true average is required.
- Prevention: remember that full groups and averages need different operators.

### Problem 2: The box count is right, but loose stock is wrong

- What is happening: full boxes appear, but leftover items do not.
- Most likely cause: `%` was omitted or the divisor was wrong.
- Fix: calculate `full = items // size` and `leftover = items % size`.
- Prevention: report both group count and remainder.

### Problem 3: The float result has extra digits

- What is happening: a result such as `1210.0000000000002` appears.
- Most likely cause: binary float representation.
- Fix: use `:.2f` or `round()` for display, and remember the money storage rule.
- Prevention: avoid raw float equality for money.

### Problem 4: The profit sign is reversed

- What is happening: a profit appears as a negative value.
- Most likely cause: `cost - sales` was written.
- Fix: use `profit = sales - cost`, then check the expected result.
- Prevention: write the formula in words before coding it.

## Common Misconceptions

1. **Wrong:** `/` and `//` are the same → **Truth:** `/` keeps division decimals, while `//` performs floor division.
2. **Wrong:** `%` calculates a percentage → **Truth:** `%` gives a remainder.
3. **Wrong:** `*` is only for money → **Truth:** it multiplies any suitable numbers.
4. **Wrong:** no Python error means the formula is correct → **Truth:** a valid formula can still give a wrong business result.
5. **Wrong:** `**` joins strings → **Truth:** `**` calculates a power.

### Exercise 5: Rafiq bhai's debugging bug

Rafiq bhai wrote:

```python
total_sales = 35000
days = 7
average_sales = total_sales // days
print(average_sales)
```

The boss wants a true average. Rafiq bhai got `5000`, which happens to be exact for this data. Other data can lose its decimal part.  
**Cause:** floor division was used for a true average.  
**Minimal fix:** `average_sales = total_sales / days`.

```python
total_sales = 35001
days = 7
average_sales = total_sales / days
print(average_sales)  # Expected: 5000.142857142857
```

**Lesson:** use `//` for full groups and `/` for a true average.

## Key Idea

Arithmetic operators turn business formulas into code. Use `/` for averages, `//` for full groups, `%` for remainders, and `**` for powers.

**Rhyme 1:** Add for totals, subtract for gain, multiply for amount right.  
**Rhyme 2:** Divide for averages, remainder for stock, power for growth in sight.
