## 1. Comparison-এর অর্থ

Comparison operator value-এর মধ্যে সম্পর্ক পরীক্ষা করে। Result হিসেব হয় `True` অথবা `False`।

```python
sales = 12000
target = 10000

print(sales > target)
```

**Output**

```text
True
```

`sales` target-এর চেয়ে বেশি, তাই comparison-এর result `True`।

## 2. Equality ও inequality

`==` জিজ্ঞাসা করে দুই value সমান কি না। `!=` জিজ্ঞাসা করে সমান নয় কি না। `=` assignment-এর জন্য, comparison-এর জন্য নয়।

```python
customer_code = "C-1023"
expected_code = "C-1023"

print(customer_code == expected_code)
print(customer_code != "C-9999")
```

**Output**

```text
True
True
```

দুই code একই, তাই `==` সত্য। `C-1023` এবং `C-9999` আলাদা, তাই `!=` সত্য।

## 3. বড় এবং ছোট তুলনা

`>` বড়, `<` ছোট বোঝায়। Profit positive কি না, stock reorder level-এর নিচে কি না, এসব rule-এ এগুলো লাগে।

```python
profit = 3500
reorder_level = 20
stock = 15

print(profit > 0)
print(stock < reorder_level)
```

**Output**

```text
True
True
```

Profit শূন্যের বেশি। Stock reorder level-এর চেয়ে কম।

## 4. Boundary comparison

`>=` মানে বড় অথবা সমান, `<=` মানে ছোট অথবা সমান। Discount rule-এ minimum amount ঠিক সমান হলেও eligible হতে পারে।

```python
order_amount = 50000
discount_limit = 50000

print(order_amount >= discount_limit)
print(order_amount <= discount_limit)
```

**Output**

```text
True
True
```

দুই value সমান। তাই বড় অথবা সমান এবং ছোট অথবা সমান, দুই condition-ই সত্য।

## 5. Boolean result

Comparison-এর ফলাফলকে Boolean value বলা হয়। আমরা result variable-এ রেখে পরে business report-এ ব্যবহার করতে পারি।

```python
amount = 32000
minimum_order = 10000
large_order = amount >= minimum_order

print(large_order)
print(type(large_order))
```

**Output**

```text
True
<class 'bool'>
```

`large_order`-এ comparison-এর result রাখা হয়েছে। তার type হলো `bool`।

## 6. `and`

`and`-এ দুইটি condition-ই সত্য হতে হয়। যেমন, order amount minimum-এর বেশি এবং customer paid হতে হবে।

```python
order_amount = 32000
minimum_order = 10000
paid = True

eligible = order_amount >= minimum_order and paid == True
print(eligible)
```

**Output**

```text
True
```

প্রথম condition সত্য এবং দ্বিতীয় condition-ও সত্য। তাই `and` result সত্য।

## 7. `or`

`or`-এ অন্তত একটি condition সত্য হলেই result সত্য। Customer cash অথবা bank transfer, যেকোনো একটি payment method থাকলে payment received ধরা যেতে পারে।

```python
cash_received = False
bank_received = True

payment_received = cash_received or bank_received
print(payment_received)
```

**Output**

```text
True
```

Cash পাওয়া যায়নি, কিন্তু bank payment পাওয়া গেছে। তাই `or` result `True`।

## 8. `not`

`not` Boolean result উল্টে দেয়। `True` হলে `False`, `False` হলে `True`।

```python
stock_available = False
stock_missing = not stock_available

print(stock_missing)
```

**Output**

```text
True
```

Stock available নয়, তাই stock missing সত্য।

## 9. Discount rule

বাস্তব rule-এ comparison এবং logical operator একসঙ্গে আসে। এখানে minimum order এবং paid status দুটোই দরকার।

```python
order_amount = 71000
minimum_order = 50000
paid = True

discount_eligible = order_amount >= minimum_order and paid
print(discount_eligible)
```

**Output**

```text
True
```

Order minimum-এর সমান বা বেশি এবং paid সত্য, তাই customer discount eligible।

## 10. Condition যাচাই

Boundary value দিয়ে test করা জরুরি। Minimum limit-এর ঠিক নিচে, সমান এবং ওপরে তিনটি case পরীক্ষা করুন।

```python
minimum_order = 50000

below = 49999 >= minimum_order
equal = 50000 >= minimum_order
above = 50001 >= minimum_order

print(below)
print(equal)
print(above)
```

**Output**

```text
False
True
True
```

49999 eligible নয়। 50000 এবং 50001 eligible। এই তিনটি case boundary rule যাচাই করে।

## Troubleshooting

### Problem 1: Comparison-এর জায়গায় value বদলে যাচ্ছে

- কী হচ্ছে: variable-এ নতুন value বসছে, comparison হচ্ছে না।
- সম্ভাব্য কারণ: `==`-এর বদলে `=` লেখা হয়েছে।
- ধাপ: assignment-এর জন্য `=`, equality check-এর জন্য `==` ব্যবহার করুন।
- প্রতিরোধ: condition পড়ার সময় মুখে বলুন, “সমান কি না?”

### Problem 2: Minimum amount-এ discount পাওয়া যাচ্ছে না

- কী হচ্ছে: limit-এর ঠিক সমান order বাদ যাচ্ছে।
- সম্ভাব্য কারণ: `>` ব্যবহার করা হয়েছে, কিন্তু rule-এ সমানও eligible।
- ধাপ: `>=` ব্যবহার করুন এবং below, equal, above test করুন।
- প্রতিরোধ: business rule-এ boundary স্পষ্ট লিখুন।

### Problem 3: `and` condition মিথ্যা হচ্ছে

- কী হচ্ছে: একটি condition সত্য হলেও পুরো result false।
- সম্ভাব্য কারণ: `and`-এ সব condition সত্য হতে হয়।
- ধাপ: প্রতিটি condition আলাদা variable-এ print করুন।
- প্রতিরোধ: complex rule ভেঙে ছোট condition পরীক্ষা করুন।

### Problem 4: `or`-এ ভুলভাবে payment accepted হচ্ছে

- কী হচ্ছে: একটি অসম্পূর্ণ payment condition-এ পুরো payment accepted।
- সম্ভাব্য কারণ: `or`-এর অর্থ অন্তত একটি সত্য, কিন্তু business rule দুটোই চাইতে পারে।
- ধাপ: rule-টি `and` নাকি `or`, আগে ঠিক করুন।
- প্রতিরোধ: payment policy কথায় লিখে তারপর operator বাছুন।

## Common Misconceptions

1. **ভুল:** `=` এবং `==` একই → **সত্য:** `=` assignment, `==` equality comparison।
2. **ভুল:** `and`-এ একটি সত্য হলেই যথেষ্ট → **সত্য:** `and`-এ সব condition সত্য চাই।
3. **ভুল:** `or`-এ সব condition সত্য চাই → **সত্য:** অন্তত একটি সত্য হলেই যথেষ্ট।
4. **ভুল:** `not` value মুছে দেয় → **সত্য:** `not` Boolean result উল্টে দেয়।
5. **ভুল:** `>` এবং `>=` একই → **সত্য:** `>=` সমান value-ও গ্রহণ করে।

### Exercise 5: Rafiq bhai-এর debugging bug

Rafiq bhai লিখেছেন:

```python
order_amount = 50000
minimum_order = 50000
eligible = order_amount > minimum_order
print(eligible)
```

Boss বললেন, minimum order ঠিক 50000 হলেও customer eligible হওয়া উচিত, কিন্তু output `False`।  
**Cause:** সমান value বাদ দেওয়ার জন্য `>` ব্যবহার করা হয়েছে।  
**Minimal fix:** `eligible = order_amount >= minimum_order`।

```python
eligible = order_amount >= minimum_order
print(eligible)  # Expected: True
```

**Lesson:** minimum rule-এ equality গ্রহণযোগ্য কি না, আগে ঠিক করুন।

## Key Idea

Comparison operator business relationship পরীক্ষা করে এবং Boolean result দেয়। `and`, `or`, `not` দিয়ে একাধিক rule জোড়া লাগানো যায়।

**ছড়া ১:** সমান হলে দুই দাগ, বড় হলে এক দাগ, rule বুঝে চলো,  
**ছড়া ২:** and-এ সব, or-এ এক, not-এ উল্টো বলো।
