## 1. `split()` কী

`split()` একটি string-কে নির্দিষ্ট separator-এর জায়গায় ভেঙে list তৈরি করে। List হলো একাধিক value-এর ordered collection। Invoice code-এর অংশ আলাদা করতে এটি useful।

```python
invoice_no = "INV-2024-007"
parts = invoice_no.split("-")

print(parts)
print(type(parts))
```

**Output**

```text
['INV', '2024', '007']
<class 'list'>
```

Hyphen separator-এর জায়গায় string ভেঙেছে। Result একটি list, যেখানে prefix, year এবং serial তিনটি আলাদা item।

গুরুত্বপূর্ণ line:

- `invoice_no` original reference রাখে।
- `split("-")` প্রতিটি hyphen-এ text ভাগ করে।
- `parts` list result ধরে রাখে।

## 2. Separator দিয়ে invoice ভাগ করা

`split(separator)`-এ separator হিসেবে যে text দেব, Python সেই text-এর জায়গায় ভাগ করবে। Slash-যুক্ত invoice-ও একইভাবে ভাগ করা যায়।

```python
raw_invoice = "INV/2024/007"
parts = raw_invoice.split("/")

print(parts[0])
print(parts[1])
print(parts[2])
```

**Output**

```text
INV
2024
007
```

এখানে slash separator। `parts[0]` prefix, `parts[1]` year এবং `parts[2]` serial।

Separator না মিললে split পুরো string-কে একটি item হিসেবে রাখে। তাই input format আগে বোঝা জরুরি।

## 3. `split()`-এর result

`split()`-এর result list হওয়ায় index দিয়ে item পড়া যায়। Empty অংশও result-এ আসতে পারে, যদি separator পাশাপাশি থাকে।

```python
customer_code = "C-1023"
parts = customer_code.split("-")

print(parts)
print(parts[0])
print(parts[1])
```

**Output**

```text
['C', '1023']
C
1023
```

Customer code দুটি অংশে ভাগ হয়েছে। Prefix এবং numeric ID আলাদা item হিসেবে রাখা হয়েছে।

একটি সতর্কতা:

```python
text = "INV--007"
print(text.split("-"))
```

**Output**

```text
['INV', '', '007']
```

দুটি hyphen পাশাপাশি থাকায় মাঝখানে empty string এসেছে। এটি error নয়, কিন্তু data validation-এর signal।

## 4. `join()` কী

`join()` list বা অন্য iterable-এর text item-গুলোকে একটি separator দিয়ে জোড়া দেয়। Syntax হলো `separator.join(items)`। Separator method-এর আগে থাকে।

```python
parts = ["INV", "2024", "007"]
invoice_no = "-".join(parts)

print(invoice_no)
```

**Output**

```text
INV-2024-007
```

Hyphen list item-গুলোর মাঝখানে বসেছে। `join()` একটি নতুন string তৈরি করেছে।

গুরুত্বপূর্ণ নিয়ম:

- `"-".join(parts)` অর্থ hyphen দিয়ে জোড়া।
- `"".join(parts)` অর্থ কোনো separator ছাড়া জোড়া।
- `parts.join("-")` ভুল syntax, কারণ join separator-এর method।

## 5. Separator দিয়ে parts জোড়া

Business report-এ list-এর values comma, slash বা newline দিয়ে জোড়া লাগতে পারে।

```python
customers = ["Rahim Traders", "Karim Store", "Jahid Enterprise"]

comma_report = ", ".join(customers)
line_report = "\n".join(customers)

print(comma_report)
print(line_report)
```

**Output**

```text
Rahim Traders, Karim Store, Jahid Enterprise
Rahim Traders
Karim Store
Jahid Enterprise
```

`", ".join(customers)` এক লাইনের report বানিয়েছে। `"\n".join(customers)` প্রতিটি customer-কে নতুন লাইনে দিয়েছে।

`join()` ব্যবহার করতে list-এর item-গুলো string হওয়া নিরাপদ। Number থাকলে আগে string-এ বদলানোর বিষয়টি পরের topics-এ আরও formal ভাবে আসবে।

## 6. `find()` দিয়ে অবস্থান খোঁজা

`find(part)` string-এর ভিতরে part প্রথম কোথায় শুরু হয়েছে, সেই index দেয়। এটি left থেকে search করে।

```python
invoice_no = "INV-2024-007"

print(invoice_no.find("INV"))
print(invoice_no.find("2024"))
print(invoice_no.find("-"))
```

**Output**

```text
0
4
3
```

`INV` index 0-তে শুরু হয়েছে। `2024` index 4-তে শুরু হয়েছে। প্রথম hyphen index 3-তে।

`find()` character বা multi-character text দুটিই খুঁজতে পারে। প্রথম matching position result হিসেবে আসে।

## 7. `find()` না পেলে কী হয়

Search text না থাকলে `find()` `-1` ফেরত দেয়। তাই result দেখে text আছে কি না যাচাই করা যায়।

```python
invoice_no = "INV-2024-007"

position = invoice_no.find("2025")
print(position)
print(position == -1)
```

**Output**

```text
-1
True
```

`2025` invoice-এ নেই। `-1` বাস্তব valid index নয়, তাই এটি not found-এর signal।

Found এবং not found আলাদা করে দেখা:

```python
code = "C-1023"

if code.find("-") != -1:
    print("Separator found")
```

**Output**

```text
Separator found
```

এখানে condition শেখানো হচ্ছে শুধু `find()` result বোঝানোর জন্য। Conditional logic-এর পূর্ণ আলোচনা Chapter 5-এ হবে।

## 8. `startswith()` দিয়ে শুরু যাচাই

`startswith(prefix)` `True` দেয় যদি string ওই prefix দিয়ে শুরু হয়। না হলে `False` দেয়।

```python
invoice_no = "INV-2024-007"

print(invoice_no.startswith("INV"))
print(invoice_no.startswith("C-"))
```

**Output**

```text
True
False
```

Invoice reference `INV` দিয়ে শুরু হয়েছে। এটি `C-` দিয়ে শুরু হয়নি। Prefix validation-এ methodটি readable।

Case-sensitive মনে রাখুন:

```python
code = "inv-2024-007"
print(code.startswith("INV"))
print(code.upper().startswith("INV"))
```

**Output**

```text
False
True
```

প্রথম comparison-এ case মেলেনি। Uppercase করে standard form বানালে match হয়েছে।

## 9. `endswith()` দিয়ে শেষ যাচাই

`endswith(suffix)` `True` দেয় যদি string ওই suffix দিয়ে শেষ হয়। File extension, serial pattern বা report label যাচাইতে এটি কাজে লাগে।

```python
invoice_no = "INV-2024-007"

print(invoice_no.endswith("007"))
print(invoice_no.endswith("2024"))
```

**Output**

```text
True
False
```

Invoice-এর শেষ তিনটি character `007`, তাই প্রথম result `True`। Stringটি `2024` দিয়ে শেষ হয়নি।

একাধিক সম্ভাব্য ending যাচাই করতে tuple ব্যবহার করা যায়:

```python
file_name = "sales_report.csv"
print(file_name.endswith((".csv", ".xlsx")))
```

**Output**

```text
True
```

এখানে filename `.csv` অথবা `.xlsx` দিয়ে শেষ হচ্ছে কি না দেখা হয়েছে। Tuple syntax এখন শুধু method-এর input হিসেবে দেখানো হলো।

## 10. Business parsing workflow

একটি invoice reference parse করে list-এ ভাগ, প্রয়োজনীয় অংশ যাচাই, তারপর standard format-এ জোড়া দেওয়া যায়।

```python
raw_invoice = " inv/2024/007 "

clean_invoice = raw_invoice.strip().upper()
parts = clean_invoice.split("/")
standard_invoice = "-".join(parts)

print(parts)
print(standard_invoice)
print(standard_invoice.startswith("INV"))
print(standard_invoice.endswith("007"))
```

**Output**

```text
['INV', '2024', '007']
INV-2024-007
True
True
```

Workflow-এর ধাপ:

- `strip()` outer space সরায়।
- `upper()` case standard করে।
- `split("/")` invoice অংশগুলো আলাদা করে।
- `join()` hyphen দিয়ে standard code বানায়।
- `startswith()` এবং `endswith()` final format যাচাই করে।

## Synthesis table

| কাজ | Syntax | Example | Result |
|---|---|---|---|
| separator দিয়ে ভাগ | `text.split("-")` | `"C-1023".split("-")` | `['C', '1023']` |
| separator দিয়ে জোড়া | `"-".join(parts)` | `["C", "1023"]` | `C-1023` |
| অবস্থান খোঁজা | `text.find(part)` | `"INV".find("V")` | `2` |
| শুরু যাচাই | `text.startswith(prefix)` | `"INV-1".startswith("INV")` | `True` |
| শেষ যাচাই | `text.endswith(suffix)` | `"INV-007".endswith("007")` | `True` |
| not found signal | `find()` result `-1` | `"C".find("X")` | `-1` |

## Troubleshooting

### Problem 1: `split()` পুরো string-কে এক item দিয়েছে

- কী হচ্ছে: learner আশা করছে তিনটি part, কিন্তু list-এ একটি item আছে।
- সম্ভাব্য কারণ: input-এর separator এবং `split()`-এর separator এক নয়।
- ধাপ: raw text-এ separator দেখুন, তারপর একই character `split()`-এ দিন।
- প্রতিরোধ: method লেখার আগে code-এর delimiter চিহ্নিত করুন।

### Problem 2: `join()`-এর syntax error হচ্ছে

- কী হচ্ছে: text parts জোড়া লাগছে না।
- সম্ভাব্য কারণ: separator-এর বদলে list-এর উপর `join()` লেখা হয়েছে।
- ধাপ: `"-".join(parts)` pattern ব্যবহার করুন।
- প্রতিরোধ: মনে রাখুন, যে text মাঝখানে বসবে সেটিই join-এর object।

### Problem 3: `find()` result `-1`

- কী হচ্ছে: learner expected position পাচ্ছে না।
- সম্ভাব্য কারণ: search text নেই, অথবা case মেলেনি।
- ধাপ: exact spelling যাচাই করুন, প্রয়োজনে `lower()` বা `upper()` দিয়ে case standard করুন।
- প্রতিরোধ: `-1`-কে not found signal হিসেবে ধরুন, valid index হিসেবে নয়।

### Problem 4: `startswith()` বা `endswith()` False দিচ্ছে

- কী হচ্ছে: text দেখতে কাছাকাছি হলেও result `False`।
- সম্ভাব্য কারণ: extra space, wrong case বা wrong suffix দেওয়া হয়েছে।
- ধাপ: আগে `strip()` করুন, case standard করুন, তারপর exact prefix বা suffix দিন।
- প্রতিরোধ: validation-এর আগে input cleaning workflow রাখুন।

## Common Misconceptions

1. **ভুল:** `split()` নতুন string ফেরত দেয় → **সত্য:** এটি সাধারণত string item-সহ একটি list ফেরত দেয়।
2. **ভুল:** `join()` list-এর method → **সত্য:** separator string-এর method হিসেবে `join()` লেখা হয়।
3. **ভুল:** `find()` text না পেলে `None` দেয় → **সত্য:** text না পেলে `-1` দেয়।
4. **ভুল:** `startswith()` case ignore করে → **সত্য:** এটি case-sensitive।
5. **ভুল:** `endswith()` শুধু file extension-এর জন্য → **সত্য:** যেকোনো suffix যাচাইতে ব্যবহার করা যায়।

a. `-1`  
b. `None`  
c. `False`

**উত্তর: a।** `-1` not found signal।

a. `False`  
b. `True`

b. `False`  
c. `4`

**উত্তর: b।** Stringটি `007` দিয়ে শেষ হয়েছে।

### 6. `join()`-এর আগে কী থাকে?

a. separator string  
b. integer index  
c. Boolean value

**উত্তর: a।** Separator object-এর method হিসেবে `join()` চলে।

### 7. `split("/")` কীসের জায়গায় string ভাগ করে?

a. hyphen  
b. slash  
c. space

**উত্তর: b।** Argument হিসেবে slash দেওয়া হয়েছে।

## Key Idea

`split()` text ভেঙে list বানায়, `join()` list-এর text জোড়া দেয়, `find()` position খোঁজে, আর `startswith()` ও `endswith()` text-এর boundary যাচাই করে। Business parsing-এ separator, case এবং whitespace ঠিকভাবে বোঝা জরুরি।

**ছড়া ১:** split করে ভাগ, join করে জোড়া,  
**ছড়া ২:** find খোঁজে, start-end রাখে ধরা।
