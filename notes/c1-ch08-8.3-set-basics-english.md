## 6. What is a set?

A set is a collection of unique values. A repeated invoice reference appears once.

```python
references = {"INV-2024-007", "INV-2024-008", "INV-2024-007"}
print(sorted(references))
```

**Output**

```text
['INV-2024-007', 'INV-2024-008']
```

- Curly braces commonly show a set.
- The duplicate reference appears once.
- `sorted()` gives readable, predictable display order.

## 7. List to set

```python
references = ["INV-2024-007", "INV-2024-008", "INV-2024-007"]
unique_references = set(references)

print(sorted(unique_references))
```

**Output**

```text
['INV-2024-007', 'INV-2024-008']
```

A set is not an order-preserving report tool. Its main job is uniqueness.

## 8. An empty set

```python
empty_set = set()
empty_dictionary = {}

print(type(empty_set).__name__)
print(type(empty_dictionary).__name__)
```

**Output**

```text
set
dict
```

`{}` is an empty dictionary. Use `set()` for an empty set.

## 9. `add()`

```python
customer_ids = {"C-1023", "C-2048"}
customer_ids.add("C-3099")
customer_ids.add("C-1023")

print(sorted(customer_ids))
```

**Output**

```text
['C-1023', 'C-2048', 'C-3099']
```

The new ID appears. Adding an old ID creates no duplicate.

## 10. `remove()` and `discard()`

```python
products = {"Rice", "Oil", "Lentil"}
products.remove("Oil")
products.discard("Sugar")

print(sorted(products))
```

**Output**

```text
['Lentil', 'Rice']
```

`remove()` raises an error for a missing value. `discard()` ignores a missing value.

## 11. Membership tests

```python
invoice_ids = {"INV-2024-007", "INV-2024-008"}

print("INV-2024-007" in invoice_ids)
print("INV-2024-009" in invoice_ids)
```

**Output**

```text
True
False
```

A set answers whether an ID has appeared.

## 14. Troubleshooting

### Problem 1: Set output order changes
- **What happens:** Items appear in a different order.
- **Likely cause:** Sets are unordered.
- **Fix:** Use `sorted(my_set)` for display.
- **Prevent it:** Do not use sets for report order.

### Problem 2: `KeyError` from `remove()`
- **What happens:** Removing a missing value raises an error.
- **Likely cause:** `remove()` expects the value to exist.
- **Fix:** Check membership or use `discard()`.
- **Prevent it:** Choose `discard()` for uncertain data.

### Problem 3: `{}` is not a set
- **What happens:** The type is `dict`.
- **Likely cause:** Empty braces mean an empty dictionary.
- **Fix:** Write `set()`.
- **Prevent it:** Memorise the empty-set syntax.

### Problem 4: `TypeError` when indexing
- **What happens:** `my_set[0]` fails.
- **Likely cause:** Sets have no indexes.
- **Fix:** Use membership, or sort into a list.
- **Prevent it:** Use a list when position matters.

## 15. Common Misconceptions

1. **Wrong:** Sets keep duplicates. → **Truth:** Each duplicate appears once.
2. **Wrong:** Sets have indexes. → **Truth:** Sets are unordered and not indexed.
3. **Wrong:** `{}` is an empty set. → **Truth:** It is an empty dictionary.
4. **Wrong:** `remove()` and `discard()` are identical. → **Truth:** `remove()` errors when missing.
5. **Wrong:** Sets preserve report order. → **Truth:** They preserve uniqueness, not order.

### Exercise 5: Sreepati debugging bug

Sreepati used an index to get the first invoice from a set.

```python
invoice_ids = {"INV-2024-007", "INV-2024-008"}
first_invoice = invoice_ids[0]
print(first_invoice)
```

**Wrong output**

```text
TypeError: 'set' object is not subscriptable
```

The boss asked, “How will you get the first item from a set?”

**Diagnosis:** Sets have no indexes, so `[0]` is invalid.

**Minimal fix**

```python
invoice_ids = {"INV-2024-007", "INV-2024-008"}
ordered_ids = sorted(invoice_ids)
first_invoice = ordered_ids[0]
print(first_invoice)
```

**Correct output**

```text
INV-2024-007
```

**Lesson:** Use sets for uniqueness or membership, not positions.

## 17. Quiz

1. What is the main job of a set?  
   a) Keep duplicates  
   b) Keep unique values  
   c) Unpack fields  
   **Answer: b.** Duplicates appear once.

2. How do you make an empty set?  
   a) `{}`  
   b) `set()`  
   c) `[]`  
   **Answer: b.** `{}` is a dictionary.

3. Which method adds a value?  
   a) `add()`  
   b) `push()`  
   c) `append_only()`  
   **Answer: a.** Sets use `add()`.

4. Which is safe when a value may be missing?  
   a) `remove()`  
   b) `discard()`  
   c) `del_index()`  
   **Answer: b.** `discard()` ignores missing values.

5. What does `my_set[0]` do?  
   a) Returns the first item  
   b) Raises `TypeError`  
   c) Sorts the set  
   **Answer: b.** Sets are not indexed.

6. How can you display set values in order?  
   a) `sorted(my_set)`  
   b) `my_set[0]`  
   c) `set.order()`  
   **Answer: a.** `sorted()` returns a list.

7. Which structure suits duplicate invoice detection?  
   a) set  
   b) tuple only  
   c) float  
   **Answer: a.** It keeps unique references.

## 18. Key Idea

A set keeps unique values. It has no index and makes no report-order promise. It suits duplicate IDs, membership checks, and safe add or remove tasks.
