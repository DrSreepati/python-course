## 6. Each string character

A string is a sequence of characters. `for` reads each character once.

```python
invoice_code = "INV"

for character in invoice_code:
    print(character)
```

**Output**

```text
I
N
V
```

`character` holds one letter at a time. The loop follows the string order.

## 7. Each list item

A list is a business garland. `for` gives one bead at a time.

```python
customers = ["Rahim Traders", "Karim Store", "Jahid Enterprise"]

for customer in customers:
    print(customer)
```

**Output**

```text
Rahim Traders
Karim Store
Jahid Enterprise
```

`customer` holds one name at a time. List order remains unchanged.

## 8. Daily sales total

Add each value in the fixed daily sales list.

```python
report = [12000, 9500, 8800, 13200, 7500]
total_sales = 0

for sale in report:
    total_sales += sale

print(total_sales)
```

**Output**

```text
51000
```

`sale` holds one amount. `total_sales` works like scales holding a running total.

## 9. Filter items with a condition

Use `if` inside the loop to report large sales only.

```python
report = [12000, 9500, 8800, 13200, 7500]

for sale in report:
    if sale >= 10000:
        print(f"Large sale: {sale}")
```

**Output**

```text
Large sale: 12000
Large sale: 13200
```

Each sale is tested. Only values of 10000 or more are printed.

## 10. Strings versus lists

Both are sequences. Their item meanings differ.

```python
code = "C-1023"
parts = ["C-1023", "INV-2024-007"]

for character in code:
    print(character)

for reference in parts:
    print(reference)
```

**Output**

```text
C
-
1
0
2
3
C-1023
INV-2024-007
```

The first loop reads characters. The second reads complete reference strings.

## 11. A business decision for each item

Apply a condition to each balance.

```python
balances = [50000, 32000, 71000]

for balance in balances:
    if balance >= 50000:
        print(f"High balance: {balance}")
    else:
        print(f"Regular balance: {balance}")
```

**Output**

```text
High balance: 50000
Regular balance: 32000
High balance: 71000
```

Each balance takes its own path.

## 13. Troubleshooting

### Problem 1
- What happens: the whole list prints once.
- Likely cause: the list was printed without a loop.
- Fix: write `for item in items` and print `item`.
- Prevention: use a singular loop variable.

### Problem 2
- What happens: the total equals only the last amount.
- Likely cause: `total = sale` overwrites the total.
- Fix: use `total += sale`.
- Prevention: preserve the old accumulator value.

### Problem 3
- What happens: the whole word appears, not each character.
- Likely cause: the original string was printed inside the loop.
- Fix: print the `character` variable.
- Prevention: read the current item variable.

### Problem 4
- What happens: some sales are missing.
- Likely cause: the threshold is wrong.
- Fix: test `>=` and the exact boundary.
- Prevention: classify each input value by hand.

## 14. Common Misconceptions

1. **Wrong:** a list loop gives the whole list each time → **Truth:** it gives one item.
2. **Wrong:** a string is only text, not a sequence → **Truth:** it is a character sequence.
3. **Wrong:** reset the total inside the loop → **Truth:** initialise it before the loop.
4. **Wrong:** list order changes during a normal loop → **Truth:** iteration keeps sequence order.
5. **Wrong:** `range()` is required for lists → **Truth:** a list is already a sequence.

## 16. Quiz

1. What does `for` over a string read?  
   a) characters  b) files  c) only ranges  
   **Answer: a**, because a string is a character sequence.
2. What does a list loop give each time?  
   a) the whole list  b) one item  c) no value  
   **Answer: b**, because the loop advances item by item.
3. What is a normal starting total?  
   a) 0  b) the last sale  c) always -1  
   **Answer: a**, because zero is the neutral sum.
4. What does `total += sale` do?  
   a) adds the sale  b) erases the total  c) slices a list  
   **Answer: a**, because it preserves and increases the old total.
5. What does `sale >= 10000` select?  
   a) large or equal sales  b) all strings  c) only zero  
   **Answer: a**, because the threshold is inclusive.
6. What happens to normal list order?  
   a) it remains  b) it becomes random  c) it reverses  
   **Answer: a**, because iteration follows sequence order.
7. Is `range()` required for a list loop?  
   a) yes  b) no  c) only for strings  
   **Answer: b**, because a list is already a sequence.
