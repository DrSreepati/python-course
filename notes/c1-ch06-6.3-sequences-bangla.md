## 6. String-এর প্রতিটি character

String একটি character sequence। `for` প্রতিটি character একবার করে নেয়।

```python
invoice_code = "INV"

for character in invoice_code:
    print(character)
```

**Output**

```text
I
N
V
```

`character` একবারে একটি letter ধরে। String-এর শুরু থেকে শেষ পর্যন্ত loop চলে।

## 7. List-এর প্রতিটি item

List হলো অনেক business value-এর মালা। `for` প্রতিটি পুঁতি আলাদা করে দেয়।

```python
customers = ["Rahim Traders", "Karim Store", "Jahid Enterprise"]

for customer in customers:
    print(customer)
```

**Output**

```text
Rahim Traders
Karim Store
Jahid Enterprise
```

`customer` একবারে একটি নাম ধরে। List-এর order বজায় থাকে।

## 8. Daily sales total

Fixed daily sales list-এর প্রতিটি value যোগ করে total করা যায়।

```python
report = [12000, 9500, 8800, 13200, 7500]
total_sales = 0

for sale in report:
    total_sales += sale

print(total_sales)
```

**Output**

```text
51000
```

`sale` একবারে একটি amount নেয়। `total_sales` দাঁড়িপাল্লার মতো running total ধরে।

## 9. Condition দিয়ে item filter

Loop-এর ভিতরে `if` দিয়ে শুধু বড় sales report করা যায়।

```python
report = [12000, 9500, 8800, 13200, 7500]

for sale in report:
    if sale >= 10000:
        print(f"Large sale: {sale}")
```

**Output**

```text
Large sale: 12000
Large sale: 13200
```

প্রতিটি sale পরীক্ষা হয়। শুধু 10000 বা তার বেশি value print হয়।

## 10. String এবং list-এর পার্থক্য

দুই ধরনের sequence-ই `for` দিয়ে পড়া যায়, কিন্তু item-এর অর্থ আলাদা।

```python
code = "C-1023"
parts = ["C-1023", "INV-2024-007"]

for character in code:
    print(character)

for reference in parts:
    print(reference)
```

**Output**

```text
C
-
1
0
2
3
C-1023
INV-2024-007
```

প্রথম loop character নেয়। দ্বিতীয় loop পুরো reference string নেয়।

## 11. Sequence item-এর উপর business decision

Customer list-এ নাম দেখে balance report করা যায়, তবে parallel data না শেখা পর্যন্ত simple list ব্যবহার করছি।

```python
balances = [50000, 32000, 71000]

for balance in balances:
    if balance >= 50000:
        print(f"High balance: {balance}")
    else:
        print(f"Regular balance: {balance}")
```

**Output**

```text
High balance: 50000
Regular balance: 32000
High balance: 71000
```

প্রতিটি balance আলাদা করে condition পেরোয়।

## 13. Troubleshooting

### সমস্যা 1
- কী হচ্ছে: পুরো list একবারে print হচ্ছে, item আলাদা হচ্ছে না।
- সম্ভাব্য কারণ: loop ছাড়া list print করা হয়েছে।
- Fix: `for item in items` লিখে item print করুন।
- Prevention: loop variable-কে singular নাম দিন।

### সমস্যা 2
- কী হচ্ছে: total শুধু শেষ amount দেখাচ্ছে।
- সম্ভাব্য কারণ: `total = sale` ব্যবহার হয়েছে।
- Fix: `total += sale` ব্যবহার করুন।
- Prevention: accumulator-এর পুরনো value রাখতে হবে মনে রাখুন।

### সমস্যা 3
- কী হচ্ছে: string-এর পুরো word প্রতি character-এর বদলে দেখা যাচ্ছে।
- সম্ভাব্য কারণ: loop variable না নিয়ে text print করা হয়েছে।
- Fix: loop-এর ভিতরে `character` print করুন।
- Prevention: current item variable পড়ুন।

### সমস্যা 4
- কী হচ্ছে: কিছু sales বাদ পড়ছে।
- সম্ভাব্য কারণ: condition threshold ভুল।
- Fix: `>=` এবং exact boundary test করুন।
- Prevention: data-এর প্রত্যেক value হাতে classify করুন।

## 14. Common Misconceptions

1. **ভুল:** list loop-এ পুরো list একবারে আসে → **সত্য:** একবারে একটি item আসে।
2. **ভুল:** string শুধু text, sequence নয় → **সত্য:** character-এর sequence।
3. **ভুল:** total loop-এর ভিতরে zero করতে হয় → **সত্য:** loop-এর আগে zero করতে হয়।
4. **ভুল:** list-এর order বদলে যায় → **সত্য:** সাধারণ `for` order বজায় রাখে।
5. **ভুল:** `range()` ছাড়া list loop হয় না → **সত্য:** list নিজেই sequence।
