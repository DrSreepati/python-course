## 6. Two names for one list

`b = a` does not build a new list. Both names point to one list.

```python
sales = [12000, 9500, 8800]
review_sales = sales
review_sales[0] = 13000

print(sales)
print(review_sales)
```

**Output**

```text
[13000, 9500, 8800]
[13000, 9500, 8800]
```

- `sales` names one list.
- `review_sales = sales` gives that list another name.
- A change through either name is shared.

## 7. Why aliasing is risky

Aliasing is risky when the boss’s original report must stay unchanged.

```python
original_report = [12000, 9500, 8800]
working_report = original_report
working_report.append(13200)

print(original_report)
```

**Output**

```text
[12000, 9500, 8800, 13200]
```

`append()` changes the shared list. It does not create a private working report.

## 8. A shallow copy with a slice

```python
original_report = [12000, 9500, 8800]
working_report = original_report[:]
working_report[0] = 13000

print(original_report)
print(working_report)
```

**Output**

```text
[12000, 9500, 8800]
[13000, 9500, 8800]
```

`[:]` makes a new outer list. The two flat lists are independent.

## 9. A copy with `.copy()`

```python
balances = [50000, 32000, 71000]
audit_balances = balances.copy()
audit_balances.pop()

print(balances)
print(audit_balances)
```

**Output**

```text
[50000, 32000, 71000]
[50000, 32000]
```

`.copy()` also makes a shallow copy. It is clear for ordinary flat lists.

## 10. Reference or copy

```python
sales = [12000, 9500]
alias = sales
copy_one = sales[:]
copy_two = sales.copy()

alias.append(8800)
copy_one.append(13200)
copy_two.append(7500)

print(sales)
print(copy_one)
print(copy_two)
```

**Output**

```text
[12000, 9500, 8800]
[12000, 9500, 13200]
[12000, 9500, 7500]
```

Only the alias changes the original list. Both copies are separate.

## 11. The nested-list warning

A shallow copy separates the outer list. Its inner rows may still be shared.

```python
table = [[12000, 9500], [8800, 13200]]
table_copy = table[:]
table_copy[0][0] = 13000

print(table)
print(table_copy)
```

**Output**

```text
[[13000, 9500], [8800, 13200]]
[[13000, 9500], [8800, 13200]]
```

Today’s rule: shallow copies suit flat lists. Nested rows need a deeper copying plan.

## 12. Business rule

Keep the original report. Make a working copy before editing. This is safer for audits.

## 13. Synthesis table

| Need | Method |
|---|---|
| Another name for one list | `b = a` |
| Slice copy of a flat list | `a[:]` |

| Protect the original | use a copy |
| Independent nested rows | shallow copy is not enough |

## 14. Troubleshooting

### Problem 1: The original report changed
- **What happens:** The working list changes the original.
- **Likely cause:** `working = original` created a reference.
- **Fix:** Use `working = original[:]` or `working = original.copy()`.
- **Prevent it:** Copy before editing.

### Problem 2: The copy also changes
- **What happens:** A nested row changes in both lists.
- **Likely cause:** A shallow copy did not copy inner rows.
- **Fix:** Use a separate copying plan for nested data.
- **Prevent it:** Distinguish flat and nested data.

### Problem 3: Two reports look identical
- **What happens:** Both outputs show the same values.
- **Likely cause:** They are aliases, or no copy was changed yet.
- **Fix:** Check the assignment and then change one item.
- **Prevent it:** Test a copy immediately after making it.

### Problem 4: `AttributeError: 'list' object has no attribute 'clone'`
- **What happens:** Python cannot find `clone()`.
- **Likely cause:** A copy method from another language was used.
- **Fix:** Use `[:]` or `.copy()`.
- **Prevent it:** Memorise Python’s two common list-copy patterns.

## 15. Common Misconceptions

1. **Wrong:** `b = a` makes a copy. → **Truth:** It gives the same list another name.
2. **Wrong:** An alias changes only itself. → **Truth:** It changes the shared list.
3. **Wrong:** `a[:]` changes the original. → **Truth:** It makes a new outer list.
4. **Wrong:** `.copy()` fully separates nested lists. → **Truth:** It is shallow.
5. **Wrong:** Equal output proves equal objects. → **Truth:** Separate copies can hold equal values.

### Exercise 5: Sreepati debugging bug

Sreepati wanted a working report while keeping the original.

```python
original = [12000, 9500, 8800]
working = original
working.pop()
print(original)
```

**Wrong output**

```text
[12000, 9500]
```

The boss asked, “Why did the audit report also shrink?”

**Diagnosis:** `working = original` is not a copy. Both names point to one list.

**Minimal fix**

```python
original = [12000, 9500, 8800]
working = original.copy()
working.pop()
print(original)
print(working)
```

**Correct output**

```text
[12000, 9500, 8800]
[12000, 9500]
```

**Lesson:** Copy before editing original business data.

## 17. Quiz

1. What does `b = a` usually do?  
   a) Gives the same list another name  
   b) Makes a new list  
   c) Sorts the list  
   **Answer: a.** Both names refer to one object.

2. Which makes a flat-list copy?  
   a) `a = b`  
   b) `a[:]`  
   c) `a == b`  
   **Answer: b.** A slice makes a new outer list.

3. What can `append()` through an alias do?  
   a) Leave the original unchanged  
   b) Change the shared original list  
   c) Cause a syntax error  
   **Answer: b.** An alias points to the same list.

4. What does `.copy()` create?  
   a) A shallow copy  
   b) A string  
   c) A tuple  
   **Answer: a.** The outer list is new.

5. What can remain shared in a nested shallow copy?  
   a) Inner rows  
   b) Variable spelling  
   c) Python version  
   **Answer: a.** Inner lists may still be shared.

6. Which is suitable for an audit-safe working report?  
   a) `working = original`  
   b) `working = original.copy()`  
   c) `working == original`  
   **Answer: b.** It separates a flat working list.

7. What can equal values in two copies mean?  
   a) They must be one object  
   b) Separate lists can hold equal values  
   c) They cannot be used  
   **Answer: b.** Contents can match while objects differ.

## 18. Key Idea

`b = a` creates a reference, not a copy. Protect flat business data with `[:]` or `.copy()` before editing.
