## 6. Mutable list

Mutable মানে তৈরি হওয়ার পরে item বদলানো যায়।

```python
sales = [12000, 9500, 8800]
sales[1] = 10000

print(sales)
```

**Output**

```text
[12000, 10000, 8800]
```

- list mutable।
- index 1-এর value বদলেছে।
- list-এর identity একই থেকে ভিতরের item বদলেছে।

## 7. Immutable values

Immutable মানে তৈরি হওয়ার পরে object-এর value সরাসরি বদলানো যায় না। নতুন value বানাতে হয়।

```python
customer_code = "C-1023"
updated_code = customer_code.replace("1023", "2048")

print(customer_code)
print(updated_code)
```

**Output**

```text
C-1023
C-2048
```

String-এর পুরোনো value বদলায়নি। `replace()` নতুন string বানিয়েছে। Tuple-এর item-ও সরাসরি বদলানো যায় না।

## 8. Shallow copy-এর outer level

```python
table = [[12000, 9500], [8800, 13200]]
table_copy = table[:]
table_copy.append([7500, 6100])

print(table)
print(table_copy)
```

**Output**

```text
[[12000, 9500], [8800, 13200]]
[[12000, 9500], [8800, 13200], [7500, 6100]]
```

Outer list আলাদা হয়েছে, তাই নতুন row যোগ করলে original বদলায় না।

## 9. Inner row কেন shared

```python
table = [[12000, 9500], [8800, 13200]]
table_copy = table[:]
table_copy[0][0] = 13000

print(table)
print(table_copy)
```

**Output**

```text
[[13000, 9500], [8800, 13200]]
[[13000, 9500], [8800, 13200]]
```

শুধু outer list কপি হয়েছে। `table[0]` এবং `table_copy[0]` একই inner row।

## 10. প্রতিটি row কপি করা

```python
table = [[12000, 9500], [8800, 13200]]
safe_table = [row[:] for row in table]
safe_table[0][0] = 13000

print(table)
print(safe_table)
```

**Output**

```text
[[12000, 9500], [8800, 13200]]
[[13000, 9500], [8800, 13200]]
```

Comprehension প্রতিটি row-এর জন্য আলাদা slice copy বানিয়েছে। তাই cell edit original-এ যায়নি।

## 11. `.copy()` দিয়ে প্রতিটি row

```python
table = [[12000, 9500], [8800, 13200]]
safe_table = [row.copy() for row in table]
safe_table[1].append(11000)

print(table)
print(safe_table)
```

**Output**

```text
[[12000, 9500], [8800, 13200]]
[[12000, 9500], [8800, 13200, 11000]]
```

প্রতিটি inner row-এর `.copy()` করা হয়েছে, তাই row append original table-এ প্রভাব ফেলেনি।

| Data বা কাজ | নিরাপদ পদ্ধতি |

## 14. Troubleshooting

### সমস্যা 1: outer copy করার পরও original cell বদলায়
- **কী হচ্ছে:** copied table-এর cell edit original-এ দেখা যাচ্ছে।
- **সম্ভাব্য কারণ:** inner rows shared আছে।
- **Fix:** `[row[:] for row in table]` ব্যবহার করুন।
- **আগে প্রতিরোধ:** nested table দেখলে প্রতিটি level copy করার পরিকল্পনা করুন।

### সমস্যা 2: `TypeError` immutable value-তে
- **কী হচ্ছে:** string বা tuple-এর item সরাসরি বদলাতে গেলে error হয়।
- **সম্ভাব্য কারণ:** immutable object-এ assignment করা হয়েছে।
- **Fix:** নতুন string বা নতুন tuple বানান।
- **আগে প্রতিরোধ:** object mutable না immutable তা আগে চিনুন।

### সমস্যা 3: safe table-এ নতুন row যোগ করলে original বদলায়
- **কী হচ্ছে:** append-এর পরে original table-এ row দেখা যায়।
- **সম্ভাব্য কারণ:** outer list কপি করা হয়নি।
- **Fix:** আগে `table[:]` বা row-copy comprehension বানান।
- **আগে প্রতিরোধ:** outer এবং inner copy দুটোই পরীক্ষা করুন।

### সমস্যা 4: copy code খুব জটিল হয়ে গেছে
- **কী হচ্ছে:** কোন level shared বোঝা যাচ্ছে না।
- **সম্ভাব্য কারণ:** এক লাইনে অনেক nested operation লেখা।
- **Fix:** `original`, `working`, এবং row-copy ধাপে ধাপে লিখুন।
- **আগে প্রতিরোধ:** audit code-এ পরিষ্কার নাম ব্যবহার করুন।

## 15. Common Misconceptions

1. **ভুল:** shallow copy সব level কপি করে। → **সত্য:** সাধারণত outer level কপি করে।
2. **ভুল:** nested table-এর `table[:]` যথেষ্ট। → **সত্য:** inner rows আলাদা করতেও copy করতে হবে।
3. **ভুল:** string-এর character assignment করা যায়। → **সত্য:** string immutable।
4. **ভুল:** tuple-এর item বদলানো যায়। → **সত্য:** tuple immutable।
5. **ভুল:** mutable মানে সবসময় খারাপ। → **সত্য:** controlled working copy-তে mutable list খুব উপকারী।

## 16. Exercises with solutions

### Exercise 1

একটি flat sales list কপি করে working list-এর প্রথম item বদলান।

**Solution**

```python
sales = [12000, 9500, 8800]
working = sales.copy()
working[0] = 13000
print(sales)
print(working)
```

**Output**

```text
[12000, 9500, 8800]
[13000, 9500, 8800]
```

### Exercise 2

একটি nested table-এর outer copy বানান এবং নতুন row যোগ করুন।

**Solution**

```python
table = [[12000, 9500], [8800, 13200]]
working = table[:]
working.append([7500, 6100])
print(table)
print(working)
```

**Output**

```text
[[12000, 9500], [8800, 13200]]
[[12000, 9500], [8800, 13200], [7500, 6100]]
```

### Exercise 3

প্রতিটি row copy করে দ্বিতীয় row-এর একটি cell বদলান।

**Solution**

```python
table = [[12000, 9500], [8800, 13200]]
working = [row.copy() for row in table]
working[1][0] = 9000
print(table)
print(working)
```

**Output**

```text
[[12000, 9500], [8800, 13200]]
[[12000, 9500], [9000, 13200]]
```

### Exercise 4

একটি string থেকে নতুন corrected code বানান, পুরোনো code অপরিবর্তিত রাখুন।

**Solution**

```python
code = "INV-2024-007"
corrected = code.replace("007", "008")
print(code)
print(corrected)
```

**Output**

```text
INV-2024-007
INV-2024-008
```

### Exercise 5: Sreepati debugging bug

Sreepati customer-day table-এর working copy বানিয়ে cell correction করতে চেয়েছিলেন।

```python
original = [[12000, 9500], [8800, 13200]]
working = original[:]
working[0][0] = 13000
print(original)
```

**Wrong output**

```text
[[13000, 9500], [8800, 13200]]
```

Boss বললেন, “Original audit table-এ correction ঢুকে গেল কেন?”

**Diagnosis:** শুধু outer list copy হয়েছে। Inner row একই object ছিল।

**Minimal fix**

```python
original = [[12000, 9500], [8800, 13200]]
working = [row[:] for row in original]
working[0][0] = 13000
print(original)
print(working)
```

**Correct output**

```text
[[12000, 9500], [8800, 13200]]
[[13000, 9500], [8800, 13200]]
```

**Lesson:** nested table copy করতে outer list এবং প্রতিটি row কপি করুন।

## 17. Quiz

1. Mutable object-এর উদাহরণ কোনটি?  
   a) list  
   b) string  
   c) tuple  
   **উত্তর: a।** list-এর item বদলানো যায়।

   a) হ্যাঁ  
   b) শুধু loop-এ  
   c) না, নতুন string বানাতে হয়

3. `table[:]` nested table-এ কী কপি করে?  
   a) outer list  
   b) সব inner cell  
   c) শুধু শেষ row  
   **উত্তর: a।** inner rows shared থাকতে পারে।

4. প্রতিটি row আলাদা করতে কোনটি উপযুক্ত?

   a) mutable  
   b) immutable  
   c) always empty  
   **উত্তর: b।** tuple item assignment করা যায় না।

6. `.copy()` nested list-এর জন্য কী করে?

7. audit-safe nested working table-এর ভালো পদ্ধতি কোনটি?

## 18. Key Idea

Shallow copy flat list-এর জন্য যথেষ্ট হতে পারে, কিন্তু nested table-এ প্রতিটি inner row-ও কপি করতে হয়। List mutable, string এবং tuple immutable।

**ছড়া ১:**  
বাইরের মালা copy করলেই শেষ নয়,  
ভিতরের পুঁতি আলাদা না হলে বদল রয়।

**ছড়া ২:**  
String tuple থাকে স্থির,  
List বদলায়, তাই copy করো ধীর।
